🟡 Lire un algorithme

Que fait cet algorithme ? Donne le résultat affiché.

Algorithme Mystere
Variables
    a, b, temp : Entier
Début
    a ← 5
    b ← 8
    temp ← a
    a ← b
    b ← temp
    Écrire(a)
    Écrire(b)
Fin
Réponse Cet algorithme échange (permute) les valeurs de a et b en utilisant une variable temporaire temp.

Affichage : 
8
5
C'est un grand classique de l'algorithmique : sans variable temporaire, on ne peut pas échanger directement deux variables.

🟡 Écrire un algorithme

Exercice : Écris un algorithme qui demande à l'utilisateur son prénom et son âge, puis affiche : "Bonjour <prénom>, tu as <âge> ans."

Solution proposée 
Algorithme Salutation
Variables
    prenom : Chaîne
    age : Entier
Début
    Écrire("Quel est ton prénom ?")
    Lire(prenom)
    Écrire("Quel est ton âge ?")
    Lire(age)
    Écrire("Bonjour ", prenom, ", tu as ", age, " ans.")
Fin

🔴 Trouver l'erreur

Ce pseudo-code contient plusieurs erreurs. Trouve-les toutes.

Algorithme Calcul
Variables
    2note : Entier
    Note Finale : Réel
Début
    2note = 15
    Note Finale ← 2note / 2
    Ecrire(Note Finale)
Fin
Réponse — 3 erreurs
  1. 2note commence par un chiffre → nom invalide
  2. Note Finale contient un espace → nom invalide (il faudrait noteFinale)
  3. 2note = 15 utilise = au lieu de ← pour l'affectation
Version corrigée : 
Algorithme Calcul
Variables
    note2 : Entier
    noteFinale : Réel
Début
    note2 ← 15
    noteFinale ← note2 / 2
    Écrire(noteFinale)
Fin

🏆 Défi — un peu plus loin

Écris un algorithme qui calcule la moyenne pondérée de deux notes : un contrôle (coefficient 1) et un examen (coefficient 2). Formule : moyenne = (controle*1 + examen*2) / 3.

Solution proposée 
Algorithme MoyennePonderee
Variables
    controle, examen : Réel
    moyenne : Réel
Début
    Écrire("Note de contrôle :")
    Lire(controle)
    Écrire("Note d'examen :")
    Lire(examen)
    moyenne ← (controle * 1 + examen * 2) / 3
    Écrire("Moyenne pondérée : ", moyenne)
Fin
