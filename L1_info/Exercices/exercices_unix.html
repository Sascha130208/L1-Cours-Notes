🟢 Niveau facile

1. Quelle commande affiche le répertoire courant ?

Réponsepwd

2. Tu es dans /home/alice. Quelle commande te fait remonter dans /home ?

Réponsecd ..

3. Quelle commande crée un dossier nommé td1 ?

Réponsemkdir td1

4. Quelle commande affiche TOUS les fichiers d'un dossier, y compris les cachés, en mode détaillé ?

Réponsels -la

5. Comment crée-t-on un fichier vide nommé rapport.txt ?

Réponsetouch rapport.txt

🟡 Niveau intermédiaire

6. Copie le dossier cours/ (avec tout son contenu) vers cours_backup/.

Réponsecp -r cours/ cours_backup/

7. Tu es dans /home/alice/documents. Donne le chemin relatif puis absolu vers /home/alice/cours/td1.txt.

Réponse Relatif : ../cours/td1.txt
Absolu : /home/alice/cours/td1.txt

8. Quelle est la différence entre echo "test" > fichier.txt exécuté deux fois, et echo "test" >> fichier.txt exécuté deux fois ?

Réponse Avec > deux fois : le fichier ne contient qu'une seule ligne "test" (la 2e commande écrase la 1ère).
Avec >> deux fois : le fichier contient deux lignes "test" (chaque commande ajoute à la fin).

9. Fichier notes.csv au format nom;matiere;note. Extrais la colonne des notes (3e colonne).

Réponsecut -d ';' -f 3 notes.csv

10. Comment afficher les 5 dernières lignes d'un fichier log.txt ?

Réponsetail -n 5 log.txt

🔴 Niveau avancé (avec pipes |)

11. villes.txt contient une ville par ligne, avec des doublons pas forcément côte à côte. Affiche les villes uniques, triées.

Réponsesort villes.txt | uniq

12. À partir de villes.txt, affiche chaque ville avec son nombre d'occurrences.

Réponsesort villes.txt | uniq -c

13. etudiants.txt au format nom:prenom:age. Trie les étudiants par âge décroissant.

Réponsesort -t ':' -k 3 -n -r etudiants.txt

14. Compte combien de lignes contient poeme.txt, sans utiliser cat avant.

Réponsewc -l poeme.txt

15. (défi) À partir de etudiants.txt, une seule ligne de commande qui affiche la liste des noms de famille uniques, triés.

Réponsecut -d ':' -f 1 etudiants.txt | sort | uniq

🧪 Exercice pratique guidé

💡 Mise en situation complète
  1. Va dans ton répertoire personnel (cd ~)
  2. Crée un dossier td_unix
  3. Rentre dedans
  4. Crée un fichier animaux.txt contenant : chat, chien, chat, oiseau, chien, chat (une ligne à la fois avec echo ... >>)
  5. Affiche le contenu avec cat
  6. Trouve la liste des animaux uniques avec leur nombre d'occurrences, triée par ordre alphabétique
  7. Vérifie avec wc -l que ton fichier contient bien 6 lignes
Solution complète 
cd ~
mkdir td_unix
cd td_unix
echo "chat" >> animaux.txt
echo "chien" >> animaux.txt
echo "chat" >> animaux.txt
echo "oiseau" >> animaux.txt
echo "chien" >> animaux.txt
echo "chat" >> animaux.txt
cat animaux.txt
sort animaux.txt | uniq -c
wc -l animaux.txt
