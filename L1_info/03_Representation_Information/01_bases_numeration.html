🔢 Bases et systèmes de numération

Ce chapitre pose les bases (c'est le cas de le dire) de tout ce qui touche au codage de l'information en machine : comment un nombre s'écrit dans une base quelconque, et comment passer d'une base à une autre.

📌 Système de numération

📌 Définition — Système de numération Un système de numération est composé de :
  • un nombre B appelé la base ;
  • un ensemble ordonné C = {a, b, c, d, ...} de cardinal B, les chiffres disponibles.
L'écriture d'un nombre X = (x_{n-1} x_{n-2} ... x_1 x_0)_B dans ce système s'interprète en calculant : 
X = x_(n-1)×B^(n-1) + x_(n-2)×B^(n-2) + ... + x_1×B^1 + x_0×B^0

Deux mots de vocabulaire à retenir :

  • x_(n-1) (le chiffre le plus à gauche) est le chiffre de poids fort ;
  • x_0 (le chiffre le plus à droite) est le chiffre de poids faible.
💡 Image mentale C'est exactement ce que tu fais déjà en base 10 sans y penser : 235 = 2×10² + 3×10¹ + 5×10⁰. La seule nouveauté, c'est que 10 peut être remplacé par n'importe quelle base B (2, 8, 16, ...).

🔄 Convertir un nombre d'une base vers une autre

Il existe plusieurs méthodes selon la situation. Le cours en présente quatre.

1. Calcul direct de l'expression

📌 Principe Si X = (x_(n-1) ... x_1 x_0)_B, on calcule directement x_(n-1)×B^(n-1) + ... + x_0×B^0. Les calculs se font dans la base d'arrivée B' (en général la base 10, car c'est la base dans laquelle on sait calculer « à la main »).
📝 Exemple — X = (11101011)₂ vers la base 10 
X = 1×2⁷ + 1×2⁶ + 1×2⁵ + 0×2⁴ + 1×2³ + 0×2² + 1×2¹ + 1×2⁰
  = 128 + 64 + 32 + 0 + 8 + 0 + 2 + 1
  = 235
Donc (11101011)₂ = (235)₁₀.

2. Divisions entières successives

📌 Principe Pour convertir X (écrit en base B) vers une base B' : effectuer des divisions entières successives de X par B' jusqu'à obtenir un quotient nul, et noter les restes R₀, R₁, ..., R_(n'-1) dans l'ordre où ils sortent. Le résultat s'écrit en lisant les restes du dernier au premier : X = (R_(n'-1) ... R₁ R₀)_B'. Les calculs se font ici dans la base de départ B.
📝 Exemple — X = (235)₁₀ vers la base 2 
235 = 2×117 + 1   →  R₀ = 1
117 = 2×58  + 1   →  R₁ = 1
 58 = 2×29  + 0   →  R₂ = 0
 29 = 2×14  + 1   →  R₃ = 1
 14 = 2×7   + 0   →  R₄ = 0
  7 = 2×3   + 1   →  R₅ = 1
  3 = 2×1   + 1   →  R₆ = 1
  1 = 2×0   + 1   →  R₇ = 1
On lit les restes du bas vers le haut : (235)₁₀ = (11101011)₂. On retrouve bien l'exemple précédent, dans l'autre sens !

3. Méthode des puissances de 2 (cas particulier base 10 → base 2)

📌 Principe
  1. Précalculer une table des puissances de 2 (1, 2, 4, 8, 16, 32, 64, 128, ...).
  2. Chercher dans la table la plus grande puissance 2^i inférieure ou égale à X, mémoriser i, puis poser X ← X − 2^i.
  3. Recommencer tant que le résultat n'est pas nul.
Chaque puissance trouvée correspond à un bit à 1 dans l'écriture binaire.
📝 Exemple — X = (235)₁₀ 
235 − 128 (2⁷) = 107   → bit 7 à 1
107 − 64  (2⁶) = 43    → bit 6 à 1
 43 − 32  (2⁵) = 11    → bit 5 à 1
 11 − 8   (2³) = 3     → bit 3 à 1 (bit 4 sauté, donc 0)
  3 − 2   (2¹) = 1     → bit 1 à 1 (bit 2 sauté, donc 0)
  1 − 1   (2⁰) = 0     → bit 0 à 1
Bits à 1 : 7, 6, 5, 3, 1, 0 → (235)₁₀ = (11101011)₂. Encore le même résultat, par une troisième méthode.

4. Cas particulier B = B'ⁿ (ou Bⁿ = B') : groupement de chiffres

📌 Principe Quand une base est une puissance de l'autre, la conversion devient un simple groupement de chiffres, sans aucun calcul :
  • si B = B'ⁿ : chaque chiffre en base B devient un groupe de n chiffres en base B' ;
  • si Bⁿ = B' : chaque groupe de n chiffres en base B devient un seul chiffre en base B'.
C'est exactement le principe utilisé pour passer de l'hexadécimal (base 16 = 2⁴) au binaire : chaque chiffre hexadécimal correspond à exactement 4 bits.
📝 Exemple — X = (3A9B)₁₆ vers le binaire On remplace chaque chiffre hexadécimal par son bloc de 4 bits (en s'aidant du tableau plus haut) : 
3 → 0011
A → 1010
9 → 1001
B → 1011
En collant les blocs : (3A9B)₁₆ = (0011 1010 1001 1011)₂ = (11101010011011)₂.
⚠️ Quelle méthode choisir ?
  • Base B quelconque → base 10 : méthode 1 (calcul direct).
  • Base 10 → base B quelconque : méthode 2 (divisions successives) — c'est la plus générale, apprends-la en priorité.
  • Base 2 ↔ base 8 ou base 16 : méthode 4 (groupement de chiffres, pas de calcul) — 3 bits ↔ 1 chiffre octal, 4 bits ↔ 1 chiffre hexadécimal.

🎯 Mini-exercices

1. Convertir (101101)₂ en base 10 (méthode 1).

Réponse 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 32 + 0 + 8 + 4 + 0 + 1 = 45. Donc (101101)₂ = (45)₁₀.

2. Convertir (45)₁₀ en base 2 par divisions successives, et vérifier que tu retombes sur le résultat précédent.

Réponse 
45 = 2×22 + 1
22 = 2×11 + 0
11 = 2×5  + 1
 5 = 2×2  + 1
 2 = 2×1  + 0
 1 = 2×0  + 1
En lisant du bas vers le haut : (45)₁₀ = (101101)₂. ✅ Même résultat que l'exercice 1.

3. Convertir (2F)₁₆ directement en binaire par groupement de chiffres.

Réponse 2 → 0010, F → 1111. Donc (2F)₁₆ = (00101111)₂ = (101111)₂ (les zéros de tête ne comptent pas).

4. Convertir (45)₁₀ en base 16 par divisions successives.

Réponse 
45 = 16×2 + 13   → reste 13 = D
 2 = 16×0 + 2    → reste 2
Donc (45)₁₀ = (2D)₁₆.
