Ex 1 — Se repérer (répertoire courant /home/alice)

Correction
  • cours1.txt : /home/alice/cours/systeme/cours1.txt ; rapport.txt : /home/bob/rapport.txt.
  • Relatifs : cours/programmation/tp1.c ; ../bob/rapport.txt.
  • . = /home/alice ; .. = /home ; cours/.. = /home/alice ; cours/systeme/notes.txt = /home/alice/cours/systeme/notes.txt ; ../alice/documents = /home/alice/documents ; ../../tmp = /tmp.
  • Absolus : /home/alice/photo.jpg et /tmp (ceux qui commencent par /). Les autres sont relatifs (même ./documents/cv.txt).

Ex 2 — Où suis-je ?

Correction

Série 1 : /home/alice/cours → …/cours/systeme → …/cours → …/cours/programmation → …/cours → /home/alice → /home/alice/documents.

Série 2 : /home/alice/cours/systeme → /home/alice/cours → /home/alice/cours/programmation → /home/alice → /home/alice (cd . ne change rien ; utile pour comprendre que . est le répertoire courant).

Ex 5 — cp, mv, rm

Correction
  • cp a.txt sauvegarde/ → a.txt reste, une copie apparaît dans sauvegarde.
  • mv a.txt sauvegarde/ → a.txt n'est plus à la racine, il est dans sauvegarde.
  • cp a.txt copie.txt; rm a.txt et mv a.txt copie.txt → même résultat visible : copie.txt, b.txt, c.txt, sauvegarde. (mv renomme directement, sans recopier les données.)

Ex 6-7 — Redirections

Correction
  • Après echo Bonjour > ; echo Alice >> ; echo Bob >> : Bonjour / Alice / Bob. Après echo Charlie > message.txt : Charlie seul.
  • > remplace, >> ajoute. Si le fichier n'existe pas, > le crée.
  • Ex 7 : copie.txt = les 3 lignes ; puis + « David 12 » ; puis echo Emma 15 > copie.txt → « Emma 15 » seul. Prudence : > détruit l'ancien contenu sans prévenir.

Ex 8 à 11 — cut, sort, paste

Correction
  • cut -d ':' -f 1 → Alice Bob Charlie David Emma ; -f 3 → L1 L1 L2 L1 L2 ; -f 1,4 → Alice:14 Bob:11 Charlie:16 David:9 Emma:13 ; -f 2-4 → Martin:L1:14 … (le délimiteur est conservé). -d = délimiteur, -f = numéros de champs.
  • nombres.txt : sort → 100 12 25 3 42 8 (alphabétique) ; sort -n → 3 8 12 25 42 100 ; sort -n -r → 100 42 25 12 8 3.
  • sort etudiants.txt → par prénom (début de ligne) ; sort -t ':' -k 2 → par nom : Bernard, Dupont, Durand, Martin, Petit ; sort -t ':' -k 4 -n → par note : 9, 11, 13, 14, 16.
  • paste -d ':' prenoms.txt notes.txt → Alice:14 … ; pour Alice:L1:14 : paste -d ':' prenoms.txt formation.txt notes.txt.

Ex 14 — Enquête : « sort a modifié mon fichier »

Correction

Faux. sort resultat.txt > resultat-trie.txt lit resultat.txt et écrit le tri dans resultat-trie.txt. resultat.txt a été modifié par la commande d'avant (cut … > resultat.txt, qui a remplacé « ancien resultat »), et il n'est pas trié (Durand est à la fin). Directement : cut -d ':' -f 2 documents/etudiants.txt | sort.

Ex 15 — Défi ventes.txt

Correction

TD2 — Composition et jokers (fichier de 10 étudiants)

Ex 1 — Résultats intermédiaires

Correction 
cut -d ':' -f 3   → L1 L1 L2 L1 L2 L2 L1 L3 L3 L2
| sort            → L1 L1 L1 L1 L2 L2 L2 L2 L3 L3
| uniq -c         → 4 L1 / 4 L2 / 2 L3
| sort -nr        → 4 L2 / 4 L1 / 2 L3

Le 1er tri (alphabétique) regroupe les valeurs identiques pour que uniq -c puisse compter ; le 2e (numérique, décroissant) classe par effectif. (À égalité, sort -nr inverse aussi l'ordre alphabétique, d'où L2 avant L1.)

Ex 2 — Conserver l'information utile

Correction

1re chaîne → 16 seulement (l'identité de l'étudiant a été détruite par cut). 2e → Charlie:Durand:L2:16 (ou Gabrielle, aussi 16 : en cas d'égalité, une seule ligne est gardée). head doit venir après le tri sinon on garde la première ligne du fichier. Règle : trier/sélectionner avant de réduire, extraire le plus tard possible.

Ex 3-4 — Construire par étapes

Correction

Notes différentes croissantes : cut -d ':' -f 4 etudiants.txt | sort -n | uniq → 9 11 13 14 15 16 (tri numérique, et avant uniq pour rendre les doublons consécutifs).

Formations par effectif décroissant : extraire → trier (alphabétique) → compter (uniq -c) → classer (sort -nr) : c'est la commande de l'Ex 1.

Ex 5 à 8 — tee, tr, paste, plusieurs fichiers

Correction
  • Ex 5 : cut -d ':' -f 2 etudiants.txt | sort | tee noms.txt | wc -l → tee reçoit les noms triés, les écrit dans noms.txt et les transmet à wc. Le nombre (10) s'affiche mais n'est pas écrit dans noms.txt.
  • Ex 6 : tr '[:upper:]' '[:lower:]' < villes.txt | sort | uniq -c | sort -nr → 3 paris / 2 lille / 2 amiens. Il faut normaliser en premier (sinon Paris, PARIS et paris sont différents).
  • Ex 7 : paste -d ':' prenoms.txt notes.txt | sort -t ':' -k 2,2 -nr | tee classement.txt | head -n 3 → Charlie:16 / Alice:14 / Emma:13 à l'écran, tout le classement dans le fichier. tee est placé avant head.
  • Ex 8 : cat groupe1.txt groupe2.txt groupe3.txt | sort -nr | head -n 5 ; version qui conserve : cat groupe?.txt | sort -nr | tee toutes-les-notes.txt | head -n 5.

Ex 9-10 — Développement des jokers

Répertoire : a.txt ab.txt abc.txt b.txt notes1.txt notes2.txt notes10.txt programme.c programme.h photo.jpg .secret.txt
Correction

Ex 11-13 — Chemins, protection, prudence

Correction
  • groupe?/notes.txt → groupe1, groupe2 ; groupe*/notes.txt → groupe1, groupe10, groupe2 ; */notes.txt → idem (commun n'a pas de notes.txt) ; groupe[12]/rapport.pdf → 2 rapports ; */*.txt → les 3 notes.txt + commun/consignes.txt. * ne traverse pas / car chaque partie du chemin est développée séparément.
  • echo *.txt → la liste ; echo "*.txt" et echo \*.txt → *.txt littéral. Sans correspondance (*.pdf), Bash laisse le motif tel quel.
  • cp rapport*.txt sauvegarde/ copie rapport-final, rapport1, rapport2 ; mv rapport?.txt sauvegarde/ déplace rapport1 et rapport2 ; rm *.txt supprime tous les .txt (dont notes.txt !) sans corbeille → vérifier avec pwd et echo *.txt.

Ex 14-17 — Synthèse et diagnostics

Correction
  • Ex 14 : cat notes-L?.txt | sort -n | uniq -c | sort -nr | tee bilan-licence.txt (notes-L? exclut notes-M1).
  • Ex 15 : motif ventes-2026-*.txt ; produits : cat ventes-2026-*.txt | cut -d ':' -f 2 | sort | uniq -c | sort -nr ; prix : cat ventes-2026-*.txt | sort -t ':' -k 3,3 -nr | tee classement-2026.txt | head -n 5.
  • Ex 16 : A → ajouter sort avant uniq -c ; B → trier avant head ; C → trier les lignes complètes (sort -t ':' -k …) au lieu d'extraire ; D → tee noms.txt | wc -l au lieu de > noms.txt | wc -l ; E → enlever les guillemets autour du joker.
  • Ex 17 : cat groupe?.txt | cut -d ':' -f 3 | sort | uniq -c | sort -nr | tee bilan-formations.txt.

TD3 — Expressions régulières

Ex 1 — Joker ou regex ?

Correction

Jokers (noms de fichiers) : *.txt, notes?.txt, image[12].jpg. Regex (contenu) : ^Alice, :[0-9]+$, ^(chat|chien)$. En joker * = n'importe quelle suite ; en regex * = répétition de l'élément précédent (« n'importe quoi » = .*).

Ex 2 à 6 — Quelles lignes sont reconnues ?

Correction
  • Ex 2 : chat → les 5 lignes ; ^chat → chat, chateau, chat noir ; chat$ → chat, un chat, le chat ; ^chat$ → chat.
  • Ex 3 : ^image..jpg$ → image1.jpg, imageA.jpg, image1Xjpg (le 2e point est quelconque) ; ^image.\.jpg$ → image1.jpg, imageA.jpg ; ^image[0-9]\.jpg$ → image1.jpg.
  • Ex 4 : ^[ABC][0-9]{2}$ → A12 B07 C99 ; ^[A-Z][0-9]+$ → A12 B07 C99 D3 ; ^[^AB][0-9]{2}$ → C99, a45 ; ^[[:upper:]][[:digit:]]{2}$ → A12 B07 C99.
  • Ex 5 : ^ab*c$ → ac abc abbc abbbc ; ^ab+c$ → abc abbc abbbc ; ^ab?c$ → ac abc ; ^ab{2,3}c$ → abbc abbbc. (abXc jamais.)
  • Ex 6 : ^(chat|chien)$ → chat chien ; ^(chat|chien)s?$ → chat chats chien chiens ; ^ch(at|ien)s?$ → les mêmes 4. Les parenthèses délimitent la portée du | et du ?.

Ex 11 — Corriger les motifs

Correction
  • *.txt (joker) → regex \.txt$ ; L1 → ^L1$ (sinon L10 passe) ; [0-9]* accepte la chaîne vide → [0-9]+ ; ^chat|chien$ → ^(chat|chien)$ ; . → \. ; [0-9]{2-3} → [0-9]{2,3} (virgule, pas tiret).

Ex 12-14 — Décomposer, concevoir, synthèse

Correction

^[A-Z][a-z]+:[A-Z][a-z]+:L[1-3]:[0-9]{1,2}$ = prénom (majuscule + minuscules) : nom : L1-L3 : note sur 1 ou 2 chiffres. Reconnues : Alice:Martin:L1:14, Bob:Dupont:L3:9. Rejetées : alice:Martin:L1:14, Bob:Dupont:L4:10. Limite : pas d'accents, de tirets ni d'espaces (Jean-Luc, Éloïse, Le Gall).

  • identifiant : ^[a-z][0-9]{2,5}$ ; module : ^(systeme|reseau|programmation)$ ; date : ^[0-9]{4}-[0-9]{2}-[0-9]{2}$ ; adresse : ^[a-zA-Z.]+@u-picardie\.fr$.
  • Synthèse : ^[0-9]{4}-[0-9]{2}-[0-9]{2}:[A-Za-z ]+:L[1-3]:(systeme|reseau|programmation):[0-9]{1,2}$

Ex 4 à 7 — sed

Correction
  • sed 's/:/|/g' f ; sed -E 's/L([1-3])/Licence \1/' f ; sed 's/^Alice/ALICE/' f ; sed 's/:/ /' f (sans g : seulement le 1er).
  • sed -n '3p' f ; sed -n '3,6p' f ; sed -n '/:L2:/p' f ; sed '/:L1:/d' f ; sed '/^$/d' f. Le fichier n'est pas modifié : sed écrit sur sa sortie.
  • Ex 6 : sed -E 's/^([^:]+):([^:]+):([^:]+):([^:]+)$/\2, \1 — \3 — \4/' f → « Martin, Alice — L1 — 14 », « Dupont, Bob — L1 — 11 ».
  • Ex 7 : prévisualiser sed 's/L1/Licence 1/g' f, puis sed -i.bak 's/L1/Licence 1/g' f → il existe f (modifié) et f.bak (l'original).

Ex 8 à 11 — awk

Correction 
awk -F ':' '{ print $1 }' f                 # prénoms
awk -F ':' '{ print $2, $4 }' f             # nom et note
awk -F ':' '{ print NR, $1, $2 }' f         # numéro de ligne
awk -F ':' '{ print $NF }' f                # dernier champ
awk -F ':' '{ print NF, $0 }' f             # nb de champs + ligne
awk -F ':' '$3 == "L2"' f
awk -F ':' '$4 >= 14 { print $1, $2 }' f
awk -F ':' '$3 != "L1"' f
awk -F ':' '$2 ~ /^D/' f                    # Dupont, Durand
awk -F ':' '$4 < 10' f                      # David, Jules
awk -F ':' '{ s += $4 } END { print s }' f                       # 127
awk -F ':' '{ s += $4 } END { if (NR > 0) print s / NR }' f      # 12.7
awk -F ':' '$3 == "L2" { n++ } END { print n }' f                # 4
awk -F ':' '$3 == "L2" { s += $4; n++ } END { if (n > 0) print s / n }' f   # 12.25
awk -F ':' 'NR == 1 || $4 > m { m = $4 } END { print m }' f      # 16
awk -F ':' '{ e[$3]++ } END { for (k in e) print k, e[k] }' f | sort   # L1 4 / L2 4 / L3 2
awk -F ':' '{ e[substr($2,1,1)]++ } END { for (k in e) print k, e[k] }' f | sort

On envoie la sortie d'un tableau associatif vers sort car l'ordre du for (k in e) n'est pas garanti.

Ex 12-14 — Composition

Correction
  • Ex 12 : grep -Ev '^#|^$' inscriptions.txt | sed -E 's/^[[:space:]]+//' | cut -d ':' -f 3 | sort | uniq -c → 2 L1 / 3 L2.
  • Ex 13 : grep -E ':[45][0-9]{2}:' acces.log | cut -d ':' -f 1 | sort | uniq -c | sort -nr | tee erreurs.txt → 2 10.0.0.2 puis 1 pour .1, .3 et .4. Version awk : awk -F ':' '$2 ~ /^[45]/ { e[$1]++ } END { for (a in e) print e[a], a }' acces.log | sort -nr.
  • Ex 14 (resultats.txt, format date:etudiant:formation:module:note) :
    • systeme par note décroissante : grep ':systeme:' resultats.txt | sort -t ':' -k 5,5 -nr
    • moyenne reseau : awk -F ':' '$4 == "reseau" { s += $5; n++ } END { if (n) print s/n }' resultats.txt → (16+11+9)/3 = 12
    • résultats par module : cut -d ':' -f 4 resultats.txt | sort | uniq -c → 3 programmation, 3 reseau, 4 systeme
    • notes < 10 : awk -F ':' '$5 < 10' resultats.txt → Bob Dupont (8), Hugo Moreau (9)
    • affichage : sed -E 's/^[^:]*:([^:]*):[^:]*:([^:]*):(.*)$/\1 — \2 — \3/' resultats.txt
    • bilan par étudiant : cut -d ':' -f 2 resultats.txt | sort | uniq -c | sort -nr → Alice Martin 2, les autres 1

TD5 — Droits et premiers scripts

Préliminaires — droits

Correction
Fichierugo
notes.txt rw-r--r--lire, écrirelirelire
analyse.sh rwxr-x---toutlire, exécuterrien
secret.txt rw-------lire, écrirerienrien
sujet.txt r--r--r--lirelirelire

Tout le monde lit notes.txt ; seule alice modifie secret.txt ; elle ne peut pas modifier sujet.txt ; le groupe peut exécuter analyse.sh, pas les autres.

Commandes : chmod u+x programme.sh ; chmod o-r notes.txt ; chmod g+r resultats.txt ; chmod a-x ancien.sh.

bash bonjour.sh marche car c'est Bash qui lit le fichier (droit r suffit) ; ./bonjour.sh échoue (« Permission denied ») sans le droit x → chmod u+x bonjour.sh → -rwxr--r--. bonjour.sh seul échoue car le répertoire courant n'est pas dans le PATH : il faut ./.

Ex 4 à 8 — Variables et guillemets

Correction
  • Correctes : nom=Alice, ville="Amiens", fichier=notes.txt, message="Bonjour tout le monde". Fausses : prenom = Bob et age =20 (le shell lance une commande « prenom »/« age »), message=Bonjour tout le monde (lance la commande « tout » avec message=Bonjour en variable temporaire).
  • echo nom → nom ; echo $nom → Alice ; echo "$nom" → Alice ; echo '$nom' → $nom ; "$nom habite à $ville" → Alice habite à Amiens ; avec apostrophes → $nom habite à $ville.
  • Ex 6 : wc -l $fichier → 2 arguments (« compte », « rendu.txt ») → erreurs ; wc -l "$fichier" → 1 argument ✔. Les guillemets de l'affectation ne « restent » pas : il faut protéger à chaque utilisation.
  • Ex 7 : echo $motif → notes1.txt notes2.txt (joker développé après remplacement) ; echo "$motif" → notes?.txt ; echo '$motif' → $motif.
  • Ex 8 : "$nom_notes.txt" cherche la variable nom_notes (vide) → « .txt » ; "${nom}_notes.txt" → Alice_notes.txt. touch "${nom}_resultat.txt".

Ex 12-13 — Substitution de commande

Correction
  • Les commandes dans $(…) sont exécutées au moment de l'affectation ; les variables contiennent leurs sorties (le chemin, la date AAAA-MM-JJ, le nombre de lignes), pas le texte « pwd ».
  • wc -l < notes.txt affiche seulement « 5 » ; wc -l notes.txt afficherait « 5 notes.txt ».
  • Ex 13 : sort → Amiens×3, Lille, Paris×2 ; uniq -c → 3 Amiens / 1 Lille / 2 Paris ; sort -nr → 3 Amiens / 2 Paris / 1 Lille ; head -n 1 → « 3 Amiens ». La variable contient le compte et la ville : un meilleur nom est ville_plus_frequente ou occurrences_et_ville.

Ex 14 et 16 — fiche.sh et compte-rendu.sh

Correction 
#!/bin/bash
# fiche.sh
fichier="$1"
lignes=$(wc -l < "$fichier")
mots=$(wc -w < "$fichier")
premiere=$(head -n 1 "$fichier")
derniere=$(tail -n 1 "$fichier")
echo "Fichier : $fichier"
echo "Nombre de lignes : $lignes"
echo "Nombre de mots : $mots"
echo "Première ligne : $premiere"
echo "Dernière ligne : $derniere"
#!/bin/bash
# compte-rendu.sh entree sortie
entree="$1"
sortie="$2"
lignes=$(wc -l < "$entree")
champs=$(head -n 1 "$entree" | tr ':' '\n' | wc -l)
premier=$(head -n 1 "$entree" | cut -d ':' -f 2)
dernier=$(tail -n 1 "$entree" | cut -d ':' -f 2)
{
    echo "Analyse de $entree"
    echo "Nombre de lignes : $lignes"
    echo "Nombre de champs de la première ligne : $champs"
    echo "Premier titre : $premier"
    echo "Dernier titre : $dernier"
} > "$sortie"                     # une seule redirection pour tout le bloc
