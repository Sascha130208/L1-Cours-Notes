1. Arborescence et chemins

  • Tout part de la racine /. Répertoires importants : /home (utilisateurs), /etc (configuration), /tmp (temporaires), /usr (programmes), /var (données variables), /dev (périphériques), /bin.
  • Répertoire personnel : /home/alice, noté ~.
  • Répertoire courant : où l'on se trouve (pwd). . = le courant, .. = le parent.
  • Chemin absolu : commence par /, désigne toujours le même fichier. Chemin relatif : interprété depuis le répertoire courant.
  • Fichiers cachés : nom qui commence par . (.bashrc) ; visibles avec ls -a.
  • Linux ne se fie pas à l'extension : file notes.txt analyse le contenu. Sous Unix « tout est fichier » (données, programmes, périphériques…).
Depuis /home/alice/cours/systeme, pour désigner /home/alice/images/logo.png :
../../images/logo.png      (relatif : on remonte 2 fois)
/home/alice/images/logo.png  (absolu)
~/images/logo.png            (absolu via ~)

3. Redirections

SyntaxeEffet
cmd > fla sortie va dans f ; remplace son contenu (crée f si besoin)
cmd >> fajoute à la fin de f
cmd < ff devient l'entrée de cmd (wc -l < f affiche juste le nombre, sans le nom du fichier)
$ echo Bonjour > message.txt     # message.txt : Bonjour
$ echo Alice >> message.txt      # Bonjour / Alice
$ echo Charlie > message.txt    # Charlie   (tout le reste est écrasé !)

Tri alphabétique vs numérique : sort sur 2, 11, 8, 100, 20 donne 100, 11, 2, 20, 8 (comparaison caractère par caractère) ; sort -n donne 2, 8, 11, 20, 100.

5. Le tube | et la méthode de composition

cmd1 | cmd2 : la sortie de cmd1 devient l'entrée de cmd2, sans fichier intermédiaire. Philosophie Unix : des outils simples qu'on combine.

cut -d ':' -f 3 etudiants.txt | sort | uniq -c | sort -nr
#   extraire        trier  regrouper/compter  classer par effectif décroissant
#   L1 L1 L2 L1 L2 → L1 L1 L1 L2 L2 →  3 L1 / 2 L2  →  3 L1 / 2 L2
⭐ Méthode (TD2)
  1. Décompose avec des verbes : sélectionner → extraire → normaliser → trier → compter → classer → limiter → conserver.
  2. Pour chaque tube, dis ce que la commande de gauche produit et ce que celle de droite reçoit.
  3. Construis la chaîne étape par étape en exécutant à chaque fois.

Règles d'or de l'ordre des commandes

  • sort avant uniq (uniq ne voit que les doublons consécutifs).
  • head après le tri (sinon on garde les 3 premières lignes du fichier, pas les 3 meilleures).
  • Ne pas extraire trop tôt une information encore utile : pour la ligne complète du meilleur, sort -t ':' -k 4,4 -nr etudiants.txt | head -n 1 et pas cut … | sort | head (qui ne donne que « 16 »).
  • tee se place à l'endroit dont on veut garder le flux : … | sort | tee noms.txt | wc -l enregistre les noms triés, et affiche seulement leur nombre.
  • Éviter les tubes inutiles : sort f plutôt que cat f | sort.
  • cmd > f | wc -l est faux : la sortie part dans f, wc ne reçoit rien.

6. Les jokers du shell (globbing)

JokerSignificationExemple
*0, 1 ou plusieurs caractères*.txt
?exactement 1 caractèreimage?.jpg → image1.jpg, image2.jpg mais pas image10.jpg
[abc], [1-3]1 caractère parmi un ensemble / intervalle*.[ch] → fichiers .c et .h
[!abc]1 caractère sauf a, b, cimage[!0].jpg
  • C'est le shell qui développe le motif avant de lancer la commande : ls *.txt devient ls cours1.txt cours2.txt notes.txt. Vérifier avec echo *.txt.
  • * ne traverse pas / : cours/*.txt ne trouve pas cours/systeme/notes.txt ; */*/*.txt = exactement deux niveaux plus bas.
  • * ne sélectionne pas les fichiers cachés : il faut .*.txt.
  • Aucune correspondance → Bash transmet le motif tel quel (ls *.pdf → « cannot access '*.pdf' »).
  • Protéger un joker : "*.txt" ou \*.txt → pas de développement.
  • Avant un rm *.txt : pwd puis echo *.txt. rm -- *.txt : -- = fin des options (protège d'un fichier nommé -ancien.txt).
  • Joker = choisit des noms de fichiers ; tube = traite le contenu : cat notes-L?.txt | sort -n | uniq -c | tee bilan.txt.

7. Expressions régulières (ERE, avec grep -E / sed -E)

SymboleSensExemple
.un caractère quelconqueL. → L1, L2, LA…
\.un vrai point\.txt$
^ / $début / fin de ligne (des positions)^L1$ = ligne exactement « L1 »
[abc] [0-9] [A-Z]un caractère de l'ensemble^[ABC]
[^0-9]un caractère hors de l'ensemble (^ juste après [)
[[:digit:]] [[:alpha:]] [[:alnum:]] [[:space:]] [[:upper:]]classes POSIX
*0 ou plus de l'élément précédentab*c → ac, abc, abbc
+1 ou plus[0-9]+ → un entier non vide
?0 ou 1 (optionnel)couleurs?
{2} {2,4} {2,}exactement 2 / de 2 à 4 / au moins 2[0-9]{2}
a|bouL1|L2
( )groupe^(chat|chien)s?$
❌ Joker ≠ regex En joker, * = « n'importe quoi ». En regex, * = « répéter l'élément d'avant » et « n'importe quoi » s'écrit .*. « Fichiers .txt » : joker *.txt, regex \.txt$. Et ^chat|chien$ ≠ ^(chat|chien)$ (le premier = « commence par chat » OU « finit par chien »).

Méthode : décrire chaque morceau séparément, assembler, ajouter ^…$ si toute la ligne doit correspondre, tester sur des exemples positifs et négatifs.

^[A-Z].*:[0-9]+$        ligne qui commence par une majuscule et finit par un nombre
^image[0-9]+\.jpg$      image1.jpg, image12.jpg (pas image.jpg, ni monimage1.jpg)
^(1[0-9]|[0-9])$        une note entre 0 et 19

CommandeEffet

10. awk — champs, conditions, calculs

awk -F ':' '{ print $1 }' f                      # 1er champ
awk -F ':' '{ print NR, $2, $4 }' f              # numéro de ligne, nom, note
awk -F ':' '$3 == "L2" { print $1, $2 }' f       # condition { action }
awk -F ':' '$4 >= 14' f                          # sans action : affiche la ligne
awk -F ':' '$2 ~ /^D/ { print $2 }' f            # ~ : correspond à la regex (!~ : ne correspond pas)
awk -F ':' '{ s += $4 } END { print s / NR }' f  # moyenne
awk -F ':' '$3=="L2" { s+=$4; n++ } END { if (n > 0) print s/n }' f
awk -F ':' '{ eff[$3]++ } END { for (f in eff) print f, eff[f] }' f | sort   # comptage par catégorie
awk -F ':' 'BEGIN { print "Début" } { print $1 } END { print NR, "lignes" }' f
ÉlémentSens
$0la ligne entière
$1, $2…les champs
NF / $NFnombre de champs / dernier champ
NRnuméro de la ligne courante (à la fin : nombre de lignes)
BEGIN { } / END { }avant la 1re ligne / après la dernière
tab[cle]++tableau associatif ; ordre de parcours non garanti → piper vers sort

Quel outil ? cut = extraire simplement ; grep = sélectionner par motif ; sed = remplacer/supprimer du texte ; awk = tester un champ précis, calculer, compter. awk -F ':' '$3 == "L2"' est plus précis que grep 'L2' (qui trouverait aussi « L2 » ailleurs dans la ligne).
