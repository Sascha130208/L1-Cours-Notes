0. L'examen : ce qu'on attend de toi

  • Note finale = 30 % QCM (2 QCM en TP) + 35 % partiel + 35 % examen terminal (1 h).
  • Langage algorithmique uniquement : « Le langage C n'est pas accepté ».
  • Indentation obligatoire : en 2023 « les algorithmes non indentés obtiendront une note nulle ».
  • Les sujets reviennent toujours aux mêmes types de questions : trace d'exécution, arbre de décision, saisie contrôlée, découper un nombre en chiffres (mod 10 / div 10), compter / sommer / multiplier dans une boucle, et à l'examen de fin de semestre : fonctions et tableaux.

1. Structure d'un algorithme

Algorithme NomDeLAlgo
/* Rôle : ce que fait l'algorithme. Données : ... Résultat : ... */
constantes
    réel TVA ← 0.20 ;
variables
    entier n, i ;
    réel prix ;
début
    écrire "Donnez n :" ;
    lire n ;
    ...
fin
  • Les instructions s'exécutent séquentiellement (dans l'ordre, une par une).
  • Chaque instruction finit par ;.
  • Commentaires : // sur une ligne et /* sur un bloc */.
  • Spécification avant d'écrire : données (nom, type, rôle), résultat, préconditions (cas général / cas particuliers).

2. Variables, types, constantes

Une variable = une boîte avec un nom, un type, une valeur

  • Déclarée une fois et une seule, avant toute utilisation : type nom ; ou type a, b, c ;
  • À la déclaration, elle n'a aucune valeur (on note ? dans une trace) → il faut l'initialiser avant de l'utiliser dans une expression.

Nom de variable (identificateur)

Lettres, chiffres et _, commence par une lettre, pas d'espace, pas de mot-clé.

ValidesNon valides (pourquoi)
a, x, solution1, unReel, s1_4_Xt1variable (chiffre au début), solution%1 (%), ma solution (espace), reel (mot-clé), a/b (/)

Les 5 types

TypeExemplesAttention
entier1, -10, 0
réel1.3, 4.0, 2.53.14 est réel ; pi tout seul est un nom, pas une valeur
booléenvrai, faux"vrai" avec guillemets est une chaîne !
caractère'a', '1', '!'un seul caractère entre apostrophes
chaîne"Bonjour", "1.3", "faux"'au revoir' : plusieurs caractères entre apostrophes → incorrect ; oui sans guillemets → c'est un nom de variable

Affectation x ← expression ;

  1. on évalue l'expression (les variables sont remplacées par leur valeur) ;
  2. la variable reçoit cette valeur (l'ancienne est perdue).
⚠️ L'ordre compte x←2; y←3; x←y; y←x; → x et y valent 3. Pour échanger, il faut une variable temporaire : tmp ← x ; x ← y ; y ← tmp ;

Constantes

constantes réel TVA ← 0.20 ; : initialisée à la déclaration, ne peut plus être modifiée (écrire TVA ← 0.3 ; plus loin = erreur).

Lire / écrire

  • lire a ; ou lire a, b ; → la valeur tapée au clavier est affectée à la variable.
  • écrire "Tu auras ", age+1, " ans" ; → on peut mélanger texte et expressions, séparés par des virgules.
  • Toujours un écrire "Donnez ..." ; avant un lire (sinon l'utilisateur ne sait pas quoi taper).

Priorités (de la plus forte à la plus faible)

  1. parenthèses (et appels de fonctions)
  2. - unaire
  3. * / div mod
  4. + -

À priorité égale : de gauche à droite. Donc a/b*c = (a/b)×c et a/b/c = a/(b×c).

Exemples : 3+4*5 = 23 ; (3+4)*5 = 35 ; 5 * 4 div 3 = 20 div 3 = 6.

5. Instructions conditionnelles

si (condition) alors
    instructions ;
sinon                // le sinon est facultatif
    instructions ;
finsi
  • On évalue la condition ; si vrai → bloc alors, sinon → bloc sinon ; puis on continue après le finsi.
  • Imbriquer plutôt qu'enchaîner quand les cas s'excluent :
// MAUVAIS : 3 tests toujours faits
si (d = 0) alors n ← 1 ; finsi
si (d > 0) alors n ← 2 ; finsi
si (d < 0) alors n ← 0 ; finsi
// BON : sinon si imbriqué
si (d = 0) alors
    n ← 1 ;
sinon
    si (d > 0) alors
        n ← 2 ;
    sinon
        n ← 0 ;
    finsi
finsi

Chaque finsi ferme le si le plus proche encore ouvert : c'est l'indentation qui rend ça lisible.

Exemple de cours : ax + b = 0

lire a, b ;
si (a = 0) alors
    si (b = 0) alors
        msg ← "n'importe quel réel" ;
    sinon
        msg ← "aucune solution" ;
    finsi
    écrire msg ;
sinon
    x ← -b / a ;      // a ≠ 0 : pas de division par 0
    écrire "la solution est x = ", x ;
finsi

6. Expressions booléennes

abnon aa et ba ou b
vraivraifauxvraivrai
vraifauxfauxfauxvrai
fauxvraivraifauxvrai
fauxfauxvraifauxfaux
  • Priorité : non > et > ou. Donc x ou y et z = x ou (y et z) ≠ (x ou y) et z (essaie x=vrai, y=vrai, z=faux).
  • Court-circuit : dans x et y, si x est faux, y n'est pas évalué ; dans x ou y, si x est vrai, y n'est pas évalué. Utile : (d ≠ 0) et (n mod d = 0) ne plante pas si d = 0.
  • « a entre 10 et 20 inclus » : (10 ≤ a) et (a ≤ 20) (jamais 10 ≤ a ≤ 20).
  • « a pas entre 10 et 20 » : (a < 10) ou (a > 20).
  • Lois de De Morgan (pour nier une condition de boucle) : non (p et q) = non p ou non q ; non (p ou q) = non p et non q.
  • Booléen lu au clavier : booléen rep ; lire rep ; si (rep) alors ... — pas si (rep = "oui").

7. L'arbre de décision (≈ 2-3 points à chaque partiel)

Un arbre binaire : chaque nœud = une condition (losange), deux branches vrai / faux, chaque feuille = une action (afficher, calculer). On commence par déclarer les variables (nom + type) comme demandé dans l'énoncé.

Exemple (prix de copies, partiel 2025) — variables : entier nb, réel prixU, ht, tva, ttc, constante réel TVA ← 0.20.

               nb ≤ 100 ?
             /vrai       \faux
     prixU ← 0.10      nb ≤ 300 ?
                     /vrai      \faux
              prixU ← 0.09   prixU ← 0.08
        (puis dans tous les cas : ht ← nb*prixU ; tva ← TVA*ht ; ttc ← ht+tva)

Traduction directe : chaque nœud devient un si … alors … sinon … finsi, les sous-arbres deviennent des si imbriqués.

8. La boucle pour (nombre de tours CONNU)

pour (i allant de valInit à valFinale pas valPas) faire
    instructions ;
finpour
  • i prend valInit, valInit+pas, … jusqu'à valFinale.
  • Pas cohérent : de 1 à 10 pas 1 ✔, de 10 à 1 pas -1 ✔, de 10 à 10 pas 1 ✔ (1 tour), de 1 à 10 pas -1 ✘, de 10 à 1 pas 1 ✘.
  • ⚠️ Ne jamais modifier le compteur dans la boucle (i ← 2*i interdit), et éviter de l'utiliser après.
  • Nombre de tours de pour i de a à b pas 1 : b − a + 1.
// Trace : pour (i allant de 2 à 4 pas 1) faire x ← 2*i ; finpour   x ← x+3 ;
// i=2 x=4 | i=3 x=6 | i=4 x=8 | sortie : x=11

9. La boucle tantque (nombre de tours INCONNU)

tantque (condition) faire
    instructions ;
fintantque
  • La condition est testée avant chaque tour → si elle est fausse dès le départ, on ne rentre jamais.
  • Il faut que quelque chose dans la boucle fasse évoluer la condition, sinon boucle infinie (x←1; tantque (x ≠ 10) faire x ← 2*x : 1,2,4,8,16… ne vaut jamais 10 !).
  • À la sortie, la condition est fausse : « tantque (a > 0 et b < 0) » → à la sortie on a a ≤ 0 ou b ≥ 0 (De Morgan).

Simuler un pour avec un tantque (demandé au partiel 2024)

pour (i allant de a à b pas p) faire
    instructions ;
finpour
i ← a ;
tantque (i ≤ b) faire
    instructions ;
    i ← i + p ;
fintantque

Quelle boucle choisir ?

« Peut-on prévoir le nombre de tours ? » → oui : pour ; non : tantque (saisie contrôlée, jusqu'à -1, chiffres d'un nombre, jeu, Syracuse…).

Méthode pour écrire une boucle

  1. faire le calcul à la main sur un exemple ;
  2. repérer ce qui se répète ;
  3. choisir pour / tantque ;
  4. initialiser les variables avant la boucle ;
  5. écrire la condition d'arrêt et l'évolution de la variable de contrôle ;
  6. tester sur un cas limite (0 tour, 1 tour) et un cas normal.

10. Fonctions et procédures (TP4, examen)

fonction avec retour entier Puissance(entier a, entier b)
variables
    entier i, res ;
début
    res ← 1 ;
    pour (i allant de 1 à b pas 1) faire
        res ← res * a ;
    finpour
    retourne res ;
fin

fonction sans retour afficheLigne(chaîne s, entier nb)     // = procédure
variables
    entier i ;
début
    pour (i allant de 1 à nb pas 1) faire
        écrire s ;
    finpour
fin
  • Avec retour : renvoie une valeur (retourne) qu'on utilise dans une expression : p ← Puissance(2, 10) ;
  • Sans retour (procédure) : fait une action (afficher, remplir un tableau) ; on l'appelle comme une instruction : afficheLigne("+", 5) ;
  • Les paramètres sont des copies des valeurs passées (sauf les tableaux, voir après) ; les variables déclarées dans la fonction sont locales.
  • « Toute fonction déclarée peut être utilisée dans les questions suivantes » → réutilise tes fonctions précédentes (c'est le but !).
  • Fonctions prédéfinies : racineCarrée(x), nombreAléatoire(), entierEnChaine(n), chaineEnEntier(c).

11. Tableaux

entier Tableau T[10] ;            // 10 cases : T[0] ... T[9]
entier Tableau M[3][4] ;          // 3 lignes, 4 colonnes : M[i][j]

pour (i allant de 0 à 9 pas 1) faire     // parcours complet
    T[i] ← 0 ;
finpour

fonction sans retour afficheTab(entier Tableau T, entier longueur)
  • Indices de 0 à longueur−1 (comme en C). Accéder à T[10] dans un tableau de 10 cases = erreur.
  • Un tableau passé en paramètre est modifiable par la fonction (c'est comme ça qu'on « remplit » deux tableaux dans SaisieNombre à l'examen 2024).
  • On passe toujours la longueur avec le tableau.

12. ⭐ Les 12 patrons à connaître par cœur

90 % des exercices sont une combinaison de ces briques.

P1. Saisie contrôlée (tombe à tous les partiels)

écrire "Donnez un entier strictement positif :" ;
lire n ;
tantque (n ≤ 0) faire
    écrire "Erreur, recommencez :" ;
    lire n ;
fintantque

La condition du tantque = la négation de ce qu'on veut. Entre 11 et 17 : tantque ((n < 11) ou (n > 17)).

P2. Parcourir les chiffres d'un nombre (mod 10 / div 10)

tantque (n > 0) faire
    chiffre ← n mod 10 ;     // dernier chiffre (unités)
    écrire chiffre ;
    n ← n div 10 ;           // on « enlève » le dernier chiffre
fintantque

1234 → affiche 4, 3, 2, 1. Sert à : somme des chiffres, nombre de chiffres, produit des chiffres pairs (Mstar), nombres insolites, inverser un nombre…

P3. Accumulateur somme / produit

somme ← 0 ;                 // élément neutre de +
produit ← 1 ;               // élément neutre de *
pour (i allant de 1 à n pas 1) faire
    somme ← somme + i ;
    produit ← produit * i ;  // factorielle
finpour

P4. Compteur

nb ← 0 ;
pour (i allant de 1 à 100 pas 1) faire
    lire val ;
    si (val mod 2 = 0) alors
        nb ← nb + 1 ;
    finsi
finpour

P5. Maximum / minimum

lire val ;
max ← val ;                       // on initialise avec la 1re valeur, PAS avec 0
pour (i allant de 2 à 100 pas 1) faire
    lire val ;
    si (val > max) alors
        max ← val ;
    finsi
finpour

P6. Valeur sentinelle (« jusqu'à ce qu'il tape -1 »)

somme ← 0 ;
lire val ;                        // lecture AVANT la boucle
tantque (val ≠ -1) faire
    somme ← somme + val ;
    lire val ;                    // lecture à la FIN du corps
fintantque

Variante « -1 ou n valeurs » : tantque ((val ≠ -1) et (cpt < n)) avec un compteur.

P7. Divisibilité, parité

a mod b = 0 ⟺ b divise a. Pair : n mod 2 = 0. Bissextile : ((a mod 4 = 0) et (a mod 100 ≠ 0)) ou (a mod 400 = 0).

P8. Test de primalité

fonction avec retour booléen EstPremier(entier n)
variables
    entier d ;
    booléen premier ;
début
    si (n < 2) alors
        premier ← faux ;
    sinon
        premier ← vrai ;
        d ← 2 ;
        tantque ((d * d ≤ n) et premier) faire
            si (n mod d = 0) alors
                premier ← faux ;
            finsi
            d ← d + 1 ;
        fintantque
    finsi
    retourne premier ;
fin

P9. Décomposition par div/mod (monnaie, durées)

// secondes → h, m, s
h ← total div 3600 ;
reste ← total mod 3600 ;
m ← reste div 60 ;
s ← reste mod 60 ;
// inverse : total ← h*3600 + m*60 + s ;

P10. Itérer jusqu'à un seuil (suite, intérêts, dépréciation)

annees ← 0 ;
valeur ← prix ;
tantque (valeur > prix / 2) faire
    valeur ← valeur * 0.9 ;
    annees ← annees + 1 ;
fintantque

P11. Recherche dans un tableau

pos ← -1 ;
i ← 0 ;
tantque ((i < long) et (pos = -1)) faire
    si (T[i] = x) alors
        pos ← i ;
    finsi
    i ← i + 1 ;
fintantque

P12. Échange de deux variables

tmp ← x ; x ← y ; y ← tmp ;
// astuce entiers sans tmp : x ← x+y ; y ← x-y ; x ← x-y ;

14. Pièges classiques

❌ À ne jamais faire
  • Utiliser une variable non initialisée (somme, compteur, max…).
  • Initialiser un max à 0 (faux si toutes les valeurs sont négatives) → prends la 1re valeur.
  • Oublier le lire dans la boucle de saisie contrôlée → boucle infinie.
  • Modifier le compteur d'un pour.
  • Diviser par une variable qui peut valoir 0 (tester avant !). Ex. : nombre insolite avec un chiffre 0 → produit = 0.
  • Écrire 10 ≤ a ≤ 20 au lieu de (10 ≤ a) et (a ≤ 20).
  • Confondre "vrai" (chaîne) et vrai (booléen), 'a' (caractère) et a (variable).
  • Oublier finsi / finpour / fintantque, ou ne pas indenter.
  • Écrire du C à la place du langage algorithmique.
