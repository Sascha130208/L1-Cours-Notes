[S1 Ex5-6] Expressions et priorités

a) Écrire en maths : a*b/c, a/b*c, a/b/c. b) Écrire en algo : (3x + 5y(z − 6)) / (4x). c) Traduire -2*2+4/x*y-x/3*z. d) Évaluer 3*x-8/y*(4*z)+2.5 pour x=10.0, y=1.0, z=2.0 et 5 * 4 div 3.
Correction
  • a) ab/c ; (a/b)·c = ac/b ; (a/b)/c = a/(bc) (gauche à droite à priorité égale).
  • b) (3*x + 5*y*(z - 6)) / (4*x) — les parenthèses autour du dénominateur sont indispensables.
  • c) −4 + (4/x)·y − (x/3)·z.
  • d) 30 − 8/1×8 + 2.5 = 30 − 64 + 2.5 = −31.5 ; 5×4 = 20 puis 20 div 3 = 6.

[S1 Ex11-13] Échanges

Correction
  • Échange de x et y : tmp ← x ; x ← y ; y ← tmp ; (tmp du même type que x et y). Même séquence pour des réels ou des booléens. Si x est entier et y réel : x ← y met un réel dans un entier → erreur (ou perte de la partie décimale).
  • Rotation de 3 variables : tmp ← x ; x ← y ; y ← z ; z ← tmp ;
  • Ex13 : x←x+y; y←x-y; x←x-y; → x = x₀+y₀ ; y = (x₀+y₀)−y₀ = x₀ ; x = (x₀+y₀)−x₀ = y₀ : échange sans variable temporaire.

[S1 Ex15] Durées

Correction 
Algorithme EnSecondes
variables
    entier h, m, s, total ;
début
    écrire "Heures, minutes, secondes :" ;
    lire h, m, s ;
    total ← h * 3600 + m * 60 + s ;
    écrire "Durée : ", total, " s" ;
fin

Algorithme EnHMS
variables
    entier h, m, s, total, reste ;
début
    écrire "Durée en secondes :" ;
    lire total ;
    h ← total div 3600 ;
    reste ← total mod 3600 ;
    m ← reste div 60 ;
    s ← reste mod 60 ;
    écrire h, "h ", m, "m ", s, "s" ;
fin

[S2 Ex6] Expressions booléennes (a = vrai, b = faux)

Correction
  • (a ou non b) et b = vrai et faux = faux
  • non a et b = faux et faux = faux
  • non (a ou b) = non vrai = faux
  • a ou b et non a = a ou (b et non a) = vrai ou … = vrai
  • a et non (a ou b) = vrai et faux = faux
  • b et a ou non b = (b et a) ou non b = faux ou vrai = vrai
  • non a ou (a et non (b ou a) ou a) = faux ou ((vrai et faux) ou vrai) = vrai

Règle : et est prioritaire sur ou (comme × sur +).

[TP4 Ex2] plusGrand, plusPetit, saisirEntre

Correction 
fonction avec retour entier plusGrand(entier a, entier b)
début

    sinon retourne b ;
    finsi
fin

fonction avec retour entier plusPetit(entier a, entier b)
début
    si (a < b) alors retourne a ;
    sinon retourne b ;
    finsi
fin

fonction avec retour entier saisirEntre(entier a, entier b)
variables
    entier x ;
début
    écrire "Entier entre ", a, " et ", b, " :" ;
    lire x ;

        écrire "Erreur :" ;
