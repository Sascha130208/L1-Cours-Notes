🛠️ Créer et modifier des fichiers et répertoires

🔍 Déterminer le type d'un fichier : file

Un fichier n'a pas forcément une extension fiable (.txt, .jpg...). La commande file regarde le contenu réel du fichier pour deviner son type.

$ file notes.txt
notes.txt: ASCII text

$ file photo.jpg
photo.jpg: JPEG image data

📁 Créer des répertoires : mkdir

mkdir = make directory.

$ ls
cours  images

$ mkdir documents
$ ls
cours  documents  images
OptionEffet
-pCrée aussi les dossiers parents manquants
$ mkdir -p projets/2026/info   # crée les 3 niveaux d'un coup

📝 Créer un fichier : 3 façons

1. touch

Crée un fichier vide, ou met à jour sa date de modification si il existe déjà.

2. Redirection

Créer/écraser un fichier en y redirigeant la sortie d'une commande.

3. Éditeur (nano)

Ouvrir un éditeur dans le terminal pour écrire directement dedans.

$ touch nouveau.txt

📖 Voir le contenu d'un fichier : cat

cat = concatenate. Affiche tout le contenu d'un fichier d'un coup.

$ cat notes.txt
Ligne 1
Ligne 2
Ligne 3

On peut aussi concaténer plusieurs fichiers :

$ cat fichier1.txt fichier2.txt

➡️ Les redirections : > et >>

Par défaut, une commande affiche son résultat à l'écran. On peut rediriger ce résultat vers un fichier.

SymboleEffet
>Remplace le contenu du fichier (ou le crée)
>>Ajoute à la fin du fichier
$ echo "Première ligne" > fichier.txt      # fichier.txt = "Première ligne"
$ echo "Deuxième ligne" >> fichier.txt     # ajoute une 2e ligne
$ echo "Nouveau contenu" > fichier.txt     # ⚠️ écrase tout !
🚨 Piège classique Confondre > et >>. Avec >, tout l'ancien contenu est perdu. Retiens : >> a "deux chevrons" comme pour dire "j'ajoute, j'ajoute" — un seul > = "je remplace tout".

✏️ Modifier un fichier : nano

nano est un éditeur de texte simple utilisable directement dans le terminal.

$ nano notes.txt
RaccourciEffet
Ctrl + OSauvegarder (Output)
Ctrl + XQuitter
Ctrl + KCouper une ligne
Ctrl + UColler
Ctrl + WRechercher

👀 Voir le début/la fin d'un fichier : head et tail

Utile pour de gros fichiers où cat afficherait beaucoup trop de lignes d'un coup.

head — début du fichier

$ head notes.txt          # 10 premières lignes par défaut
$ head -n 5 notes.txt     # 5 premières lignes

tail — fin du fichier

$ tail notes.txt          # 10 dernières lignes par défaut
$ tail -n 3 notes.txt     # 3 dernières lignes
OptionEffet
-n NAffiche N lignes au lieu de 10
-f(tail seulement) follow — suit le fichier en temps réel
