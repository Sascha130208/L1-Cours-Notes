Exercice 1 — Cours et suites (7 pts)

1. Définition formelle de « lim uₙ = +∞ ». (1 pt)

Réponse ∀A ∈ R, ∃N ∈ N, ∀n ∈ N, (n ≥ N ⇒ uₙ ≥ A).
(Dans le cours on écrit A > 0 : c'est équivalent. Ce qu'il faut absolument : les quantificateurs dans le bon ordre, et uₙ ≥ A et non |uₙ| ≥ A.)

2. Théorème de la limite monotone (suites croissantes). (2 pts)

Réponse Soit (uₙ) une suite réelle croissante.
• Si (uₙ) est majorée, alors elle converge, et sa limite est sup{uₙ : n ∈ N}.
• Si (uₙ) n'est pas majorée, alors uₙ → +∞.
(En particulier une suite croissante a toujours une limite dans R ∪ {+∞}.)

3. uₙ ≤ vₙ pour tout n et uₙ → +∞. A-t-on vₙ → +∞ ? (2 pts)

Réponse : oui Soit A ∈ R. Comme uₙ → +∞, il existe N tel que pour tout n ≥ N, uₙ ≥ A. Alors pour n ≥ N : vₙ ≥ uₙ ≥ A. Donc vₙ → +∞. ∎
⚠️ Ici l'énoncé a « forcément » et laisse croire à un piège. Ce n'est pas un piège : c'est une question de cours (Prop. 7 : comparaison vers +∞) à redémontrer avec la définition.

4. lim(n→+∞) ( n² − 2n√n cos(n³) ). (2 pts)

Réponse : +∞ cos(n³) n'a aucune raison d'avoir une limite, mais −1 ≤ cos(n³) ≤ 1. On minore donc : n² − 2n√n cos(n³) ≥ n² − 2n√n = n√n(√n − 2).
Or n√n → +∞ et √n − 2 → +∞, donc le produit → +∞. Par comparaison, la suite tend vers +∞.
Variante : n²(1 − 2cos(n³)/√n), avec |2cos(n³)/√n| ≤ 2/√n → 0 (gendarmes), donc le facteur → 1 et on obtient +∞ × 1 = +∞.
🔧 Outil : un terme borné (cos, sin, (−1)ⁿ) à côté d'un terme qui explose : on borne le cos par ±1 et on compare (ou on factorise le terme dominant).

Exercice 2 — Limites de fonctions (6 pts)

1. lim(x→−∞) (3x⁵ − 6x⁴ + 2x + 1)/(x² + 2x − 3) (1 pt)

Réponse : −∞ On factorise : numérateur 3x⁵(1 − 2/x + …), dénominateur x²(1 + 2/x − 3/x²). Donc f(x) = 3x³ · (1 − 2/x + 2/(3x⁴) + 1/(3x⁵)) / (1 + 2/x − 3/x²). La fraction → 1 et 3x³ → −∞ (x → −∞, puissance impaire). Limite : −∞.

2. lim(x→1) (x² + 4x − 5)/(3x² − 9x + 6) (2 pts)

Réponse : −2 En x = 1 : 1+4−5 = 0 et 3−9+6 = 0 : forme 0/0. On factorise : x²+4x−5 = (x−1)(x+5) ; 3x²−9x+6 = 3(x²−3x+2) = 3(x−1)(x−2).
Pour x ≠ 1 : (x+5)/(3(x−2)) → 6/(3·(−1)) = −2.

3. lim(x→+∞) ( √(x²+4x+3) − √(x²+1) ) (3 pts)

Réponse : 2 Forme ∞ − ∞. Quantité conjuguée :
√(x²+4x+3) − √(x²+1) = ((x²+4x+3) − (x²+1)) / (√(x²+4x+3) + √(x²+1)) = (4x+2)/(√(x²+4x+3) + √(x²+1)).
On divise num. et dén. par x (x > 0, donc √(x²+…)/x = √(1+…/x…)) : (4 + 2/x) / (√(1 + 4/x + 3/x²) + √(1 + 1/x²)) → 4/(1+1) = 2.
🔧 Outil : différence de racines ⇒ quantité conjuguée, puis diviser par la plus grande puissance.

Exercice 3 — Valeurs intermédiaires (5 pts)

1. f : [0,1] → R continue. Montrer que f n'est pas surjective. (2 pts)

Preuve [0,1] est un segment et f est continue, donc f([0,1]) est un segment [m, M] (Théorème de l'image d'un segment) : en particulier f est bornée. L'image f([0,1]) ⊂ [m,M] ne contient pas M + 1, donc M+1 n'a pas d'antécédent : f n'est pas surjective (sur R). ∎
🔧 Outil : « continue sur un segment ⇒ bornée ». Hypothèse « segment » cruciale (sur ]0,1], 1/x est continue et non bornée).

2. g(x) = (x⁵ − 3x + 1)/(x² − x) sur ]0,1[ est surjective. (3 pts)

Preuve x² − x = x(x−1) < 0 sur ]0,1[ (jamais nul), donc g est continue sur ]0,1[.
• en 0⁺ : numérateur → 1, dénominateur → 0⁻ ⇒ g → −∞ ;
• en 1⁻ : numérateur → 1 − 3 + 1 = −1, dénominateur → 0⁻ ⇒ g → +∞.
Soit y ∈ R. Il existe a ∈ ]0,1[ avec g(a) < y et b ∈ ]0,1[ avec g(b) > y. TVI sur [a,b] (a < b ici) : il existe c avec g(c) = y. Donc g est surjective. ∎
🔧 Attention au signe du dénominateur : 0⁻ et non 0⁺ : c'est là que les points se perdent.

Exercice 4 — Bornée (3 pts)

f : R → R bornée, g : R → R continue.

1. f∘g est bornée. (1 pt)

Preuve Il existe M tel que |f(y)| ≤ M pour tout y ∈ R. En particulier |f(g(x))| ≤ M pour tout x. ∎ (La continuité de g ne sert pas.)

2. g∘f est bornée. (2 pts)

Preuve Soit M tel que |f(x)| ≤ M pour tout x : f(R) ⊂ [−M, M]. g est continue sur le segment [−M, M], donc bornée sur ce segment : il existe K tel que |g(y)| ≤ K pour y ∈ [−M, M]. Alors pour tout x, f(x) ∈ [−M, M] donc |g(f(x))| ≤ K. ∎
⚠️ Ici la continuité de g est indispensable et c'est le piège : g continue sur R n'est pas bornée sur R (ex. g(x) = x), c'est le fait que f(R) reste dans un segment qui sauve.

Exercice 5 — Suite récurrente (6 pts)

f : R → R continue, f(0) = 1, f(x) ≠ x pour tout x. uₙ₊₁ = f(uₙ).

1. f(x) > x pour tout x ∈ R. (2 pts)

Preuve Posons φ(x) = f(x) − x : continue sur R, et φ(x) ≠ 0 pour tout x. De plus φ(0) = f(0) − 0 = 1 > 0.
Supposons par l'absurde qu'il existe a avec φ(a) < 0. 0 est entre φ(a) et φ(0) : le TVI donne un point c (entre a et 0) où φ(c) = 0, c'est-à-dire f(c) = c : contradiction. Donc φ > 0 partout : f(x) > x. ∎
🔧 Outil : « continue, ne s'annule jamais » ⇒ signe constant, fixé par une valeur (ici en 0).

2. (uₙ) est strictement croissante. (1 pt)

Preuve Pour tout n : uₙ₊₁ = f(uₙ) > uₙ d'après la question 1 appliquée à x = uₙ. ∎

3. uₙ → +∞. (3 pts)

Preuve (uₙ) est croissante (question 2). Par le théorème de la limite monotone : soit elle converge, soit elle tend vers +∞.
Supposons par l'absurde qu'elle converge vers ℓ ∈ R. Comme f est continue en ℓ, la caractérisation séquentielle donne f(uₙ) → f(ℓ), c'est-à-dire uₙ₊₁ → f(ℓ). Mais uₙ₊₁ → ℓ aussi (sous-suite d'une suite convergente). Par unicité de la limite, f(ℓ) = ℓ : cela contredit l'hypothèse f(x) ≠ x pour tout x.
Donc (uₙ) ne converge pas, et étant croissante, uₙ → +∞. ∎
🔧 Outil : suite récurrente uₙ₊₁ = f(uₙ), f continue : si elle converge, la limite est un point fixe (ℓ = f(ℓ)). Pas de point fixe possible ⇒ pas de convergence.
