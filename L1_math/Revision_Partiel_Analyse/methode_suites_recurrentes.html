🔁 Suites récurrentes uₙ₊₁ = f(uₙ) — la méthode

C'est la fin du chapitre 2 du livre (§5, Prop. 13, 14, 15) et la question typique « difficile » du partiel (ex. 5 du sujet blanc). Elle mélange tout : continuité, limite monotone, point fixe, récurrence.

📌 Les trois résultats du cours 🔴 à savoir
  • Prop. 13 : si f est continue et uₙ → ℓ, alors f(ℓ) = ℓ (point fixe). Preuve : uₙ₊₁ → ℓ et f(uₙ) → f(ℓ) (continuité, caractérisation séquentielle), donc ℓ = f(ℓ) par unicité de la limite.
  • Prop. 14 : f : [a,b] → [a,b] continue et croissante ⇒ pour tout u₀ ∈ [a,b], (uₙ) est monotone, converge vers ℓ ∈ [a,b] avec f(ℓ) = ℓ. (Si u₁ ≥ u₀ : croissante ; si u₁ ≤ u₀ : décroissante.)
  • Prop. 15 : f : [a,b] → [a,b] continue et décroissante ⇒ (u₂ₙ) et (u₂ₙ₊₁) convergent, vers des points fixes de f∘f (qui peuvent être différents).

La méthode en 6 étapes

ÉtapeQuoi faireOutil
1. DessinerTracer le graphe de f et la droite y = x, placer u₀, u₁, u₂… (escalier ou escargot) pour conjecturer : monotone ? limite ?Brouillon

3. MonotonieÉtudier le signe de f(x) − x sur [a,b]. Si f(x) ≥ x alors uₙ₊₁ = f(uₙ) ≥ uₙ : croissante. Ou bien : f croissante et u₁ ≥ u₀ ⇒ croissante par récurrence.Signe de f(x)−x

⚠️ Les 4 pièges
  • Oublier de vérifier f([a,b]) ⊂ [a,b] : c'est l'hypothèse « cachée » de la Prop. 14.
  • Dire « la limite est un point fixe » avant d'avoir prouvé que la suite converge. La Prop. 13 est un « si converge alors… ».
  • Prendre n'importe quel point fixe. Il y en a souvent plusieurs : le bon est celui qui est compatible avec la monotonie et les bornes.
  • Utiliser la Prop. 13 sans continuité de f. Toujours écrire « f est continue ».

Exemple 1 — u₀ = 1, uₙ₊₁ = √(2 + uₙ)

Essaie d'abord : montre que (uₙ) converge et calcule sa limite.

Correction Étape 1. f(x) = √(2+x) est continue et croissante sur [−2,+∞[. Points fixes : √(2+x) = x ⟺ x ≥ 0 et x² = 2+x, i.e. x² − x − 2 = 0, i.e. x = 2 (l'autre racine −1 est négative). On conjecture ℓ = 2.
Étape 2. f([0,2]) ⊂ [0,2] : si 0 ≤ x ≤ 2, √2 ≤ f(x) ≤ √4 = 2. Et u₀ = 1 ∈ [0,2]. Par récurrence, uₙ ∈ [0,2] pour tout n.
Étape 3. u₁ = √3 ≥ 1 = u₀ et f est croissante : par récurrence, uₙ₊₁ ≥ uₙ pour tout n (si uₙ ≥ uₙ₋₁, alors f(uₙ) ≥ f(uₙ₋₁)). Donc (uₙ) est croissante.
Étape 4. Croissante et majorée par 2 : elle converge vers ℓ ∈ [1,2].
Étape 5. f est continue, donc f(ℓ) = ℓ : ℓ = 2 (seule racine ≥ 0). Donc uₙ → 2. ∎

Exemple 2 — u₀ ∈ [0,1], uₙ₊₁ = uₙ − uₙ²

Ici f(x) = x − x² n'est pas croissante sur tout [0,1] : la Prop. 14 ne s'applique pas telle quelle. On fait directement les étapes 2 à 5.

Correction Bornes. Pour x ∈ [0,1], f(x) = x(1−x) ≥ 0 et f(x) = x − x² ≤ x ≤ 1. Donc f([0,1]) ⊂ [0,1] et, par récurrence, uₙ ∈ [0,1] pour tout n.
Monotonie. uₙ₊₁ − uₙ = −uₙ² ≤ 0 : (uₙ) est décroissante.
Convergence. Décroissante et minorée par 0 : elle converge vers ℓ ∈ [0,1].
Limite. f est continue : ℓ = ℓ − ℓ², donc ℓ² = 0, ℓ = 0. ∎
💡 Leçon : pas besoin de la Prop. 14 : borné + monotone suffit, à condition de bien prouver chaque morceau.

Exemple 3 — pas de point fixe : le sujet blanc, ex. 5

f : R → R continue, f(0) = 1, f(x) ≠ x pour tout x, uₙ₊₁ = f(uₙ). Montrer que uₙ → +∞.

Correction (résumé) 1. φ(x) = f(x) − x est continue, ne s'annule jamais, et φ(0) = 1 > 0 : par TVI, φ > 0 partout, i.e. f(x) > x. 2. Alors uₙ₊₁ = f(uₙ) > uₙ : strictement croissante. 3. Si elle convergeait vers ℓ, la Prop. 13 donnerait f(ℓ) = ℓ : impossible. Donc elle ne converge pas, et croissante ⇒ uₙ → +∞. (Correction complète : sujet blanc corrigé.)
💡 Leçon : la Prop. 13 sert aussi dans l'autre sens : pas de point fixe ⇒ pas de convergence.

Exemple 4 — f décroissante : uₙ₊₁ = 1 + 1/uₙ, u₀ > 0 (livre, exemple 18)

Résumé de la méthode f(x) = 1 + 1/x est continue et strictement décroissante sur ]0,+∞[. Donc f∘f est croissante, avec f∘f(x) = (2x+1)/(x+1). Points fixes de f∘f : x² − x − 1 = 0, soit x = (1 ± √5)/2 ; le seul positif est ℓ = (1+√5)/2. Si 0 < u₀ ≤ ℓ : u₂ ≥ u₀ donc (u₂ₙ) est croissante, (u₂ₙ₊₁) décroissante, u₂ₙ ≤ u₂ₙ₊₁, et les deux convergent vers ℓ. Les deux sous-suites ayant la même limite, (uₙ) converge vers (1+√5)/2. (Attention : ]0,+∞[ n'est pas un segment, le livre fait la vérification à la main.)

À toi : entraînement (livre, mini-exercices du §5)

  1. u₀ = 0, uₙ₊₁ = (1/9)uₙ³ + 1 : montrer uₙ ≥ 0, croissante, puis trouver les points fixes de f(x) = x³/9 + 1 et conclure.
  2. u₀ ∈ [0,1], uₙ₊₁ = uₙ − uₙ² (exemple 2 ci-dessus, à refaire sans regarder).
  3. u₀ = 4, uₙ₊₁ = (uₙ + 2)/4 : conjecturer la limite et la prouver.
