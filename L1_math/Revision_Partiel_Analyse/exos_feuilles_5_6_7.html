Feuille 5

Exercice 1 — Parité et monotonie

1. fₙ(x) = xⁿ est-elle paire ou impaire ?

Réponse fₙ(−x) = (−x)ⁿ = (−1)ⁿ xⁿ.
• Si n est pair : fₙ(−x) = xⁿ = fₙ(x), donc paire.
• Si n est impair : fₙ(−x) = −xⁿ = −fₙ(x), donc impaire.
(Pour n = 0, f₀ = 1 est paire.)

🔧 Outil : pour la parité, on calcule toujours f(−x) et on compare à f(x) et −f(x).

2. f et g croissantes : que dire de f+g, f×g, f∘g ?

Réponse • f+g est croissante. Si x ≤ y, alors f(x) ≤ f(y) et g(x) ≤ g(y), on additionne : f(x)+g(x) ≤ f(y)+g(y).
• f×g n'est pas forcément monotone. Contre-exemple : f = g = id (croissantes). Alors f×g : x ↦ x² est décroissante sur ]−∞,0] et croissante sur [0,+∞[ : ni croissante ni décroissante. (On ne peut pas multiplier des inégalités si les nombres sont négatifs.)
• f∘g est croissante. Si x ≤ y, alors g(x) ≤ g(y) (g croissante), puis f(g(x)) ≤ f(g(y)) (f croissante).

🔧 Outil : « croissante » se prouve avec « soient x ≤ y » ; « pas croissante » se prouve avec un contre-exemple.

3. f et g impaires : f+g, f×g, g∘f ?

Réponse • (f+g)(−x) = f(−x)+g(−x) = −f(x)−g(x) = −(f+g)(x) : impaire.
• (f×g)(−x) = (−f(x))(−g(x)) = f(x)g(x) : paire.
• (g∘f)(−x) = g(f(−x)) = g(−f(x)) = −g(f(x)) : impaire.

4. f paire et g impaire : f+g, f×g, g∘f ?

Réponse • f+g : en général ni paire ni impaire. Contre-exemple : f = 1 (paire), g(x) = x (impaire). (f+g)(x) = 1+x, mais (f+g)(−1) = 0, alors que (f+g)(1) = 2 : pas paire (0 ≠ 2) ni impaire (0 ≠ −2).
• (f×g)(−x) = f(x)·(−g(x)) = −(f×g)(x) : impaire.
• (g∘f)(−x) = g(f(−x)) = g(f(x)) = (g∘f)(x) : paire.

🔧 Table de signes à retenir : paire = « +1 », impaire = « −1 ». Pour le produit on multiplie : paire×impaire = impaire, impaire×impaire = paire. Pour la somme, ça marche seulement si les deux ont la même parité.

Exercice 2 — Limites

a) lim(x→−∞) (x³+x²−2x+1)/(x²+1)

Réponse On factorise par le terme dominant : (x³+x²−2x+1)/(x²+1) = x · (1 + 1/x − 2/x² + 1/x³) / (1 + 1/x²).
La fraction tend vers 1 (tous les 1/xᵏ → 0) et x → −∞. Donc la limite vaut −∞.
🔧 Degré num (3) > degré dén (2) : ça tend vers ±∞, le signe est celui de x quand x → −∞.

b) lim(x→1) (2x−2)/(x²+2x−3)

Réponse Forme 0/0. On factorise : x²+2x−3 = (x−1)(x+3) (racines 1 et −3), et 2x−2 = 2(x−1).
Pour x ≠ 1 : (2x−2)/(x²+2x−3) = 2/(x+3) → 2/4 = 1/2.
🔧 0/0 en un point = le facteur (x−x₀) se simplifie.

c) lim(x→+∞) (2cos(x)+1)/x

Réponse cos n'a pas de limite en +∞, mais elle est bornée. Pour x > 0 : |2cos(x)+1| ≤ 3, donc |(2cos x+1)/x| ≤ 3/x → 0. Par le théorème des gendarmes, la limite vaut 0.
🔧 borné ÷ (→ +∞) → 0 : toujours gendarmes avec la majoration de la partie bornée.

Exercice 3 — Preuves sur la parité et la périodicité

1. f impaire ⇒ f(0) = 0.

Preuve Comme f est impaire, f(−0) = −f(0), c'est-à-dire f(0) = −f(0). Donc 2f(0) = 0, soit f(0) = 0. ∎

2. f paire et croissante ⇒ f constante.

Preuve Soit x ≥ 0. Comme 0 ≤ x et f croissante : f(0) ≤ f(x).
Comme −x ≤ 0 et f croissante : f(−x) ≤ f(0). Or f est paire : f(−x) = f(x). Donc f(x) ≤ f(0).
Donc f(x) = f(0) pour tout x ≥ 0. Pour x < 0, f(x) = f(−x) = f(0) (car −x > 0). Donc f est constante égale à f(0). ∎

3. f périodique et croissante ⇒ f constante.

Preuve Soit T > 0 une période : f(x+T) = f(x) pour tout x, donc par récurrence f(x+nT) = f(x) pour tout n ∈ N.
Soient x ≤ y. Par Archimède, il existe n ∈ N tel que nT > y − x, i.e. y ≤ x + nT. Comme f est croissante : f(x) ≤ f(y) ≤ f(x+nT) = f(x). Donc f(y) = f(x). Cela vaut pour tout couple x ≤ y : f est constante. ∎

🔧 Outil : périodicité + Archimède = on peut « remonter » au-dessus de n'importe quel réel en ajoutant des périodes.

Exercice 4 — « Croissante » : global contre local

1. Si ∃δ > 0, ∀x, ∀y ∈ [x, x+δ], f(y) ≥ f(x), alors f est croissante.

Preuve Le δ est le même pour tous les x. Fixons-le.
Soient x ≤ y. Par Archimède, il existe n ∈ N* tel que (y−x)/n ≤ δ. Posons xₖ = x + k(y−x)/n pour k = 0, …, n : on a x₀ = x, xₙ = y, et xₖ₊₁ ∈ [xₖ, xₖ+δ]. L'hypothèse donne f(xₖ₊₁) ≥ f(xₖ) pour chaque k, donc f(y) = f(xₙ) ≥ f(xₙ₋₁) ≥ … ≥ f(x₀) = f(x). ∎

🔧 Outil : découper [x,y] en petits pas de taille ≤ δ.

2. Même hypothèse mais avec δ qui dépend de x (∀x, ∃δ). f est-elle forcément croissante ?

Réponse Non. Contre-exemple : f(x) = 1 si x < 0, f(x) = 0 si x ≥ 0.
• Pour x < 0, on prend δ = |x|/2 : tout y ∈ [x,x+δ] est < 0, donc f(y) = 1 ≥ f(x) = 1.
• Pour x ≥ 0, on prend δ = 1 : f(y) = 0 ≥ f(x) = 0.
Mais f(−1) = 1 > f(0) = 0 avec −1 < 0 : f n'est pas croissante.
💡 Leçon : l'ordre des quantificateurs change tout. ∃δ ∀x (δ uniforme) ≠ ∀x ∃δ (δ dépend de x).

Feuille 6

Exercice 1

1. f : R*₊ → R avec f(x) ≥ x pour tout x > 0. Est-elle croissante ?

Réponse Non. Contre-exemple : f(x) = x + 1/x. On a bien f(x) ≥ x, mais f(1/2) = 5/2 > f(1) = 2 alors que 1/2 < 1 : pas croissante.

2. lim(x→+∞) f(x)/x = 1. A-t-on lim f(x) = +∞ ?

Preuve : oui Prenons ε = 1/2 dans la définition de f(x)/x → 1 : il existe B tel que, pour x ≥ B, |f(x)/x − 1| ≤ 1/2, donc f(x)/x ≥ 1/2. Comme x > 0 : f(x) ≥ x/2.
Soit A > 0. Pour x ≥ max(B, 2A, 1) : f(x) ≥ x/2 ≥ A. Donc f(x) → +∞. ∎
🔧 Outil : « équivalent » à x ⇒ minoré par x/2 dès qu'on est assez loin ⇒ comparaison.

Exercice 2 — Dix limites

a) lim(x→π) cos(x + 3 sin x)

Réponse Composée de fonctions continues sur R, donc continue : on remplace. cos(π + 3·sin π) = cos(π) = −1.

b) lim(x→0) ( cos x + 1/sin(x)² )

Réponse cos x → 1. Et sin(x)² → 0 par valeurs strictement positives (un carré, non nul pour x ≠ 0 proche de 0), donc 1/sin(x)² → +∞. Somme : +∞.

c) lim(x→−∞) (2x⁴−3x²+x)/(x⁴+2x+1)

Réponse Même degré : on divise num. et dén. par x⁴ : (2 − 3/x² + 1/x³)/(1 + 2/x³ + 1/x⁴) → 2/1 = 2.

d) lim(x→+∞) (2x − √x + 1)/(x+2)

Réponse On divise par x (pour x > 0) : (2 − 1/√x + 1/x)/(1 + 2/x) → 2/1 = 2. (Car √x/x = 1/√x → 0.)

e) lim(x→2) (x²−x−2)/(x²−3x+2)

Réponse 0/0. x²−x−2 = (x−2)(x+1) et x²−3x+2 = (x−1)(x−2). Pour x ≠ 2 : (x+1)/(x−1) → 3/1 = 3.

f) lim(x→1) x/(x−1)

Réponse Le numérateur tend vers 1, le dénominateur vers 0 en changeant de signe.
• à droite (x → 1⁺) : x−1 → 0⁺, donc x/(x−1) → +∞ ;
• à gauche (x → 1⁻) : x−1 → 0⁻, donc → −∞.
Les limites latérales sont différentes : pas de limite en 1.

g) lim(x→+∞) ( √(x³+1) − x )

Réponse Forme ∞ − ∞, mais ici on peut minorer : pour x ≥ 1, √(x³+1) ≥ √(x³) = x√x, donc √(x³+1) − x ≥ x√x − x = x(√x − 1) → +∞. Par comparaison, la limite est +∞.
🔧 La quantité conjuguée marche aussi : = (x³+1−x²)/(√(x³+1)+x), équivalent à x³/x^(3/2) = x^(3/2). Mais la minoration directe est plus courte.

h) lim(x→+∞) ( √(4x²+x) − 2√(x²+1) )

Réponse On sépare : √(4x²+x) − 2x et 2x − 2√(x²+1).
• √(4x²+x) − 2x = (4x²+x−4x²)/(√(4x²+x)+2x) = x/(√(4x²+x)+2x) = 1/(√(4+1/x)+2) → 1/4.
• 2x − 2√(x²+1) = 2(x²−(x²+1))/(x+√(x²+1)) = −2/(x+√(x²+1)) → 0.
Somme : 1/4.
🔧 Outil : plusieurs racines ⇒ on les regroupe avec ce qu'il faut pour que chaque morceau se conjugue proprement (ici 2x sert de « pivot »).

i) lim(x→+∞) (x sin x + 1)/(2x²+1)

Réponse Pour x > 0 : |x sin x + 1| ≤ x + 1, donc |…| ≤ (x+1)/(2x²+1) → 0 (degré 1 contre degré 2). Gendarmes : limite 0.

j) lim(x→0) cos(1/x)

Réponse Pas de limite. Deux suites qui tendent vers 0 :
• xₙ = 1/(2nπ) → 0 et cos(1/xₙ) = cos(2nπ) = 1 → 1 ;
• yₙ = 1/(π+2nπ) → 0 et cos(1/yₙ) = cos(π+2nπ) = −1 → −1.
Si une limite ℓ existait, la caractérisation séquentielle donnerait ℓ = 1 et ℓ = −1 : absurde. ∎
🔧 Outil : « pas de limite » ⇒ deux suites vers le même point avec deux limites d'images différentes.

Exercice 3

1. f : [0,1[ → R croissante et majorée, M = sup f([0,1[). Montrer lim(x→1) f(x) = M.

Preuve Soit ε > 0. Comme M − ε < M, le réel M−ε n'est pas un majorant de f([0,1[) (caractérisation de la borne sup) : il existe x₀ ∈ [0,1[ tel que f(x₀) > M − ε.
Posons δ = 1 − x₀ > 0. Pour x ∈ ]x₀, 1[ (soit |x−1| < δ) : f étant croissante, f(x) ≥ f(x₀) > M − ε ; et f(x) ≤ M car M est un majorant. Donc |f(x) − M| ≤ ε. ∎
🔧 Outil : c'est le théorème de la limite monotone pour les fonctions. Même schéma que pour les suites.

2. f : R → R périodique avec ℓ = lim(x→+∞) f(x) ∈ [−∞,+∞] existante. Montrer que f est constante.

Preuve Soit T > 0 une période. Fixons x ∈ R et posons uₙ = x + nT. Alors uₙ → +∞, donc par la caractérisation séquentielle f(uₙ) → ℓ.
Mais f(uₙ) = f(x) pour tout n : la suite est constante égale à f(x), donc converge vers f(x). Par unicité de la limite : ℓ = f(x) (en particulier ℓ est fini).
Cela vaut pour tout x : f(x) = ℓ pour tout x ∈ R, f est constante. ∎

3. f continue en 0 et f(2x) = f(x) pour tout x. Montrer f(x) = f(x/2ⁿ) puis que f est constante.

Preuve (i) Par récurrence sur n ≥ 1, pour x fixé : P(n) : f(x) = f(x/2ⁿ).
• P(1) : l'hypothèse appliquée à x/2 donne f(x) = f(2·(x/2)) = f(x/2).
• Hérédité : si f(x) = f(x/2ⁿ), l'hypothèse appliquée à x/2ⁿ⁺¹ donne f(x/2ⁿ) = f(2·x/2ⁿ⁺¹) = f(x/2ⁿ⁺¹). Donc f(x) = f(x/2ⁿ⁺¹).

(ii) x/2ⁿ → 0 et f est continue en 0, donc par la caractérisation séquentielle f(x/2ⁿ) → f(0). Mais f(x/2ⁿ) = f(x) est constante : sa limite est f(x). Par unicité : f(x) = f(0). Ceci pour tout x : f est constante. ∎
🔧 Outil : équation fonctionnelle + continuité en un point ⇒ on itère pour se rapprocher de ce point.

Exercice 4 — f(x) = ⌊cos x⌋

1. Points de discontinuité cos x ∈ [−1, 1]. Donc ⌊cos x⌋ vaut :
• 1 si et seulement si cos x = 1, i.e. x = 2kπ ;
• 0 si cos x ∈ [0, 1[, i.e. x ∈ [−π/2+2kπ, π/2+2kπ] privé de 2kπ ;
• −1 si cos x ∈ [−1, 0[, i.e. x ∈ ]π/2+2kπ, 3π/2+2kπ[.

Examinons les points où ça change :
• x = 2kπ : f = 1, mais juste à côté cos x < 1 et ≥ 0 donc f = 0 : la limite est 0 ≠ 1 → discontinue.
• x = π/2 + 2kπ : f = 0 (car cos = 0) ; à droite cos < 0 donc f = −1 → limite à droite −1 ≠ 0 → discontinue.
• x = 3π/2 + 2kπ : f = 0 ; à gauche cos < 0 donc f = −1 → discontinue.
• Ailleurs, f est localement constante (par exemple en x = π, cos = −1 et f = −1 autour) : continue.

Réponse : f est discontinue exactement sur {2kπ : k ∈ Z} ∪ {π/2 + kπ : k ∈ Z}.
2. Graphe (de −π à 3π)

Lecture : f = 0 autour de 0 et 2π (mais avec le point isolé f(0) = f(2π) = 1), f = −1 quand cos x < 0. Les points pleins sont les valeurs prises, les ronds vides sont les valeurs non prises.

Feuille 7 — Théorème des valeurs intermédiaires

📌 Rappel : le TVI et ses deux usages TVI : f continue sur [a,b], y entre f(a) et f(b) ⇒ il existe c ∈ [a,b] avec f(c) = y.
Usage 1 — « Il existe x tel que… » : on fabrique φ = (côté gauche) − (côté droit), on montre φ(a) ≥ 0 ≥ φ(b) (ou l'inverse), TVI ⇒ φ(c) = 0.
Usage 2 — « f est surjective » : f(I) est un intervalle ; si f tend vers −∞ d'un côté et +∞ de l'autre, f(I) = R.

Exercice 1

1. Il existe x ∈ ]0, π/2[ tel que cos x = x.

Preuve Posons h(x) = cos x − x, continue sur [0, π/2]. h(0) = 1 > 0 et h(π/2) = −π/2 < 0. Par le TVI, il existe x ∈ [0, π/2] avec h(x) = 0, et comme h(0) ≠ 0 ≠ h(π/2), on a x ∈ ]0, π/2[. ∎

2. f(x) = (x⁸ − 4x⁶ + x + 1)/(x − 1) sur ]1, +∞[ est surjective.

Preuve f est continue sur ]1,+∞[ (fraction rationnelle, dénominateur non nul). Cherchons ses limites aux bords :
• en 1⁺ : numérateur → 1−4+1+1 = −1, dénominateur → 0⁺, donc f → −∞ ;
• en +∞ : f(x) = x⁷ · (1 − 4/x² + 1/x⁷ + 1/x⁸)/(1 − 1/x) → +∞.
Soit y ∈ R. Il existe a > 1 avec f(a) < y et b > 1 avec f(b) > y (par les limites). Comme f est continue sur le segment d'extrémités a et b, le TVI donne un c avec f(c) = y. Donc tout réel a un antécédent : f est surjective. ∎

3. g(x) = x sin x est surjective de R dans R.

Preuve g est continue sur R. Pour k ∈ N :
• g(π/2 + 2kπ) = π/2 + 2kπ (car sin = 1) → +∞ ;
• g(3π/2 + 2kπ) = −(3π/2 + 2kπ) (car sin = −1) → −∞.
Soit y ∈ R. On choisit k assez grand pour que a = π/2+2kπ vérifie g(a) > y et b = 3π/2+2kπ vérifie g(b) < y. TVI sur le segment d'extrémités a, b : il existe c avec g(c) = y. ∎
🔧 Outil : si on ne peut pas calculer la limite (ici g n'a pas de limite), on exhibe deux suites de points où g est très grand / très négatif.

Exercice 2

1. f continue, f(x)² = 1 pour tout x. Alors f ≡ 1 ou f ≡ −1.

Preuve Pour tout x, f(x)² = 1 donne f(x) ∈ {−1, 1}. Supposons par l'absurde qu'il existe a et b avec f(a) = −1 et f(b) = 1. f est continue sur le segment d'extrémités a, b, et 0 est entre −1 et 1 : le TVI donne c avec f(c) = 0, mais alors f(c)² = 0 ≠ 1. Contradiction. Donc f ne prend qu'une seule des deux valeurs : f ≡ 1 ou f ≡ −1. ∎

2. f, g continues avec f(x) ≠ g(x) pour tout x. Alors f < g partout ou f > g partout.

Preuve Posons h = f − g : continue, et h(x) ≠ 0 pour tout x. Si h prenait une valeur > 0 en a et une valeur < 0 en b, le TVI donnerait un zéro de h entre a et b : contradiction. Donc h > 0 partout (f > g) ou h < 0 partout (f < g). ∎
🔧 Outil : « continue qui ne s'annule jamais ⇒ signe constant » (sur un intervalle). C'est le cœur de plein d'exercices.

Exercice 3 — Points fixes

1. f : [a,b] → [a,b] continue ⇒ il existe x avec f(x) = x.

Preuve Posons φ(x) = f(x) − x, continue sur [a,b]. Comme f(a) ∈ [a,b], f(a) ≥ a donc φ(a) ≥ 0. Comme f(b) ≤ b, φ(b) ≤ 0. Donc 0 est entre φ(b) et φ(a) : le TVI donne x ∈ [a,b] avec φ(x) = 0, c'est-à-dire f(x) = x. ∎

2. f : R → R continue : a-t-on forcément un point fixe ?

Réponse Non. f(x) = x + 1 est continue et f(x) = x équivaut à 1 = 0 : jamais. (On a perdu l'hypothèse « f envoie [a,b] dans lui-même ».)

3. f : R → R continue et décroissante ⇒ un unique point fixe.

Preuve Posons φ(x) = f(x) − x : continue et strictement décroissante. En effet si x < y : f(x) ≥ f(y) et −x > −y, donc φ(x) > φ(y).
Existence. Posons a = min(0, f(0) − 1) et b = max(0, f(0) + 1). Comme f est décroissante, a ≤ 0 ⇒ f(a) ≥ f(0), donc φ(a) = f(a) − a ≥ f(0) − a ≥ f(0) − (f(0) − 1) = 1 > 0. De même b ≥ 0 ⇒ f(b) ≤ f(0), donc φ(b) ≤ f(0) − b ≤ f(0) − (f(0)+1) = −1 < 0. Le TVI sur [a,b] donne x avec φ(x) = 0.
Unicité. φ est strictement monotone donc injective : elle s'annule au plus une fois. ∎

Exercice 4

1. φ : [a,b] → R continue avec φ(a) + φ(b) = 0 ⇒ φ s'annule.

Preuve φ(b) = −φ(a) : φ(a) et φ(b) sont opposés (ou nuls), donc 0 est entre φ(a) et φ(b). TVI : il existe x ∈ [a,b] avec φ(x) = 0. ∎

2. f : [a,b] → R continue avec f(a) = f(b) ⇒ il existe x ∈ [a, (a+b)/2] tel que f(x) = f(x + (b−a)/2).

Preuve Posons ψ(x) = f(x) − f(x + (b−a)/2) pour x ∈ [a, (a+b)/2]. L'argument x + (b−a)/2 reste dans [(a+b)/2, b] ⊂ [a,b], donc ψ est bien définie et continue.
ψ(a) = f(a) − f((a+b)/2) et ψ((a+b)/2) = f((a+b)/2) − f(b). Somme : ψ(a) + ψ((a+b)/2) = f(a) − f(b) = 0. La question 1 (appliquée à ψ sur [a, (a+b)/2]) donne x avec ψ(x) = 0. ∎

3. Le randonneur : deux points de même altitude à 36 h d'écart.

Preuve Soit h : [0, 72] → R l'altitude en fonction du temps (en heures). Elle est continue (il ne se téléporte pas) et h(0) = h(72) (retour au départ). On applique la question 2 avec a = 0, b = 72, (b−a)/2 = 36 : il existe t ∈ [0, 36] avec h(t) = h(t + 36). ∎
🧰 Ce qu'on retient de ces trois feuilles
  • Preuve d'« il existe… » → fabrique φ (différence des deux côtés), cherche deux points de signes opposés, TVI.
  • Preuve de « surjective » → continuité + limites (ou deux suites de points) aux deux bouts.
  • « Continue qui ne s'annule pas » → signe constant sur l'intervalle.
  • Limite d'une fonction → factoriser le terme dominant (±∞), simplifier (x−x₀) (0/0), quantité conjuguée (racines), gendarmes (borné × petit).
  • « Pas de limite » → deux suites vers le même point avec deux limites d'images différentes.
  • Équations fonctionnelles (périodique, f(2x) = f(x)) → itérer + caractérisation séquentielle + unicité de la limite.
