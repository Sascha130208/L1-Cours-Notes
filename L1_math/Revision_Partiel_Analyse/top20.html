🎯 Top 20 : ce qui a le plus de chances de tomber

D'où vient cette liste Le prof a dit : « connaître parfaitement les définitions », « savoir refaire les démonstrations simples du cours » et savoir retrouver les limites des feuilles de TD. Le vrai sujet aura la même longueur et la même difficulté que le sujet blanc (27 points pour 20). Cette fiche est une estimation à partir de ces indications, pas une garantie. Imprime-la (1 page A4, Ctrl + P), cache-la, et récris chaque point de mémoire.

🔴 Définitions à réciter mot pour mot

  1. uₙ → ℓ : ∀ε>0, ∃N∈N, ∀n≥N, |uₙ−ℓ| ≤ ε.
  2. uₙ → +∞ : ∀A>0, ∃N∈N, ∀n≥N, uₙ ≥ A. Piège : uₙ ≥ A, pas |uₙ| ≥ A. Tombée au sujet blanc.
  3. sup A = le plus petit des majorants. Caractérisation (Prop. 5) : M = sup A ⟺ (∀x∈A, x ≤ M) et (∀y<M, ∃x∈A, y<x).
  4. Suites adjacentes : (uₙ) croissante, (vₙ) décroissante, vₙ − uₙ → 0.
  5. limx→x₀ f = ℓ : ∀ε>0, ∃δ>0, ∀x∈I, |x−x₀|<δ ⇒ |f(x)−ℓ|<ε. En +∞ : ∀ε>0, ∃B, ∀x≥B, |f(x)−ℓ|<ε.
  6. f continue en x₀ : même définition avec ℓ = f(x₀).

🔴 Énoncés complets (hypothèses + conclusion)

  1. Limite monotone : (uₙ) croissante et majorée ⇒ converge vers sup{uₙ} ; croissante non majorée ⇒ uₙ → +∞. Tombé au sujet blanc.
  2. Adjacentes : elles convergent vers la même limite ℓ, et uₙ ≤ ℓ ≤ vₙ pour tout n.
  3. Bolzano–Weierstrass : toute suite bornée admet une sous-suite convergente.
  4. TVI : f continue sur le segment [a,b], y entre f(a) et f(b) ⇒ ∃c∈[a,b], f(c)=y. Image d'un segment : f continue sur [a,b] ⇒ f([a,b]) = [m,M] (bornée, atteint ses bornes).
  5. Caractérisation séquentielle : f continue en x₀ ⟺ pour toute suite uₙ → x₀, f(uₙ) → f(x₀).

🟠 Preuves courtes à refaire

  1. √2 ∉ Q : par l'absurde, √2 = p/q irréductible ⇒ p² = 2q² ⇒ p pair ⇒ p = 2k ⇒ q² = 2k² ⇒ q pair : contradiction.
  2. Unicité de la limite : par l'absurde ℓ ≠ ℓ', on prend ε = |ℓ−ℓ'|/3. Pour n ≥ max(N, N') : |ℓ−ℓ'| ≤ |ℓ−uₙ| + |uₙ−ℓ'| ≤ 2ε < |ℓ−ℓ'|.
  3. Convergente ⇒ bornée : ε = 1 donne N, puis |uₙ| ≤ |ℓ|+1 pour n ≥ N ; M = max(|u₀|, …, |u_{N−1}|, |ℓ|+1).
  4. uₙ ≤ vₙ et uₙ → +∞ ⇒ vₙ → +∞ : soit A ; ∃N, ∀n ≥ N, uₙ ≥ A ; alors vₙ ≥ uₙ ≥ A. ∎ Le prof l'attend mot pour mot.
  5. Croissante majorée ⇒ converge : ℓ = sup{uₙ} existe (R4). Soit ε : par Prop. 5, ∃N, ℓ−ε < u_N ; pour n ≥ N, ℓ−ε < u_N ≤ uₙ ≤ ℓ.
  6. Récurrente, f continue, uₙ → ℓ ⇒ f(ℓ) = ℓ : uₙ₊₁ → ℓ (sous-suite) et uₙ₊₁ = f(uₙ) → f(ℓ) (séquentielle) ; unicité de la limite.

🛠️ Exercices types

  1. Limites (≈ 6 pts) : fraction en ±∞ → factoriser par le terme dominant ; forme 0/0 en a → factoriser par (x−a) (astuce : r₂ = −b/a − r₁) ; √… − √… → quantité conjuguée puis diviser par x ; cos, sin, (−1)ⁿ → encadrer par ±1 puis comparer ou gendarmes ; « pas de limite » → deux suites (ou sous-suites) de limites différentes.
  2. Signe constant + suite récurrente (sujet blanc ex. 5) : f continue, f(x) ≠ x, f(0) = 1. On pose φ = f − id, continue, jamais nulle, φ(0) = 1 > 0. S'il existait a avec φ(a) < 0, le TVI donnerait un zéro : absurde. Donc f(x) > x, (uₙ) est croissante ; si elle convergeait, sa limite serait un point fixe (n° 17) : absurde. Donc uₙ → +∞ (n° 7).
  3. Surjectivité / bornée : surjective sur ]a,b[ : continuité, limites aux bornes (signe de 0⁻ / 0⁺), puis, pour y donné, trouver α avec g(α) ≤ y et β avec g(β) ≥ y et appliquer le TVI du cours sur [α,β] (pas de « TVI avec limites ») ; continue sur un segment ⇒ bornée ⇒ pas surjective sur R (y = M+1) ; g∘f bornée : f(R) ⊂ [−M, M] et g continue sur ce segment est bornée.

⚠️ Les contre-exemples à avoir en tête

  1. (−1)ⁿ : bornée mais divergente. 1/x sur ]0,1] : continue mais pas bornée (il faut un segment). g(x) = x : continue sur R mais pas bornée. A = {1 − 1/n} : sup = 1, pas de max.
