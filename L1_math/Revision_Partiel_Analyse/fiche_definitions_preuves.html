💡 Code des étiquettes 🔴 À savoir mot pour mot définition ou énoncé à réciter exactement. 🟠 Preuve à refaire démonstration courte et « simple ». 🟢 À comprendre preuve longue : en connaître l'idée suffit.
« Prop. 5 » veut dire « Proposition 5 du chapitre en cours » dans le livre.
⚠️ Piège de rédaction : « < » ou « ≤ » ? Le livre écrit la limite d'une suite avec |uₙ − ℓ| ≤ ε (large), mais la limite d'une fonction et la continuité avec |x − x₀| < δ ⇒ |f(x) − ℓ| < ε (stricts). Les deux versions sont équivalentes (remarque du livre). Au partiel, écris celle du cours : tu es sûr d'avoir tout bon.

CHAPITRE 1 — Les nombres réels

1.1 Définitions et énoncés 🔴

📌 À réciter
  • ℚ = { p/q | p ∈ Z, q ∈ N* }. Prop. 1 : un nombre est rationnel ⟺ son écriture décimale est finie ou périodique.
  • Prop. 2 : √2 ∉ Q.
  • Propriété (R1) : (R, +, ×) est un corps commutatif.
  • Déf. 2 — relation d'ordre sur E : relation réflexive (x ≼ x), antisymétrique (x≼y et y≼x ⇒ x=y), transitive (x≼y et y≼z ⇒ x≼z). Déf. 3 — totale : pour tous x, y, x ≼ y ou y ≼ x. (R2) : ≤ est un ordre total sur R.
  • Compatibilité avec l'ordre : a≤b et c≥0 ⇒ ac ≤ bc ; a≤b et c≤0 ⇒ ac ≥ bc.
  • (R3) Propriété d'Archimède : ∀x ∈ R, ∃n ∈ N, n > x.
  • Prop. 3 — partie entière : pour x ∈ R il existe un unique entier relatif E(x) tel que E(x) ≤ x < E(x) + 1.
  • Valeur absolue : |x| = x si x ≥ 0, |x| = −x si x < 0. Prop. 4 : |x| ≥ 0 ; |−x| = |x| ; |x| > 0 ⟺ x ≠ 0 ; √(x²) = |x| ; |xy| = |x||y| ; inégalité triangulaire |x+y| ≤ |x|+|y| ; seconde ||x|−|y|| ≤ |x−y|. Et |x−a| < r ⟺ a−r < x < a+r.
  • Déf. 4 — intervalle : sous-ensemble I ⊂ R tel que ∀a,b ∈ I, ∀x ∈ R, (a ≤ x ≤ b ⇒ x ∈ I). Déf. 5 : intervalle ouvert = ensemble ]a,b[ = {x : a < x < b}.
  • Déf. 6 — voisinage : V est un voisinage de a s'il existe un intervalle ouvert I avec a ∈ I et I ⊂ V.
  • Théorème 1 — densité : (1) Q est dense dans R : tout intervalle ouvert non vide contient une infinité de rationnels ; (2) R∖Q est dense dans R : une infinité d'irrationnels.
  • Déf. 7 — plus grand élément de A (partie non vide) : α ∈ A et ∀x ∈ A, x ≤ α ; noté max A, unique s'il existe. Plus petit élément : α ∈ A et ∀x ∈ A, x ≥ α.
  • Déf. 8 : M est un majorant de A si ∀x ∈ A, x ≤ M ; m est un minorant si ∀x ∈ A, x ≥ m. A est majorée / minorée si elle a un majorant / minorant ; bornée si les deux.
  • Déf. 9 — borne supérieure : α est la borne sup de A si c'est un majorant de A et le plus petit des majorants. Idem inf A : le plus grand des minorants.
  • Théorème 2 (R4) : toute partie de R non vide et majorée admet une borne supérieure ; toute partie non vide et minorée admet une borne inférieure.
  • Prop. 5 — caractérisation de sup A : c'est l'unique réel tel que (i) si x ∈ A alors x ≤ sup A, et (ii) pour tout y < sup A il existe x ∈ A avec y < x.
  • Prop. 6 — autre caractérisation : sup A est l'unique réel tel que (i) c'est un majorant de A et (ii) il existe une suite (xₙ) d'éléments de A qui converge vers sup A. (Très utile : elle sert dans la preuve du TVI.)

1.2 Preuves 🟠

P1. Prop. 2 — √2 ∉ Q (par l'absurde) 🟠 Supposons √2 = p/q avec p ∈ Z, q ∈ N* premiers entre eux (ce sera important). Alors 2q² = p². Donc p² est pair, donc p est pair (si p était impair, p² le serait) : p = 2p'. Alors 2q² = 4p'², soit q² = 2p'² : q² est pair, donc q est pair. Ainsi 2 divise p et q : contradiction avec « premiers entre eux ». Donc √2 ∉ Q. ∎
P2. Prop. 3 — existence et unicité de la partie entière 🟠 Existence (pour x ≥ 0). Par Archimède, il existe n ∈ N avec n > x. L'ensemble K = {k ∈ N : k ≤ x} est fini (ses éléments sont < n) et non vide (0 ∈ K) : il a un plus grand élément k_max. On a k_max ≤ x (car k_max ∈ K) et k_max + 1 > x (car k_max + 1 ∉ K). On prend E(x) = k_max.
Unicité. Si k ≤ x < k+1 et ℓ ≤ x < ℓ+1 (entiers), alors k ≤ x < ℓ+1 donc k < ℓ+1, et de même ℓ < k+1. Donc ℓ − 1 < k < ℓ + 1 : le seul entier strictement entre ℓ−1 et ℓ+1 est ℓ, donc k = ℓ. ∎
P3. Prop. 4 — inégalités triangulaires 🟠 On a −|x| ≤ x ≤ |x| et −|y| ≤ y ≤ |y|. En additionnant : −(|x|+|y|) ≤ x+y ≤ |x|+|y|, d'où |x+y| ≤ |x|+|y|.
Seconde : comme x = (x−y)+y, la première inégalité donne |x| ≤ |x−y| + |y|, donc |x|−|y| ≤ |x−y|. En échangeant x et y : |y|−|x| ≤ |y−x| = |x−y|. Donc ||x|−|y|| ≤ |x−y|. ∎
P4. Théorème 1 — densité de Q et de R∖Q 🟠 Un rationnel dans ]a,b[ (a < b). Par Archimède, il existe un entier q > 1/(b−a) ; comme b−a > 0, q ∈ N*. Posons p = E(aq) + 1. Alors p − 1 ≤ aq < p, donc a < p/q ; et p/q ≤ a + 1/q < a + (b−a) = b. Donc p/q ∈ ]a,b[.
Un irrationnel dans ]a,b[. On applique ce qui précède à ]a−√2, b−√2[ : il y a un rationnel r dedans, donc r + √2 ∈ ]a,b[. Il est irrationnel : sinon √2 = (r+√2) − r serait rationnel (différence de rationnels), ce qui contredit P1.
Une infinité. On découpe ]a,b[ en N sous-intervalles ouverts disjoints, chacun contient un rationnel et un irrationnel : donc au moins N de chaque, pour tout N. ∎
P5. Prop. 5 — caractérisation de la borne supérieure 🟠 (⇒) sup A est un majorant, donc (i). Pour (ii), fixons y < sup A : comme sup A est le plus petit majorant, y n'est pas un majorant, donc il existe x ∈ A avec y < x.
(⇐) Soit α vérifiant (i) et (ii). Par (i), α est un majorant. Si ce n'était pas le plus petit, il existerait un majorant y < α ; par (ii), il existe x ∈ A avec y < x, ce qui contredit « y majorant ». Donc α = sup A. ∎
P6. Exemple 9 — A = {1 − 1/n : n ∈ N*} : sup A = 1, min A = 0, pas de max 🟠 sup A = 1 par la caractérisation (Prop. 5). (i) Pour tout n, 1 − 1/n < 1 : 1 est un majorant. (ii) Soit y < 1. On prend n tel que 1/n < 1 − y (Archimède, n > 1/(1−y)). Alors y < 1 − 1/n et 1 − 1/n ∈ A.
min A = 0 : 0 = 1 − 1/1 ∈ A et 1 − 1/n ≥ 0 pour tout n ≥ 1.
Pas de max : si α = max A, alors α ∈ A donc α = 1 − 1/n₀ < 1 ; mais α est un majorant donc α ≥ sup A = 1. Contradiction. ∎
P7. Prop. 3 (Feuille 1) — les « calculs de sup » : −A, A∪B, A+B 🟠 Schéma toujours le même : (1) montrer que la valeur proposée est un majorant ; (2) montrer qu'on ne peut pas faire plus petit, avec la caractérisation « ∀ε > 0, ∃x ∈ A, x > M − ε ».
Exemple : sup(A+B) = sup A + sup B. (1) Pour a ∈ A, b ∈ B : a + b ≤ sup A + sup B. (2) Soit ε > 0 : il existe a ∈ A avec a > sup A − ε/2 et b ∈ B avec b > sup B − ε/2, donc a + b > sup A + sup B − ε. ∎

CHAPITRE 2 — Les suites

2.1 Définitions et énoncés 🔴

📌 À réciter
  • Déf. 1 : une suite est une application u : N → R ; uₙ = u(n) est le terme général.
  • Déf. 2 : (uₙ) est majorée si ∃M ∈ R, ∀n, uₙ ≤ M ; minorée si ∃m, ∀n, uₙ ≥ m ; bornée si majorée et minorée, c'est-à-dire ∃M, ∀n, |uₙ| ≤ M.
  • Déf. 3 : croissante si ∀n, uₙ₊₁ ≥ uₙ ; strictement croissante si uₙ₊₁ > uₙ ; décroissante / strictement décroissante avec ≤ / < ; monotone si croissante ou décroissante.
  • Déf. 4 — limite finie : (uₙ) a pour limite ℓ ∈ R si ∀ε > 0, ∃N ∈ N, ∀n ∈ N, (n ≥ N ⇒ |uₙ − ℓ| ≤ ε). (Le N dépend de ε : on ne peut pas échanger « pour tout » et « il existe ».)
  • Déf. 5 — limite infinie : uₙ → +∞ si ∀A > 0, ∃N, ∀n ≥ N, uₙ ≥ A. uₙ → −∞ si ∀A > 0, ∃N, ∀n ≥ N, uₙ ≤ −A.
  • Déf. 6 : convergente = admet une limite finie ; divergente sinon (tend vers ±∞, ou n'a pas de limite).
  • Prop. 1 : si une suite converge, sa limite est unique.
  • Prop. 2 : uₙ → ℓ ⟺ (uₙ − ℓ) → 0 ⟺ |uₙ − ℓ| → 0 ; et uₙ → ℓ ⇒ |uₙ| → |ℓ|.
  • Prop. 3 — opérations (suites convergentes) : λuₙ → λℓ ; uₙ + vₙ → ℓ + ℓ' ; uₙ × vₙ → ℓℓ' ; si ℓ ≠ 0, uₙ ≠ 0 à partir d'un rang et 1/uₙ → 1/ℓ.
  • Prop. 4 — limites infinies : si vₙ → +∞ : (1) 1/vₙ → 0 ; (2) si (uₙ) minorée, uₙ + vₙ → +∞ ; (3) si (uₙ) minorée par λ > 0, uₙ × vₙ → +∞ ; (4) si uₙ → 0 avec uₙ > 0 à partir d'un rang, 1/uₙ → +∞.
  • Formes indéterminées : +∞ − ∞, 0 × ∞, ∞/∞, 0/0, 1^∞, ∞⁰ : étude au cas par cas.
  • Prop. 5 (= Prop. 11) : toute suite convergente est bornée. (La réciproque est fausse : (−1)ⁿ.)
  • Prop. 6 : (uₙ) bornée et vₙ → 0 ⇒ uₙvₙ → 0.
  • Prop. 7 — limites et inégalités : (1) uₙ ≤ vₙ pour tout n, les deux convergent ⇒ lim uₙ ≤ lim vₙ ; (2) uₙ → +∞ et vₙ ≥ uₙ ⇒ vₙ → +∞ ; (3) gendarmes : uₙ ≤ vₙ ≤ wₙ, lim uₙ = ℓ = lim wₙ ⇒ (vₙ) converge et lim vₙ = ℓ. Remarque : uₙ > 0 et converge ⇒ lim ≥ 0 seulement (ex. 1/(n+1)).
  • Prop. 8 — suite géométrique aⁿ : a = 1 constante ; a > 1 : → +∞ ; −1 < a < 1 : → 0 ; a ≤ −1 : diverge.
  • Prop. 9 — série géométrique : pour a ≠ 1, 1 + a + … + aⁿ = (1 − aⁿ⁺¹)/(1 − a). Si |a| < 1, cela tend vers 1/(1−a).
  • Théorème 1 — critère du rapport : (uₙ) suite de réels non nuls, s'il existe ℓ tel que |uₙ₊₁/uₙ| < ℓ < 1 (à partir d'un rang), alors uₙ → 0. Cor. 1 : si |uₙ₊₁/uₙ| → 0, alors uₙ → 0. Si le rapport est > ℓ > 1, la suite diverge (|uₙ| → +∞) ; si ℓ = 1, on ne peut rien dire.
  • Exemple 9 : aⁿ/n! → 0 pour tout a ∈ R.
  • Prop. 10 : pour a ∈ R, uₙ = E(10ⁿa)/10ⁿ vérifie 0 ≤ a − uₙ < 1/10ⁿ ; donc uₙ → a (approximation décimale).
  • Théorème 2 — suite monotone : toute suite croissante et majorée converge. Aussi : décroissante minorée converge ; croissante non majorée ⇒ → +∞ ; décroissante non minorée ⇒ → −∞.
  • Déf. 7 — suites adjacentes : (1) (uₙ) croissante et (vₙ) décroissante ; (2) uₙ ≤ vₙ pour tout n ; (3) lim(vₙ − uₙ) = 0. Théorème 3 : deux suites adjacentes convergent vers la même limite ℓ (et uₙ ≤ ℓ ≤ vₙ).
  • Déf. 8 — suite extraite (sous-suite) : (u_φ(n)) où φ : N → N est strictement croissante. Prop. 12 / Cor. 2 : si uₙ → ℓ, toute sous-suite tend vers ℓ ; donc une suite avec deux sous-suites de limites différentes diverge. Théorème 4 (Bolzano-Weierstrass) : toute suite bornée admet une sous-suite convergente.
  • Suite récurrente : u₀ ∈ R, uₙ₊₁ = f(uₙ). Prop. 13 : si f est continue et uₙ → ℓ, alors f(ℓ) = ℓ (ℓ est un point fixe). Prop. 14 : si f : [a,b] → [a,b] est continue et croissante, alors pour tout u₀ ∈ [a,b] la suite est monotone et converge vers ℓ ∈ [a,b] avec f(ℓ) = ℓ. Prop. 15 : si f : [a,b] → [a,b] est continue et décroissante, alors (u₂ₙ) et (u₂ₙ₊₁) convergent vers des points fixes de f∘f (pas forcément égaux). Méthode complète : page « suites récurrentes ».
  • Négation à savoir faire : « uₙ ne tend pas vers +∞ » ⟺ ∃A > 0, ∀N, ∃n ≥ N, uₙ < A.

2.2 Preuves 🟠

P8. Prop. 1 — unicité de la limite (par l'absurde) 🟠 Soit (uₙ) convergente avec deux limites ℓ ≠ ℓ'. Choisissons ε > 0 avec ε < |ℓ − ℓ'|/2. Il existe N₁ tel que n ≥ N₁ ⇒ |uₙ − ℓ| < ε et N₂ tel que n ≥ N₂ ⇒ |uₙ − ℓ'| < ε. Pour N = max(N₁, N₂) : |ℓ − ℓ'| ≤ |ℓ − u_N| + |u_N − ℓ'| < 2ε < |ℓ − ℓ'|. Contradiction : donc ℓ = ℓ'. ∎
P9. Prop. 4.1 — si uₙ → +∞ alors 1/uₙ → 0 🟠 Soit ε > 0. Comme uₙ → +∞, il existe N tel que n ≥ N ⇒ uₙ ≥ 1/ε. Donc 0 ≤ 1/uₙ ≤ ε pour n ≥ N. ∎
P10. Prop. 5 — convergente ⇒ bornée 🟠 Avec ε = 1 : il existe N tel que pour n ≥ N, |uₙ − ℓ| ≤ 1, donc |uₙ| = |ℓ + (uₙ − ℓ)| ≤ |ℓ| + 1. En posant M = max(|u₀|, …, |u_{N−1}|, |ℓ|+1), on a |uₙ| ≤ M pour tout n. ∎
P11. Prop. 6 — borné × tend vers 0 → 0 🟠 Soit M > 0 avec |uₙ| ≤ M pour tout n. Soit ε > 0 ; on applique la définition de vₙ → 0 avec ε' = ε/M : il existe N tel que n ≥ N ⇒ |vₙ| ≤ ε/M. Alors |uₙvₙ| = |uₙ||vₙ| ≤ M · ε/M = ε. ∎
P12. Prop. 3 — limite d'un produit (utilise P10 et P11) 🟠 On écrit uₙvₙ − ℓℓ' = (uₙ − ℓ)vₙ + ℓ(vₙ − ℓ'). Le terme ℓ(vₙ − ℓ') tend vers 0. Et (uₙ − ℓ)vₙ → 0 par la Prop. 6, car (vₙ) converge donc est bornée (Prop. 5) et uₙ − ℓ → 0. Donc uₙvₙ − ℓℓ' → 0, soit uₙvₙ → ℓℓ'. ∎
La somme se fait directement avec ε/2 : |(uₙ+vₙ) − (ℓ+ℓ')| ≤ |uₙ−ℓ| + |vₙ−ℓ'| ≤ ε/2 + ε/2.
P13. Prop. 7 — limites et inégalités 🟠 (1) On pose wₙ = vₙ − uₙ ≥ 0, convergente. Si ℓ = lim wₙ < 0, on prend ε = |ℓ|/2 = −ℓ/2 : il existe N avec n ≥ N ⇒ |wₙ − ℓ| < ε, donc wₙ < ℓ + ε = ℓ/2 < 0 : contradiction avec wₙ ≥ 0. Donc lim wₙ ≥ 0.
(2) Pour A > 0, il existe N avec uₙ ≥ A pour n ≥ N ; alors vₙ ≥ uₙ ≥ A.
(3) Gendarmes. En retranchant uₙ on se ramène à 0 ≤ uₙ ≤ vₙ avec vₙ → 0 : pour ε > 0, il existe N tel que n ≥ N ⇒ |vₙ| < ε ; comme |uₙ| = uₙ ≤ vₙ = |vₙ|, on a |uₙ| < ε. ∎ (Version directe : ℓ − ε ≤ uₙ ≤ vₙ ≤ wₙ ≤ ℓ + ε à partir d'un rang.)
P14. Prop. 8 — suite géométrique (inégalité de Bernoulli) 🟠 a > 1. On écrit a = 1 + b avec b > 0. Par le binôme de Newton, tous les termes sont positifs, donc aⁿ = (1+b)ⁿ ≥ 1 + nb → +∞.
|a| < 1, a ≠ 0. On pose c = 1/|a| > 1 : cⁿ → +∞ donc |a|ⁿ = 1/cⁿ → 0, donc aⁿ → 0.
a ≤ −1. Si aⁿ → ℓ : a²ⁿ ≥ 1 donne ℓ ≥ 1, et a²ⁿ⁺¹ ≤ a ≤ −1 donne ℓ ≤ −1 : contradiction. ∎
P15. Prop. 9 — somme géométrique 🟠 (1 − a)(1 + a + … + aⁿ) = (1 + a + … + aⁿ) − (a + a² + … + aⁿ⁺¹) = 1 − aⁿ⁺¹ (somme télescopique). On divise par 1 − a ≠ 0. ∎
P16. Théorème 1 — critère du rapport 🟠 Supposons |uₙ₊₁/uₙ| < ℓ < 1 pour tout n (à partir d'un rang N on fait pareil). Alors |uₙ| = |u₀| · |u₁/u₀| · |u₂/u₁| ⋯ |uₙ/uₙ₋₁| < |u₀| ℓⁿ. Comme 0 ≤ ℓ < 1, ℓⁿ → 0 (Prop. 8), donc par gendarmes uₙ → 0. ∎
Exemple 9 : aⁿ/n! → 0. Si a ≠ 0, uₙ₊₁/uₙ = a/(n+1) → 0 : on applique le Cor. 1.
P17. Théorème 2 — croissante majorée ⇒ converge 🟠 L'ensemble A = {uₙ : n ∈ N} est non vide et majoré : il a une borne sup ℓ (Théorème 2, ch. 1). Soit ε > 0. Par la caractérisation (Prop. 5), il existe N tel que ℓ − ε < u_N ≤ ℓ. Comme (uₙ) est croissante, pour n ≥ N : ℓ − ε < u_N ≤ uₙ ≤ ℓ, donc |uₙ − ℓ| ≤ ε. ∎
Non majorée ⇒ +∞ : pour tout A il existe N avec u_N ≥ A, puis uₙ ≥ u_N ≥ A pour n ≥ N.
P18. Les deux exemples : ζ(2) converge, la suite harmonique diverge 🟠 ζ(2) : uₙ = 1 + 1/2² + … + 1/n². Croissante (uₙ₊₁ − uₙ = 1/(n+1)² > 0). Par récurrence uₙ ≤ 2 − 1/n : vrai pour n = 1 (1 ≤ 1) ; si vrai au rang n, uₙ₊₁ ≤ 2 − 1/n + 1/(n+1)² et 1/(n+1)² ≤ 1/(n(n+1)) = 1/n − 1/(n+1), donc uₙ₊₁ ≤ 2 − 1/(n+1). Croissante majorée par 2 : elle converge.
Harmonique : uₙ = 1 + 1/2 + … + 1/n. Croissante. u₂ₙ − uₙ = 1/(n+1) + … + 1/(2n) ≥ n · 1/(2n) = 1/2 (n termes, chacun ≥ 1/(2n)). Si uₙ → L ∈ R, alors u₂ₙ → L (sous-suite) et u₂ₙ − uₙ → 0 : contradiction. Donc elle diverge ; croissante, elle tend vers +∞. ∎
P19. Théorème 3 — suites adjacentes 🟠 (uₙ) est croissante et majorée par v₀ (car uₙ ≤ vₙ ≤ v₀) : elle converge vers ℓ. (vₙ) est décroissante et minorée par u₀ : elle converge vers ℓ'. Alors ℓ' − ℓ = lim(vₙ − uₙ) = 0, donc ℓ = ℓ'. (Et uₙ ≤ ℓ ≤ vₙ pour tout n.) ∎
Exemple 12 : uₙ = Σ 1/k² et vₙ = uₙ + 2/(n+1) sont adjacentes ; ou, comme dans la feuille 3, Tₙ = Sₙ + 1/n.
P20. Prop. 12 — sous-suite d'une suite convergente 🟠 Comme φ est strictement croissante de N dans N, φ(n) ≥ n pour tout n (récurrence). Si uₙ → ℓ : pour ε > 0, il existe N avec k ≥ N ⇒ |u_k − ℓ| ≤ ε ; pour n ≥ N, φ(n) ≥ N donc |u_φ(n) − ℓ| ≤ ε. ∎
Exemple : (−1)ⁿ diverge : u₂ₙ = 1 et u₂ₙ₊₁ = −1.
P21. Prop. 13 — suite récurrente convergente : la limite est un point fixe 🟠 Quand n → +∞, uₙ → ℓ et donc aussi uₙ₊₁ → ℓ. Comme f est continue en ℓ et uₙ → ℓ, on a f(uₙ) → f(ℓ) (Prop. 7 du ch. 3). La relation uₙ₊₁ = f(uₙ) donne à la limite ℓ = f(ℓ) (unicité de la limite). ∎
P22. Prop. 14 — f continue croissante de [a,b] dans [a,b] 🟠 Si u₁ ≥ u₀, alors comme f est croissante, u₂ = f(u₁) ≥ f(u₀) = u₁, et par récurrence (uₙ) est croissante (si u₁ ≤ u₀, décroissante). Elle est majorée par b (resp. minorée par a), donc converge vers ℓ ∈ [a,b], et f(ℓ) = ℓ par la Prop. 13. ∎ (L'hypothèse cachée : f([a,b]) ⊂ [a,b], à vérifier toujours.)
P23. Théorème 4 — Bolzano-Weierstrass (idée) 🟢 Les termes sont dans un segment [a₀,b₀]. On coupe en deux ; une moitié contient uₙ pour une infinité d'indices : on la garde, [a₁,b₁], et on choisit un indice φ(1) > φ(0) avec u_φ(1) ∈ [a₁,b₁]. En itérant : intervalles [aₙ,bₙ] de longueur (b−a)/2ⁿ, (aₙ) croissante, (bₙ) décroissante, donc adjacentes, de même limite ℓ. Par gendarmes, u_φ(n) → ℓ.

CHAPITRE 3 — Limites et fonctions continues

3.1 Définitions et énoncés 🔴

📌 À réciter
  • Déf. 1 : une fonction f : U → R (U ⊂ R, souvent un intervalle), U = domaine de définition. Graphe : Γ_f = {(x, f(x)) | x ∈ U}.
  • Déf. 2/3 : f ≥ g si ∀x, f(x) ≥ g(x) ; majorée sur U : ∃M, ∀x ∈ U, f(x) ≤ M ; minorée ; bornée : ∃M, ∀x ∈ U, |f(x)| ≤ M.
  • Déf. 4 : croissante sur U : ∀x,y ∈ U, x ≤ y ⇒ f(x) ≤ f(y) ; strictement croissante : x < y ⇒ f(x) < f(y) ; décroissante : x ≤ y ⇒ f(x) ≥ f(y) ; monotone : croissante ou décroissante.
  • Déf. 5 : I intervalle symétrique par rapport à 0 ; paire : f(−x) = f(x) (graphe symétrique par rapport à l'axe des ordonnées) ; impaire : f(−x) = −f(x) (graphe symétrique par rapport à l'origine).
  • Déf. 6 : f : R → R est périodique de période T > 0 si ∀x, f(x+T) = f(x).
  • Déf. 7 — limite finie en x₀ : ∀ε > 0, ∃δ > 0, ∀x ∈ I, (|x − x₀| < δ ⇒ |f(x) − ℓ| < ε).
  • Déf. 8 — limite +∞ en x₀ : ∀A > 0, ∃δ > 0, ∀x ∈ I, (|x − x₀| < δ ⇒ f(x) > A). (−∞ : f(x) < −A.)
  • Déf. 9 — limite en +∞ : limite ℓ : ∀ε > 0, ∃B > 0, ∀x ∈ I, (x > B ⇒ |f(x) − ℓ| < ε) ; limite +∞ : ∀A > 0, ∃B > 0, ∀x ∈ I, (x > B ⇒ f(x) > A).
  • Limites usuelles : xⁿ → +∞ en +∞ ; en −∞ : +∞ si n pair, −∞ si n impair ; 1/xⁿ → 0 en ±∞. Fraction rationnelle (coeff. dominants aₙ, b_m > 0) en +∞ : +∞ si n > m, aₙ/b_m si n = m, 0 si n < m.
  • Déf. 10 — limite à droite / à gauche en x₀ : limite de la restriction de f à ]x₀,b[ (resp. ]a,x₀[), notée lim_{x→x₀⁺} / lim_{x→x₀⁻}. Si f a une limite en x₀, les limites à gauche et à droite coïncident. Exemple 8 : E n'a pas de limite en 2 (1 à gauche, 2 à droite).
  • Prop. 1 : unicité de la limite. Prop. 2 : opérations (λf, f+g, f×g, 1/f si ℓ ≠ 0 ; si f → ±∞, 1/f → 0). Prop. 3 : composition : lim_{x₀} f = ℓ et lim_ℓ g = ℓ' ⇒ lim_{x₀} g∘f = ℓ'. Prop. 4 : f ≤ g ⇒ ℓ ≤ ℓ' ; f ≤ g et f → +∞ ⇒ g → +∞ ; gendarmes.
  • Déf. 11 — continuité en x₀ ∈ I : ∀ε > 0, ∃δ > 0, ∀x ∈ I, (|x − x₀| < δ ⇒ |f(x) − f(x₀)| < ε), c'est-à-dire f admet une limite en x₀ (qui vaut alors f(x₀)). Continue sur I : continue en tout point de I.
  • Fonctions continues connues : constantes, √x sur [0,+∞[, sin, cos, |x|, exp sur R, ln sur ]0,+∞[, polynômes, fractions rationnelles (où le dénominateur ne s'annule pas). La partie entière E n'est pas continue aux entiers.
  • Lemme 1 — signe local : f continue en x₀ et f(x₀) ≠ 0 ⇒ ∃δ > 0, ∀x ∈ ]x₀−δ, x₀+δ[, f(x) ≠ 0.
  • Prop. 5 : somme, produit, λf, 1/f (si f(x₀) ≠ 0) de fonctions continues en x₀ : continues en x₀. Prop. 6 : f : I → R, g : J → R, f(I) ⊂ J, f continue en x₀ et g continue en f(x₀) ⇒ g∘f continue en x₀.
  • Déf. 12 — prolongement par continuité : f : I∖{x₀} → R est prolongeable par continuité en x₀ si f a une limite finie ℓ en x₀ ; on pose f̃(x₀) = ℓ et f̃(x) = f(x) ailleurs.
  • Prop. 7 — caractérisation séquentielle : f est continue en x₀ ⟺ pour toute suite (uₙ) qui converge vers x₀, la suite (f(uₙ)) converge vers f(x₀).
  • Théorème 1 — TVI : f : [a,b] → R continue sur un segment ; pour tout réel y compris entre f(a) et f(b), il existe c ∈ [a,b] tel que f(c) = y. Cor. 1 : si f(a)·f(b) < 0, il existe c ∈ ]a,b[ avec f(c) = 0. Cor. 2 : f continue sur un intervalle I ⇒ f(I) est un intervalle. (Attention : f([a,b]) n'est pas forcément [f(a), f(b)].)
  • Théorème 2 : f : [a,b] → R continue ⇒ il existe m, M avec f([a,b]) = [m,M] : l'image d'un segment est un segment ; f est bornée et atteint ses bornes.
  • Déf. 13 : injective : f(x) = f(x') ⇒ x = x' ; surjective : ∀y ∈ F, ∃x ∈ E, y = f(x) ; bijective : les deux, i.e. ∀y, ∃!x, y = f(x). Prop. 8 : si f bijective, il existe une unique g = f⁻¹ avec g∘f = id_E et f∘g = id_F.
  • Théorème 3 — de la bijection : f : I → R continue et strictement monotone sur l'intervalle I ⇒ (1) f est une bijection de I sur l'intervalle J = f(I) ; (2) f⁻¹ : J → I est continue, strictement monotone, de même sens de variation que f. Lemme 2 : strictement monotone ⇒ injective.

3.2 Preuves 🟠

P24. Prop. 7 — caractérisation séquentielle de la continuité (⇒ et ⇐) 🟠 (⇒) Soit f continue en x₀ et uₙ → x₀. Soit ε > 0 : il existe δ > 0 tel que |x − x₀| < δ ⇒ |f(x) − f(x₀)| < ε. Pour ce δ, il existe N tel que n ≥ N ⇒ |uₙ − x₀| < δ. Donc pour n ≥ N, |f(uₙ) − f(x₀)| < ε : f(uₙ) → f(x₀).
(⇐) Par contraposée : si f n'est pas continue en x₀, alors ∃ε₀ > 0, ∀δ > 0, ∃x_δ ∈ I, |x_δ − x₀| < δ et |f(x_δ) − f(x₀)| > ε₀. Avec δ = 1/n, on obtient uₙ avec |uₙ − x₀| < 1/n (donc uₙ → x₀) et |f(uₙ) − f(x₀)| > ε₀ : f(uₙ) ne tend pas vers f(x₀). ∎
🔧 Usages : (a) montrer « pas de limite » avec deux suites ; (b) suites récurrentes (P21).
P25. Lemme 1 — signe local 🟠 Supposons f(x₀) > 0 (l'autre cas est pareil). On applique la continuité avec ε tel que 0 < ε < f(x₀) : il existe δ > 0 tel que x ∈ ]x₀−δ, x₀+δ[ ⇒ f(x₀) − ε < f(x) < f(x₀) + ε. Comme f(x₀) − ε > 0, on a f(x) > 0 sur ce voisinage. ∎
P26. Exemple 12 — prolongement par continuité de x sin(1/x) en 0 🟠 Pour x ≠ 0, |f(x)| = |x||sin(1/x)| ≤ |x| ; par gendarmes (−|x| ≤ f(x) ≤ |x|), f(x) → 0 en 0. Limite finie : f est prolongeable par continuité en 0 en posant f̃(0) = 0. ∎
P27. Théorème 1 — le TVI (par la borne supérieure) 🟠 Cas f(a) ≤ y ≤ f(b) (l'autre cas : on applique le résultat à −f). Soit A = {x ∈ [a,b] | f(x) ≤ y} : non vide (a ∈ A) et majoré par b. Donc c = sup A existe, c ∈ [a,b]. Montrons f(c) = y.
• f(c) ≤ y. Comme c = sup A, il existe une suite (uₙ) d'éléments de A qui converge vers c (Prop. 6, ch. 1). On a f(uₙ) ≤ y ; comme f est continue en c, f(uₙ) → f(c) ; par passage à la limite dans l'inégalité, f(c) ≤ y.
• f(c) ≥ y. Si c = b : f(c) = f(b) ≥ y. Sinon, pour tout x ∈ ]c, b], x ∉ A (au-dessus du sup), donc f(x) > y ; f étant continue en c, sa limite à droite en c vaut f(c), donc f(c) ≥ y.
Donc f(c) = y. ∎
P28. Cor. 1 et Cor. 2 — TVI : f(a)f(b) < 0 et image d'un intervalle 🟠 Cor. 1. f(a)·f(b) < 0 signifie que f(a) et f(b) sont de signes contraires, donc 0 est compris entre eux : le TVI (avec y = 0) donne c avec f(c) = 0 ; c ≠ a, b car f(a), f(b) ≠ 0.
Cor. 2. Soient y₁ ≤ y₂ dans f(I), y₁ = f(x₁), y₂ = f(x₂), et y ∈ [y₁,y₂]. y est compris entre f(x₁) et f(x₂) : le TVI entre x₁ et x₂ (qui sont dans I, donc tout le segment aussi) donne x avec f(x) = y : y ∈ f(I). ∎
Application (ex. 13) : un polynôme de degré impair a une racine réelle : P → −∞ en −∞ et +∞ en +∞ (si le coefficient dominant est positif), donc P(a) < 0 < P(b) pour certains a, b.
P29. Théorème 2 — l'image d'un segment est un segment 🟢 À comprendre, pas à refaire mot à mot. (1) f est bornée : si elle ne l'était pas, pour tout n l'ensemble Aₙ = {x : f(x) ≥ n} est non vide ; sₙ = sup Aₙ est décroissante minorée, donc converge vers ℓ ∈ [a,b] ; par continuité f(sₙ) → f(ℓ) mais f(sₙ) ≥ n → +∞ : contradiction. (2) f(I) est un intervalle borné d'extrémités m = inf f(I) et M = sup f(I) ; si M ∉ f(I), g = 1/(M − f) est continue donc bornée par (1), mais g(xₙ) → +∞ quand f(xₙ) → M : contradiction. Donc M ∈ f(I), de même m.
À retenir surtout : continue sur un segment ⇒ bornée et atteint ses bornes (c'est ce qui sert dans le sujet blanc, ex. 3.1 et 4.2).
P30. Lemme 2 et Théorème 3 — théorème de la bijection 🟢 / 🟠 Lemme 2 (🟠). Soit f strictement monotone et f(x) = f(x'). Si x < x', on aurait f(x) < f(x') ou f(x) > f(x') : impossible. Donc x ≥ x' ; en échangeant les rôles, x ≤ x' ; donc x = x' : f est injective.
Théorème 3. (1) f est injective (Lemme 2), donc bijective de I sur J = f(I) ; J est un intervalle par le TVI (Cor. 2). (2) Strictement croissante : si y < y', avec x = f⁻¹(y), x' = f⁻¹(y') : f(x) < f(x') donc (si x ≥ x', on aurait f(x) ≥ f(x')) x < x' : f⁻¹ est strictement croissante. Continuité de f⁻¹ (🟢) : pour y₀ = f(x₀) et ε > 0, on choisit δ avec f(x₀−ε) < y₀−δ et f(x₀+ε) > y₀+δ ; alors |y − y₀| < δ ⇒ |f⁻¹(y) − x₀| < ε. ∎
