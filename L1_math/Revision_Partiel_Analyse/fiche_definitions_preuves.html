📚 Analyse 1.1 — Définitions et preuves à connaître

Le prof l'a écrit : « vous devez connaître parfaitement les définitions et savoir refaire les démonstrations simples du cours ». Cette page suit le cours dans l'ordre, depuis le début, jusqu'à la continuité. Pour chaque notion : la définition exacte, puis (si c'est une preuve à savoir) la preuve, cachée pour que tu essaies d'abord.

💡 Méthode d'apprentissage 1) Lis la définition, cache-la, réécris-la de mémoire. 2) Pour chaque preuve : lis le titre, essaie sur papier, puis ouvre. 3) Une preuve est « sue » quand tu peux l'écrire sans rien regarder en justifiant chaque ligne. Pour la mise en forme, voir la méthode de rédaction. Cours détaillé : ch. 1 · ch. 2 · ch. 3.

Partie 1 — Les réels

1.1 Définitions

📌 À savoir mot pour mot
  • Intervalle : I ⊂ R est un intervalle si ∀a,b ∈ I, ∀x, (a ≤ x ≤ b ⇒ x ∈ I). Segment = intervalle [a,b] fermé borné.
  • Valeur absolue : |x| = x si x ≥ 0, |x| = −x si x < 0. Inégalité triangulaire : |x+y| ≤ |x| + |y|.
  • Partie entière : ⌊x⌋ est l'unique entier k tel que k ≤ x < k+1.
  • Majorant de A : M tel que ∀a ∈ A, a ≤ M. Minorant : m tel que ∀a ∈ A, a ≥ m. A est majorée / minorée / bornée si elle a un majorant / minorant / les deux.
  • Plus grand élément (max) de A : α ∈ A et ∀a ∈ A, a ≤ α. Idem plus petit élément.
  • Borne supérieure sup A : le plus petit majorant de A. Borne inférieure inf A : le plus grand minorant.
  • Axiome / théorème de la borne supérieure : toute partie non vide et majorée de R admet une borne supérieure.
  • Propriété d'Archimède : ∀x ∈ R, ∃n ∈ N, n > x.
  • Densité de Q : entre deux réels a < b il y a un rationnel (et un irrationnel).

1.2 Preuves à savoir

P1. √2 est irrationnel Supposons par l'absurde √2 = p/q avec p ∈ Z, q ∈ N* premiers entre eux. Alors p² = 2q², donc p² est pair, donc p est pair (si p était impair, p² serait impair) : p = 2p'. Alors 4p'² = 2q², soit q² = 2p'², donc q est pair. Alors p et q sont tous deux pairs, ce qui contredit « premiers entre eux ». ∎
P2. Caractérisation de la borne supérieure : M = sup A ⟺ (M majorant) et (∀ε > 0, ∃a ∈ A, a > M − ε) (⇒) Si M = sup A, c'est un majorant. Soit ε > 0. Comme M − ε < M et que M est le plus petit majorant, M−ε n'est pas un majorant : il existe a ∈ A avec a > M − ε.
(⇐) Soit M majorant vérifiant la propriété. Soit M' un majorant avec M' < M. Avec ε = M − M' > 0, il existe a ∈ A avec a > M − ε = M' : M' n'est pas un majorant. Contradiction. Donc tout majorant est ≥ M : M = sup A. ∎
🔧 Usage : montrer qu'un nombre est un sup (ex. sup{1 − 1/n} = 1 : on prend n > 1/ε par Archimède).
P3. Exercices types sur les sup (feuille 1, ex. 4) : inf(−A) = −sup A, sup(A∪B) = max(sup A, sup B), sup(A+B) = sup A + sup B Schéma commun : montrer que le candidat est un majorant, puis qu'on ne peut pas faire plus petit (avec la caractérisation ε).

Exemple : sup(A+B) = sup A + sup B. Soit s = sup A + sup B.
• Majorant : pour a ∈ A, b ∈ B, a + b ≤ sup A + sup B.
• Plus petit : soit ε > 0. Il existe a ∈ A avec a > sup A − ε/2 et b ∈ B avec b > sup B − ε/2. Alors a + b > s − ε. ∎
P4. Inégalité triangulaire et la seconde ||x| − |y|| ≤ |x − y| On a −|x| ≤ x ≤ |x| et −|y| ≤ y ≤ |y|. En additionnant : −(|x|+|y|) ≤ x+y ≤ |x|+|y|, c'est-à-dire |x+y| ≤ |x|+|y|.
Seconde : |x| = |(x−y)+y| ≤ |x−y| + |y| donc |x| − |y| ≤ |x−y|. En échangeant x et y : |y| − |x| ≤ |x−y|. Donc ||x|−|y|| ≤ |x−y|. ∎

Partie 2 — Les suites

2.1 Définitions

📌 À savoir mot pour mot
  • Limite finie : uₙ → ℓ ⟺ ∀ε > 0, ∃N ∈ N, ∀n ≥ N, |uₙ − ℓ| ≤ ε.
  • Limite +∞ : uₙ → +∞ ⟺ ∀A, ∃N, ∀n ≥ N, uₙ ≥ A. (−∞ : uₙ ≤ −A.)
  • Convergente : a une limite finie. Divergente : sinon (limite infinie ou pas de limite).
  • Bornée : ∃M, ∀n, |uₙ| ≤ M. Croissante : ∀n, uₙ ≤ uₙ₊₁.
  • Suite extraite (sous-suite) : (u_φ(n)) avec φ : N → N strictement croissante.
  • Suites adjacentes : (uₙ) croissante, (vₙ) décroissante, uₙ ≤ vₙ pour tout n, et vₙ − uₙ → 0.
  • Négation à connaître : « uₙ ne tend pas vers +∞ » ⟺ ∃A, ∀N, ∃n ≥ N, uₙ < A.

2.2 Théorèmes à énoncer

📌 Énoncés exacts
  • Unicité de la limite.
  • Convergente ⇒ bornée. (La réciproque est fausse : (−1)ⁿ.)
  • Passage à la limite dans les inégalités larges : uₙ ≤ vₙ et les deux convergent ⇒ lim uₙ ≤ lim vₙ (pas d'inégalité stricte conservée).
  • Comparaison : uₙ ≤ vₙ et uₙ → +∞ ⇒ vₙ → +∞.
  • Gendarmes : uₙ ≤ vₙ ≤ wₙ, uₙ → ℓ et wₙ → ℓ ⇒ vₙ → ℓ.
  • Borné × tend vers 0 → 0.
  • Limite monotone : croissante majorée ⇒ converge (vers sup) ; croissante non majorée ⇒ → +∞.
  • Suites adjacentes ⇒ elles convergent vers la même limite, et uₙ ≤ ℓ ≤ vₙ.
  • Sous-suites : uₙ → ℓ ⇒ toute sous-suite → ℓ. Bolzano-Weierstrass : toute suite bornée a une sous-suite convergente.
  • Critère du rapport : uₙ > 0, uₙ₊₁/uₙ → ℓ < 1 ⇒ uₙ → 0 (feuille 3). Si ℓ > 1 ⇒ +∞. Si ℓ = 1 on ne peut pas conclure (n et 1/(n+1)).
  • Suite géométrique : aⁿ → 0 si |a| < 1 ; → +∞ si a > 1 ; diverge si a ≤ −1. Somme : 1 + a + … + aⁿ = (1 − aⁿ⁺¹)/(1 − a).

2.3 Preuves à savoir

P5. Unicité de la limite Supposons uₙ → ℓ et uₙ → ℓ' avec ℓ ≠ ℓ'. Posons ε = |ℓ − ℓ'|/3 > 0. Il existe N₁ avec |uₙ − ℓ| ≤ ε pour n ≥ N₁ et N₂ avec |uₙ − ℓ'| ≤ ε pour n ≥ N₂. Pour n ≥ max(N₁,N₂) : |ℓ − ℓ'| ≤ |ℓ − uₙ| + |uₙ − ℓ'| ≤ 2ε = (2/3)|ℓ − ℓ'|, ce qui donne |ℓ−ℓ'| ≤ (2/3)|ℓ−ℓ'|, impossible car |ℓ−ℓ'| > 0. ∎
(Avec la définition en « ≤ ε », on prend ε = |ℓ−ℓ'|/3 : avec /2 on obtiendrait seulement |ℓ−ℓ'| ≤ |ℓ−ℓ'|, pas de contradiction.)
P6. Convergente ⇒ bornée Soit uₙ → ℓ. Avec ε = 1 : il existe N tel que n ≥ N ⇒ |uₙ − ℓ| ≤ 1, donc |uₙ| ≤ |ℓ| + 1. Posons M = max(|u₀|, …, |u_{N−1}|, |ℓ|+1) : alors |uₙ| ≤ M pour tout n. ∎
P7. Somme : uₙ → ℓ, vₙ → ℓ' ⇒ uₙ + vₙ → ℓ + ℓ' Soit ε > 0. Il existe N₁ tel que n ≥ N₁ ⇒ |uₙ − ℓ| ≤ ε/2 et N₂ tel que n ≥ N₂ ⇒ |vₙ − ℓ'| ≤ ε/2. Pour n ≥ max(N₁, N₂) : |(uₙ+vₙ) − (ℓ+ℓ')| ≤ |uₙ − ℓ| + |vₙ − ℓ'| ≤ ε. ∎
P8. Borné × tend vers 0 → 0 (feuille 2, ex. 3.1) Soit M > 0 avec |uₙ| ≤ M. Soit ε > 0 ; comme vₙ → 0, il existe N tel que n ≥ N ⇒ |vₙ| ≤ ε/M. Alors |uₙvₙ| ≤ M·ε/M = ε. ∎
P9. Comparaison vers +∞ et gendarmes Comparaison. Soit A. Il existe N : n ≥ N ⇒ uₙ ≥ A. Alors vₙ ≥ uₙ ≥ A pour n ≥ N. ∎
Gendarmes. Soit ε > 0. Il existe N tel que pour n ≥ N : ℓ − ε ≤ uₙ et wₙ ≤ ℓ + ε. Alors ℓ − ε ≤ uₙ ≤ vₙ ≤ wₙ ≤ ℓ + ε, soit |vₙ − ℓ| ≤ ε. ∎
P10. Théorème de la limite monotone (croissante majorée converge) Soit A = {uₙ : n ∈ N}, non vide et majorée. Elle a une borne sup ℓ (théorème de la borne supérieure). Soit ε > 0. Par caractérisation (P2), il existe N avec u_N > ℓ − ε. Comme (uₙ) est croissante, pour n ≥ N : ℓ − ε < u_N ≤ uₙ ≤ ℓ. Donc |uₙ − ℓ| ≤ ε : uₙ → ℓ. ∎
Non majorée : pour tout A il existe N avec u_N ≥ A, puis uₙ ≥ u_N ≥ A pour n ≥ N : uₙ → +∞.
P11. Suites adjacentes convergent vers la même limite (uₙ) est croissante et uₙ ≤ vₙ ≤ v₀ (car (vₙ) décroissante) : majorée, donc converge vers ℓ. (vₙ) est décroissante et vₙ ≥ uₙ ≥ u₀ : minorée, donc converge vers ℓ'. Alors vₙ − uₙ → ℓ' − ℓ ; mais vₙ − uₙ → 0, donc ℓ = ℓ' (unicité). En plus uₙ ≤ ℓ ≤ vₙ (croissante vers ℓ ⇒ uₙ ≤ ℓ ; décroissante vers ℓ ⇒ vₙ ≥ ℓ). ∎
P12. Sous-suite d'une suite convergente ; critère de divergence Comme φ est strictement croissante à valeurs dans N, φ(n) ≥ n (récurrence). Si uₙ → ℓ : pour ε > 0, il existe N avec k ≥ N ⇒ |u_k − ℓ| ≤ ε. Pour n ≥ N, φ(n) ≥ n ≥ N donc |u_φ(n) − ℓ| ≤ ε. ∎
Conséquence : deux sous-suites de limites différentes ⇒ la suite diverge ((−1)ⁿ).
P13. La suite harmonique diverge (feuille 3, ex. 5) Hₙ = 1 + 1/2 + … + 1/n est croissante. H₂ₙ − Hₙ = 1/(n+1) + … + 1/(2n) : n termes, tous ≥ 1/(2n), donc ≥ n · 1/(2n) = 1/2. Si Hₙ → L ∈ R, alors H₂ₙ → L aussi (sous-suite) et H₂ₙ − Hₙ → 0, contredisant ≥ 1/2. Donc Hₙ diverge, et comme elle est croissante, Hₙ → +∞. ∎
P14. Critère du rapport (feuille 3, ex. 2.1) Soit ℓ < r < 1. À partir d'un rang N, uₙ₊₁/uₙ < r, donc uₙ₊₁ < r uₙ < uₙ (car uₙ > 0, r < 1) : décroissante. Par récurrence 0 < uₙ < rⁿ⁻ᴺ u_N → 0 (suite géométrique de raison r ∈ [0,1[). Gendarmes : uₙ → 0. ∎
P15. Une suite d'entiers convergente est stationnaire (feuille 2, ex. 3.4) Avec ε = 1/2 : pour n, m ≥ N, |uₙ − uₘ| ≤ |uₙ − ℓ| + |ℓ − uₘ| < 1. Or uₙ − uₘ est un entier de valeur absolue < 1 : il vaut 0. Donc uₙ = u_N pour tout n ≥ N. ∎

Partie 3 — Limites de fonctions et continuité

3.1 Définitions

📌 À savoir mot pour mot
  • Paire / impaire : f(−x) = f(x) / f(−x) = −f(x) pour tout x (domaine symétrique). Périodique de période T > 0 : f(x+T) = f(x) pour tout x.
  • Croissante : x ≤ y ⇒ f(x) ≤ f(y). Strictement croissante : x < y ⇒ f(x) < f(y).
  • Limite finie en x₀ : ∀ε > 0, ∃δ > 0, ∀x ∈ I, (|x − x₀| ≤ δ ⇒ |f(x) − ℓ| ≤ ε).
  • Limite +∞ en x₀ : ∀A, ∃δ > 0, ∀x, (|x−x₀| ≤ δ ⇒ f(x) ≥ A). Limite en +∞ : ∀ε, ∃B, ∀x ≥ B, |f(x) − ℓ| ≤ ε.
  • Continue en x₀ : f a pour limite f(x₀) en x₀. Continue sur I : continue en tout point.
  • Prolongement par continuité en x₀ : si f a une limite finie ℓ en x₀, on pose f(x₀) = ℓ.
  • Bijection : injective + surjective. Surjective : ∀y, ∃x, f(x) = y.

3.2 Théorèmes à énoncer

📌 Énoncés exacts
  • Caractérisation séquentielle : f a pour limite ℓ en x₀ ⟺ pour toute suite xₙ → x₀, f(xₙ) → ℓ. Même chose pour la continuité (avec ℓ = f(x₀)). Usage : prouver « pas de limite » (deux suites) et « si uₙ → ℓ et f continue, alors f(uₙ) → f(ℓ) » (suites récurrentes).
  • Opérations (somme, produit, quotient, composée) et continuité de ces opérations. Gendarmes pour les fonctions.
  • Théorème des valeurs intermédiaires : f continue sur [a,b], y entre f(a) et f(b) ⇒ ∃c ∈ [a,b], f(c) = y.
  • Image d'un intervalle : f continue sur un intervalle I ⇒ f(I) est un intervalle.
  • Image d'un segment : f continue sur [a,b] ⇒ f([a,b]) = [m, M] : f est bornée et atteint ses bornes.
  • Théorème de la bijection : f continue et strictement monotone sur un intervalle I ⇒ bijection de I sur f(I), et f⁻¹ est continue, strictement monotone de même sens.

3.3 Preuves à savoir

P16. Caractérisation séquentielle (⇒) : si f → ℓ en x₀ et xₙ → x₀, alors f(xₙ) → ℓ Soit ε > 0. Il existe δ > 0 tel que |x − x₀| ≤ δ ⇒ |f(x) − ℓ| ≤ ε. Comme xₙ → x₀, il existe N tel que n ≥ N ⇒ |xₙ − x₀| ≤ δ. Alors pour n ≥ N : |f(xₙ) − ℓ| ≤ ε. ∎
Corollaire (« pas de limite ») : si xₙ → x₀, yₙ → x₀ avec f(xₙ) → a, f(yₙ) → b, a ≠ b, alors f n'a pas de limite en x₀ (par unicité). Exemple : cos(1/x) en 0.
P17. Théorème des valeurs intermédiaires (par la borne supérieure) Supposons f(a) ≤ y ≤ f(b) (sinon on applique le résultat à −f). Soit A = {x ∈ [a,b] : f(x) ≤ y} : non vide (a ∈ A), majorée par b. Soit c = sup A ∈ [a,b].
• f(c) ≤ y : par caractérisation de la borne sup, il existe aₙ ∈ A avec aₙ → c. Comme f(aₙ) ≤ y et f est continue en c, f(c) = lim f(aₙ) ≤ y.
• f(c) ≥ y : si c = b, f(c) = f(b) ≥ y. Si c < b, les points xₙ = c + (b−c)/n sont dans ]c,b], donc hors de A (ce sont des points au-dessus du sup) : f(xₙ) > y ; xₙ → c donc f(c) = lim f(xₙ) ≥ y.
Donc f(c) = y. ∎
P18. Corollaire : continue, ne s'annule pas sur un intervalle ⇒ signe constant Si f prenait des valeurs > 0 en a et < 0 en b, le TVI (entre a et b) donnerait un point où f = 0. Contradiction. ∎ (À savoir refaire : sert dans la feuille 7 et dans le sujet blanc, ex. 5.)
P19. Image d'un intervalle : f(I) est un intervalle Soient y₁ < y₂ dans f(I), y₁ = f(x₁), y₂ = f(x₂), et y ∈ [y₁, y₂]. Le TVI entre x₁ et x₂ (dans I car c'est un intervalle) donne c avec f(c) = y : y ∈ f(I). ∎
