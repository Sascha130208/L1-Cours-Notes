Exercice 1 — Limites de suites

a) 2n / √(n²+1)

Réponse : 2 Pour n ≥ 1 : √(n²+1) = n·√(1 + 1/n²), donc 2n/√(n²+1) = 2/√(1 + 1/n²) → 2/√1 = 2.
🔧 Outil : factoriser le terme dominant sous la racine (n²), puis la racine sort en n.

b) ((−1)ⁿ n² − 3n) / (n+1)

Réponse : pas de limite • n pair : (n² − 3n)/(n+1) = n(1 − 3/n)/(1 + 1/n) → +∞.
• n impair : (−n² − 3n)/(n+1) = −n(1 + 3/n)/(1 + 1/n) → −∞.
Les sous-suites (u₂ₙ) et (u₂ₙ₊₁) ont des limites différentes : par le théorème sur les sous-suites, (uₙ) n'a pas de limite (elle ne tend ni vers un réel, ni vers +∞, ni vers −∞).
🔧 Outil : un (−1)ⁿ qui multiplie un terme dominant ⇒ séparer pairs / impairs.

c) ⌊ n/(n+1) ⌋

Réponse : 0 Pour tout n ∈ N : 0 ≤ n/(n+1) < 1, donc la partie entière vaut 0. La suite est constante égale à 0 : limite 0.
⚠️ Piège : n/(n+1) → 1 mais la partie entière ne passe pas à la limite (E n'est pas continue en 1). Le calcul « la limite est ⌊1⌋ = 1 » est faux.

d) √(n²+n+1) − n

Réponse : 1/2 Forme ∞ − ∞ : quantité conjuguée.
√(n²+n+1) − n = (n² + n + 1 − n²) / (√(n²+n+1) + n) = (n+1)/(√(n²+n+1) + n).
On divise par n : (1 + 1/n) / (√(1 + 1/n + 1/n²) + 1) → 1/(1+1) = 1/2.

Exercice 2 — Sous-suites pairs / impairs

1. (u₂ₙ) et (u₂ₙ₊₁) convergent vers ℓ. Montrer que uₙ → ℓ.

Preuve Soit ε > 0. Comme u₂ₖ → ℓ, il existe N₁ tel que pour tout k ≥ N₁, |u₂ₖ − ℓ| ≤ ε. Comme u₂ₖ₊₁ → ℓ, il existe N₂ tel que pour tout k ≥ N₂, |u₂ₖ₊₁ − ℓ| ≤ ε.
Posons N = max(2N₁, 2N₂ + 1). Soit n ≥ N.
• Si n = 2k est pair : 2k ≥ 2N₁ donc k ≥ N₁ et |uₙ − ℓ| = |u₂ₖ − ℓ| ≤ ε.
• Si n = 2k+1 est impair : 2k+1 ≥ 2N₂+1 donc k ≥ N₂ et |uₙ − ℓ| = |u₂ₖ₊₁ − ℓ| ≤ ε.
Dans les deux cas |uₙ − ℓ| ≤ ε : uₙ → ℓ. ∎
🔧 Outil : on prend le max des deux seuils (en recalant les indices : n = 2k ou 2k+1). Réciproque (vraie) : si uₙ → ℓ, toute sous-suite tend vers ℓ.

2. (u₆ₙ) est une sous-suite de (u₂ₙ) et de (u₃ₙ) ; (u₆ₙ₊₃) est une sous-suite de (u₂ₙ₊₁) et de (u₃ₙ).

Preuve Une sous-suite de (vₙ) est une suite (v_φ(n)) avec φ : N → N strictement croissante.
• 6n = 2·(3n) : u₆ₙ = v_φ(n) avec vₘ = u₂ₘ et φ(n) = 3n (strictement croissante).
• 6n = 3·(2n) : vₘ = u₃ₘ, φ(n) = 2n.
• 6n+3 = 2·(3n+1) + 1 : vₘ = u₂ₘ₊₁, φ(n) = 3n+1.
• 6n+3 = 3·(2n+1) : vₘ = u₃ₘ, φ(n) = 2n+1. ∎

3. (u₂ₙ), (u₂ₙ₊₁), (u₃ₙ) convergent. Montrer que (uₙ) converge.

Preuve Notons a = lim u₂ₙ, b = lim u₂ₙ₊₁, c = lim u₃ₙ.
• (u₆ₙ) est une sous-suite de (u₂ₙ) donc u₆ₙ → a ; c'est aussi une sous-suite de (u₃ₙ) donc u₆ₙ → c. Unicité de la limite : a = c.
• (u₆ₙ₊₃) est une sous-suite de (u₂ₙ₊₁) donc u₆ₙ₊₃ → b ; c'est aussi une sous-suite de (u₃ₙ) donc u₆ₙ₊₃ → c. Donc b = c.
Ainsi a = b = c : (u₂ₙ) et (u₂ₙ₊₁) ont la même limite, et par la question 1, (uₙ) converge. ∎
🔧 Idée : le troisième morceau (u₃ₙ) fait le pont entre pairs et impairs, car il contient à la fois des indices pairs (6n) et impairs (6n+3).

Exercice 3 — Le critère de Cauchy

Définition à connaître (uₙ) est de Cauchy si ∀ε > 0, ∃N ∈ N, ∀m, n ≥ N, |uₘ − uₙ| ≤ ε.
Théorème (critère de Cauchy) : une suite réelle converge ⟺ elle est de Cauchy.

1. Convergente ⇒ de Cauchy.

Preuve Soit uₙ → ℓ et ε > 0. Il existe N tel que pour tout n ≥ N, |uₙ − ℓ| ≤ ε/2. Alors pour m, n ≥ N :
|uₘ − uₙ| = |(uₘ − ℓ) + (ℓ − uₙ)| ≤ |uₘ − ℓ| + |uₙ − ℓ| ≤ ε/2 + ε/2 = ε. ∎
🔧 Outil : inégalité triangulaire en intercalant ℓ, avec ε/2.

2. De Cauchy ⇒ bornée.

Preuve On prend ε = 1 : il existe N tel que pour tous m, n ≥ N, |uₘ − uₙ| ≤ 1. En particulier, pour n ≥ N : |uₙ − u_N| ≤ 1, donc |uₙ| ≤ |u_N| + 1.
Posons M = max(|u₀|, |u₁|, …, |u_{N−1}|, |u_N| + 1) (maximum d'un nombre fini de réels). Alors |uₙ| ≤ M pour tout n. ∎
🔧 Outil : « à partir d'un rang, tout est proche de u_N » + « avant ce rang, il n'y a qu'un nombre fini de termes ».

3. De Cauchy avec une sous-suite convergente ⇒ convergente.

Preuve Soit φ strictement croissante avec u_φ(k) → ℓ. Soit ε > 0.
• Cauchy (avec ε/2) : il existe N₁ tel que |uₘ − uₙ| ≤ ε/2 pour tous m, n ≥ N₁.
• Convergence de la sous-suite : il existe N₂ tel que |u_φ(k) − ℓ| ≤ ε/2 pour tout k ≥ N₂.
Posons k = max(N₁, N₂). Comme φ est strictement croissante à valeurs dans N, φ(k) ≥ k ≥ N₁. Alors pour tout n ≥ N₁ :
|uₙ − ℓ| ≤ |uₙ − u_φ(k)| + |u_φ(k) − ℓ| ≤ ε/2 + ε/2 = ε (le premier terme car n, φ(k) ≥ N₁). Donc uₙ → ℓ. ∎
🔧 Outil : φ(k) ≥ k pour une extractrice. Un terme de la sous-suite sert de « pivot » entre uₙ et ℓ.

4. Le critère de Cauchy.

Preuve (⇒) C'est la question 1.
(⇐) Si (uₙ) est de Cauchy, elle est bornée (question 2). Par le théorème de Bolzano–Weierstrass, elle admet une sous-suite convergente. Par la question 3, (uₙ) converge. ∎
💡 Intérêt : on peut prouver qu'une suite converge sans connaître sa limite.

Exercice 4 — Pics et sous-suites monotones

Définition Un indice n est un pic si u_p < uₙ pour tout p > n (c'est un terme strictement plus grand que tous ceux qui le suivent).

1. Infinité de pics ⇒ sous-suite strictement décroissante.

Preuve Soient n₀ < n₁ < n₂ < … les pics rangés par ordre croissant (il y en a une infinité, donc on peut les énumérer sans fin). Comme n_k est un pic et n_{k+1} > n_k, on a u_{n_{k+1}} < u_{n_k}. Donc (u_{n_k}) est une sous-suite strictement décroissante (extractrice k ↦ n_k strictement croissante). ∎

2. Un nombre fini de pics ⇒ sous-suite croissante.

Preuve Soit N un entier strictement supérieur à tous les pics (possible : il y en a un nombre fini ; s'il n'y en a aucun, N = 0). Aucun indice n ≥ N n'est un pic.
On construit φ par récurrence : φ(0) = N. Si φ(k) ≥ N est construit, comme φ(k) n'est pas un pic, il existe p > φ(k) avec u_p ≥ u_φ(k) ; on pose φ(k+1) = p.
Alors φ(k+1) > φ(k) (strictement croissante) et u_φ(k+1) ≥ u_φ(k) : (u_φ(k)) est une sous-suite croissante. ∎
🔧 Idée : « pas un pic » veut dire « plus loin, il existe un terme au moins aussi grand » : on le prend, et on recommence.

3. Toute suite réelle admet une sous-suite monotone.

Preuve Deux cas exhaustifs : infinité de pics (question 1 : sous-suite décroissante) ou nombre fini de pics (question 2 : sous-suite croissante). Dans les deux cas, il existe une sous-suite monotone. ∎

4. Nouvelle démonstration de Bolzano–Weierstrass.

Preuve Soit (uₙ) bornée. Par la question 3, elle admet une sous-suite monotone (v_k). Cette sous-suite est elle-même bornée (par la même borne que (uₙ)). Par le théorème de la limite monotone : une suite croissante majorée converge (vers son sup) ; une suite décroissante minorée converge (vers son inf). Donc (v_k) converge : (uₙ) admet une sous-suite convergente. ∎
🔧 Chaîne à retenir : bornée ⇒ sous-suite monotone (pics) ⇒ monotone + bornée ⇒ converge (limite monotone).
🧰 Ce que cette feuille t'apprend (à retenir pour le partiel)
  • Pairs + impairs de même limite ⇒ convergence (et le « pont » u₃ₙ).
  • Pas de limite ⇐ deux sous-suites de limites différentes (ex. 1 b).
  • Cauchy : convergente ⇒ Cauchy (ε/2) ; Cauchy ⇒ bornée (ε = 1) ; Cauchy + sous-suite convergente ⇒ convergente ; donc critère de Cauchy avec Bolzano–Weierstrass.
  • Pics : toute suite a une sous-suite monotone ⇒ Bolzano–Weierstrass.
  • Ne jamais écrire « la limite de la partie entière est la partie entière de la limite ».
