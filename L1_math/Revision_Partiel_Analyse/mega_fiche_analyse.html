CHAPITRE 1 — Les nombres réels

N1 · Rationnels, irrationnels, √2 🔴🟠

📌 Énoncé (polycopié 1.1)
  • Rationnel : x ∈ Q s'il existe p ∈ Z et q ∈ N* tels que x = p/q. Irrationnel : un réel qui n'est pas rationnel (R∖Q).
  • Admis : un réel est rationnel ⟺ son écriture décimale est finie ou périodique à partir d'un certain rang.
  • Proposition : √2 est irrationnel.
  • Q et R∖Q forment une partition de R : tout réel est dans l'un, et un seul, des deux.
🗣️ En français « Rationnel » = « fraction d'entiers ». Le dénominateur est dans N* (jamais 0). Tout décimal fini est rationnel (0,125 = 1/8). √2 est la diagonale d'un carré de côté 1 : on ne peut pas l'écrire comme fraction, ce qui montre que Q ne suffit pas pour mesurer toutes les longueurs.
❓ Q1. Écris la définition de « x est un rationnel ». Pourquoi q ∈ N* et pas q ∈ Z ? x ∈ Q ⟺ ∃p ∈ Z, ∃q ∈ N*, x = p/q. On prend q ≥ 1 pour exclure 0 ; le signe est porté par p. Avec q ∈ Z* on obtiendrait les mêmes nombres, mais le polycopié fixe q ∈ N*.
❓ Q2. Soit x ∈ Q et y ∈ R∖Q. x + y est-il irrationnel ? xy ? x + y : oui, toujours. Si x + y = r ∈ Q, alors y = r − x serait rationnel (différence de deux rationnels) : contradiction.
xy : non, pas toujours. Pour x = 0 : xy = 0 ∈ Q. En revanche si x ≠ 0, xy est irrationnel (sinon y = (xy)/x serait rationnel). (C'est la question 1.1 de la feuille 1.)
🧩 Démonstration — √2 ∉ Q (par l'absurde) 🟠 Supposons √2 = p/q avec p ∈ Z, q ∈ N* premiers entre eux (on peut toujours simplifier la fraction ; c'est l'hypothèse qui fera craquer la preuve).
Alors 2 = p²/q², soit p² = 2q² : p² est pair.
Si p est pair alors p² l'est ; si p est impair, p = 2k+1 et p² = 4k²+4k+1 est impair. Donc p² pair ⇒ p pair : p = 2p'.
On remplace : 4p'² = 2q², donc q² = 2p'² est pair, donc q est pair (même argument).
Ainsi 2 divise à la fois p et q : contradiction avec « premiers entre eux ». Donc √2 ∉ Q. ∎
⚠️ Pièges Dans la preuve, il faut justifier « p² pair ⇒ p pair » (par la contraposée ci-dessus) : c'est l'étape que les correcteurs regardent. Sans « premiers entre eux », il n'y a pas de contradiction.

N2 · Calculs avec les inégalités 🔴

📌 Énoncé (polycopié 1.2) Pour tous x, y, z ∈ R : x ≤ x (réflexivité) ; x ≤ y et y ≤ x ⇒ x = y (antisymétrie) ; x ≤ y et y ≤ z ⇒ x ≤ z (transitivité) ; x ≤ y ou y ≤ x (ordre total) ; x ≤ y ⇒ x+z ≤ y+z ; x ≤ y et z ≥ 0 ⇒ xz ≤ yz ; x ≤ y et z ≤ 0 ⇒ xz ≥ yz. Passage aux inverses : 0 < x ≤ y ⇒ 0 < 1/y ≤ 1/x.
🗣️ En français « Total » veut dire qu'on peut toujours comparer deux réels (ce n'est pas vrai pour les complexes ou les sous-ensembles). Multiplier par un négatif retourne l'inégalité : −2 < 3 donne 8 > −12 en multipliant par −4. Inverser (1/x) retourne aussi, pour des nombres positifs.
❓ Q. Qu'est-ce qu'un ordre total ? Donne un ordre qui n'est pas total. Un ordre est total si deux éléments quelconques sont comparables. L'inclusion ⊂ sur les parties de R n'est pas totale : {1} et {2} ne sont pas comparables.

N3 · Intervalles et caractérisation 🔴🟠

📌 Énoncé (polycopié 1.2 et 1.6)
  • Définition : les intervalles de R sont (pour a < b) : [a,b], [a,b[, ]a,b], ]a,b[ ; ]−∞,a], ]−∞,a[, [a,+∞[, ]a,+∞[ ; le singleton [a,a] = {a}, ∅ et R.
  • Remarque : −∞ et +∞ ne sont pas des réels : le crochet est toujours tourné vers l'extérieur de leur côté.
  • Théorème (caractérisation) : I ⊂ R est un intervalle ⟺ pour tous x, z ∈ I et tout y ∈ R, x ≤ y ≤ z ⟹ y ∈ I.
🗣️ En français Un intervalle est une partie « sans trou » : si tu prends deux points dedans, tout ce qui est entre eux y est aussi. R∖{0} n'est pas un intervalle : il contient −1 et 1 mais pas 0. Un segment est un intervalle [a,b] fermé borné. La caractérisation est l'outil pour montrer qu'une image est un intervalle (N37).
❓ Q1. Énonce la caractérisation des intervalles. I est un intervalle ⟺ ∀x, z ∈ I, ∀y ∈ R, (x ≤ y ≤ z ⇒ y ∈ I).
❓ Q2. Les parties ]−∞,−2] ∪ R₊, ]−1,0[ ∪ [0,1], [−10,−2] ∩ ]−4,4[ sont-elles des intervalles ? Première : non, elle contient −2 et 0 mais pas −1. Deuxième : oui, c'est ]−1,1] (les deux morceaux se recollent en 0). Troisième : [−10,−2] ∩ ]−4,4[ = ]−4,−2], oui.
🧩 Démonstration du théorème de caractérisation 🟠 (⇒) Pour chaque forme d'intervalle on vérifie la propriété en enchaînant les inégalités. Par exemple pour I = [a,b[ : si x, z ∈ I et x ≤ y ≤ z, alors a ≤ x ≤ y ≤ z < b, donc y ∈ [a,b[. Les autres cas sont identiques (seuls changent les « < » et « ≤ »).
(⇐) Soit I non vide vérifiant la propriété (si I = ∅ c'est un intervalle). Posons α = inf I et β = sup I, avec α = −∞ si I n'est pas minorée et β = +∞ si elle n'est pas majorée.
• Clairement I ⊂ [α,β] (en ignorant les infinis).
• Soit y ∈ ]α,β[. Comme y > α, y n'est pas un minorant de I : il existe x ∈ I avec x < y. De même y < β donne z ∈ I avec y < z. Par la propriété, y ∈ I. Donc ]α,β[ ⊂ I.
Ainsi ]α,β[ ⊂ I ⊂ [α,β] : I ne diffère de ]α,β[ que par la présence éventuelle de α et β, c'est-à-dire que I est de l'une des formes ]α,β[, [α,β[, ]α,β], [α,β] (ou un singleton si α = β). ∎
⚠️ Pièges Un singleton {a} est un intervalle ([a,a]) ; ∅ aussi. L'ensemble {x ∈ Q : x ≥ 0} n'est pas un intervalle (entre 0 et 1 il y a √2/2 ∉ Q). Une réunion d'intervalles qui se touchent peut être un intervalle (]−1,0[ ∪ [0,1] = ]−1,1]), mais pas si un point manque ([−1,0[ ∪ ]0,1]).

N4 · Valeur absolue, inégalité triangulaire, distance 🔴🟠

📌 Énoncé (polycopié 1.3)
  • |x| = x si x ≥ 0, |x| = −x si x < 0. Distance entre x et y : |x − y|.
  • Pour tous x, y ∈ R, r ∈ R₊ : |x| ≥ 0 ; |x| = 0 ⟺ x = 0 ; |−x| = |x| ; |xy| = |x||y| ; −|x| ≤ x ≤ |x| ; |x| ≤ r ⟺ −r ≤ x ≤ r.
  • Inégalité triangulaire : |x + y| ≤ |x| + |y|. Corollaire : | |x| − |y| | ≤ |x − y|.
  • Pour a, x ∈ R, r > 0 : |x − a| < r ⟺ a − r < x < a + r ⟺ x ∈ ]a−r, a+r[.
🗣️ En français |x − a| < r se lit « x est à distance < r de a » : c'est la même chose que « x est dans l'intervalle ouvert centré en a de rayon r ». L'inégalité triangulaire dit qu'aller tout droit est plus court qu'un détour : |x − y| ≤ |x − z| + |z − y|. Tu l'utiliseras dans toutes les preuves de limites.
❓ Q1. Énonce l'inégalité triangulaire et sa seconde forme. |x+y| ≤ |x|+|y| et | |x| − |y| | ≤ |x − y|.
❓ Q2. Traduis « |x − 3| ≤ 2 » en encadrement, puis « x ∈ [1, 5] » avec une valeur absolue. |x − 3| ≤ 2 ⟺ 1 ≤ x ≤ 5. Réciproquement x ∈ [1,5] ⟺ |x − 3| ≤ 2 (centre = milieu, rayon = demi-longueur).
🧩 Démonstrations 🟠 |x| ≤ r ⟺ −r ≤ x ≤ r. Si x ≥ 0 : |x| = x et −r ≤ 0 ≤ x, donc les deux conditions se réduisent à x ≤ r. Si x < 0 : |x| = −x ≤ r ⟺ x ≥ −r, et x < 0 ≤ r : les deux conditions se réduisent à x ≥ −r. (De même avec « < » pour |x−a| < r.)
Triangulaire. On a −|x| ≤ x ≤ |x| et −|y| ≤ y ≤ |y|. En additionnant : −(|x|+|y|) ≤ x+y ≤ |x|+|y|, donc |x+y| ≤ |x|+|y| (équivalence précédente avec r = |x|+|y|).
Corollaire. x = (x−y) + y donne |x| ≤ |x−y| + |y|, donc |x| − |y| ≤ |x−y|. En échangeant x et y : |y| − |x| ≤ |x−y|. Les deux ensemble donnent | |x| − |y| | ≤ |x−y|. ∎

N5 · Voisinage, intérieur, adhérence 🔴

📌 Énoncé (polycopié 1.3 et 1.4)
  • Voisinage : V ⊂ R est un voisinage de a s'il existe r > 0 tel que ]a − r, a + r[ ⊂ V.
  • Point intérieur : a ∈ Å si ∃r > 0, ]a − r, a + r[ ⊂ A. Intérieur : Å = ensemble des points intérieurs.
  • Point adhérent : a ∈ Ā si ∀r > 0, A ∩ [a − r, a + r] ≠ ∅. De façon équivalente : ∀δ > 0, ∃x ∈ A, |x − a| ≤ δ.
  • Proposition : Å ⊂ A ⊂ Ā. Exemple : pour A = [0,1[, Å = ]0,1[ et Ā = [0,1].
  • Caractérisation séquentielle : x ∈ Ā ⟺ il existe une suite (aₙ) d'éléments de A avec aₙ → x.
🗣️ En français Intérieur = les points entourés par la partie (on peut bouger un peu dans les deux sens sans sortir). Adhérence = les points qu'on peut approcher par des points de la partie (même s'ils n'y sont pas : 1 est adhérent à [0,1[). [0,2] est un voisinage de 1 (il contient ]1/2, 3/2[) mais pas de 0.
❓ Q. Détermine l'intérieur et l'adhérence de A = ]0,1] ∪ {2}. Å = ]0,1[ (1 n'est pas intérieur car 1+r ∉ A ; 2 est isolé). Ā = [0,1] ∪ {2} (0 est adhérent par 1/n).
🧩 Démonstrations 🟠 Å ⊂ A ⊂ Ā. Si a ∈ Å : a ∈ ]a−r,a+r[ ⊂ A, donc a ∈ A. Si a ∈ A : pour tout r > 0, a ∈ A ∩ [a−r,a+r] qui est donc non vide, donc a ∈ Ā.
Caractérisation séquentielle. (⇒) Si x ∈ Ā : pour tout n, avec δ = 1/(n+1), il existe aₙ ∈ A avec |aₙ − x| ≤ 1/(n+1). Par gendarmes, aₙ → x. (⇐) Si aₙ ∈ A et aₙ → x : pour r > 0, il existe N avec |a_N − x| ≤ r, donc a_N ∈ A ∩ [x−r, x+r] et x ∈ Ā. ∎

N6 · Majorant, minorant, maximum, minimum 🔴🟠

📌 Énoncé (polycopié 1.5)
  • M est un majorant de A si ∀x ∈ A, x ≤ M ; A est majorée si elle a un majorant. m est un minorant si ∀x ∈ A, m ≤ x ; minorée. Bornée = majorée et minorée.
  • Si M majore A, tout M' ≥ M la majore aussi.
  • Maximum (pour A ≠ ∅) : M = max A si M ∈ A et ∀x ∈ A, x ≤ M. Minimum : m ∈ A et m ≤ x pour tout x.
  • Proposition : s'il existe, le max (resp. le min) est unique.
🗣️ En français La différence cruciale : un majorant est un nombre qui domine toute la partie, il peut être en dehors de la partie ; le maximum est un majorant qui appartient à la partie. Pour A = [0,1[ : les majorants sont [1,+∞[ ; il n'y a pas de maximum (si x ∈ [0,1[, alors (x+1)/2 ∈ [0,1[ est plus grand).
❓ Q1. Donne les majorants et minorants de [0,1[, puis son max et son min. Minorants : ]−∞,0]. Majorants : [1,+∞[. min = 0 (il est dans la partie). Pas de max.
❓ Q2. Écris la négation de « A est majorée ». ∀M ∈ R, ∃x ∈ A, x > M. Exemple : N n'est pas majorée.
🧩 Démonstration — unicité du maximum 🟠 Soient M et M' deux maxima de A. Comme M' ∈ A et M majore A, M' ≤ M. Comme M ∈ A et M' majore A, M ≤ M'. Par antisymétrie, M = M'. (Idem pour le minimum.) ∎

N7 · Borne supérieure, borne inférieure 🔴

📌 Énoncé (polycopié 1.5)
  • Borne supérieure : pour A non vide et majorée, M = sup A si M est le plus petit majorant de A.
  • Borne inférieure : pour A non vide et minorée, m = inf A si m est le plus grand minorant.
  • Remarque : A a un maximum ⟺ sup A ∈ A (et alors max A = sup A). Idem avec inf et min.
🗣️ En français Le sup, c'est « le plafond le plus bas » : parmi tous les nombres au-dessus de la partie, le plus petit. Il peut être atteint (alors c'est le max) ou seulement approché (1 pour [0,1[). Le sup est une borne, pas forcément un élément.
❓ Q1. Donne les définitions de sup A et de inf A. sup A : le plus petit majorant de A. inf A : le plus grand minorant de A.
❓ Q2. Calcule sup, inf, max, min de A = {1 − 1/n : n ∈ N*}. inf A = min A = 0 (atteint pour n = 1). sup A = 1, pas de maximum (1 n'est pas dans A). Preuve du sup : voir N8.
🧩 Démonstration — max ⟺ sup ∈ A 🟠 Soit M = sup A. Si A a un maximum m : m est un majorant, donc M ≤ m ; et m ∈ A est ≤ à tout majorant donc m ≤ M ; ainsi m = M ∈ A. Réciproquement si M ∈ A, comme M majore A, c'est un maximum. ∎

N8 · Caractérisation par ε du sup et de l'inf 🔴🟠

📌 Énoncé (polycopié 1.5 et 2.3)
  • Proposition : A non vide majorée, M ∈ R. M = sup A ⟺ (i) M majore A et (ii) ∀ε > 0, ∃x ∈ A, M − ε < x.
  • Version inf : m = inf A ⟺ (i) m minore A et (ii) ∀ε > 0, ∃x ∈ A, x < m + ε.
  • Version séquentielle : M = sup A ⟺ M majore A et il existe une suite (xₙ) d'éléments de A telle que xₙ → M.
🗣️ En français (i) dit « M est un plafond » ; (ii) dit « on ne peut pas le baisser, même d'un tout petit ε : il y a toujours un élément de A qui dépasse M − ε ». Les deux ensemble = « le plus petit plafond ». C'est l'outil numéro 1 pour prouver qu'un nombre est un sup.
❓ Q1. Énonce la caractérisation de M = sup A. M majore A et ∀ε > 0, ∃x ∈ A, M − ε < x.
❓ Q2. Écris le schéma de preuve pour montrer qu'un réel M est le sup de A. (1) Montrer que M est un majorant : ∀x ∈ A, x ≤ M. (2) Fixer ε > 0 et construire un élément x ∈ A avec x > M − ε. (3) Conclure par la proposition.

(⇐) Par (i), M est un majorant. Soit M' un majorant avec M' < M. Prenons ε = M − M' > 0 : (ii) donne x ∈ A avec x > M − ε = M', ce qui contredit « M' majore A ». Donc aucun majorant n'est < M : M est le plus petit, M = sup A. ∎
Version séquentielle. (⇒) Avec ε = 1/(n+1) on obtient xₙ ∈ A avec M − 1/(n+1) < xₙ ≤ M ; gendarmes : xₙ → M. (⇐) Soit ε > 0 ; comme xₙ → M, il existe n avec |xₙ − M| ≤ ε/2, donc xₙ ≥ M − ε/2 > M − ε : (ii) est vérifiée.

N9 · Propriété de la borne supérieure (l'axiome de R) 🔴🟠

📌 Énoncé (polycopié 1.6)

N10 · Propriété d'Archimède 🔴🟠

📌 Énoncé (polycopié 1.6)

N27 · Fonctions : bornée, monotone, paire/impaire, périodique 🔴🟠

N31 · Composition, limites et ordre, gendarmes 🔴🟠

📌 Énoncé (polycopié 3.5 et 3.6)
  • Composition : f : A → B, g : B → R. Si lim_{x→a} f(x) = b et lim_{y→b} g(y) = ℓ, alors lim_{x→a} g(f(x)) = ℓ (a, b, ℓ ∈ R ∪ {±∞}). Il faut vérifier que f(A) ⊂ B et que b est approchable dans B.
  • Passage à la limite : lim f = ℓ, lim g = ℓ', f ≤ g au voisinage de a ⇒ ℓ ≤ ℓ'. lim f = +∞ et f ≤ g ⇒ lim g = +∞. lim f = −∞ et g ≤ f ⇒ lim g = −∞. Les inégalités strictes ne passent pas (1/x > 0, limite 0).
  • Gendarmes : f ≤ g ≤ h au voisinage de a, lim f = lim h = ℓ ⇒ lim g = ℓ. Exemple : x sin(1/x) → 0 en 0 car −|x| ≤ x sin(1/x) ≤ |x|.

N33 · Continuité en un point et sur une partie 🔴🟠

📌 Énoncé (polycopié 4.1)
  • f : A → R, a ∈ A. f est continue en a si lim_{x→a} f(x) = f(a), c'est-à-dire ∀ε > 0, ∃δ > 0, ∀x ∈ A, |x − a| ≤ δ ⇒ |f(x) − f(a)| ≤ ε. Continue sur A : continue en tout point de A.
  • Caractérisation séquentielle : f continue en a ⟺ pour toute suite (xₙ) de A avec xₙ → a, f(xₙ) → f(a).
  • Conservation locale du signe : f continue en a et f(a) > 0 ⇒ ∃δ > 0, ∀x ∈ A, |x−a| ≤ δ ⇒ f(x) > 0 (idem < 0) ; si f(a) ≠ 0, f ne s'annule pas au voisinage de a.
  • Continues : constantes, identité, polynômes, fractions rationnelles (où le dénominateur ne s'annule pas), |x|, √x, sin, cos, exp, ln. La partie entière n'est pas continue aux entiers.
🗣️ En françaisContinue = pas de saut : un petit changement de x entraîne un petit changement de f(x). Le rayon δ peut dépendre de ε et du point a. Pour prouver une discontinuité, on donne une suite xₙ → a telle que f(xₙ) ne tend pas vers f(a).

N35 · Opérations, fonctions lipschitziennes, min/max 🔴🟠

📌 Énoncé (polycopié 4.2)
  • f, g : A → R continues sur A, h : B → R continue sur B, f(A) ⊂ B, C = {x ∈ A : g(x) ≠ 0}, λ ∈ R : λf, f+g, fg continues sur A ; f/g continue sur C ; h∘f continue sur A.

N36 · Théorème des valeurs intermédiaires (TVI) 🔴🟠

📌 Énoncé (polycopié 4.3)
  • TVI : a ≤ b, f : [a,b] → R continue sur [a,b]. Pour tout y compris entre f(a) et f(b), il existe c ∈ [a,b] tel que f(c) = y.
  • Remarque : sur un intervalle I, le TVI s'applique entre deux points quelconques x₁ ≤ x₂ de I.
  • Cas des zéros : f(a)f(b) < 0 (ou f(a) < 0 < f(b)) ⇒ ∃c ∈ ]a,b[, f(c) = 0.
  • Exemple : f : [a,b] → [a,b] continue ⇒ il existe un point fixe c, f(c) = c.
  • Sans continuité, c'est faux : 0 sur [0,1/2[, 1 sur [1/2,1] ne prend jamais 1/2 (et elle est pourtant croissante).
🗣️ En françaisUne fonction continue ne peut pas passer d'une valeur à une autre sans passer par toutes les valeurs intermédiaires (on peut tracer le graphe sans lever le crayon). Les 3 usages au partiel :
  1. « Il existe x tel que A(x) = B(x) » : on pose φ = A − B (continue), on trouve a, b avec φ(a) ≤ 0 ≤ φ(b) (ou l'inverse), TVI : φ(c) = 0.
  2. « f est surjective » : pour y ∈ R, on trouve a, b (avec les limites en ±∞ ou des suites de points) tels que f(a) < y < f(b), TVI : f(c) = y.
  3. « Signe constant » : si φ continue ne s'annule jamais, alors φ > 0 partout ou φ < 0 partout (sinon TVI donne un zéro).

  • Le TVI n'est pas « f([a,b]) = [f(a), f(b)] » : x² sur [−1,1] donne [0,1].

N37 · Image d'un intervalle par une fonction continue 🔴🟠

📌 Énoncé (polycopié 4.3)Théorème : I intervalle, f : I → R continue ⇒ f(I) est un intervalle. Attention : f(I) ne se lit pas à partir de f(a), f(b) : x² sur [−1,1] donne [0,1] alors que [f(−1), f(1)] = [1,1].
🗣️ En françaisC'est le TVI reformulé avec la caractérisation des intervalles (N3) : l'image n'a « pas de trou ».
❓ Q. Énonce le théorème et dis pourquoi f(I) peut être différent de [f(a),f(b)].Si f monte puis redescend, l'image dépasse f(b).
🧩 Démonstration 🟠Soient y₁ = f(x₁), y₂ = f(x₂) dans f(I), y₁ ≤ y₂, et y tel que y₁ ≤ y ≤ y₂. y est compris entre f(x₁) et f(x₂) ; le TVI sur le segment d'extrémités x₁, x₂ (contenu dans I car I est un intervalle) donne x avec f(x) = y : y ∈ f(I). Par la caractérisation (N3), f(I) est un intervalle. ∎

N38 · Fonction continue sur un segment : bornée et bornes atteintes 🔴🟢

📌 Énoncé (polycopié 4.4)
  • Théorème : f : [a,b] → R continue ⇒ f est bornée, et il existe α, β ∈ [a,b] avec f(α) ≤ f(x) ≤ f(β) pour tout x : elle atteint son min m = f(α) et son max M = f(β).
  • Corollaire : f([a,b]) = [m,M] : l'image d'un segment est un segment.
  • Faux sans « segment » : 1/x sur ]0,1] est continue mais non majorée.
🗣️ En françaisSur un segment (fermé borné), une fonction continue ne peut pas « s'échapper vers l'infini » et elle atteint réellement son plus haut et son plus bas niveau. On l'utilise pour dire « il existe un max » dans les sujets.
❓ Q. Donne un contre-exemple si le domaine n'est pas fermé, puis s'il n'est pas borné.1/x sur ]0,1] (non bornée) ; x sur [0,+∞[ (non bornée) ; x sur ]0,1[ (bornée, mais n'atteint ni 0 ni 1).
🧩 Idée de preuve 🟢Bornée. Sinon, pour tout n il existe xₙ ∈ [a,b] avec |f(xₙ)| ≥ n. B–W : sous-suite x_φ(n) → c ∈ [a,b]. Par continuité f(x_φ(n)) → f(c), donc |f(x_φ(n))| est bornée, contradiction avec ≥ φ(n) → +∞.
Max atteint. M = sup f([a,b]) existe (bornée). Il existe xₙ avec f(xₙ) → M ; B–W : x_φ(n) → β ∈ [a,b] ; continuité : f(β) = lim f(x_φ(n)) = M. Idem pour le min. Corollaire : l'image est un intervalle (N37) contenant m et M et contenue dans [m,M] : c'est [m,M].

N39 · Monotonie et théorème de la bijection 🔴🟠

📌 Énoncé (polycopié 4.5)
  • I intervalle, f : I → R strictement monotone ⇒ f est injective.
  • I intervalle, f strictement monotone et f(I) intervalle ⇒ f est continue.
  • Théorème de la bijection : f : I → R continue et strictement monotone. Alors J = f(I) est un intervalle, f : I → J est bijective, et f⁻¹ : J → I est continue et strictement monotone de même sens.
  • Exemple : x ↦ x² de [0,+∞[ dans [0,+∞[ est bijective ; sa réciproque √ est continue strictement croissante.
🗣️ En françaisTVI donne l'existence d'un antécédent ; la stricte monotonie donne l'unicité (injectivité). Ensemble : exactement un antécédent pour chaque valeur de J. Définitions rappelées : injective : f(x) = f(x') ⇒ x = x' ; surjective : tout y a un antécédent ; bijective : les deux.
❓ Q1. Énonce le théorème de la bijection avec ses hypothèses.Voir énoncé : continuité et stricte monotonie, sur un intervalle.
❓ Q2. Pourquoi x ↦ 1/x n'est pas décroissante sur R* ?−1 < 1 mais f(−1) = −1 < 1 = f(1) : l'inégalité n'est pas renversée. Elle est strictement décroissante sur chaque intervalle ]−∞,0[ et ]0,+∞[.
🧩 Démonstrations 🟠 Strictement monotone ⇒ injective. Si x ≠ x', disons x < x', alors f(x) < f(x') ou f(x) > f(x') : dans les deux cas f(x) ≠ f(x').
Théorème. f(I) = J est un intervalle (N37). f : I → J est injective (ci-dessus) et surjective par définition de J : bijective. Monotonie de f⁻¹ (cas strictement croissante) : y < y' dans J, x = f⁻¹(y), x' = f⁻¹(y'). Si x ≥ x', alors y = f(x) ≥ f(x') = y', contradiction : donc x < x'. Continuité de f⁻¹ : f⁻¹ : J → I est strictement monotone et son image I est un intervalle, donc continue par la deuxième proposition (le « pas de saut » : une fonction strictement monotone qui saute omettrait des valeurs de I). ∎
🧩 Application — surjection et bijection de fonctions usuelles 🟠f(x) = x³ + x : continue, strictement croissante (somme de deux strictement croissantes), f → ±∞ en ±∞ : f(R) = R et f bijective de R sur R. Le √ se construit ainsi, sans ε–δ.

N40 · Continuité uniforme, théorème de Heine 🔴🟢

📌 Énoncé (polycopié 4.6, « complément »)
  • f : A → R est uniformément continue sur A si ∀ε > 0, ∃δ > 0, ∀x,y ∈ A, |x − y| < δ ⇒ |f(x) − f(y)| < ε.
  • Lipschitzienne ⇒ uniformément continue ⇒ continue. Réciproques fausses : √x sur [0,+∞[ est uniformément continue mais pas lipschitzienne ; x² est continue sur R mais pas uniformément.
  • Théorème de Heine : f continue sur un segment [a,b] ⇒ uniformément continue.
🗣️ En françaisContinuité ordinaire : δ dépend de ε et du point a. Uniforme : δ ne dépend que de ε (le même pour tous les points). Les quantificateurs : ∀ε ∃δ ∀x,y (uniforme) contre ∀a ∀ε ∃δ ∀x. Chapitre complément : l'énoncé suffit pour le partiel.
🧩 Lipschitzienne ⇒ unif. continue ⇒ continue 🟠Si f est κ-lipschitzienne, δ = ε/(κ+1) convient pour tous x,y : |f(x) − f(y)| ≤ κ|x−y| < κδ ≤ ε. Si f est uniformément continue, fixer y = a dans la définition donne la continuité en a. x² pas uniformément continue : xₙ = n+1/n, yₙ = n : |xₙ − yₙ| = 1/n → 0 mais |xₙ² − yₙ²| = 2 + 1/n² ≥ 2.
