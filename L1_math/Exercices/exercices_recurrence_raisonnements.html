✏️ Exercices — Récurrence & raisonnements classiques

Cache la correction avant de cliquer sur "Réponse" — cherche vraiment, même 10-15 minutes, avant de regarder. Et pense à rédiger ta réponse en phrases complètes, pas juste le calcul : c'est ça, la moitié des points en L1.

💡 Envie de plus d'exercices ? Cette page couvre les deux chapitres vus « en avance ». Pour aller plus loin, la page ressources externes t'indique où trouver, sur Exo7, les fiches correspondantes avec encore plus d'exercices corrigés.

🟢 Niveau facile — récurrence, l'essentiel

1. Rappelle les deux étapes du principe de récurrence pour prouver ∀n ≥ n₀, P(n).

Réponse
  1. Initialisation : montrer que P(n₀) est vraie.
  2. Hérédité : montrer que ∀n ≥ n₀, P(n) ⇒ P(n+1) (en supposant P(n) vraie, en déduire que P(n+1) l'est aussi).

2. Dans une hérédité, un étudiant écrit directement la formule pour P(N+1) sans jamais se servir de P(N). Qu'est-ce qui cloche ?

Réponse Le principe même de la récurrence est de partir de l'hypothèse P(N) pour en déduire P(N+1). Si on ne s'en sert jamais, la démonstration ne prouve rien par récurrence — c'est une erreur très fréquente à l'écrit.

3. Pour prouver ∀n ∈ N, P(n), à quel rang doit-on vérifier l'initialisation ?

Réponse Au rang n₀ = 0 (puisque N commence à 0). Si l'énoncé porte sur ∀n ≥ 1, l'initialisation se fait au rang 1, etc. — c'est toujours le premier rang concerné par l'énoncé.

🟡 Niveau intermédiaire — rédiger une récurrence complète

4. (grand classique) Montre par récurrence que pour tout n ∈ N :

Σ(k=0 à n) k  =  n(n+1) / 2
Solution proposée Considérons P(n) : Σ(k=0 à n) k = n(n+1)/2.

Initialisation. Pour n = 0 : à gauche, la somme vaut 0 ; à droite, 0×1/2 = 0. Les deux valent 0, donc P(0) est vraie.

Hérédité. Soit n ∈ N. Supposons P(n) vraie, c'est-à-dire Σ(k=0 à n) k = n(n+1)/2. Montrons P(n+1) : 
Σ(k=0 à n+1) k = Σ(k=0 à n) k + (n+1)
               = n(n+1)/2 + (n+1)
               = (n+1)(n/2 + 1)
               = (n+1)(n+2)/2
On retrouve bien la formule au rang n+1, donc P(n+1) est vraie.

Conclusion. Par récurrence, P(n) est vraie pour tout n ∈ N.

5. Montre par récurrence que pour tout n ∈ N, 2ⁿ ≥ n + 1.

Solution proposée Considérons P(n) : 2ⁿ ≥ n + 1.

Initialisation. Pour n = 0 : 2⁰ = 1 ≥ 0 + 1 = 1. C'est vrai (égalité).

Hérédité. Soit n ∈ N. Supposons 2ⁿ ≥ n + 1. Alors : 
2ⁿ⁺¹ = 2 × 2ⁿ ≥ 2(n+1) = 2n + 2 = (n+2) + n ≥ n + 2
(on utilise n ≥ 0 pour la dernière inégalité). Donc 2ⁿ⁺¹ ≥ n + 2 = (n+1) + 1, ce qui est exactement P(n+1).

Conclusion. Par récurrence, 2ⁿ ≥ n + 1 pour tout n ∈ N.

6. Montre par récurrence que pour tout n ∈ N*, n³ - n est divisible par 6.

Solution proposée Considérons P(n) : « n³ - n est divisible par 6 », pour n ≥ 1.

Initialisation. Pour n = 1 : 1³ - 1 = 0, et 0 est divisible par 6. Donc P(1) est vraie.

Hérédité. Soit n ≥ 1. Supposons qu'il existe k ∈ Z tel que n³ - n = 6k. Montrons P(n+1) : 
(n+1)³ - (n+1) = n³ + 3n² + 3n + 1 - n - 1
               = (n³ - n) + 3n² + 3n
               = 6k + 3n(n+1)
Or n(n+1) est un produit de deux entiers consécutifs, donc toujours pair : n(n+1) = 2m pour un certain m ∈ Z. Donc 3n(n+1) = 6m, et : 
(n+1)³ - (n+1) = 6k + 6m = 6(k+m)
qui est bien divisible par 6. Donc P(n+1) est vraie.

Conclusion. Par récurrence, n³ - n est divisible par 6 pour tout n ∈ N*.

🔴 Niveau avancé — récurrence forte

7. Quelle est la différence entre la récurrence « simple » et la récurrence « forte » ?

Réponse Dans la récurrence simple, pour prouver P(n+1) on a le droit de supposer seulement P(n). Dans la récurrence forte, on a le droit de supposer P(k) vraie pour tous les rangs k entre n₀ et n — c'est plus puissant, utile quand un seul rang précédent ne suffit pas à faire le calcul.

8. (suite de Fibonacci) On définit u₀ = 1, u₁ = 1, et uₙ₊₂ = uₙ₊₁ + uₙ. Montre par récurrence forte que pour tout n ∈ N, uₙ ≤ 2ⁿ.

Solution proposée Considérons P(n) : uₙ ≤ 2ⁿ.

Initialisation (à deux rangs, car la relation fait intervenir deux termes précédents).
u₀ = 1 ≤ 2⁰ = 1 ✅ et u₁ = 1 ≤ 2¹ = 2 ✅.

Hérédité. Soit n ∈ N. Supposons P(k) vraie pour tout k avec 0 ≤ k ≤ n+1 (en particulier pour les rangs n et n+1). Montrons P(n+2) : 
uₙ₊₂ = uₙ₊₁ + uₙ ≤ 2ⁿ⁺¹ + 2ⁿ ≤ 2ⁿ⁺¹ + 2ⁿ⁺¹ = 2 × 2ⁿ⁺¹ = 2ⁿ⁺²
Donc P(n+2) est vraie.

Conclusion. Par récurrence forte, uₙ ≤ 2ⁿ pour tout n ∈ N. (Et c'est exactement pour ce genre de suite — où un terme dépend de deux termes précédents — qu'on a besoin de la version forte, avec une initialisation sur deux rangs.)

🧭 Raisonnements classiques — repérer la bonne méthode

9. Pour chacun de ces énoncés à prouver, quelle méthode choisirais-tu en premier réflexe : absurde, contraposée, équivalence, contre-exemple, ou récurrence ?

  • a) ∀n ∈ N, 3ⁿ ≥ n + 1
  • b) « L'assertion "toute fonction est croissante ou décroissante" est fausse »
  • c) n² impair ⇒ n impair
  • d) x = 2 ⇔ x² - 4 = 0 et x ≥ 0
Réponse a) Récurrence (un « pour tout n ∈ N » avec une relation entre rangs successifs).
b) Contre-exemple (montrer qu'une assertion universelle est fausse : il suffit d'exhiber une fonction qui n'est ni l'un ni l'autre, par exemple x ↦ x² sur R).
c) Contraposée (prouver directement « impair » à partir de « n² impair » est pénible ; « n pair ⇒ n² pair » est immédiat).
d) Équivalence : il faut montrer les deux implications séparément (sens direct et réciproque).

10. (par l'absurde) Montre qu'il n'existe pas de plus grand entier naturel.

Solution proposée Supposons par l'absurde qu'il existe un plus grand entier naturel, notons-le N. Alors N + 1 est aussi un entier naturel, et N + 1 > N. Cela contredit le fait que N soit le plus grand. Contradiction, donc l'hypothèse de départ est fausse : il n'existe pas de plus grand entier naturel.

11. (par contraposée) Soit n ∈ Z. Montre par contraposée que « n² non divisible par 3 » ⇒ « n non divisible par 3 ».

Solution proposée La contraposée à montrer est : « n divisible par 3 » ⇒ « n² divisible par 3 ».

Si n est divisible par 3, alors il existe k ∈ Z tel que n = 3k. On a alors n² = 9k² = 3(3k²), qui est bien divisible par 3.

La contraposée étant vraie, l'implication de départ l'est aussi. ✅

🏆 Défi — combiner récurrence et raisonnements

12. Montre par récurrence que pour tout n ∈ N, 1 + 2 + 4 + ... + 2ⁿ = 2ⁿ⁺¹ - 1 (somme des puissances de 2 de 0 à n).

Solution proposée Considérons P(n) : Σ(k=0 à n) 2ᵏ = 2ⁿ⁺¹ - 1.

Initialisation. Pour n = 0 : à gauche 2⁰ = 1 ; à droite 2¹ - 1 = 1. Égalité vérifiée, P(0) est vraie.

Hérédité. Soit n ∈ N. Supposons P(n) vraie. Alors : 
Σ(k=0 à n+1) 2ᵏ = Σ(k=0 à n) 2ᵏ + 2ⁿ⁺¹
                = (2ⁿ⁺¹ - 1) + 2ⁿ⁺¹
                = 2 × 2ⁿ⁺¹ - 1
                = 2ⁿ⁺² - 1
qui est bien la formule au rang n+1. Donc P(n+1) est vraie.

Conclusion. Par récurrence, la formule est vraie pour tout n ∈ N.

13. (contre-exemple + rédaction) Un camarade affirme : « pour tout entier naturel n, n² + n + 41 est un nombre premier ». Montre que c'est faux.

Solution proposée Il suffit de trouver un seul contre-exemple. Testons n = 41 : 
41² + 41 + 41 = 41(41 + 1 + 1) = 41 × 43
Ce nombre est divisible par 41 (et différent de 41), donc il n'est pas premier. L'assertion est donc fausse dès n = 41.

(Remarque amusante : cette formule donne bien des nombres premiers pour n = 0 à 39 — c'est un exemple classique pour montrer qu'il ne faut jamais se fier à « ça marche sur les premiers cas testés » comme preuve !)

14. (absurde + récurrence) Montre que pour tout n ∈ N, il n'existe pas d'entier naturel m tel que n < m < n + 1.

Solution proposée Soit n ∈ N fixé. Supposons par l'absurde qu'il existe m ∈ N avec n < m < n + 1.

Comme m et n sont des entiers avec m > n, on a nécessairement m ≥ n + 1 (il n'y a pas d'entier strictement entre deux entiers consécutifs — propriété de N). Mais on a supposé m < n + 1. Donc n + 1 ≤ m < n + 1, ce qui est absurde (un nombre ne peut pas être strictement inférieur à lui-même).

Donc un tel m n'existe pas, pour tout n ∈ N.
