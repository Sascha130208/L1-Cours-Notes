Exercice 1 — Vrai ou faux ?

1. Soient (u_n) une suite réelle croissante et (v_n) une suite réelle convergente qui vérifient u_n ≤ v_n pour tout n. La suite (u_n) converge-t-elle ?

Réponse Vrai. (v_n) converge donc elle est bornée (Prop. 5, chapitre 2) : il existe M tel que v_n ≤ M pour tout n. Alors u_n ≤ v_n ≤ M : (u_n) est croissante et majorée, donc elle converge (Théorème 2, chapitre 2).

2. Soient (u_n) une suite réelle qui converge et (v_n) une suite réelle qui diverge. La suite (u_nv_n) diverge-t-elle ?

Réponse Faux. Contre-exemple : u_n = 0 pour tout n (converge vers 0), v_n = (-1)ⁿ (diverge). Alors u_nv_n = 0 pour tout n, qui converge. (Le résultat est vrai si on suppose en plus lim u_n ≠ 0.)

3. Soit (u_n) une suite de réels positifs qui converge vers 0. La suite (u_n) est-elle décroissante à partir d'un certain rang ?

Réponse Faux. Contre-exemple : u_n = (2+(-1)ⁿ)/n pour n≥1. On a bien u_n → 0 et u_n > 0. Mais en comparant termes voisins, u_n ne finit jamais par être décroissante : elle « zigzague » indéfiniment entre une branche ≈ 3/n (n pair) et une branche ≈ 1/n (n impair), avec des alternances de hausse et de baisse à chaque pas, aussi loin qu'on aille dans la suite.

4. Soit (u_n) une suite réelle avec lim(n→+∞)(u_(n+1)-u_n) = 0. La suite (u_n) converge-t-elle ?

Réponse Faux. Contre-exemple : u_n = √n. On a u_(n+1)-u_n = √(n+1)-√n → 0 (calcul classique par quantité conjuguée), mais u_n = √n → +∞, donc (u_n) diverge.

Exercice 2 — Critère du rapport (généralisation)

Soit (u_n) une suite de réels strictement positifs telle que ℓ = lim(n→+∞) u_(n+1)/u_n ∈ [0,+∞] existe.

1. Supposons ℓ ∈ [0,1[. Montre que (u_n) est strictement décroissante à partir d'un certain rang puis que lim u_n = 0.

Solution proposée Choisissons r tel que ℓ < r < 1 (par exemple r = (ℓ+1)/2). Comme u_(n+1)/u_n → ℓ < r, il existe N tel que n ≥ N ⇒ u_(n+1)/u_n < r.

Décroissance. Comme u_n > 0 et r < 1, on a pour n ≥ N : u_(n+1) < r·u_n < u_n. La suite est strictement décroissante à partir du rang N.

Limite nulle. Par récurrence, pour n ≥ N : u_n < r^(n-N)·u_N. Comme 0 ≤ r < 1, on a r^(n-N) → 0 quand n → +∞ (Prop. 8, chapitre 2). Comme de plus u_n > 0, on a 0 < u_n < r^(n-N)u_N → 0, et par le théorème des gendarmes, u_n → 0. ∎

2. Supposons ℓ ∈ ]1,+∞]. Montre que (u_n) est strictement croissante à partir d'un certain rang puis que lim u_n = +∞.

Solution proposée Posons w_n = 1/u_n > 0. Alors w_(n+1)/w_n = u_n/u_(n+1) → 1/ℓ. Comme ℓ > 1, on a 1/ℓ ∈ [0,1[ (y compris si ℓ = +∞, où 1/ℓ = 0).

On applique la question 1 à la suite (w_n) : elle est strictement décroissante à partir d'un certain rang, et w_n → 0.

Comme w_n = 1/u_n → 0 avec u_n > 0, on en déduit u_n → +∞. Et (w_n) décroissante signifie w_(n+1) < w_n, c'est-à-dire 1/u_(n+1) < 1/u_n, donc (les u_n étant positifs) u_(n+1) > u_n : (u_n) est strictement croissante à partir du même rang. ∎

3. En considérant les cas où u_n = n et où u_n = 1/(n+1), montre qu'on ne peut pas conclure sur le comportement asymptotique de (u_n) lorsque ℓ = 1.

Solution proposée Pour u_n = n : u_(n+1)/u_n = (n+1)/n → 1, et u_n = n → +∞.

Pour u_n = 1/(n+1) : u_(n+1)/u_n = (n+1)/(n+2) → 1, et u_n → 0.

Les deux suites ont le même ℓ = 1, mais des comportements radicalement différents (+∞ contre 0). Le critère du rapport ne dit donc rien quand ℓ = 1 : il faut étudier la suite par une autre méthode dans ce cas.

Exercice 3 — Calculs de limites

a) (2n³-n+1)/(n³-n²+1)   b) ⌊(3n²+(-1)ⁿ)/(n+1)⌋   c) 2ⁿ/n²⁰²⁶   d) 2026ⁿ/n!

Réponses a) Fraction rationnelle, même degré (3) au numérateur et au dénominateur : la limite est le rapport des coefficients dominants, 2/1 = 2.

b) (3n²+(-1)ⁿ)/(n+1) → +∞ (degré 2 au numérateur contre degré 1 au dénominateur, le (-1)ⁿ borné n'y change rien). Si une suite tend vers +∞, sa partie entière aussi (car ⌊x_n⌋ ≥ x_n - 1 → +∞). Donc la limite est +∞.

c) 2ⁿ/n²⁰²⁶ → +∞ : toute exponentielle de base >1 écrase n'importe quelle puissance de n (croissances comparées, cf. Chapitre 4).

d) 2026ⁿ/n! → 0 : c'est exactement l'Exemple 9 du chapitre 2 (« aⁿ/n! → 0 pour tout a ∈ R ») — la factorielle bat toujours l'exponentielle.

Exercice 4 — ζ(2), via des suites adjacentes

Soient (S_n)_(n≥1) et (T_n)_(n≥1) définies par S_n = Σ(k=1 à n) 1/k² et T_n = S_n + 1/n.

1. Montre que (S_n) et (T_n) sont adjacentes.

Solution proposée (S_n) croissante. S_(n+1) - S_n = 1/(n+1)² > 0. ✓

(T_n) décroissante. 
T_(n+1) - T_n = [S_(n+1)+1/(n+1)] - [S_n+1/n]
              = 1/(n+1)² + 1/(n+1) - 1/n
              = 1/(n+1)² - [1/n - 1/(n+1)]
              = 1/(n+1)² - 1/(n(n+1))
              = [n - (n+1)] / [n(n+1)²]
              = -1 / [n(n+1)²] < 0
Donc (T_n) est décroissante. ✓

S_n ≤ T_n. T_n - S_n = 1/n > 0, donc S_n < T_n. ✓

lim(T_n-S_n) = 0. T_n - S_n = 1/n → 0. ✓

Les trois conditions de la Définition 7 (chapitre 2) sont vérifiées : (S_n) et (T_n) sont adjacentes.

2. En déduire que S = lim(n→+∞) S_n ∈ R existe et que S ≤ 2.

Solution proposée Par le Théorème 3 (chapitre 2), deux suites adjacentes convergent vers la même limite : S = lim S_n = lim T_n existe dans R.

Comme (T_n) est décroissante, T_n ≤ T_1 pour tout n ≥ 1. Or T_1 = S_1 + 1/1 = 1 + 1 = 2. Donc S_n ≤ T_n ≤ T_1 = 2 pour tout n. En passant à la limite : S ≤ 2. ∎

(Remarque : cette limite s'appelle ζ(2), et vaut en réalité π²/6 ≈ 1,645 — un résultat célèbre d'Euler que tu verras probablement plus tard.)

Exercice 5 — La série harmonique diverge

Soit (H_n)_(n≥1) définie par H_n = Σ(k=1 à n) 1/k.

1. Montre que (H_n) est croissante.

Solution proposée H_(n+1) - H_n = 1/(n+1) > 0 pour tout n ≥ 1. Donc (H_n) est (strictement) croissante. ∎

2. Montre que H_(2n) - H_n ≥ 1/2 pour tout n ∈ N*.

Solution proposée 
H_(2n) - H_n = 1/(n+1) + 1/(n+2) + ... + 1/(2n)
Cette somme comporte exactement n termes (de k=n+1 à k=2n), et chacun de ces termes vérifie 1/k ≥ 1/(2n) (car k ≤ 2n). Donc : 
H_(2n) - H_n ≥ n × 1/(2n) = 1/2
∎

3. Montre que lim(n→+∞) H_n = +∞.

Solution proposée (H_n) est croissante (question 1), donc par le Théorème 2 (chapitre 2), soit elle converge vers une limite finie L, soit elle tend vers +∞.

Supposons par l'absurde qu'elle converge vers L ∈ R. Alors la sous-suite (H_(2n)) converge aussi vers L (Prop. 12, chapitre 2 : toute sous-suite d'une suite convergente converge vers la même limite). Donc : 
H_(2n) - H_n → L - L = 0
Mais d'après la question 2, H_(2n) - H_n ≥ 1/2 pour tout n, donc en passant à la limite, 0 ≥ 1/2 — contradiction.

Donc (H_n) ne converge pas vers une limite finie ; étant croissante, elle tend nécessairement vers +∞. ∎

Exercice 6 — Critère spécial des séries alternées

Soit (u_n)_(n≥0) une suite décroissante de réels positifs convergeant vers 0, et S_n = Σ(k=0 à n) (-1)ᵏu_k.

1. Montre que (S_2n) et (S_(2n+1)) sont adjacentes.

Solution proposée (S_2n) décroissante. 
S_(2n+2) - S_2n = (-1)^(2n+1)u_(2n+1) + (-1)^(2n+2)u_(2n+2) = -u_(2n+1) + u_(2n+2)
Comme (u_n) est décroissante, u_(2n+2) ≤ u_(2n+1), donc -u_(2n+1)+u_(2n+2) ≤ 0 : S_(2n+2) ≤ S_2n. ✓

(S_(2n+1)) croissante. 
S_(2n+3) - S_(2n+1) = (-1)^(2n+2)u_(2n+2) + (-1)^(2n+3)u_(2n+3) = u_(2n+2) - u_(2n+3)
Comme (u_n) décroissante, u_(2n+2) ≥ u_(2n+3), donc cette différence est ≥ 0 : S_(2n+3) ≥ S_(2n+1). ✓

S_(2n+1) ≤ S_2n. S_2n - S_(2n+1) = -(-1)^(2n+1)u_(2n+1) = u_(2n+1) ≥ 0 (car u_n ≥ 0). ✓

lim(S_2n - S_(2n+1)) = 0. C'est lim u_(2n+1) = 0, vrai car u_n → 0 et une sous-suite d'une suite convergente vers 0 converge aussi vers 0. ✓

Les trois conditions sont réunies (avec (S_(2n+1)) croissante ≤ (S_2n) décroissante, différence → 0) : les deux suites sont adjacentes.

2. En déduire que S = lim(n→+∞) S_n ∈ R existe et que S_(2n+1) ≤ S ≤ S_2n pour tout n.

Solution proposée Par le Théorème 3, (S_2n) et (S_(2n+1)) étant adjacentes, elles convergent vers une même limite S ∈ R. De plus, pour des suites adjacentes, chaque terme de la suite croissante est ≤ S et chaque terme de la suite décroissante est ≥ S : S_(2n+1) ≤ S ≤ S_2n pour tout n.

Il reste à voir que la suite (S_n) elle-même (pas seulement ses deux sous-suites) converge vers S. Fixons ε > 0 : il existe N₁ tel que n≥N₁ ⇒ |S_2n - S| < ε, et N₂ tel que n≥N₂ ⇒ |S_(2n+1)-S| < ε. En posant N = max(2N₁, 2N₂+1), tout m ≥ N (pair ou impair) vérifie |S_m - S| < ε. Donc S_n → S. ∎

(C'est le critère spécial des séries alternées (critère de Leibniz), une méthode très puissante : elle prouve la convergence — et donne même un encadrement de l'erreur — sans jamais calculer la somme exacte.)
