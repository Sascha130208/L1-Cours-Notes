Exercice 1 — Vrai ou faux ?

1. Soit (u_n) une suite réelle telle que (|u_n|) converge. La suite (u_n) converge-t-elle ?

Réponse Faux. Contre-exemple : u_n = (-1)ⁿ. Alors |u_n| = 1 pour tout n (constante, donc convergente), mais (u_n) oscille entre 1 et -1 et ne converge pas.

2. Soit (u_n) une suite réelle telle que lim|u_n| = 0. A-t-on lim u_n = 0 ?

Réponse Vrai. |u_n| → 0 signifie ∀ε>0, ∃N, n≥N ⇒ ||u_n|-0| < ε, c'est-à-dire |u_n| < ε. Mais c'est exactement |u_n - 0| < ε. C'est donc précisément la définition de u_n → 0. (Attention, ce résultat est spécifique au cas où la limite de |u_n| vaut 0 — ce n'est pas vrai pour une limite non nulle, cf. exercice précédent avec |u_n|→1.)

3. Soit (u_n) une suite de réels non nuls telle que (1/u_n) converge. La suite (u_n) converge-t-elle ?

Réponse Faux. Contre-exemple : u_n = n. Alors 1/u_n = 1/n → 0 (converge), mais u_n = n → +∞ (diverge).

4. Soit (u_n) une suite de réels non nuls qui diverge. A-t-on lim 1/u_n = 0 ?

Réponse Faux. Contre-exemple : u_n = (-1)ⁿ (diverge, ne tend pas vers ±∞). Alors 1/u_n = (-1)ⁿ également, qui ne tend pas vers 0 (elle diverge aussi). Le résultat 1/u_n → 0 n'est garanti que si u_n → +∞ ou u_n → -∞.

Exercice 2 — Calculs de limites

Détermine (lorsqu'elle existe) la limite de chaque suite.

a) √n   b) n-√n   c) (n²-n-2)/(2n+1)   d) (-1)ⁿn/(n+1)   e) n+(-1)ⁿ   f) √(n+1)-√n

Réponses a) √n → +∞.

b) n-√n = n(1 - 1/√n) → +∞ (car 1-1/√n → 1 et n → +∞).

c) Fraction rationnelle, degré 2 au numérateur contre degré 1 au dénominateur, coefficient dominant positif : (n²-n-2)/(2n+1) → +∞.

d) N'a pas de limite. La sous-suite des rangs pairs u_(2n) = 2n/(2n+1) → 1, la sous-suite des rangs impairs u_(2n+1) = -( 2n+1)/(2n+2) → -1. Deux sous-suites, deux limites différentes : la suite diverge.

e) n+(-1)ⁿ → +∞ : (-1)ⁿ est bornée, elle est « absorbée » par n → +∞ (Prop. 4.2, chapitre 2).

f) Quantité conjuguée : √(n+1)-√n = 1/(√(n+1)+√n) → 0 (dénominateur → +∞).

Exercice 3 — Rédaction de preuves

1. Soient (u_n) une suite réelle bornée et (v_n) une suite réelle convergeant vers 0. Montre que lim(n→+∞) u_nv_n = 0.

Solution proposée C'est la Proposition 6 du cours (chapitre 2). Comme (u_n) est bornée, il existe M > 0 tel que |u_n| ≤ M pour tout n. Fixons ε > 0. Comme v_n → 0, il existe N tel que n ≥ N ⇒ |v_n| < ε/M. Alors pour n ≥ N : 
|u_nv_n| = |u_n|·|v_n| ≤ M × ε/M = ε
Donc u_nv_n → 0. ∎

2. Soit (u_n) une suite réelle telle que lim(n→+∞)(u_(n+1)-u_n) ∈ ]0,+∞] existe. Montre que (u_n) est strictement croissante à partir d'un certain rang puis qu'elle vérifie lim u_n = +∞.

Solution proposée Notons L = lim(u_(n+1)-u_n) ∈ ]0,+∞]. Dans tous les cas (L fini ou infini), il existe une constante c > 0 et un rang N tels que u_(n+1) - u_n ≥ c pour tout n ≥ N (par exemple c = L/2 si L est fini, ou c = 1 si L = +∞, en utilisant la définition de la limite dans chaque cas).

Stricte croissance. Comme c > 0, pour n ≥ N on a u_(n+1) > u_n : la suite est strictement croissante à partir du rang N.

Divergence vers +∞. Pour n ≥ N, en sommant les différences (somme télescopique) : 
u_n = u_N + Σ(k=N à n-1) (u_(k+1)-u_k) ≥ u_N + (n-N)·c
Comme c > 0, le membre de droite tend vers +∞ quand n → +∞. Par comparaison (Prop. 7.2, chapitre 2), u_n → +∞. ∎

3. Soit (u_n) une suite réelle qui ne tend pas vers +∞. Montre que (u_n) admet une sous-suite majorée.

Solution proposée « (u_n) ne tend pas vers +∞ » signifie que la propriété ∀A>0, ∃N, ∀n≥N, u_n≥A est fausse, c'est-à-dire (négation) : 
∃A > 0, ∀N, ∃n ≥ N, u_n < A
Fixons un tel A. On construit une suite d'indices strictement croissante par récurrence : pour N=0, on obtient n_0 ≥ 0 avec u_(n_0) < A. Pour N = n_0+1, on obtient n_1 ≥ n_0+1 > n_0 avec u_(n_1) < A. En itérant, on construit n_0 < n_1 < n_2 < ... tels que u_(n_k) < A pour tout k.

La sous-suite (u_(n_k)) est donc majorée par A. ∎

4. Soit (u_n) une suite d'entiers qui converge. Montre que (u_n) est constante à partir d'un certain rang.

Solution proposée Notons ℓ = lim u_n. En appliquant la définition de la limite avec ε = 1/2 : il existe N tel que n ≥ N ⇒ |u_n - ℓ| < 1/2.

Pour n, m ≥ N, par l'inégalité triangulaire : 
|u_n - u_m| ≤ |u_n - ℓ| + |ℓ - u_m| < 1/2 + 1/2 = 1
Or u_n et u_m sont des entiers, donc |u_n-u_m| est un entier ≥ 0. Le seul entier strictement inférieur à 1 est 0. Donc u_n = u_m pour tous n,m ≥ N : la suite est constante (égale à u_N) à partir du rang N. ∎

Exercice 4 — Moyennes de Cesàro

1. Soit (u_n) une suite convergeant vers ℓ ∈ R. Montre que lim(n→+∞) (u_0+u_1+...+u_n)/(n+1) = ℓ.

Solution proposée Posons v_n = u_n - ℓ, de sorte que v_n → 0. Il suffit de montrer que la moyenne des v_n tend vers 0 (on retrouvera le résultat en ajoutant ℓ, puisque la moyenne de (u_n) est la moyenne de (v_n) plus ℓ).

Fixons ε > 0. Comme v_n → 0, il existe N tel que n ≥ N ⇒ |v_n| < ε/2. Découpons la moyenne en deux paquets : 
(v_0+...+v_n)/(n+1) = (v_0+...+v_(N-1))/(n+1) + (v_N+...+v_n)/(n+1)
Le premier terme a un numérateur C = v_0+...+v_(N-1) constant (indépendant de n), donc C/(n+1) → 0 : il existe N' tel que n ≥ N' ⇒ |C/(n+1)| < ε/2.

Le second terme contient n-N+1 termes, chacun de valeur absolue < ε/2, donc : 
|(v_N+...+v_n)/(n+1)| ≤ (n-N+1)/(n+1) × ε/2 ≤ ε/2
(car (n-N+1)/(n+1) ≤ 1). Pour n ≥ max(N,N'), la somme des deux termes est < ε/2 + ε/2 = ε. Donc la moyenne des v_n tend vers 0, et donc la moyenne des u_n tend vers ℓ. ∎

2. Soit (u_n) une suite convergeant vers ℓ ∈ R. Détermine lim(n→+∞) (0·u_0+1·u_1+...+n·u_n)/n².

Solution proposée Intuition. Comme u_k → ℓ, on a k·u_k ≈ k·ℓ pour k grand, et Σ(k=0 à n) k ≈ n²/2. On s'attend donc à une limite égale à ℓ/2.

Rédaction. Écrivons u_k = ℓ + ε_k avec ε_k → 0. Notons S_n = Σ(k=0 à n) k·u_k. Alors : 
S_n = ℓ Σ(k=0 à n) k + Σ(k=0 à n) k·ε_k = ℓ · n(n+1)/2 + Σ(k=0 à n) k·ε_k
Donc : 
S_n/n² = ℓ(n+1)/(2n) + (1/n²) Σ(k=0 à n) k·ε_k
Le premier terme tend vers ℓ/2 (car (n+1)/(2n) → 1/2).

Pour le second terme, on adapte l'argument de la question 1 (« moyenne pondérée qui tend vers 0 ») : fixons η > 0, il existe N tel que k ≥ N ⇒ |ε_k| < η. Alors pour n ≥ N : 
|Σ(k=0 à n) k·ε_k| ≤ Σ(k=0 à N-1) k|ε_k| + Σ(k=N à n) k·η ≤ C' + η·n(n+1)/2
où C' est une constante (indépendante de n). En divisant par n² : 
(1/n²)|Σ k·ε_k| ≤ C'/n² + η(n+1)/(2n) → η/2  lorsque n → +∞
Ceci est vrai pour tout η > 0 arbitrairement petit, donc la limite supérieure de (1/n²)|Σ k·ε_k| vaut 0 : ce terme tend vers 0.

Conclusion. lim S_n/n² = ℓ/2 + 0 = ℓ/2.
