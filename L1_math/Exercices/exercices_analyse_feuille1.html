Exercice 1 — Vrai ou faux ?

Pour chaque question, réponds par « vrai » ou « faux » en justifiant.

1. Soient x ∈ Q et y ∈ R\Q. A-t-on x+y ∈ R\Q ? A-t-on xy ∈ R\Q ?

Réponse x+y ∈ R\Q : vrai. Si x+y était rationnel, alors y = (x+y) - x serait rationnel (différence de deux rationnels), ce qui contredit y ∈ R\Q. Donc x+y est irrationnel.

xy ∈ R\Q : faux en général. Contre-exemple : x = 0 ∈ Q, y = √2 ∈ R\Q, alors xy = 0 ∈ Q. (C'est vrai si on suppose x ≠ 0, mais l'énoncé ne le précise pas.)

2. L'ensemble {x ∈ R : 1 ≤ -2x+1 < 3} est-il un intervalle ? Est-ce un segment ?

Réponse On résout : 1 ≤ -2x+1 < 3 ⟺ 0 ≤ -2x < 2. En divisant par -2 (on inverse les inégalités !) : 0 ≥ x > -1, c'est-à-dire x ∈ ]-1, 0].

C'est bien un intervalle. Mais ce n'est pas un segment : un segment est un intervalle fermé et borné [a,b], or ]-1,0] n'est pas fermé en -1.

3. Soit x ∈ R tel que |x+2026| > 2026. A-t-on x > 0 ?

Réponse Faux. L'inégalité équivaut à x+2026 > 2026 ou x+2026 < -2026, c'est-à-dire x > 0 ou x < -4052. Contre-exemple : x = -5000 vérifie |x+2026| = |-2974| = 2974 > 2026, mais x < 0.

4. Soient x, y ∈ R tels que xy ≥ 0. A-t-on |x+y| = |x|+|y| ?

Réponse Vrai. xy ≥ 0 signifie que x et y sont de même signe (ou l'un des deux est nul). Si x,y ≥ 0 : x+y ≥ 0 donc |x+y| = x+y = |x|+|y|. Si x,y ≤ 0 : x+y ≤ 0 donc |x+y| = -(x+y) = |x|+|y|. Dans les deux cas, égalité.

5. Soient A et B deux parties de R telles que A est minorée, B est majorée et A ⊂ B. La partie A est-elle bornée ? La partie B est-elle bornée ?

Réponse A bornée : vrai. A est minorée par hypothèse. Comme A ⊂ B et B est majorée (par un certain M), tout élément de A est aussi ≤ M : donc A est aussi majorée. Minorée + majorée = bornée.

B bornée : faux. Rien ne dit que B est minorée. Contre-exemple : B = ]-∞, 5] (majorée par 5, non minorée), A = [0,1] ⊂ B (bien minorée). B n'est pas bornée.

6. L'ensemble {|x-1| : x ∈ R+} est-il minoré ? Admet-il un plus petit élément ?

Réponse Quand x décrit R+ = [0,+∞[, |x-1| décrit [0,+∞[ tout entier (la valeur 0 est atteinte en x=1, et |x-1| peut être arbitrairement grand). L'ensemble est donc [0,+∞[.

Il est minoré (par 0), et il admet un plus petit élément : min = 0, atteint en x = 1.

7. Soit A une partie non vide et majorée de R telle que sup(A) > 0. A-t-on a > 0 pour tout a ∈ A ? Existe-t-il a ∈ A tel que a > 0 ?

Réponse « a > 0 pour tout a ∈ A » : faux. Contre-exemple : A = [-1,1], sup(A) = 1 > 0, mais -1 ∈ A n'est pas > 0.

« Existe-t-il a ∈ A tel que a > 0 » : vrai. Par la caractérisation de la borne supérieure (Prop. 5, chapitre 1) appliquée à y = 0 < sup(A) : il existe a ∈ A tel que a > 0.

8. Soit x ∈ R. A-t-on ⌊2x⌋ = 2⌊x⌋ ?

Réponse Faux. Contre-exemple : x = 0,6. Alors ⌊x⌋ = 0 donc 2⌊x⌋ = 0, mais ⌊2x⌋ = ⌊1,2⌋ = 1 ≠ 0.

Exercice 2 — Est-ce un intervalle ?

Pour chacune des parties de R suivantes, détermine si c'est un intervalle.

a) ]-∞,-2] ∪ R+   b) [-1,1]∪]0,5]   c) ]-1,0[∪[0,1]   d) [-10,-2]∩]-4,4[   e) {x∈Q : x≥0}   f) {x∈R : 1≤x²≤4}

Réponses a) Non. Il y a un « trou » entre -2 et 0 : par exemple -3 et 1 sont dans l'ensemble, mais -1 (compris entre les deux) n'y est pas.

b) Oui. L'union vaut en fait [-1,5] : tout x ∈ [-1,0] est dans [-1,1], tout x ∈ ]0,5] est dans le second ensemble.

c) Oui. L'union vaut ]-1,1] (car [0,1] = {0}∪]0,1] recolle exactement avec ]-1,0[).

d) Oui. Une intersection de deux intervalles est toujours un intervalle. Ici [-10,-2]∩]-4,4[ = ]-4,-2].

e) Non. 0 et 2 sont dans l'ensemble, mais √2 (compris entre les deux) n'y est pas car irrationnel.

f) Non. 1≤x²≤4 ⟺ |x|∈[1,2] ⟺ x∈[-2,-1]∪[1,2]. -1 et 1 sont dans l'ensemble, mais 0 (entre les deux) n'y est pas.

Exercice 3 — Minorée/majorée, min/max, inf/sup

Pour chaque partie : est-elle minorée ? majorée ? quels sont (s'ils existent) son plus petit élément, son plus grand élément, sa borne inférieure, sa borne supérieure ?

a) [-1,0[∪[1,2[   b) {x∈R : |x|≤|x-2|}   c) N   d) {x∈R : x²+1≤10}   e) {x∈Q : x²≤2}   f) {1-1/n : n∈N*}

Réponses a) Minorée et majorée (bornée). min = -1 (atteint), inf = -1. Pas de maximum (les valeurs s'approchent de 2 sans jamais l'atteindre) mais sup = 2.

b) |x| ≤ |x-2| ⟺ x² ≤ (x-2)² ⟺ 0 ≤ -4x+4 ⟺ x ≤ 1. L'ensemble est ]-∞,1] : non minorée, majorée par 1. Pas de min, pas d'inf. max = 1 (atteint, car 1≤1), sup = 1.

c) N. Minorée (par 0), non majorée. min = inf = 0. Pas de max, pas de sup (borne supérieure infinie).

d) x²+1≤10 ⟺ x²≤9 ⟺ x∈[-3,3]. Bornée. min=inf=-3, max=sup=3 (les deux atteints).

e) Ensemble des rationnels dans [-√2,√2]. Bornée (majorée par exemple par 2, minorée par -2). sup = √2, inf = -√2 (bornes réelles, comme vu au chapitre 1) — mais ni max ni min : √2 est irrationnel donc jamais atteint par un élément de l'ensemble, et par densité de Q on peut toujours trouver un rationnel plus proche de √2.

f) C'est exactement l'exemple du cours (chapitre 1, Exemple 9) : minorée et majorée. min = inf = 0 (atteint en n=1). Pas de maximum, mais sup = 1.

Exercice 4 — Propriétés du sup/inf (rédaction complète)

1. Soit A une partie non vide et majorée de R, et posons -A = {-a : a∈A}. Montrer que -A est non vide et minoré et que inf(-A) = -sup(A).

Solution proposée A non vide ⇒ -A non vide (si a∈A, alors -a∈-A). Notons M = sup(A) (existe par le théorème R4, car A non vide majorée).

-M est un minorant de -A. Pour tout a∈A, a ≤ M, donc -a ≥ -M : tout élément de -A est ≥ -M.

-M est le plus grand des minorants. Soit m un minorant quelconque de -A : ∀a∈A, -a ≥ m, c'est-à-dire ∀a∈A, a ≤ -m. Donc -m est un majorant de A, donc -m ≥ M (M est le plus petit des majorants), donc m ≤ -M.

-M est donc bien le plus grand des minorants de -A : inf(-A) = -M = -sup(A). ∎

2. Soient A et B deux parties de R telles que A est non vide, B est majorée et A ⊂ B. Montrer que A est majorée et que sup(A) ≤ sup(B).

Solution proposée B majorée, non vide (car A⊂B et A non vide), donc M = sup(B) existe. Comme A⊂B, tout élément de A est un élément de B, donc ≤ M : M est un majorant de A, donc A est majorée.

A étant non vide et majorée, sup(A) existe, et comme sup(A) est le plus petit des majorants de A tandis que M en est un, on a sup(A) ≤ M = sup(B). ∎

3. Soient A et B deux parties non vides et majorées de R. Montrer que A∪B est non vide et majoré et que sup(A∪B) = max{sup(A),sup(B)}.

Solution proposée A∪B non vide (car A l'est). Posons M = max{sup(A), sup(B)}. Pour x∈A∪B : si x∈A, x≤sup(A)≤M ; si x∈B, x≤sup(B)≤M. Donc M majore A∪B, qui est donc majoré, et sup(A∪B) ≤ M.

Pour l'égalité : supposons sans perte de généralité sup(A) ≥ sup(B), donc M = sup(A). Comme A ⊂ A∪B, la question 2 donne sup(A) ≤ sup(A∪B), donc M ≤ sup(A∪B).

Combiné à sup(A∪B) ≤ M, on obtient sup(A∪B) = M = max{sup(A),sup(B)}. ∎

4. Soient A et B deux parties non vides et majorées de R avec A∩B ≠ ∅. Démontrer que sup(A∩B) ≤ min{sup(A),sup(B)}. Cette inégalité peut-elle être stricte ?

Solution proposée A∩B est non vide (hypothèse), et A∩B ⊂ A et A∩B ⊂ B. Par la question 2 appliquée deux fois : sup(A∩B) ≤ sup(A) et sup(A∩B) ≤ sup(B), donc sup(A∩B) ≤ min{sup(A),sup(B)}. ∎

Oui, l'inégalité peut être stricte. Exemple : A = [0,1]∪{5} (sup = 5), B = [0,1]∪{3} (sup = 3). Alors A∩B = [0,1], donc sup(A∩B) = 1 < 3 = min{sup(A),sup(B)}.

5. Soient A et B deux parties non vides et majorées de R, et A+B = {a+b : a∈A, b∈B}. Montrer que A+B est non vide et majoré et que sup(A+B) = sup(A)+sup(B).

Solution proposée A+B non vide (clair). Notons α = sup(A), β = sup(B). Pour tout a∈A, b∈B : a≤α, b≤β, donc a+b ≤ α+β : A+B est majoré par α+β, donc sup(A+B) ≤ α+β.

Pour l'inégalité inverse, utilisons la caractérisation de la borne sup (Prop. 5). Soit y < α+β. Posons ε = α+β-y > 0. Par caractérisation de α = sup(A), il existe a∈A tel que a > α - ε/2. De même il existe b∈B tel que b > β - ε/2. Alors : 
a+b > α+β - ε = y
et a+b ∈ A+B. On a donc trouvé, pour tout y < α+β, un élément de A+B strictement supérieur à y : par la caractérisation de la borne sup, sup(A+B) = α+β. ∎

Exercice 5 — Partie entière

1. Détermine : a) ⌊0,7⌋, b) ⌊2,3⌋, c) ⌊-1⌋, d) ⌊-1,9⌋, e) ⌊-2,1⌋.

Réponse a) 0 — b) 2 — c) -1 — d) -2 — e) -3.
⚠️ Piège classique : ⌊-1,9⌋ = -2 et pas -1 : on arrondit toujours vers le bas (l'entier immédiatement inférieur), même pour les négatifs.

2. Soient x,y ∈ R. Montre que ⌊x⌋+⌊y⌋ ≤ ⌊x+y⌋ ≤ ⌊x⌋+⌊y⌋+1.

Solution proposée Par définition, ⌊x⌋ ≤ x < ⌊x⌋+1 et ⌊y⌋ ≤ y < ⌊y⌋+1. En additionnant : 
⌊x⌋+⌊y⌋ ≤ x+y < ⌊x⌋+⌊y⌋+2
Notons n = ⌊x⌋+⌊y⌋ (un entier). On a donc n ≤ x+y < n+2.

Première inégalité. n est un entier ≤ x+y. Or ⌊x+y⌋ est le plus grand entier ≤ x+y, donc n ≤ ⌊x+y⌋, c'est-à-dire ⌊x⌋+⌊y⌋ ≤ ⌊x+y⌋.

Seconde inégalité. Si on avait ⌊x+y⌋ ≥ n+2, on aurait x+y ≥ ⌊x+y⌋ ≥ n+2, ce qui contredit x+y < n+2. Donc ⌊x+y⌋ ≤ n+1 = ⌊x⌋+⌊y⌋+1. ∎

3. Soit x ∈ R. Montre que ⌊x⌋ + ⌊x+1/2⌋ = ⌊2x⌋.

Solution proposée Écrivons x = ⌊x⌋ + f où f = x - ⌊x⌋ ∈ [0,1[ est la partie fractionnaire. Deux cas :

Cas 1 : 0 ≤ f < 1/2. Alors f+1/2 ∈ [1/2, 1[, donc ⌊x+1/2⌋ = ⌊x⌋. À gauche : ⌊x⌋+⌊x+1/2⌋ = 2⌊x⌋. À droite : 2x = 2⌊x⌋+2f avec 2f ∈ [0,1[, donc ⌊2x⌋ = 2⌊x⌋. Égalité vérifiée.

Cas 2 : 1/2 ≤ f < 1. Alors f+1/2 ∈ [1, 3/2[, donc ⌊x+1/2⌋ = ⌊x⌋+1. À gauche : ⌊x⌋+⌊x+1/2⌋ = 2⌊x⌋+1. À droite : 2f ∈ [1,2[, donc ⌊2x⌋ = 2⌊x⌋+1. Égalité vérifiée aussi.

Dans les deux cas, ⌊x⌋+⌊x+1/2⌋ = ⌊2x⌋. ∎

Exercice 6 — Un encadrement classique et son application

1. Montre que 2(√(n+1)-√n) < 1/√n < 2(√n-√(n-1)) pour tout n ∈ N*.

Solution proposée L'astuce est de multiplier par la quantité conjuguée. Pour l'inégalité de droite : 
2(√n-√(n-1)) = 2(√n-√(n-1))(√n+√(n-1)) / (√n+√(n-1))
             = 2(n-(n-1)) / (√n+√(n-1))
             = 2 / (√n+√(n-1))
Comme √(n-1) < √n, on a √n+√(n-1) < 2√n, donc : 
2/(√n+√(n-1)) > 2/(2√n) = 1/√n
D'où 1/√n < 2(√n-√(n-1)).

De même pour l'inégalité de gauche : 2(√(n+1)-√n) = 2/(√(n+1)+√n), et comme √(n+1) > √n, √(n+1)+√n > 2√n, donc 2/(√(n+1)+√n) < 2/(2√n) = 1/√n. ∎

2. En déduire la valeur de ⌊1 + 1/√2 + ... + 1/√100⌋.

Solution proposée Notons S = Σ(k=1 à 100) 1/√k = 1 + Σ(k=2 à 100) 1/√k. On applique l'encadrement de la question 1 pour n = 2, ..., 100, puis on somme (les sommes se télescopent) :

Majoration. 
Σ(n=2 à 100) 1/√n < Σ(n=2 à 100) 2(√n-√(n-1)) = 2(√100 - √1) = 2×9 = 18
Minoration. 
Σ(n=2 à 100) 1/√n > Σ(n=2 à 100) 2(√(n+1)-√n) = 2(√101 - √2) ≈ 2(10,0499-1,4142) ≈ 17,271
Donc 17,271 < Σ(k=2 à 100) 1/√k < 18, et en ajoutant le premier terme (k=1, valeur 1) : 
18,271 < S < 19
S est strictement compris entre 18,27 et 19, donc ⌊S⌋ = 18.
