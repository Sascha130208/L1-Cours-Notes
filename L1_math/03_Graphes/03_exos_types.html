1️⃣ Exercice type — Matrice d'adjacence

📄 Énoncé Soit G le graphe non orienté de sommets {1,2,3,4,5} et d'arêtes {1,2}, {1,5}, {2,3}, {2,4}, {3,4}, {4,5}.
1. Donner sa matrice d'adjacence. 2. Donner l'ordre, la taille et le degré de chaque sommet. 3. Vérifier le lemme des poignées de main.
🔎 Ce qu'il faut reconnaître Pur exercice de définition. Le seul réflexe : la matrice d'un graphe non orienté doit sortir symétrique, et sans boucle la diagonale est nulle. Ces deux vérifications te disent immédiatement si tu t'es trompé.
✅ Rédaction type 1. On numérote les sommets de 1 à 5 et on place M_xy = 1 lorsque {x,y} est une arête : 
      1  2  3  4  5
  1 [ 0  1  0  0  1 ]
  2 [ 1  0  1  1  0 ]
  3 [ 0  1  0  1  0 ]
  4 [ 0  1  1  0  1 ]
  5 [ 1  0  0  1  0 ]
Contrôle : la matrice est bien symétrique (graphe non orienté) et de diagonale nulle (pas de boucle).

2. L'ordre de G est Card(S) = 5 et sa taille est Card(A) = 6. Les degrés se lisent en sommant chaque ligne :
d(1) = 2, d(2) = 3, d(3) = 2, d(4) = 3, d(5) = 2.

3. Σ d(x) = 2+3+2+3+2 = 12 = 2×6 = 2m. Le lemme des poignées de main est bien vérifié.

2️⃣ Exercice type — « Est-ce possible ? »

📄 Énoncé 1. Un groupe de 9 amis se disent bonjour le matin. Chacun serre la main à exactement 3 autres. Montrer que cette situation est impossible.
2. Un graphe simple non orienté a 15 arêtes, 3 sommets de degré 4 et tous les autres de degré 3. Combien a-t-il de sommets ?
🔎 Ce qu'il faut reconnaître Dès qu'un énoncé donne des degrés et demande un nombre (ou demande de montrer une impossibilité), c'est le lemme des poignées de main. Deux usages : la parité (pour l'impossibilité) et l'équation Σ d(x) = 2m avec une inconnue (pour le comptage).
✅ Rédaction type 1. Modélisons la situation par le graphe G des poignées de main : les sommets sont les 9 personnes, et on relie deux personnes qui se serrent la main. Par hypothèse, d(x) = 3 pour les 9 sommets.
Par le lemme des poignées de main, Σ d(x) = 2m, donc la somme des degrés est paire.
Or ici Σ d(x) = 9 × 3 = 27, qui est impair. Contradiction.
Donc une telle situation est impossible. ∎
💡 La formulation générale Ce qu'on vient de démontrer est le fait général : le nombre de sommets de degré impair est toujours pair. Ici on aurait 9 sommets de degré impair : impossible.
2. Notons n le nombre de sommets. Il y a 3 sommets de degré 4 et n-3 sommets de degré 3. Donc Σ d(x) = 3×4 + (n-3)×3 = 12 + 3n - 9 = 3n + 3.
Le lemme des poignées de main donne Σ d(x) = 2m = 2×15 = 30, d'où 3n + 3 = 30, soit n = 9.
Le graphe a donc 9 sommets.
Contrôle de cohérence : avec 9 sommets, un graphe simple a au plus 9×8/2 = 36 arêtes, et les degrés (4 et 3) sont bien ≤ 8 : rien n'interdit l'existence d'un tel graphe.

3️⃣ Exercice type — Suite graphique

📄 Énoncé Une suite finie d'entiers naturels est dite graphique si c'est la suite des degrés des sommets d'un graphe simple.
1. Existe-t-il un graphe de suite de degrés (1,2,3,4) ? Un graphe simple ?
2. Montrer que (6,5,5,4,3,3,2,2,2) est graphique.
🔎 Ce qu'il faut reconnaître Trois tests de rejet dans cet ordre, avant tout calcul : (a) la somme est-elle paire ? (b) un degré dépasse-t-il n-1 (impossible dans un graphe simple à n sommets) ? (c) sinon, on déroule l'algorithme d'Havel-Hakimi : on retire le plus grand degré s en décrémentant de 1 les s degrés suivants, on retrie, et on recommence.
✅ Rédaction type 1. La somme vaut 1+2+3+4 = 10, qui est paire : le graphe aurait m = 10/2 = 5 arêtes et n = 4 sommets.
Un tel graphe existe si l'on autorise les arêtes multiples : sur les sommets a,b,c,d de degrés respectifs 1, 2, 3, 4, on peut prendre les arêtes {a,d}, {b,c}, {b,d}, {c,d}, {c,d} — le sommet d est d'extrémité de 3 arêtes dont une double… (il suffit d'ajuster ; l'essentiel est le point suivant).
En revanche, aucun graphe SIMPLE ne convient : dans un graphe simple à n = 4 sommets, un sommet est relié à au plus n-1 = 3 autres sommets, donc d(x) ≤ 3 pour tout x. Or la suite contient le degré 4. Contradiction. ∎

2. La suite (6,5,5,4,3,3,2,2,2) a 9 termes, de somme 32 (paire) et de maximum 6 ≤ 8 = n-1 : aucun test de rejet ne s'applique. On déroule Havel-Hakimi. 
(6,5,5,4,3,3,2,2,2)
  on retire le 6, on décrémente les 6 suivants :
    (5,5,4,3,3,2) → (4,4,3,2,2,1),   reste (2,2)
  après tri :      (4,4,3,2,2,2,2,1)
  on retire le 4 :
    (4,3,2,2) → (3,2,1,1),           reste (2,2,1)
  après tri :      (3,2,2,2,1,1,1)
  on retire le 3 : (2,2,2) → (1,1,1), reste (1,1,1)
  après tri :      (1,1,1,1,1,1)
  on retire les 1 deux par deux :     (0,0,0,0,0,0)
On aboutit à la suite nulle, qui est bien graphique (le graphe sans arête). Donc, en remontant les étapes, (6,5,5,4,3,3,2,2,2) est graphique. ∎
Remarque : la remontée n'est pas qu'un argument — elle construit le graphe : à chaque étape on relie le sommet retiré aux sommets dont on avait décrémenté le degré.

4️⃣ Exercice type — Compter les chemins

📄 Énoncé Soit C₄ le cycle de sommets 1, 2, 3, 4 et d'arêtes {1,2}, {2,3}, {3,4}, {4,1}.
Combien y a-t-il de chemins de longueur 3 allant du sommet 1 au sommet 2 ? Les énumérer pour vérifier.
🔎 Ce qu'il faut reconnaître « Nombre de chemins de longueur k » est la signature du Théorème 22 : la réponse est le coefficient (A^k)_ij. Attention : il s'agit de chemins quelconques, pas forcément élémentaires — on a le droit de repasser par un sommet.
✅ Rédaction type La matrice d'adjacence de C₄ est 
      1  2  3  4
  1 [ 0  1  0  1 ]
  2 [ 1  0  1  0 ]
  3 [ 0  1  0  1 ]
  4 [ 1  0  1  0 ]
On calcule A² : 
A² = [ 2  0  2  0 ]
     [ 0  2  0  2 ]
     [ 2  0  2  0 ]
     [ 0  2  0  2 ]
puis A³ = A²·A, dont la première ligne vaut 2×(ligne 1 de A) + 2×(ligne 3 de A) = (0, 4, 0, 4).
Donc (A³)₁₂ = 4 : par le théorème 22, il y a 4 chemins de longueur 3 du sommet 1 au sommet 2.

Vérification par énumération : (1,2,1,2), (1,4,1,2), (1,2,3,2), (1,4,3,2). On en compte bien 4.
Observation : aucun de ces chemins n'est élémentaire — ils repassent tous par un sommet. C'est normal : dans C₄, les sommets 1 et 2 sont à distance 1, et on ne peut les relier en 3 pas qu'en faisant un détour.

5️⃣ Exercice type — Connexité

📄 Énoncé Le graphe défini par la matrice d'adjacence suivante est-il connexe ? 
[ 0  0  0  1  0 ]
[ 0  0  1  0  0 ]
[ 0  1  0  0  0 ]
[ 1  0  0  0  1 ]
[ 0  0  0  1  0 ]
🔎 Ce qu'il faut reconnaître Deux méthodes légitimes : le théorème 24 (calculer B = A+A²+A³+A⁴), ou l'algorithme « tache d'huile ». En devoir, la tache d'huile est bien plus rapide et parfaitement rigoureuse — réserve le calcul matriciel aux cas où l'énoncé l'exige explicitement.
✅ Rédaction type La matrice est symétrique de diagonale nulle : le graphe est non orienté et simple. On lit ses arêtes : {1,4}, {2,3}, {4,5}.

Algorithme de la tache d'huile depuis le sommet 1 : 
Composante = {1}
voisins de 1 : 4          → Composante = {1,4}
voisins de 4 : 1, 5       → Composante = {1,4,5}
voisins de 5 : 4          → rien de nouveau, on s'arrête
La composante connexe de 1 est {1,4,5} ≠ S.
Donc le graphe n'est pas connexe : il a exactement deux composantes connexes, {1,4,5} et {2,3}. ∎
Contrôle : il n'existe effectivement aucun chemin du sommet 1 au sommet 2, puisque aucune arête ne relie {1,4,5} à {2,3}.

6️⃣ Exercice type — Isomorphisme

📄 Énoncé 1. G a pour sommets s,p,t,r,q et pour arêtes {s,p},{p,q},{s,t},{t,q},{s,r},{r,q}. H a pour sommets 1,…,5 et pour arêtes {1,3},{1,4},{1,5},{2,3},{2,4},{2,5}. Montrer que G et H sont isomorphes.
2. Le cycle C₆ et la réunion disjointe de deux triangles sont-ils isomorphes ?
🔎 Ce qu'il faut reconnaître Les deux questions appellent des rédactions opposées : pour oui il faut construire une bijection explicite ; pour non il suffit d'un seul invariant qui diffère. Commence toujours par comparer les suites de degrés : soit elles diffèrent et tu as fini, soit elles coïncident et elles t'indiquent quels sommets apparier.
✅ Rédaction type 1. Calculons d'abord les degrés.
Dans G : d(s) = 3 (p, t, r), d(q) = 3 (p, t, r), et d(p) = d(t) = d(r) = 2.
Dans H : d(1) = d(2) = 3, et d(3) = d(4) = d(5) = 2.
Les suites de degrés coïncident : (3,3,2,2,2). On apparie les sommets de degré 3 entre eux et ceux de degré 2 entre eux. Posons 
  Φ(s) = 1    Φ(q) = 2    Φ(p) = 3    Φ(t) = 4    Φ(r) = 5
Φ est bien une bijection de {s,p,t,r,q} sur {1,…,5}. Vérifions qu'elle transporte les arêtes :
Arête de GImage par ΦArête de H ?
{s,p}{1,3}oui
{s,t}{1,4}oui
{s,r}{1,5}oui
{p,q}{3,2}oui
{t,q}{4,2}oui
{r,q}{5,2}oui
Les 6 arêtes de G ont pour images les 6 arêtes de H, et les deux graphes ont le même nombre d'arêtes : l'équivalence « {x,y} arête de G ⟺ {Φ(x),Φ(y)} arête de H » est donc vérifiée dans les deux sens.
Donc G et H sont isomorphes. ∎
Remarque : les deux sont en fait le graphe biparti complet K₂,₃, de parts {s,q} et {p,t,r} d'un côté, {1,2} et {3,4,5} de l'autre.

2. Les deux graphes ont 6 sommets, 6 arêtes, et la même suite de degrés (2,2,2,2,2,2) : ces invariants-là ne permettent pas de conclure.
En revanche, C₆ est connexe (une composante connexe), tandis que la réunion de deux triangles en a deux. Or le nombre de composantes connexes est un invariant par isomorphisme : une bijection qui préserve les arêtes préserve l'existence des chemins.
Donc ces deux graphes ne sont pas isomorphes. ∎
⚠️ L'erreur classique Écrire « ils ont la même suite de degrés donc ils sont isomorphes ». C'est faux : cet exemple en est précisément le contre-exemple. La suite des degrés est une condition nécessaire, jamais suffisante.

7️⃣ Exercice type — Arbres et comptage

📄 Énoncé Soit T un arbre dont tous les sommets sont de degré 1 ou 3. Si T a 10 sommets de degré 3, combien a-t-il de sommets de degré 1 ?
🔎 Ce qu'il faut reconnaître Un exercice où l'on combine deux formules : les poignées de main (Σ d = 2m) et la propriété caractéristique des arbres (m = n-1). C'est cette combinaison qui ferme le système : une équation, une inconnue.
✅ Rédaction type Notons f le nombre de sommets de degré 1 (les feuilles). Tous les sommets étant de degré 1 ou 3, le nombre total de sommets est n = f + 10.
Comme T est un arbre, il a exactement n - 1 arêtes (Proposition 29) : m = f + 9.
Le lemme des poignées de main donne alors 
Σ d(x) = f×1 + 10×3 = f + 30
Σ d(x) = 2m = 2(f + 9) = 2f + 18
D'où f + 30 = 2f + 18, c'est-à-dire f = 12.
L'arbre a donc 12 sommets de degré 1 (et 22 sommets en tout, pour 21 arêtes). ∎
Contrôle : Σ d = 12 + 30 = 42 = 2×21 ✔

8️⃣ Exercice type — Code de Prüfer

📄 Énoncé Soit l'arbre T à 8 sommets d'arêtes {1,2}, {1,3}, {1,6}, {3,4}, {4,5}, {6,7}, {6,8}.
1. Déterminer son code de Prüfer. 2. Combien y a-t-il d'arbres à 8 sommets étiquetés ?
🔎 Ce qu'il faut reconnaître Mécanique pure, mais il faut appliquer la règle à la lettre : à chaque étape, on prend la feuille de plus petite étiquette (pas le plus petit sommet, pas une feuille au hasard) et on écrit l'étiquette de son voisin (pas la sienne). On s'arrête quand il reste 2 sommets, donc après n-2 étapes.
✅ Rédaction type 1. L'arbre a n = 8 sommets, son code aura donc n - 2 = 6 termes. On applique l'algorithme :
ÉtapeFeuillesPlus petiteSon voisin → code
12, 5, 7, 821
25, 7, 854
34, 7, 843
43, 7, 831
51, 7, 816
67, 876
Il ne reste que les sommets 6 et 8 : on s'arrête. Le code de Prüfer de T est (1, 4, 3, 1, 6, 6).
Contrôle utile : un sommet apparaît dans le code d(x) - 1 fois. Ici 1 apparaît 2 fois (d(1) = 3 ✔), 6 apparaît 2 fois (d(6) = 3 ✔), 3 et 4 une fois (degré 2 ✔), et 2, 5, 7, 8 jamais (ce sont bien les feuilles ✔).

2. Par la formule de Cayley, il y a n^(n-2) = 8⁶ = 262 144 arbres à 8 sommets étiquetés de 1 à 8.
C'est exactement le nombre de 6-uplets d'entiers de 1 à 8 — la bijection de Prüfer étant précisément ce qui démontre la formule.

9️⃣ Exercice type — Clique, stable et nombre chromatique

📄 Énoncé Une personne souhaite inviter six amis 1,…,6. Certains ont des relations difficiles :
1 avec 2 ; 2 avec 1, 5, 6 ; 3 avec 5 ; 4 avec 5 ; 5 avec 2, 3, 4, 6 ; 6 avec 2, 5.
1. Représenter la situation par un graphe où deux personnes pouvant être invitées ensemble sont reliées.
2. Chercher la clique ayant le plus grand nombre de sommets.
3. Combien de personnes au maximum peut-on inviter sans ambiance difficile ? Lesquelles ?
🔎 Ce qu'il faut reconnaître Le piège est dans l'énoncé : il demande un graphe de compatibilité, alors que les données sont des incompatibilités. Il faut donc travailler dans le graphe complémentaire. Ensuite, « le plus grand groupe tous compatibles » = clique maximale dans le graphe de compatibilité (= stable maximal dans le graphe des conflits).
✅ Rédaction type 1. Notons D le graphe des relations difficiles, d'arêtes {1,2}, {2,5}, {2,6}, {3,5}, {4,5}, {5,6} (6 arêtes).
Le graphe demandé C est son complémentaire : on relie deux personnes lorsqu'elles peuvent être invitées ensemble. Comme il y a 6×5/2 = 15 paires au total, C a 15 - 6 = 9 arêtes : 
C : {1,3} {1,4} {1,5} {1,6} {2,3} {2,4} {3,4} {3,6} {4,6}
2. Cherchons une clique de C, c'est-à-dire un groupe de personnes deux à deux compatibles.
Considérons {1, 3, 4, 6} et vérifions les 6 paires : {1,3} ✔, {1,4} ✔, {1,6} ✔, {3,4} ✔, {3,6} ✔, {4,6} ✔.
C'est donc une clique d'ordre 4.
Elle est maximale : une clique d'ordre 5 contiendrait 2 ou 5. Or 2 n'est compatible qu'avec 3 et 4 (deux sommets seulement), donc 2 ne peut appartenir qu'à une clique d'ordre ≤ 3 ; et 5 n'est compatible qu'avec 1, donc à une clique d'ordre ≤ 2. Aucune clique d'ordre 5 n'existe.

3. Inviter un groupe sans ambiance difficile, c'est exactement choisir une clique de C. Le maximum est donc de 4 personnes : 1, 3, 4 et 6. ∎
💡 Les deux points de vue {1,3,4,6} est une clique de C et, de façon équivalente, un stable de D : aucune des 6 paires n'est une relation difficile. Selon la façon dont tu as modélisé, tu cherches l'un ou l'autre — mais c'est le même calcul.

🔟 Exercice type — Glouton et Welsh-Powell

📄 Énoncé On reprend le graphe D des relations difficiles de l'exercice 9 : arêtes {1,2}, {2,5}, {2,6}, {3,5}, {4,5}, {5,6}.
1. Colorier D par l'algorithme glouton (ordre naturel des sommets), puis par Welsh-Powell.
2. En déduire χ(D), en justifiant la valeur exacte.
🔎 Ce qu'il faut reconnaître Un algorithme de coloriage ne donne jamais qu'une majoration de χ. Pour conclure à la valeur exacte, il faut toujours ajouter une minoration — presque toujours en exhibant une clique (ici, chercher un triangle).
✅ Rédaction type Les degrés sont : d(1)=1, d(2)=3, d(3)=1, d(4)=1, d(5)=4, d(6)=2.

1a. Algorithme glouton, sommets dans l'ordre 1, 2, 3, 4, 5, 6 :
SommetCouleurs des voisins déjà coloriésCouleur attribuée
1—c1
21 → c1c2
3— (5 non colorié)c1
4— (5 non colorié)c1
52 → c2 ; 3 → c1 ; 4 → c1c3
62 → c2 ; 5 → c3c1
Le glouton utilise 3 couleurs : c1 = {1,3,4,6}, c2 = {2}, c3 = {5}.

1b. Algorithme de Welsh-Powell. On trie par degré décroissant : 5 (4), 2 (3), 6 (2), 1 (1), 3 (1), 4 (1). 
Couleur 1 : on colorie 5 ; on écarte ses voisins 2, 3, 4, 6.
            reste 1, non voisin de 5 → couleur 1.
            → couleur 1 = {5, 1}
Couleur 2 : liste restante 2, 6, 3, 4. On colorie 2 ;
            6 est voisin de 2 → écarté ; 3 et 4 ne le sont pas → couleur 2.
            → couleur 2 = {2, 3, 4}
Couleur 3 : il ne reste que 6.   → couleur 3 = {6}
Welsh-Powell utilise lui aussi 3 couleurs, mais la répartition est différente.

2. Valeur exacte de χ(D) — en deux temps.
Majoration. Les deux algorithmes produisent un coloriage propre à 3 couleurs, donc χ(D) ≤ 3.
Minoration. Les sommets 2, 5 et 6 sont deux à deux reliés ({2,5}, {5,6}, {2,6} sont des arêtes) : ils forment une clique d'ordre 3. Ils exigent donc 3 couleurs distinctes, d'où χ(D) ≥ 3.
Conclusion : χ(D) = 3. Les deux coloriages trouvés sont donc optimaux. ∎
⚠️ Ne te fie pas au seul algorithme Ici les algorithmes tombent juste, mais ce n'est pas garanti : le cours donne un graphe biparti (χ = 2) sur lequel les deux en trouvent 4. Sans la minoration par la clique, l'exercice n'est pas traité.

1️⃣1️⃣ Exercice type — Formule d'Euler

📄 Énoncé 1. Soit G un graphe simple, connexe, planaire, 4-régulier à 6 sommets. Combien y a-t-il de faces dans une représentation planaire de G ?
2. Soit G un graphe planaire à a arêtes, s sommets et f faces, avec s ≥ 3. Montrer que f ≤ 2a/3, puis que 2 - s + a/3 ≤ 0.
🔎 Ce qu'il faut reconnaître Dès qu'on parle de faces, c'est Euler. Le schéma est presque toujours le même : on obtient le nombre d'arêtes par les poignées de main, puis on injecte dans s - a + f = 2. Pour la question 2, le couple d'outils est Lemme 49 (Σ d(f) = 2a) + Lemme 50 (d(f) ≥ 3).
✅ Rédaction type 1. G est 4-régulier à s = 6 sommets, donc par le théorème 15 a = s×r/2 = 6×4/2 = 12 arêtes.
G étant planaire et connexe, la formule d'Euler s'applique : s - a + f = 2, d'où f = 2 - s + a = 2 - 6 + 12 = 8.
Toute représentation planaire de G a donc 8 faces (face extérieure comprise). ∎
Remarque importante : la réponse ne dépend pas du dessin choisi — c'est le corollaire de la formule d'Euler. Un tel graphe existe bien : c'est l'octaèdre.

2. Comme s ≥ 3, le Lemme 50 assure que toute face est de degré ≥ 3. En sommant sur les f faces : Σ_f d(f) ≥ 3f.
Or le Lemme 49 donne Σ_f d(f) = 2a. Donc 3f ≤ 2a, c'est-à-dire

f ≤ 2a/3.

Par la formule d'Euler, f = 2 - s + a. En reportant dans l'inégalité : 2 - s + a ≤ 2a/3, soit 2 - s + a - 2a/3 ≤ 0, c'est-à-dire

2 - s + a/3 ≤ 0.

∎
Lecture : en multipliant par 3 on retrouve a ≤ 3s - 6, l'inégalité fondamentale de planarité.

1️⃣2️⃣ Exercice type — Non-planarité

📄 Énoncé 1. Il était une fois un roi qui avait 5 fils. Il souhaita que chacun construise son château, et que ces châteaux soient tous reliés deux à deux par des routes qui ne se coupent pas. Est-ce possible ?
2. Trois villas doivent être reliées au gaz, à l'électricité et à l'eau. Peut-on construire ces canalisations sans qu'elles se chevauchent ?
🔎 Ce qu'il faut reconnaître Ce sont les deux énoncés folkloriques des deux graphes interdits : « tous reliés deux à deux » → K₅ ; « chaque villa à chaque usine » → K₃,₃. Dans les deux cas on raisonne par l'absurde avec la formule d'Euler. Pour K₃,₃, attention : l'inégalité m ≤ 3n-6 ne suffit pas, il faut utiliser la bipartition.
✅ Rédaction type 1. La question revient à savoir si K₅ est planaire. Supposons qu'il le soit.
K₅ a s = 5 sommets et a = 5×4/2 = 10 arêtes. Il est connexe, donc la formule d'Euler donne f = 2 - s + a = 2 - 5 + 10 = 7 faces.
Par le Lemme 49, Σ_f d(f) = 2a = 20.
Mais K₅ est simple avec s ≥ 3, donc chaque face est de degré ≥ 3 (Lemme 50), d'où Σ_f d(f) ≥ 3×7 = 21 > 20. Contradiction.
Donc K₅ n'est pas planaire : il est impossible de relier les 5 châteaux deux à deux sans croisement. ∎

2. Le graphe de la situation est K₃,₃ (3 villas d'un côté, 3 sources de l'autre, chaque villa reliée à chaque source). Supposons-le planaire.
K₃,₃ a s = 6 sommets et a = 3×3 = 9 arêtes, donc f = 2 - 6 + 9 = 5 faces, et Σ_f d(f) = 2a = 18.
Ici, le Lemme 50 (degré ≥ 3) ne suffit pas : il donnerait seulement Σ d(f) ≥ 15, ce qui est compatible avec 18.
Mais K₃,₃ est biparti, donc tous ses cycles sont de longueur paire (Théorème 68) ; une face étant bordée par un cycle, son degré est pair et ≥ 3, donc ≥ 4. D'où Σ_f d(f) ≥ 4×5 = 20 > 18. Contradiction.
Donc K₃,₃ n'est pas planaire : le réseau de canalisations demandé est impossible. ∎
💡 Le réflexe de vérification Avant de te lancer, teste m ≤ 3n-6 : pour K₅, 10 > 3×5-6 = 9 → conclusion immédiate. Pour K₃,₃, 9 ≤ 3×6-6 = 12 → le test échoue, il faut passer par la bipartition. C'est exactement ce qui distingue les deux cas.

1️⃣3️⃣ Exercice type — Tracer d'un seul trait

📄 Énoncé Soit le graphe de sommets A, B, C, D, E et d'arêtes {A,B}, {B,C}, {C,D}, {D,A}, {A,C}, {B,D}, {A,E}, {B,E}.
Peut-on le tracer d'un seul trait, sans lever le crayon et sans repasser deux fois sur un trait déjà tracé ? Si oui, donner un tel tracé.
🔎 Ce qu'il faut reconnaître « D'un seul trait sans repasser » = chemin passant une fois par chaque arête = eulérien ou semi-eulérien. Le théorème d'Euler se vérifie en comptant simplement les sommets de degré impair : 0 → cycle eulérien, 2 → chemin semi-eulérien (qui doit partir de l'un et finir à l'autre), plus de 2 → impossible.
✅ Rédaction type Le graphe est connexe (tout sommet est relié à A ou B, eux-mêmes reliés). Calculons les degrés :
SommetVoisinsDegréParité
AB, D, C, E4pair
BA, C, D, E4pair
CB, D, A3impair
DC, A, B3impair
EA, B2pair
Contrôle : Σ d = 4+4+3+3+2 = 16 = 2×8 ✔ (8 arêtes).

Il y a exactement deux sommets de degré impair : C et D. Le graphe étant connexe, le théorème d'Euler assure qu'il est semi-eulérien : le tracé existe, mais il ne peut pas revenir à son point de départ — il doit nécessairement partir de C et finir en D (ou l'inverse).

Un tracé explicite : 
C — A — E — B — A — D — B — C — D
  (AC) (AE) (BE) (AB) (AD) (BD) (BC) (CD)
Les 8 arêtes sont utilisées une fois chacune, le tracé part de C et arrive en D. ✔ ∎
💡 Si l'énoncé exigeait un retour au point de départ Il faudrait rendre le graphe eulérien. Par la Proposition 63 : C et D sont de degré impair et l'arête {C,D} existe déjà, donc on ajoute un sommet z et les deux arêtes {C,z} et {z,D}. Tous les degrés deviennent pairs.

1️⃣4️⃣ Exercice type — Cycle hamiltonien

📄 Énoncé Soit G le graphe de sommets 1,…,5 et d'arêtes {1,2}, {2,3}, {3,4}, {4,5}, {5,1}, {1,3}, {2,4}.
1. Montrer, à l'aide du théorème d'Ore, que G est hamiltonien. 2. Exhiber un cycle hamiltonien.
🔎 Ce qu'il faut reconnaître Ore ne se vérifie que sur les couples de sommets NON reliés — c'est l'erreur n°1 que de tester tous les couples. Il faut donc d'abord lister les paires non adjacentes, puis vérifier d(v) + d(w) ≥ n pour chacune.
✅ Rédaction type 1. G est simple, non orienté, avec n = 5 ≥ 3. Calculons les degrés :
d(1) = 3 (2, 5, 3), d(2) = 3 (1, 3, 4), d(3) = 3 (2, 4, 1), d(4) = 3 (3, 5, 2), d(5) = 2 (4, 1).
Les paires non reliées sont {1,4}, {2,5} et {3,5} (les 7 arêtes couvrent les 7 autres paires sur les 10 possibles). Vérifions la condition d'Ore pour chacune :
Paire non reliéed(v) + d(w)≥ n = 5 ?
{1,4}3 + 3 = 6oui
{2,5}3 + 2 = 5oui
{3,5}3 + 2 = 5oui
Pour tout couple (v,w) de sommets non reliés par une arête, d(v) + d(w) ≥ 5 = n. Par le théorème 64 (Ore), G est hamiltonien. ∎

2. Le cycle (1, 2, 3, 4, 5, 1) convient : ses arêtes {1,2}, {2,3}, {3,4}, {4,5}, {5,1} appartiennent toutes à G, et il passe une et une seule fois par chacun des 5 sommets avant de revenir au départ. C'est donc un cycle hamiltonien. ∎
⚠️ Si Ore n'était pas vérifié On ne pourrait rien conclure : la condition est suffisante, pas nécessaire. Il faudrait alors soit exhiber un cycle à la main, soit démontrer l'impossibilité par un autre argument (par exemple : un graphe biparti à nombre impair de sommets n'est jamais hamiltonien).

1️⃣5️⃣ Exercice type — Lemme de Hall

📄 Énoncé Quatre étudiants a₁, a₂, a₃, a₄ doivent se voir attribuer chacun un projet distinct parmi p₁, p₂, p₃, p₄. Les vœux sont :
a₁ : {p₁} ; a₂ : {p₁} ; a₃ : {p₁, p₂} ; a₄ : {p₂, p₃, p₄}.
Peut-on satisfaire tout le monde ? Et si a₂ acceptait aussi p₃ ?
🔎 Ce qu'il faut reconnaître Appariement un-à-un entre deux groupes = lemme de Hall sur un graphe biparti. Pour répondre non, il suffit d'exhiber un seul ensemble S qui viole la condition — inutile de les tester tous. Pour répondre oui, le plus rapide est d'exhiber directement l'appariement.
✅ Rédaction type Modélisons par le graphe biparti G = (S, A, B) avec A = {a₁,a₂,a₃,a₄}, B = {p₁,p₂,p₃,p₄}, et une arête {aᵢ, pⱼ} lorsque aᵢ accepte pⱼ. Satisfaire tout le monde, c'est trouver une bijection f : A → B avec aᵢ adjacent à f(aᵢ).

Cas initial : c'est impossible.
Prenons S = {a₁, a₂, a₃}. L'ensemble de ses voisins est V(S) = {p₁} ∪ {p₁} ∪ {p₁, p₂} = {p₁, p₂}.
Donc Card V(S) = 2 < 3 = Card S : la condition de Hall est violée.
Par le théorème 69, aucune bijection convenable n'existe : on ne peut pas satisfaire tout le monde. ∎
En clair : trois étudiants se partagent seulement deux projets acceptables — deux d'entre eux devraient recevoir le même projet.

Cas modifié : a₂ : {p₁, p₃}.
Exhibons directement un appariement : 
f(a₁) = p₁    f(a₂) = p₃    f(a₃) = p₂    f(a₄) = p₄
Chaque étudiant reçoit un projet qu'il accepte (p₁ ∈ {p₁} ✔, p₃ ∈ {p₁,p₃} ✔, p₂ ∈ {p₁,p₂} ✔, p₄ ∈ {p₂,p₃,p₄} ✔), et les quatre projets attribués sont deux à deux distincts : f est bien une bijection.
Donc tout le monde peut être satisfait. ∎
💡 Pourquoi exhiber plutôt que vérifier Hall Vérifier la condition de Hall « pour tout S ⊂ A » demande d'examiner 2⁴ - 1 = 15 sous-ensembles. Exhiber une bijection prouve la même chose en trois lignes. On réserve Hall au sens « impossible », où un seul contre-exemple suffit.

1️⃣6️⃣ Exercice type — Arbre couvrant minimal (Kruskal)

📄 Énoncé On veut relier cinq villes A, B, C, D, E par un réseau de câbles de coût total minimal. Les liaisons possibles et leurs coûts :
AC = 1, BC = 2, DE = 3, AB = 4, BD = 5, AE = 7, CD = 8, CE = 10.
Déterminer un réseau de coût minimal et son coût total.
🔎 Ce qu'il faut reconnaître « Tout relier au coût minimal » = arbre couvrant de poids minimal → Kruskal (arêtes par poids croissant) ou Prim. Le réflexe de contrôle : l'arbre obtenu doit avoir exactement n - 1 arêtes.
✅ Rédaction type On applique l'algorithme de Kruskal en parcourant les arêtes par poids croissant, et en n'ajoutant une arête que si elle relie deux composantes connexes distinctes de l'arbre en construction (sinon elle créerait un cycle).
ArêtePoidsDécisionComposantes après
AC1ajoutée{A,C} {B} {D} {E}
BC2ajoutée{A,B,C} {D} {E}
DE3ajoutée{A,B,C} {D,E}
AB4rejetée (A et B déjà connectés → cycle)inchangé
BD5ajoutée{A,B,C,D,E}
Tous les sommets sont désormais dans une seule composante : l'algorithme s'arrête (les arêtes restantes AE, CD, CE créeraient des cycles).

Arbre couvrant minimal : {A,C}, {B,C}, {D,E}, {B,D}.
Coût total : 1 + 2 + 3 + 5 = 11.

Contrôles :

  • il est connexe et sans cycle : c'est bien un arbre ✔

∎

1️⃣7️⃣ Exercice type — Plus court chemin (Dijkstra)

📄 Énoncé Soit le graphe orienté valué de sommets s, a, b, c, t et d'arcs :
s→a (2), s→b (5), a→b (1), a→c (4), b→c (1), b→t (6), c→t (2).
Déterminer le plus court chemin de s à t et sa longueur.
🔎 Ce qu'il faut reconnaître Plus court chemin depuis un sommet, avec des valuations toutes positives → Dijkstra. Il faut le dire explicitement dans la rédaction : « les valuations étant positives, l'algorithme de Dijkstra s'applique ». Et il faut tenir deux tableaux : Dist et Pred — c'est Pred qui permet de reconstruire le chemin à la fin.
✅ Rédaction type Toutes les valuations sont positives : l'algorithme de Dijkstra s'applique. On initialise Dist(s) = 0 et Dist(x) = +∞ ailleurs.
ÉtapeSommet traitéMises à jourDist (s,a,b,c,t)
0—initialisation(0, ∞, ∞, ∞, ∞)
1s (0)a ← 0+2 = 2 ; b ← 0+5 = 5(0, 2, 5, ∞, ∞)
2a (2)b ← min(5, 2+1) = 3 ; c ← 2+4 = 6(0, 2, 3, 6, ∞)
3b (3)c ← min(6, 3+1) = 4 ; t ← 3+6 = 9(0, 2, 3, 4, 9)
4c (4)t ← min(9, 4+2) = 6(0, 2, 3, 4, 6)
5t (6)—(0, 2, 3, 4, 6)
Tableau des prédécesseurs à la fin : Pred(a) = s, Pred(b) = a, Pred(c) = b, Pred(t) = c.

Reconstruction du chemin, en remontant depuis t : t ← c ← b ← a ← s, soit le chemin s → a → b → c → t.
Longueur : 2 + 1 + 1 + 2 = 6, ce qui coïncide bien avec Dist(t) = 6. ∎
💡 Ce qu'il faut remarquer Le chemin optimal n'emprunte aucun des deux arcs « directs » (s→b à 5 et b→t à 6) : il passe par quatre petits arcs. C'est exactement ce que Dijkstra sait trouver et qu'un choix glouton naïf « je prends toujours l'arc le moins cher » manquerait.

🎯 Checklist de rédaction

✅ Les réflexes qui rapportent des points
  • Modéliser explicitement. « On note G le graphe dont les sommets sont … et où l'on relie x et y lorsque … » — cette phrase vaut des points à elle seule.
  • Nombre chromatique : toujours deux temps. Minoration par une clique, majoration par un coloriage explicite.
  • Planaire : « il existe un dessin ». Pour prouver que oui → dessiner. Pour prouver que non → Euler ou Kuratowski, jamais « je n'y arrive pas ».
  • Vérifier la somme des degrés. Σ d = 2m détecte la plupart des erreurs de recopie, gratuitement.
  • Arbre : contrôler n-1 arêtes à la fin de tout Kruskal ou Prim.
  • Citer l'hypothèse des algorithmes. « Les valuations étant positives, Dijkstra s'applique » — un correcteur attend cette phrase.
  • Conditions suffisantes. Ore ou Brooks non vérifiés ne permettent jamais de conclure à la négative.
