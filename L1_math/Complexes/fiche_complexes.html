Les nombres complexes : à quoi ça sert et comment s'en servir

Cette fiche suit le chapitre 6 du polycopié (pages 31 à 40). Pour chaque notion tu as : ce que c'est, à quoi ça sert (dans quel type d'exercice on la sort), et un exemple calculé. Les exercices à faire seul avec correction sont dans la page d'exercices types.

🧭 L'idée en 30 secondes Un nombre complexe, c'est un point du plan. On l'écrit \(z = x + iy\) où \(x\) et \(y\) sont des réels et où \(i\) est un nombre « inventé » tel que \(i^2 = -1\).
  • Pour additionner et développer : on utilise la forme \(x + iy\) (forme algébrique).
  • Pour multiplier, diviser, mettre à une puissance : on utilise la forme \(r e^{i\theta}\) (forme exponentielle). Les modules se multiplient, les angles s'additionnent.
  • Pour faire disparaître \(i\) d'un dénominateur ou savoir si un nombre est réel : on utilise le conjugué \(\bar z\).
  • Pour mesurer une distance : on utilise le module \(|z|\).

1. Pourquoi inventer les nombres complexes ?

Dans \(\mathbb{R}\), l'équation \(x^2 + 1 = 0\) n'a pas de solution : un carré est toujours \(\ge 0\), donc \(x^2 + 1 \ge 1\). On ajoute alors un nombre \(i\) avec \(i^2 = -1\). Résultat : cette équation a une solution (\(i^2 + 1 = 0\)), et on gagne bien plus :

Ce que ça permetExemple
Résoudre toutes les équations polynomiales\(z^2 + z + 1 = 0\) n'a pas de racine réelle, mais en a deux dans \(\mathbb{C}\). Le théorème fondamental dit que ça marche pour tout polynôme.
Faire de la géométrie par le calculUne rotation du plan = une multiplication par \(e^{i\theta}\). Un cercle = une équation \(|z - a| = r\).
Simplifier la trigonométrieLes formules \(\cos(a+b)\), \(\cos^3 x\), \(\cos 3x\)… se retrouvent en quelques lignes grâce à \(e^{i\theta}\).
Calculer des puissances énormes\((1+i)^{20}\) se calcule de tête en forme exponentielle (voir §5).

2. Forme algébrique : calculer

Ce que c'est

Formellement, \(\mathbb{C}\) est l'ensemble des couples \((x,y)\) de réels avec \((x,y)+(x',y') = (x+x',\,y+y')\) et \((x,y)\cdot(x',y') = (xx'-yy',\,xy'+yx')\). On note \(i = (0,1)\) et on vérifie \(i^2 = (0,1)(0,1) = (-1,0) = -1\). Au lieu de \((x,y)\) on écrit \(x + iy\). Le point \((x,y)\) du plan s'appelle l'affixe de \(z\).

  • \(\operatorname{Re}(z) = x\) : partie réelle. \(\operatorname{Im}(z) = y\) : partie imaginaire (c'est un réel, sans le \(i\)).
  • \(z\) est réel si \(\operatorname{Im}(z) = 0\), imaginaire pur si \(\operatorname{Re}(z) = 0\).
  • Addition, multiplication : commutatives, associatives, distributives, comme avec les réels. Il y a un neutre (\(0\) et \(1\)), un opposé, et un inverse pour tout \(z \ne 0\). Donc \(\mathbb{C}\) est un corps.

À quoi ça sert

Dès qu'on te demande « calculer », « écrire sous forme \(a + ib\) », « donner la partie réelle ». La règle unique : on développe comme d'habitude, et on remplace \(i^2\) par \(-1\).

Exemple (du cours) \[(1+2i)(3+4i) = 3 + 4i + 6i + 8i^2 = (3-8) + i(4+6) = -5 + 10i.\]

Les puissances de \(i\)

\(i^0 = 1,\ i^1 = i,\ i^2 = -1,\ i^3 = -i,\ i^4 = 1\), puis ça recommence tous les 4. Pour \(i^n\) : on divise \(n\) par 4 et on regarde le reste. Exemple : \(2025 = 4\times 506 + 1\), donc \(i^{2025} = i\).

⚠️ Pièges
  • \(i^2 = -1\), pas \(+1\). Et \(i\) n'est pas « \(\sqrt{-1}\) » à écrire dans les calculs : \(\sqrt{-1}\cdot\sqrt{-1}\ne\sqrt{(-1)(-1)}\). On travaille avec \(i\).
  • Il n'y a pas d'ordre dans \(\mathbb{C}\) : écrire \(z \le z'\) ou « \(i > 0\) » n'a aucun sens. On ne compare que des modules ou des parties réelles.

3. Le conjugué : diviser, tester « réel »

Ce que c'est

Le conjugué de \(z = x + iy\) est \(\bar z = x - iy\) : symétrique par rapport à l'axe des réels. Exemples : \(\bar i = -i\), \(\bar 2 = 2\), \(\overline{3+4i} = 3-4i\).

Propriétés (proposition 28), pour tous \(z, z'\) :

  • \(\bar{\bar z} = z\)
  • \(\overline{z+z'} = \bar z + \bar z'\), \(\overline{zz'} = \bar z\,\bar z'\), \(\overline{z^n} = \bar z^{\,n}\) : le conjugué « passe » dans les sommes, produits, puissances.
  • \(\operatorname{Re}(z) = \dfrac{z+\bar z}{2}\), \(\operatorname{Im}(z) = \dfrac{z-\bar z}{2i}\)
  • \(z\bar z = x^2 + y^2\) : toujours un réel \(\ge 0\). C'est LA formule à retenir.

À quoi ça sert

Usage n°1 : supprimer \(i\) au dénominateur. On multiplie en haut et en bas par le conjugué du dénominateur, car \(z\bar z\) est réel :

Exemple (du cours) \[\frac{2+i}{1-i} = \frac{(2+i)(1+i)}{(1-i)(1+i)} = \frac{2 + 2i + i + i^2}{1^2 + 1^2} = \frac{1+3i}{2}.\]

Usage n°2 : savoir si un nombre est réel ou imaginaire pur sans calculer.

  • \(z\) est réel \(\iff z = \bar z\).
  • \(z\) est imaginaire pur \(\iff z = -\bar z\).

Usage n°3 : résoudre une équation qui contient \(z\) et \(\bar z\). On pose \(z = x+iy\), on remplace, et on identifie parties réelle et imaginaire (deux équations réelles).

4. Le module : mesurer

Ce que c'est

\(|z| = \sqrt{x^2+y^2} = \sqrt{z\bar z}\). C'est la distance entre l'origine et le point \(z\) (théorème de Pythagore). Plus généralement \(|z - z'|\) est la distance entre les points \(z\) et \(z'\).

Inverse : si \(z\ne 0\), \(z^{-1} = \dfrac{\bar z}{|z|^2}\).

Propriétés (proposition 31) :

  • \(|\bar z| = |z|\) ; \(|z| = 0 \iff z = 0\)
  • \(|zz'| = |z||z'|\) ; \(\left|\dfrac{z}{z'}\right| = \dfrac{|z|}{|z'|}\) ; \(|z^n| = |z|^n\) : le module se comporte bien avec \(\times\), \(/\), puissances.
  • \(|\operatorname{Re}(z)| \le |z|\) et \(|\operatorname{Im}(z)| \le |z|\)
  • Inégalité triangulaire : \(\big||z| - |z'|\big| \le |z - z'| \le |z| + |z'|\).
⚠️ Piège Le module ne se comporte pas bien avec la somme : \(|z+z'| \ne |z|+|z'|\) en général (c'est seulement \(\le\)). Exemple : \(|1 + (-1)| = 0 \ne 2\).

À quoi ça sert

  • Décrire des ensembles de points : \(|z - a| = r\) est le cercle de centre \(a\) et de rayon \(r\) ; \(|z-a| = |z-b|\) est la médiatrice de \([a,b]\).
  • Encadrer une quantité (inégalité triangulaire). Exemple : si \(|z| = 2\), alors \(1 \le |z+1| \le 3\).
  • Calculer un module d'un gros produit sans développer : \(|(1+i)^{10}| = |1+i|^{10} = (\sqrt2)^{10} = 32\).

5. Forme trigonométrique et exponentielle : multiplier, puissances

Ce que c'est

Un point du plan peut se repérer par ses coordonnées cartésiennes \((x,y)\) ou par ses coordonnées polaires \((r,\theta)\) : \(r = |z|\) est la distance à l'origine, et \(\theta\) l'argument (l'angle avec l'axe des réels, défini à \(2\pi\) près). Alors :

\[z = r(\cos\theta + i\sin\theta) = r e^{i\theta}\quad\text{avec}\quad e^{i\theta} = \cos\theta + i\sin\theta.\]

Le point \(e^{i\theta}\) est sur le cercle unité (module 1). Règles de calcul (elles sont exactement celles de l'exponentielle) :

  • \(re^{i\theta}\cdot r'e^{i\theta'} = rr'\,e^{i(\theta+\theta')}\) : on multiplie les modules, on additionne les angles.
  • \(\dfrac{re^{i\theta}}{r'e^{i\theta'}} = \dfrac{r}{r'}e^{i(\theta-\theta')}\) : on divise les modules, on soustrait les angles.
  • \((re^{i\theta})^n = r^n e^{in\theta}\).
  • \(\overline{e^{i\theta}} = e^{-i\theta}\).
📐 Fiche détaillée Le schéma complet avec le cercle trigonométrique et toutes les valeurs à connaître est dans la fiche « forme exponentielle ».

Comment trouver \(r\) et \(\theta\) (méthode en 3 étapes)

  1. Calculer \(r = |z| = \sqrt{x^2+y^2}\).
  2. Factoriser : \(z = r\left(\dfrac{x}{r} + i\dfrac{y}{r}\right)\). On cherche \(\theta\) tel que \(\cos\theta = \dfrac{x}{r}\) et \(\sin\theta = \dfrac{y}{r}\).
  3. Reconnaître l'angle avec le tableau des valeurs usuelles (ci-dessous), en regardant le signe de \(\cos\) et de \(\sin\) pour savoir dans quel quadrant on est.
\(\theta\)\(0\)\(\pi/6\)\(\pi/4\)\(\pi/3\)\(\pi/2\)\(\pi\)
\(\cos\theta\)\(1\)\(\frac{\sqrt3}{2}\)\(\frac{\sqrt2}{2}\)\(\frac12\)\(0\)\(-1\)
\(\sin\theta\)\(0\)\(\frac12\)\(\frac{\sqrt2}{2}\)\(\frac{\sqrt3}{2}\)\(1\)\(0\)
Exemples
  • \(z = 2+2i\) : \(r = \sqrt{8} = 2\sqrt2\). \(\cos\theta = \sin\theta = \frac{2}{2\sqrt2} = \frac{\sqrt2}{2}\), donc \(\theta = \frac\pi4\). D'où \(z = 2\sqrt2\,e^{i\pi/4}\) (exemple du cours).
  • \(z = 1 + i\sqrt3\) : \(r = 2\). \(\cos\theta = \frac12\), \(\sin\theta = \frac{\sqrt3}{2}\), donc \(\theta = \frac\pi3\). D'où \(z = 2e^{i\pi/3}\).
  • \(z = -1 + i\) : \(r = \sqrt2\). \(\cos\theta = -\frac{\sqrt2}{2}\), \(\sin\theta = \frac{\sqrt2}{2}\) : on est dans le 2ᵉ quadrant, \(\theta = \frac{3\pi}{4}\). D'où \(z = \sqrt2\,e^{3i\pi/4}\).
  • \(z = -i\) : \(r = 1\), \(\cos\theta = 0\), \(\sin\theta = -1\), donc \(\theta = -\frac\pi2\). D'où \(z = e^{-i\pi/2}\).
⚠️ Piège classique Ne retiens pas aveuglément « \(\theta = \arctan(y/x)\) » : la calculatrice donne un angle dans \(]-\pi/2,\pi/2[\), donc faux quand \(x < 0\). Pour \(-1+i\) : \(\arctan(-1) = -\frac\pi4\), mais le vrai argument est \(\frac{3\pi}{4}\). Vérifie toujours le signe de \(\cos\) et de \(\sin\).

À quoi ça sert

  • Calculer des puissances : \((1+i)^{20}\). On écrit \(1+i = \sqrt2\,e^{i\pi/4}\), donc \((1+i)^{20} = (\sqrt2)^{20}e^{i\,20\pi/4} = 2^{10}e^{5i\pi} = 1024\times(-1) = -1024\). En forme algébrique ce serait un cauchemar.
  • Dire quand une puissance est réelle / imaginaire pure : \((1+i)^n\) est réel \(\iff n\frac\pi4 \equiv 0 \pmod\pi \iff n\) multiple de \(4\).
  • Calculer un quotient : on divise les modules et on soustrait les angles.
  • Interpréter géométriquement : multiplier par \(e^{i\theta}\) = tourner de l'angle \(\theta\) autour de \(0\) ; multiplier par un réel \(r>0\) = agrandir par le facteur \(r\). Donc multiplier par \(re^{i\theta}\) = tourner et agrandir (une similitude).
  • Retrouver des valeurs de \(\cos\) et \(\sin\) exotiques : on écrit un même nombre sous les deux formes et on identifie (voir l'exercice \(\cos\frac{5\pi}{12}\) dans les exos).

Rappel : \(\arg(zz') = \arg z + \arg z'\) et \(\arg(z/z') = \arg z - \arg z'\), toujours modulo \(2\pi\).

6. Euler, De Moivre, linéarisation

Formules d'Euler

\[\cos\theta = \frac{e^{i\theta}+e^{-i\theta}}{2},\qquad \sin\theta = \frac{e^{i\theta}-e^{-i\theta}}{2i}.\]

À quoi ça sert : transformer du \(\cos\) / \(\sin\) en exponentielles (et inversement). C'est l'outil de la linéarisation.

Formule de De Moivre

\[(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta).\]

Preuve en une ligne : \((e^{i\theta})^n = e^{in\theta}\). À quoi ça sert : exprimer \(\cos(n\theta)\) ou \(\sin(n\theta)\) en fonction de \(\cos\theta\), \(\sin\theta\) (on développe le membre de gauche avec le binôme, puis on prend partie réelle / imaginaire).

Exemple : \(\cos 3\theta\) en fonction de \(\cos\theta\) \((\cos\theta + i\sin\theta)^3 = \cos^3\theta + 3i\cos^2\theta\sin\theta - 3\cos\theta\sin^2\theta - i\sin^3\theta\). On prend la partie réelle : \(\cos 3\theta = \cos^3\theta - 3\cos\theta\sin^2\theta = \cos^3\theta - 3\cos\theta(1-\cos^2\theta) = 4\cos^3\theta - 3\cos\theta\).

Linéariser \(\cos(x)^p\sin(x)^q\)

But : transformer un produit de puissances de \(\cos\) et \(\sin\) en une somme de \(\cos(nx)\), \(\sin(mx)\) et de constantes. À quoi ça sert : surtout à intégrer (on sait intégrer \(\cos(nx)\), pas \(\cos^4 x\)) et à simplifier.

Méthode :

  1. Écrire \(\cos x = \frac{e^{ix}+e^{-ix}}{2}\) et \(\sin x = \frac{e^{ix}-e^{-ix}}{2i}\), puis élever à la puissance voulue.
  2. Développer (binôme de Newton).
  3. Simplifier avec \(e^{ikx}e^{i\ell x} = e^{i(k+\ell)x}\).
  4. Regrouper les termes opposés : \(e^{inx}+e^{-inx} = 2\cos(nx)\) et \(e^{inx}-e^{-inx} = 2i\sin(nx)\).
Exemples (du cours) \[\cos^2 x = \frac14\left(e^{2ix} + 2 + e^{-2ix}\right) = \frac{\cos 2x}{2} + \frac12.\] \[\sin^3 x = -\frac{1}{8i}\left(e^{3ix} - 3e^{ix} + 3e^{-ix} - e^{-3ix}\right) = -\frac{\sin 3x}{4} + \frac34\sin x.\]
Bonus : formules d'addition De \(e^{i(a\pm b)} = e^{ia}e^{\pm ib}\) on déduit en prenant parties réelle et imaginaire : \(\cos(a+b) = \cos a\cos b - \sin a\sin b\), \(\sin(a+b) = \sin a\cos b + \cos a\sin b\), etc. Les formules « somme en produit » (\(\cos a + \cos b = 2\cos\frac{a+b}{2}\cos\frac{a-b}{2}\)…) s'en déduisent.

7. Équations du second degré

Soit \((E)\) : \(az^2 + bz + c = 0\) avec \(a \ne 0\) (les coefficients peuvent même être complexes). On pose \(\Delta = b^2 - 4ac\) et on met sous forme canonique :

\[az^2+bz+c = a\left(\left(z+\frac{b}{2a}\right)^2 - \frac{\Delta}{4a^2}\right).\]

CasSolutions
\(\Delta\) réel \(> 0\)deux solutions : \(\dfrac{-b\pm\sqrt\Delta}{2a}\)
\(\Delta = 0\)une racine double : \(\dfrac{-b}{2a}\)
\(\Delta\) réel \(< 0\)deux solutions complexes conjuguées (si \(a,b,c\) réels) : \(\dfrac{-b\pm i\sqrt{-\Delta}}{2a}\)
\(\Delta\) complexe non réeldeux solutions \(\dfrac{-b\pm\delta}{2a}\) où \(\delta\) est une racine carrée de \(\Delta\) (\(\delta^2 = \Delta\))

Dans tous les cas il y a exactement deux solutions (comptées avec multiplicité), et \(az^2+bz+c = a(z-z_1)(z-z_2)\).

Exemple : \(z^2 + z + 1 = 0\) \(\Delta = 1 - 4 = -3 = (i\sqrt3)^2\). Solutions : \(z = \dfrac{-1 \pm i\sqrt3}{2}\). Ce sont les deux racines cubiques de l'unité autres que \(1\) (voir §8).

Comment trouver \(\delta\) quand \(\Delta\) est complexe

Méthode du cours (polaire) : on écrit \(\Delta = re^{i\theta}\) et on prend \(\delta = \sqrt r\,e^{i\theta/2}\). Alors \(\delta^2 = re^{i\theta} = \Delta\). ✓

Méthode algébrique (souvent plus simple à la main) : on pose \(\delta = u+iv\) et on écrit \(\delta^2 = \Delta = a+ib\), ce qui donne le système \[u^2 - v^2 = a,\qquad 2uv = b,\qquad u^2+v^2 = |\Delta|\] (la 3ᵉ vient de \(|\delta|^2 = |\Delta|\) ; elle permet de trouver \(u^2\) et \(v^2\) directement par somme et différence).

Exemple : \(z^2 - 3z + (3 - i) = 0\) \(\Delta = 9 - 4(3-i) = -3 + 4i\), \(|\Delta| = 5\). Système : \(u^2 - v^2 = -3\), \(u^2+v^2 = 5\), donc \(u^2 = 1\), \(v^2 = 4\). Avec \(2uv = 4 > 0\), \(u\) et \(v\) ont le même signe : \(\delta = 1+2i\). Alors \(z = \dfrac{3\pm(1+2i)}{2}\), soit \(z_1 = 2+i\) et \(z_2 = 1-i\).
Vérification : somme \(= 3\) ✓ (égale à \(-b/a\)), produit \((2+i)(1-i) = 3-i\) ✓ (égal à \(c/a\)).

À quoi ça sert : résoudre « toute » équation du second degré, factoriser un polynôme (par exemple \(X^2+X+1 = (X-j)(X-\bar j)\)), et vérifier ses réponses avec somme et produit des racines.

8. Racines de l'unité et équations \(z^n = a\)

Ce que c'est

Une racine \(n\)-ième de l'unité est un complexe \(z\) tel que \(z^n = 1\). Pour les trouver on écrit \(z = re^{i\theta}\), donc \(z^n = r^ne^{in\theta} = 1\) :

  • module : \(r^n = 1\) avec \(r>0\), donc \(r = 1\) ;
  • angle : \(e^{in\theta} = 1 \iff n\theta = 2k\pi\), donc \(\theta = \dfrac{2k\pi}{n}\).

Il y en a exactement \(n\) : \[\omega_k = e^{2ik\pi/n},\qquad k = 0,1,\dots,n-1.\]

Racines 6ᵉ de l'unité : sommets d'un hexagone régulier inscrit dans le cercle unité (angle \(2\pi/6 = \pi/3\) entre deux voisines).

Interprétation géométrique

Elles ont toutes un module \(1\) (cercle unité) et sont régulièrement réparties : deux voisines forment un angle \(\frac{2\pi}{n}\). Ce sont les sommets d'un polygone régulier à \(n\) côtés inscrit dans le cercle unité.

Exemples (du cours)

  • \(z^3 = 1\) : \(\omega_0 = 1\), \(\omega_1 = e^{2i\pi/3} = -\frac12 + i\frac{\sqrt3}{2}\), \(\omega_2 = e^{4i\pi/3} = -\frac12 - i\frac{\sqrt3}{2}\). Triangle équilatéral.
  • \(z^4 = 1\) : \(1,\ i,\ -1,\ -i\). Carré.

Propriétés (avec \(\omega = e^{2i\pi/n}\))

Les \(n\) racines sont \(1,\omega,\omega^2,\dots,\omega^{n-1}\).

  • Somme : pour \(n \ge 2\), \(1+\omega+\dots+\omega^{n-1} = 0\). Preuve : somme géométrique de raison \(\omega\ne1\), donc \(\dfrac{1-\omega^n}{1-\omega} = \dfrac{1-1}{1-\omega} = 0\).
  • Factorisation : \(X^n - 1 = \prod_{k=0}^{n-1}(X-\omega^k)\). Pour \(n=4\) : \(X^4-1 = (X-1)(X-i)(X+1)(X+i) = (X^2-1)(X^2+1)\).
  • Produit : \(\prod_{k=0}^{n-1}\omega^k = (-1)^{n+1}\).

À quoi ça sert : résoudre \(z^n = a\)

Même méthode que pour \(z^n = 1\), avec \(a = \rho e^{i\alpha}\) : on cherche \(z = re^{i\theta}\) avec \(r^n = \rho\) et \(n\theta = \alpha + 2k\pi\). Donc \[z_k = \rho^{1/n}\,e^{i(\alpha+2k\pi)/n},\qquad k = 0,\dots,n-1.\] Il y a toujours exactement \(n\) solutions (pour \(a\ne0\)), réparties comme un polygone régulier.

Exemple : \(z^3 = i\) \(i = e^{i\pi/2}\), donc \(\rho = 1\), \(\alpha = \frac\pi2\) et \(\theta = \dfrac{\pi/2 + 2k\pi}{3} = \dfrac\pi6 + \dfrac{2k\pi}{3}\) :
  • \(k=0\) : \(e^{i\pi/6} = \frac{\sqrt3}{2} + \frac i2\)
  • \(k=1\) : \(e^{5i\pi/6} = -\frac{\sqrt3}{2} + \frac i2\)
  • \(k=2\) : \(e^{3i\pi/2} = -i\)
Vérification pour \(-i\) : \((-i)^3 = -i^3 = -(-i) = i\) ✓.

9. Théorème fondamental de l'algèbre

Théorème (d'Alembert–Gauss). Tout polynôme \(a_nz^n + \dots + a_1z + a_0\) de degré \(n \ge 1\) à coefficients complexes (ou réels) admet au moins une racine dans \(\mathbb{C}\).

Corollaire. Un polynôme de degré \(n\) a au plus \(n\) racines dans \(\mathbb{C}\), et exactement \(n\) si on les compte avec leur multiplicité.

À quoi ça sert : savoir combien de solutions on doit trouver (et donc savoir quand on a fini). Par exemple \(x^4 + 6x^3 - 7 = 0\) a au plus 4 racines complexes ; \(z^n = 1\) en a exactement \(n\), donc les \(\omega_k\) sont toutes les solutions, pas besoin d'en chercher d'autres.

Pour la culture Le théorème dit qu'une racine existe, pas qu'on sait la calculer. Galois a montré que pour \(n \ge 5\) il n'existe en général aucune formule (avec \(+,\times\), complexes et racines \(n\)-ièmes) donnant les solutions.

  5. Oublier des solutions : \(z^n=a\) en a \(n\), pas une seule.
