A. Calculer en forme algébique

A.1 Produit

Écrire \((2-3i)(1+4i)\) sous la forme \(a+ib\).

🎯 Outil : développer comme d'habitude, puis \(i^2=-1\).

Correction \[(2-3i)(1+4i) = 2 + 8i - 3i - 12i^2 = 2 + 5i + 12 = 14 + 5i.\]

A.2 Quotient

Écrire \(\dfrac{3+i}{2-i}\) sous la forme \(a+ib\).

🎯 Outil : multiplier haut et bas par le conjugué du dénominateur (\(z\bar z\) est réel).

Correction Le conjugué de \(2-i\) est \(2+i\), et \((2-i)(2+i) = 4+1 = 5\). \[\frac{3+i}{2-i} = \frac{(3+i)(2+i)}{(2-i)(2+i)} = \frac{6 + 3i + 2i + i^2}{5} = \frac{5+5i}{5} = 1+i.\] Vérification : \((1+i)(2-i) = 2 - i + 2i - i^2 = 3 + i\) ✓.

A.3 Puissances de \(i\)

Calculer \(i^{2025}\) et \(i^{2026}\).

🎯 Outil : les puissances de \(i\) se répètent tous les 4 (\(i^4 = 1\)) : reste de la division par 4.

Correction \(2025 = 4\times506 + 1\), donc \(i^{2025} = (i^4)^{506}\cdot i = i\). \(2026 = 4\times506 + 2\), donc \(i^{2026} = i^2 = -1\).

A.4 Équation avec \(z\) et \(\bar z\)

Résoudre dans \(\mathbb{C}\) : \(z + 2\bar z = 3 + i\).

🎯 Outil : poser \(z=x+iy\) avec \(x,y\) réels, puis identifier parties réelle et imaginaire.

Correction Soit \(z = x+iy\). Alors \(\bar z = x - iy\) et \(z + 2\bar z = (x+2x) + i(y-2y) = 3x - iy\). L'équation devient \(3x - iy = 3 + i\). Deux complexes sont égaux si et seulement si leurs parties réelles et imaginaires sont égales : \(3x = 3\) et \(-y = 1\), donc \(x = 1\), \(y = -1\). Solution : \(z = 1 - i\). Vérification : \((1-i) + 2(1+i) = 3 + i\) ✓.

B. Conjugué : réel, imaginaire pur

B.1 Un nombre est-il imaginaire pur ?

Montrer que \(z = \dfrac{1+i}{1-i}\) est un imaginaire pur.

🎯 Outil : supprimer le \(i\) du dénominateur, puis lire la partie réelle.

Correction \[z = \frac{(1+i)(1+i)}{(1-i)(1+i)} = \frac{1 + 2i + i^2}{2} = \frac{2i}{2} = i.\] Donc \(\operatorname{Re}(z) = 0\) : \(z\) est un imaginaire pur (c'est même \(i\)).

B.2 Utiliser « réel \(\iff z=\bar z\) »

Montrer que pour tout \(z\in\mathbb{C}\), \(z+\bar z\) est réel et \(z-\bar z\) est imaginaire pur.

🎯 Outil : \(w\) réel \(\iff w=\bar w\) ; \(w\) imaginaire pur \(\iff w=-\bar w\).

Correction Soit \(z\in\mathbb{C}\) quelconque et \(w = z+\bar z\). Alors \(\bar w = \bar z + \bar{\bar z} = \bar z + z = w\), donc \(w\) est réel. Soit \(w' = z - \bar z\). Alors \(\bar{w'} = \bar z - z = -w'\), donc \(w'\) est imaginaire pur. (Autre façon : \(z+\bar z = 2\operatorname{Re}(z)\) et \(z-\bar z = 2i\operatorname{Im}(z)\).)

C. Module et inégalité triangulaire

C.1 Calculs de modules

Calculer \(|3-4i|\), \(|(1+i)^{10}|\) et \(\left|\dfrac{3+4i}{1-i}\right|\).

🎯 Outil : \(|z|=\sqrt{x^2+y^2}\) et \(|zz'| = |z||z'|\), \(|z/z'| = |z|/|z'|\), \(|z^n| = |z|^n\) (pas besoin de développer).

Correction
  • \(|3-4i| = \sqrt{9+16} = 5\).
  • \(|(1+i)^{10}| = |1+i|^{10} = (\sqrt2)^{10} = 2^5 = 32\).
  • \(\left|\dfrac{3+4i}{1-i}\right| = \dfrac{|3+4i|}{|1-i|} = \dfrac{5}{\sqrt2} = \dfrac{5\sqrt2}{2}\).

C.2 Encadrer avec l'inégalité triangulaire

Soit \(z\in\mathbb{C}\) avec \(|z| = 2\). Montrer que \(1 \le |z+1| \le 3\).

🎯 Outil : \(\big||z|-|z'|\big| \le |z-z'| \le |z|+|z'|\) avec le bon choix de \(z'\).

Correction On applique l'inégalité triangulaire avec \(z' = -1\) (donc \(z - z' = z+1\), \(|z'| = 1\)) : \[\big||z| - 1\big| \le |z+1| \le |z| + 1.\] Avec \(|z| = 2\) : \(1 \le |z+1| \le 3\). ∎ Les bornes sont atteintes : \(z=2\) donne \(|z+1| = 3\) et \(z=-2\) donne \(|z+1| = 1\).

D. Forme exponentielle, puissances, valeurs exactes de cos et sin

D.1 Mettre sous forme exponentielle

Écrire sous la forme \(re^{i\theta}\) : (a) \(-\sqrt3 + i\) ; (b) \(1 - i\) ; (c) \(-3\) ; (d) \(-2i\).

🎯 Outil : \(r=|z|\), puis \(\cos\theta = x/r\) et \(\sin\theta = y/r\) ; regarder les signes pour le quadrant.

Correction
  • (a) \(r = \sqrt{3+1} = 2\). \(\cos\theta = -\frac{\sqrt3}{2}\), \(\sin\theta = \frac12\) : 2ᵉ quadrant, \(\theta = \frac{5\pi}{6}\). Donc \(-\sqrt3+i = 2e^{5i\pi/6}\).
  • (b) \(r = \sqrt2\). \(\cos\theta = \frac{\sqrt2}{2}\), \(\sin\theta = -\frac{\sqrt2}{2}\) : \(\theta = -\frac\pi4\). Donc \(1-i = \sqrt2\,e^{-i\pi/4}\).
  • (c) \(r=3\), \(\cos\theta=-1\), \(\sin\theta=0\) : \(\theta=\pi\). Donc \(-3 = 3e^{i\pi}\).
  • (d) \(r=2\), \(\cos\theta=0\), \(\sin\theta=-1\) : \(\theta=-\frac\pi2\). Donc \(-2i = 2e^{-i\pi/2}\).

D.2 Grosses puissances

Calculer \((1+i)^{20}\), \((\sqrt3+i)^{12}\) et \((1-i)^{10}\).

🎯 Outil : forme exponentielle, \((re^{i\theta})^n = r^ne^{in\theta}\).

Correction
  • \(1+i = \sqrt2\,e^{i\pi/4}\), donc \((1+i)^{20} = 2^{10}e^{i\,5\pi} = 1024\,e^{i\pi} = -1024\).
  • \(\sqrt3+i = 2e^{i\pi/6}\) (module \(2\), \(\cos=\frac{\sqrt3}2\), \(\sin=\frac12\)), donc \((\sqrt3+i)^{12} = 2^{12}e^{i\,2\pi} = 4096\).
  • \(1-i = \sqrt2\,e^{-i\pi/4}\), donc \((1-i)^{10} = 2^5e^{-i\,5\pi/2} = 32\,e^{-i\pi/2} = -32i\) (car \(-\frac{5\pi}{2} \equiv -\frac\pi2 \pmod{2\pi}\)).
Contrôle du dernier : \((1-i)^2 = -2i\), donc \((1-i)^{10} = (-2i)^5 = -32\,i^5 = -32i\) ✓.

D.3 Pour quels \(n\) est-ce réel ?

Pour quels entiers \(n\in\mathbb{N}\) le nombre \((1+i)^n\) est-il réel ? imaginaire pur ?

🎯 Outil : forme exponentielle \(\sqrt2^{\,n}e^{in\pi/4}\) et regarder quand l'angle \(n\pi/4\) vaut \(0\) ou \(\pi\) (réel), \(\pm\frac\pi2\) (imaginaire pur) modulo \(\pi\).

Correction \((1+i)^n = (\sqrt2)^n\,\big(\cos\frac{n\pi}{4} + i\sin\frac{n\pi}{4}\big)\), avec \((\sqrt2)^n \ne 0\).
  • Réel \(\iff \sin\frac{n\pi}{4} = 0 \iff \frac{n\pi}{4} = k\pi \iff n = 4k\). Donc \(n\) multiple de 4.
  • Imaginaire pur \(\iff \cos\frac{n\pi}{4} = 0 \iff \frac{n\pi}{4} = \frac\pi2 + k\pi \iff n = 2 + 4k\). Donc \(n \equiv 2 \pmod 4\).
Contrôle : \((1+i)^2 = 2i\) (imaginaire pur, \(n=2\)) ; \((1+i)^4 = (2i)^2 = -4\) (réel, \(n=4\)) ✓.

D.4 Valeur exacte de \(\cos\frac{5\pi}{12}\)

On pose \(z = \dfrac{1+i}{\sqrt3 - i}\). Calculer \(z\) de deux façons et en déduire \(\cos\frac{5\pi}{12}\) et \(\sin\frac{5\pi}{12}\).

🎯 Outil : écrire un même nombre sous forme algébrique et exponentielle, puis identifier. C'est le truc pour obtenir des valeurs de \(\cos\) / \(\sin\) qui ne sont pas dans le tableau.

Correction Forme algébrique. On multiplie par le conjugué \(\sqrt3 + i\) (et \((\sqrt3-i)(\sqrt3+i) = 3+1 = 4\)) : \[z = \frac{(1+i)(\sqrt3+i)}{4} = \frac{\sqrt3 + i + i\sqrt3 + i^2}{4} = \frac{(\sqrt3-1) + i(\sqrt3+1)}{4}.\] Forme exponentielle. \(1+i = \sqrt2\,e^{i\pi/4}\) et \(\sqrt3 - i = 2e^{-i\pi/6}\). Donc \[z = \frac{\sqrt2}{2}\,e^{i(\frac\pi4+\frac\pi6)} = \frac{\sqrt2}{2}\,e^{5i\pi/12} = \frac{\sqrt2}{2}\left(\cos\frac{5\pi}{12} + i\sin\frac{5\pi}{12}\right).\] Identification. Parties réelles : \(\frac{\sqrt2}{2}\cos\frac{5\pi}{12} = \frac{\sqrt3-1}{4}\), donc \(\cos\frac{5\pi}{12} = \frac{\sqrt3-1}{2\sqrt2} = \dfrac{\sqrt6-\sqrt2}{4}\). Parties imaginaires : \(\sin\frac{5\pi}{12} = \dfrac{\sqrt6+\sqrt2}{4}\). (Numériquement \(\cos75° \approx 0{,}2588\) ✓.)

E. Linéarisation, De Moivre, intégrales

E.1 Linéariser \(\cos^4 x\)

Linéariser \(\cos^4 x\).

🎯 Outil : Euler, binôme, regrouper \(e^{inx}+e^{-inx} = 2\cos nx\).

Correction \[\cos^4 x = \frac{(e^{ix}+e^{-ix})^4}{16} = \frac{e^{4ix} + 4e^{2ix} + 6 + 4e^{-2ix} + e^{-4ix}}{16}.\] (Les coefficients \(1,4,6,4,1\) sont ceux du binôme ; \(e^{ix}e^{-ix}=1\) donne le terme constant.) On regroupe : \(e^{4ix}+e^{-4ix} = 2\cos4x\) et \(4(e^{2ix}+e^{-2ix}) = 8\cos2x\). Donc \[\cos^4 x = \frac{2\cos4x + 8\cos2x + 6}{16} = \frac{\cos 4x + 4\cos 2x + 3}{8}.\] Contrôle en \(x=0\) : à gauche \(1\), à droite \(\frac{1+4+3}{8} = 1\) ✓.

E.2 Une intégrale grâce à la linéarisation

En déduire \(\displaystyle\int_0^{\pi/2}\cos^4 x\,dx\).

🎯 Outil : c'est à ça que sert la linéarisation : on ne sait pas intégrer \(\cos^4\), mais on sait intégrer \(\cos(nx)\).

Correction \[\int_0^{\pi/2}\cos^4x\,dx = \int_0^{\pi/2}\frac{\cos4x + 4\cos2x + 3}{8}\,dx = \left[\frac{\sin4x}{32} + \frac{\sin2x}{4} + \frac{3x}{8}\right]_0^{\pi/2}.\] En \(\frac\pi2\) : \(\sin2\pi = 0\), \(\sin\pi = 0\), reste \(\frac{3\pi}{16}\). En \(0\) : tout vaut \(0\). Donc l'intégrale vaut \(\dfrac{3\pi}{16}\).

E.3 De Moivre : \(\sin 3x\) en fonction de \(\sin x\)

Exprimer \(\sin 3x\) uniquement à l'aide de \(\sin x\).

🎯 Outil : De Moivre \((\cos x+i\sin x)^3 = \cos3x + i\sin3x\), on développe à gauche et on prend la partie imaginaire.

Correction \[(\cos x + i\sin x)^3 = \cos^3x + 3i\cos^2x\sin x - 3\cos x\sin^2x - i\sin^3x.\] Partie imaginaire : \(\sin3x = 3\cos^2x\sin x - \sin^3x\). Avec \(\cos^2x = 1-\sin^2x\) : \[\sin 3x = 3(1-\sin^2x)\sin x - \sin^3x = 3\sin x - 4\sin^3x.\] Contrôle avec \(x=\frac\pi2\) : \(\sin\frac{3\pi}{2} = -1\) et \(3\cdot1 - 4\cdot1 = -1\) ✓. (Cette formule est la même que \(\sin^3x = \frac34\sin x - \frac{\sin3x}{4}\) du cours, lue dans l'autre sens.)

F. Équations du second degré

F.1 \(\Delta\) réel négatif

Résoudre \(z^2 - 2z + 5 = 0\) et \(2z^2 + 2z + 1 = 0\) dans \(\mathbb{C}\).

🎯 Outil : \(\Delta = b^2-4ac\) ; si \(\Delta<0\), \(\sqrt\Delta = i\sqrt{-\Delta}\).

Correction
  • \(\Delta = 4 - 20 = -16 = (4i)^2\). Solutions : \(z = \dfrac{2\pm4i}{2} = 1\pm2i\).
  • \(\Delta = 4 - 8 = -4 = (2i)^2\). Solutions : \(z = \dfrac{-2\pm2i}{4} = \dfrac{-1\pm i}{2}\).
Comme les coefficients sont réels, les deux solutions sont conjuguées (bon réflexe de contrôle). Vérification de la 1ʳᵉ : somme \(=2\) ✓, produit \((1+2i)(1-2i) = 5\) ✓.

F.2 \(\Delta\) complexe non réel

Résoudre \(z^2 + 2z + (1 - 2i) = 0\).

🎯 Outil : calculer \(\Delta\), en trouver une racine carrée complexe \(\delta\), puis \(z = \frac{-b\pm\delta}{2a}\).

Correction \(\Delta = 4 - 4(1-2i) = 8i\). On cherche \(\delta\) avec \(\delta^2 = 8i\). Méthode polaire : \(8i = 8e^{i\pi/2}\), donc \(\delta = \sqrt8\,e^{i\pi/4} = 2\sqrt2\left(\frac{\sqrt2}{2} + i\frac{\sqrt2}{2}\right) = 2+2i\). Vérification : \((2+2i)^2 = 4 + 8i - 4 = 8i\) ✓. Alors \[z = \frac{-2\pm(2+2i)}{2} \quad\Rightarrow\quad z_1 = i,\quad z_2 = -2-i.\] Contrôle : somme \(= -2 = -b/a\) ✓ ; produit \(i(-2-i) = -2i - i^2 = 1-2i = c/a\) ✓.

G. Racines de l'unité, équations \(z^n=a\)

G.1 Résoudre \(z^4 = -4\)

Résoudre dans \(\mathbb{C}\) l'équation \(z^4 = -4\).

🎯 Outil : écrire \(a\) en exponentielle, puis \(r^n=\rho\) et \(n\theta = \alpha+2k\pi\) : il y a exactement \(n\) solutions.

Correction \(-4 = 4e^{i\pi}\). On cherche \(z = re^{i\theta}\) : \(r^4e^{4i\theta} = 4e^{i\pi}\), donc \(r^4 = 4\), soit \(r=\sqrt2\), et \(4\theta = \pi+2k\pi\), soit \(\theta = \frac\pi4 + k\frac\pi2\), \(k=0,1,2,3\).
\(k\)\(\theta\)\(z_k=\sqrt2\,e^{i\theta}\)
0\(\frac\pi4\)\(1+i\)
1\(\frac{3\pi}{4}\)\(-1+i\)
2\(\frac{5\pi}{4}\)\(-1-i\)
3\(\frac{7\pi}{4}\)\(1-i\)
Les 4 solutions sont les sommets d'un carré. Contrôle : \((1+i)^4 = ((1+i)^2)^2 = (2i)^2 = -4\) ✓. Et le théorème fondamental dit qu'il n'y en a pas d'autres (degré 4).

G.2 Somme des racines 5ᵉ et un \(\cos\) exact

Soit \(\omega = e^{2i\pi/5}\). Montrer que \(1+\omega+\omega^2+\omega^3+\omega^4 = 0\), puis que \(\cos\frac{2\pi}{5} + \cos\frac{4\pi}{5} = -\frac12\).

🎯 Outil : somme géométrique avec \(\omega^5=1\), puis partie réelle.

Correction Somme. \(\omega\ne1\), donc \(1+\omega+\dots+\omega^4 = \dfrac{1-\omega^5}{1-\omega} = \dfrac{1-1}{1-\omega} = 0\) (car \(\omega^5 = e^{2i\pi}=1\)). Partie réelle. \(\omega^k = e^{2ik\pi/5}\), donc \(\operatorname{Re}(\omega^k) = \cos\frac{2k\pi}{5}\) et \[1 + \cos\tfrac{2\pi}{5} + \cos\tfrac{4\pi}{5} + \cos\tfrac{6\pi}{5} + \cos\tfrac{8\pi}{5} = 0.\] Or \(\frac{6\pi}{5} = 2\pi - \frac{4\pi}{5}\) donc \(\cos\frac{6\pi}{5} = \cos\frac{4\pi}{5}\), et \(\frac{8\pi}{5} = 2\pi-\frac{2\pi}{5}\) donc \(\cos\frac{8\pi}{5} = \cos\frac{2\pi}{5}\). Il reste \(1 + 2\cos\frac{2\pi}{5} + 2\cos\frac{4\pi}{5} = 0\), c'est-à-dire \(\cos\frac{2\pi}{5}+\cos\frac{4\pi}{5} = -\frac12\). ∎

G.3 Le nombre \(j\)

Soit \(j = e^{2i\pi/3}\). Montrer que \(j^2+j+1=0\), puis calculer \(1 + j^{100} + j^{200}\).

🎯 Outil : \(j^3 = 1\), donc on réduit les exposants modulo 3 ; et la somme des racines de l'unité vaut 0.

Correction \(j\) est une racine cubique de l'unité différente de \(1\) : \(j^3=1\) et \(j^3 - 1 = (j-1)(j^2+j+1) = 0\) avec \(j-1\ne0\), donc \(j^2+j+1=0\). \(100 = 3\times33+1\) donc \(j^{100} = j\) ; \(200 = 3\times66+2\) donc \(j^{200} = j^2\). Ainsi \[1 + j^{100} + j^{200} = 1 + j + j^2 = 0.\]

H. Géométrie dans le plan complexe

H.1 Ensembles de points

Décrire géométriquement les ensembles : (a) \(\{z : |z-i| = 2\}\) ; (b) \(\{z : |z-1| = |z+1|\}\).

🎯 Outil : \(|z-a|\) est la distance entre \(z\) et \(a\). Sinon, poser \(z=x+iy\) et élever au carré.

Correction
  • (a) \(|z-i|\) est la distance de \(z\) au point \(i\). C'est le cercle de centre \(i\) et de rayon 2.
  • (b) Les points à égale distance de \(1\) et de \(-1\) : la médiatrice de ces deux points, c'est-à-dire l'axe imaginaire. Par le calcul : avec \(z=x+iy\), \(|z-1|^2 = (x-1)^2+y^2\) et \(|z+1|^2 = (x+1)^2+y^2\). L'égalité donne \(-2x = 2x\), donc \(x=0\) : \(\{iy : y\in\mathbb{R}\}\).

H.2 Rotation

(a) Quelle est l'image du point \(2+i\) par la rotation de centre \(0\) et d'angle \(\frac\pi2\) ? (b) Quelle est l'image du point \(2\) par la rotation de centre \(1\) et d'angle \(\frac\pi2\) ? (c) Montrer que les points \(0\), \(1\) et \(e^{i\pi/3}\) forment un triangle équilatéral.

🎯 Outil : tourner de \(\theta\) autour de \(0\) = multiplier par \(e^{i\theta}\). Autour d'un centre \(c\) : \(z \mapsto c + e^{i\theta}(z-c)\).

Correction
  • (a) \(e^{i\pi/2} = i\). Image : \(i(2+i) = 2i + i^2 = -1+2i\).
  • (b) On se ramène au centre \(0\) : \(z' = 1 + i(2-1) = 1+i\).
  • (c) \(|e^{i\pi/3}| = 1\) (distance de \(0\) à \(C\)) ; \(|1-0| = 1\) ; et \(\left|e^{i\pi/3}-1\right| = \left|-\frac12+i\frac{\sqrt3}{2}\right| = \sqrt{\frac14+\frac34} = 1\). Les trois côtés valent 1 : équilatéral. ∎

I. Vrai ou faux ?

Pour chaque affirmation : vraie (la prouver) ou fausse (donner un contre-exemple précis).

  1. Pour tout \(z\in\mathbb{C}\), \(z^2 = |z|^2\).
  2. Pour tout \(z\in\mathbb{C}\), \(|z^2| = |z|^2\).
  3. Si \(|z| = 1\), alors \(\dfrac1z = \bar z\).
  4. Pour tous \(z,z'\in\mathbb{C}\), \(|z+z'| = |z|+|z'|\).
Correction
  1. Faux. Contre-exemple : \(z=i\) : \(z^2=-1\) mais \(|z|^2 = 1\). (C'est vrai exactement quand \(z\) est réel.)
  2. Vrai. Soit \(z\) quelconque. \(|z^2| = |z\cdot z| = |z||z|=|z|^2\) (le module est multiplicatif).
  3. Vrai. Soit \(z\) avec \(|z|=1\). Alors \(z\bar z = |z|^2 = 1\), donc \(\bar z\) est l'inverse de \(z\) : \(\frac1z=\bar z\). (Utile : sur le cercle unité, inverse = conjugué.)
  4. Faux. Contre-exemple : \(z=1\), \(z'=-1\) : \(|z+z'| = 0\) mais \(|z|+|z'| = 2\). On a seulement \(\le\) (inégalité triangulaire).

J. Teste-toi (réponses courtes)

Réponds sur papier, puis déplie.

  1. Que vaut \(i^7\) ?
  2. Quel est le module de \(1 - i\sqrt3\) ?
  3. Quelle est la forme exponentielle de \(-1\) ?
  4. Combien l'équation \(z^7 = 3\) a-t-elle de solutions dans \(\mathbb{C}\) ?
  5. Que vaut \(\left(e^{i\pi/3}\right)^6\) ?
  6. Quel est le conjugué de \(\dfrac{1+3i}{2}\) ?
Réponses
  1. \(i^7 = i^4\cdot i^3 = -i\).
  2. \(\sqrt{1+3} = 2\).
  3. \(e^{i\pi}\).
  4. 7 (une par \(k=0,\dots,6\)).
  5. \(e^{2i\pi} = 1\).
  6. \(\dfrac{1-3i}{2}\).
