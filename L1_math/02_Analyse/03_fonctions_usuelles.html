🧰 Chapitre 4 — Fonctions usuelles

Ce chapitre construit rigoureusement le catalogue de fonctions que tu utilises depuis le lycée (ln, exp, puissances) et en ajoute de nouvelles : les réciproques circulaires (arccos, arcsin, arctan) et les fonctions hyperboliques (ch, sh, th) et leurs réciproques.

1️⃣ Logarithme et exponentielle

📌 Proposition 1 — Le logarithme népérien Il existe une unique fonction ln : ]0,+∞[ → R telle que ln'(x) = 1/x et ln(1) = 0. Elle vérifie, pour a,b > 0 :
  1. ln(ab) = ln a + ln b
  2. ln(1/a) = -ln a
  3. ln(aⁿ) = n ln a
  4. ln est continue, strictement croissante, bijection de ]0,+∞[ sur R
  5. lim(x→0) ln(1+x)/x = 1
  6. ln est concave et ln x ≤ x - 1
💡 Logarithme en base a, logarithme décimal log_a(x) = ln(x)/ln(a), avec log_a(a) = 1. Le logarithme décimal log₁₀ vérifie x = 10^y ⟺ y = log₁₀(x) ; le logarithme en base 2 (log₂) intervient beaucoup en informatique.
📌 Définition 1 — Exponentielle exp : R → ]0,+∞[ est la bijection réciproque de ln. On note aussi eˣ.
📌 Proposition 2 exp(ln x) = x pour x>0, ln(exp x) = x pour tout x ; exp(a+b) = exp(a)×exp(b) ; exp continue, strictement croissante, lim(-∞) exp = 0, lim(+∞) exp = +∞ ; exp' = exp, convexe, exp x ≥ 1+x.

Puissances et comparaison des croissances

📌 Définition — Puissance réelle Pour a > 0, b ∈ R : a^b = exp(b ln a). En particulier √a = a^(1/2), ⁿ√a = a^(1/n).
⚠️ Ne pas confondre x ↦ xᵃ (fonction puissance, base variable) et x ↦ aˣ (fonction exponentielle de base a, exposant variable) — deux fonctions très différentes qui se ramènent toutes deux à exp via aˣ = exp(x ln a).
📌 Proposition 4 — Croissances comparées lim(x→+∞) ln(x)/x = 0 et lim(x→+∞) exp(x)/x = +∞.
💡 Hiérarchie à retenir (en +∞) ln x ≪ x^a (a>0) ≪ exp x : le logarithme est toujours battu par n'importe quelle puissance positive de x, elle-même toujours battue par l'exponentielle. Combiné à la factorielle (chapitre 2 : aⁿ/n! → 0), c'est le classement complet des croissances comparées.

2️⃣ Fonctions circulaires inverses

⚠️ Le problème de départ cos, sin, tan ne sont pas injectives sur R (périodiques). Pour définir une réciproque, il faut d'abord les restreindre à un intervalle où elles sont bijectives — c'est exactement le principe du théorème de la bijection (chapitre 3).

Arccosinus

📌 Définition cos : [0,π] → [-1,1] est continue et strictement décroissante, donc bijective. Sa réciproque est arccos : [-1,1] → [0,π]. 
cos(arccos x) = x  pour x ∈ [-1,1]
arccos(cos x) = x  pour x ∈ [0,π]  (⚠️ seulement sur [0,π] !)
Dérivée : arccos'(x) = -1/√(1-x²) pour x ∈ ]-1,1[.

Arcsinus

📌 Définition sin : [-π/2, π/2] → [-1,1] est bijective (strictement croissante). Sa réciproque : arcsin : [-1,1] → [-π/2,π/2]. 
sin(arcsin x) = x  pour x ∈ [-1,1]
arcsin(sin x) = x  pour x ∈ [-π/2, π/2]
Dérivée : arcsin'(x) = 1/√(1-x²) pour x ∈ ]-1,1[.

Arctangente

📌 Définition tan : ]-π/2, π/2[ → R est bijective. Sa réciproque : arctan : R → ]-π/2, π/2[. 
tan(arctan x) = x  pour tout x
arctan(tan x) = x  pour x ∈ ]-π/2, π/2[
Dérivée : arctan'(x) = 1/(1+x²), pour tout x ∈ R.
💡 Méthode générale pour dériver ces fonctions Toujours le même principe : partir de cos(arccos x) = x, dériver les deux côtés (dérivée d'une composée), isoler arccos'(x), puis exprimer sin(arccos x) en fonction de x via cos²+sin²=1. C'est une démonstration-type à savoir refaire.
⚠️ Piège classique aux exercices arccos(cos x) = x n'est vrai que si x ∈ [0,π] ! Pour un x hors de cet intervalle, il faut d'abord le ramener dans [0,π] en utilisant la 2π-périodicité et la parité de cos. Même remarque pour arcsin et arctan avec leurs intervalles respectifs.

3️⃣ Fonctions hyperboliques et leurs réciproques

📌 Définitions — ch, sh, th 
ch x = (eˣ + e⁻ˣ) / 2      (cosinus hyperbolique)
sh x = (eˣ - e⁻ˣ) / 2      (sinus hyperbolique)
th x = sh x / ch x          (tangente hyperbolique)
📌 Proposition 5 — Identité et dérivées fondamentales ch²x - sh²x = 1 (analogue hyperbolique de cos²+sin²=1) ; ch' = sh, sh' = ch, th' = 1 - th² = 1/ch².

sh et th sont bijectives sur R (impaires, strictement croissantes). ch restreinte à [0,+∞[ est bijective vers [1,+∞[.
