🔢 Chapitre 1 — Les nombres réels

Ce chapitre pose les fondations de tout le cours d'analyse : qu'est-ce qu'un nombre réel, comment le manipuler (ordre, valeur absolue, partie entière), et la notion-clé de borne supérieure qui remplace le maximum quand celui-ci n'existe pas.

❓ Pourquoi ce chapitre

💡 Le fil rouge du cours Deux exemples très simples guident tout le chapitre : les nombres √10 et 1,10^(1/12). On va apprendre à montrer que √10 n'est pas rationnel, puis à l'encadrer entre deux entiers consécutifs — les outils qu'on construit ici (suites, limites, fonctions continues) serviront ensuite à en calculer des centaines de décimales.

1️⃣ L'ensemble des rationnels Q

📌 Définition — Nombres rationnels Q = { p/q | p ∈ Z, q ∈ N* }

Les nombres décimaux (de la forme a/10ⁿ avec a ∈ Z, n ∈ N) sont des exemples de rationnels.

📌 Proposition 1 Un nombre est rationnel si et seulement s'il admet une écriture décimale périodique ou finie.

Exemple : 3/5 = 0,6 (finie), 1/3 = 0,333... (périodique).

√2 n'est pas rationnel

📌 Proposition 2 √2 ∉ Q
📝 Démonstration (par l'absurde) — à connaître par cœur Supposons par l'absurde que √2 ∈ Q. Alors il existe p ∈ Z, q ∈ N* premiers entre eux (fraction irréductible) tels que √2 = p/q.

En élevant au carré : 2q² = p². Donc p² est pair, donc p est pair (si p était impair, p² serait impair). On écrit p = 2p'.

En remplaçant : 2q² = 4p'², donc q² = 2p'². Donc q est pair aussi, par le même argument.

Mais alors p et q sont tous les deux pairs, ce qui contredit le fait qu'ils sont premiers entre eux. Contradiction, donc √2 ∉ Q.

Les irrationnels apparaissent naturellement en géométrie : la diagonale d'un carré de côté 1 vaut √2 ; la circonférence d'un cercle de rayon 1/2 vaut π (irrationnel aussi) ; e = exp(1) également.

2️⃣ Propriétés de R

📌 Propriété (R1) (R, +, ×) est un corps commutatif : addition et multiplication usuelles, commutatives, associatives, distributives, avec neutres 0 et 1, opposé et inverse (pour a ≠ 0).

Relation d'ordre

📌 Définitions — relation d'ordre Une relation R sur un ensemble E est une relation d'ordre si elle est :
  • réflexive : ∀x, xRx ;
  • antisymétrique : (xRy et yRx) ⇒ x = y ;
  • transitive : (xRy et yRz) ⇒ xRz.
Elle est totale si de plus ∀x, y ∈ E, on a xRy ou yRx (deux éléments sont toujours comparables).
📌 Propriété (R2) La relation ≤ sur R est une relation d'ordre, et elle est totale. Les opérations sont compatibles avec l'ordre : a ≤ b et c ≤ d ⇒ a+c ≤ b+d, a ≤ b et c ≥ 0 ⇒ ac ≤ bc, a ≤ b et c ≤ 0 ⇒ ac ≥ bc (⚠️ on inverse le sens quand on multiplie par un négatif).

Propriété d'Archimède

📌 Propriété (R3) — Archimède R est archimédien : ∀x ∈ R, ∃n ∈ N, n > x. Autrement dit, aucun réel n'est « plus grand que tous les entiers ».
📌 Proposition 3 — Partie entière Soit x ∈ R. Il existe un unique entier relatif, noté E(x) (ou ⌊x⌋), tel que E(x) ≤ x < E(x) + 1.

Exemple 1. E(2,853) = 2, E(π) = 3, E(-3,5) = -4 (⚠️ pas -3 ! on arrondit toujours vers le bas).

Exemple 2 — encadrement. 3² = 9 < 10 < 16 = 4² donc 3 < √10 < 4, donc E(√10) = 3.

Valeur absolue

📌 Définition — Valeur absolue |x| = x si x ≥ 0, |x| = -x si x < 0.
📌 Proposition 4
  1. |x| ≥ 0 ; |-x| = |x| ; |x| > 0 ⟺ x ≠ 0
  2. √(x²) = |x|
  3. |xy| = |x||y|
  4. Inégalité triangulaire : |x + y| ≤ |x| + |y|
  5. Seconde inégalité triangulaire : ||x| - |y|| ≤ |x - y|
💡 Interprétation géométrique |x - y| représente la distance entre x et y sur la droite numérique. En particulier |x-a| < r ⟺ x ∈ ]a-r, a+r[ : c'est la notion de voisinage, essentielle pour définir les limites au chapitre suivant.

Densité de Q dans R

📌 Théorème 1 — Densité
  1. Q est dense dans R : tout intervalle ouvert non vide de R contient une infinité de rationnels.
  2. R \ Q est dense dans R : tout intervalle ouvert non vide contient une infinité d'irrationnels.

Démonstration détaillée : tout intervalle contient un rationnel

À démontrer. Pour tous réels a < b, il existe r ∈ Q tel que a < r < b.

💡 L'idée en une image : la règle graduée Fixons un entier q ≥ 1. Les fractions de dénominateur q, c'est-à-dire les p/q avec p ∈ Z, sont espacées de 1/q sur la droite : ce sont les graduations d'une règle.
Si le pas 1/q est strictement plus petit que la longueur b − a de l'intervalle, une graduation tombe forcément dans ]a, b[ : on ne peut pas « sauter par-dessus ».

Étape 1 — choisir q grâce à Archimède. Comme a < b, on a b − a > 0, donc M = 1/(b−a) est bien un réel. La propriété d'Archimède (« pour tout réel M il existe un entier plus grand que M ») donne un q ∈ N* tel que

q > 1/(b − a)

On multiplie par b − a > 0 (le sens de l'inégalité est conservé) : q(b − a) > 1, soit 1/q < b − a. C'est exactement la condition « pas < longueur » du dessin.

Étape 2 — choisir p avec la partie entière. On pose p = E(aq) + 1. Par définition de la partie entière, E(aq) ≤ aq < E(aq) + 1, donc

p − 1 ≤ aq < p

Ainsi p est le plus petit entier strictement supérieur à aq : p/q est la première graduation à droite de a.

Étape 3 — vérifier que a < p/q < b.

  • Minoration. On divise aq < p par q > 0 : a < p/q.
  • Majoration. On divise p − 1 ≤ aq par q : p/q − 1/q ≤ a, donc p/q ≤ a + 1/q. Or 1/q < b − a (étape 1), d'où p/q ≤ a + 1/q < a + (b − a) = b.
📝 Conclusion On a a < p/q < b avec p ∈ Z et q ∈ N*, donc r = p/q ∈ Q convient. ∎

Résumé en 3 lignes : (1) Archimède ⇒ q > 1/(b−a), donc 1/q < b−a ; (2) p = E(aq)+1 ⇒ p−1 ≤ aq < p ; (3) on en déduit a < p/q ≤ a + 1/q < b.
⚠️ Pièges classiques
  • On ne dit pas « q est plus petit que 1/(b−a) » : c'est l'inverse, q doit être plus grand. Plus q est grand, plus la règle est finement graduée.
  • Le +1 dans p = E(aq)+1 sert à avoir p/q strictement plus grand que a (avec p = E(aq) on pourrait avoir p/q = a, ou être à gauche de a).
  • Pour la majoration, il faut une inégalité stricte quelque part : elle vient de 1/q < b − a.
💡 Et pour un irrationnel ? On prend un rationnel r dans ]a − √2, b − √2[ (même preuve, l'intervalle a la même longueur b − a > 0), puis r + √2 ∈ ]a, b[ est irrationnel (somme d'un rationnel et d'un irrationnel). D'où la densité de R \ Q.

3️⃣ Borne supérieure, borne inférieure

⚠️ Pourquoi ce n'est pas juste "maximum" L'intervalle ]0, 1[ n'a ni plus grand ni plus petit élément (pour tout x dans l'intervalle, on trouve toujours un élément plus proche du bord). Pourtant, intuitivement, « 1 » joue un rôle particulier : c'est le plus petit majorant. C'est exactement ce que formalise la borne supérieure.

Majorants, minorants

📌 Définitions Soit A une partie non vide de R.
  • M est un majorant de A si ∀x ∈ A, x ≤ M.
  • m est un minorant de A si ∀x ∈ A, x ≥ m.
  • A est majorée (resp. minorée) si elle admet un majorant (resp. un minorant). Bornée = majorée et minorée.

Attention : il n'y a pas unicité du majorant (tout nombre plus grand qu'un majorant en est aussi un).

Maximum, minimum

📌 Définition α est le plus grand élément (maximum, noté max A) de A si α ∈ A et ∀x ∈ A, x ≤ α. S'il existe, il est unique.

Exemple : max[a,b] = b. Mais ]a,b[ n'a ni maximum ni minimum : ils n'existent pas toujours.

La borne supérieure : la solution

📌 Définition 9 — Borne supérieure / inférieure α est la borne supérieure de A (notée sup A) si α est un majorant de A et si c'est le plus petit des majorants. Idem pour inf A, le plus grand des minorants.

Exemple. sup ]a,b[ = b (même si b ∉ ]a,b[ !), inf ]a,b[ = a.

📌 Théorème 2 (R4) — Existence de la borne supérieure Toute partie non vide et majorée de R admet une borne supérieure. De même, toute partie non vide et minorée admet une borne inférieure.
💡 Pourquoi c'est LE théorème fondamental de ce chapitre C'est ce théorème qui fait toute la différence entre Q et R : dans Q, l'ensemble {x ∈ Q : x² ≤ 2} est majoré mais n'a pas de borne supérieure rationnelle (ce serait √2, qui n'est pas dans Q). C'est précisément la propriété qui « bouche les trous » de Q pour construire R.
📌 Proposition 5 — Caractérisation pratique de sup A sup A est l'unique réel vérifiant :
  1. si x ∈ A, alors x ≤ sup A (c'est un majorant) ;
  2. pour tout y < sup A, il existe x ∈ A tel que y < x (aucun nombre plus petit n'est majorant).
📝 Exemple rédigé — A = {1 - 1/n | n ∈ N*} Montrons que sup A = 1 avec la caractérisation.

(i) Pour tout n ∈ N*, 1 - 1/n < 1, donc 1 est bien un majorant de A.

(ii) Soit y < 1. On cherche n tel que y < 1 - 1/n, c'est-à-dire 1/n < 1 - y, c'est-à-dire n > 1/(1-y). Un tel n existe par la propriété d'Archimède (car 1-y > 0). Donc x = 1 - 1/n ∈ A convient.

Par la caractérisation, sup A = 1. Et on vérifie que min A = 0 (atteint en n=1), mais A n'a pas de maximum (on montre par l'absurde qu'aucun u_n ne peut être le plus grand élément).

📊 Tableau récapitulatif

NotionExiste toujours (si A non vide) ?
Majorant / minorantNon — seulement si A est majorée / minorée
max / minNon, même si A est bornée (ex : ]0,1[)
sup / infOui, dès que A est majorée / minorée (Théorème R4)

Si max A existe, alors sup A = max A. La borne supérieure généralise le maximum et existe beaucoup plus souvent.
