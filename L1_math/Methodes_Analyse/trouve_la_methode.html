🧭 Trouve la méthode

Le but n'est pas seulement de résoudre l'exercice : c'est de savoir quoi faire en lisant l'énoncé. Absurde ? Contre-exemple ? Disjonction de cas ? Quelle définition déplier ? Quel théorème citer ?

Comment s'entraîner sur cette page
  1. Lis l'énoncé. Avant d'ouvrir quoi que ce soit, écris sur ta feuille : vrai ou faux, et quelle méthode tu vas utiliser.
  2. Ouvre « 🧭 Quelle méthode ? » et compare avec ton choix.
  3. Rédige ta réponse, puis ouvre « ✍️ Rédaction » pour comparer.
  4. Lis le « ⚠️ Piège » : ce sont des erreurs faites pour de vrai en TD.

1. Les 4 questions à se poser devant un énoncé

  1. Est-ce vrai ? Teste 3 ou 4 valeurs, dont des valeurs « extrêmes » : 0, un nombre négatif, un nombre très grand, ½.
  2. Si c'est faux : un contre-exemple concret suffit. Pose-le, vérifie qu'il respecte toutes les hypothèses, puis montre que la conclusion est fausse. Pas besoin d'absurde.
  3. Si c'est vrai, regarde la forme de ce qu'il faut montrer :
    • une propriété négative (« n'est pas rationnel », « n'est pas majoré », « il n'existe pas ») → absurde ;
    • une hypothèse sur un signe, une valeur absolue, un max/min → disjonction de cas ;
    • « il existe » → exhiber l'élément (ou absurde si on ne peut pas le construire) ;
    • sinon → preuve directe : écrire les définitions avec les quantificateurs, et enchaîner.
  4. Conclus par une phrase qui répond à la question posée.

3. Les exercices

Source : Feuille d'exercices 1, exercice 1 (UPJV, Analyse 1.1, 2026–2027). Pour chaque question : vrai ou faux, en justifiant.

Q1a · Rationnel + irrationnel

Feuille 1, ex. 1, question 1

Soient x ∈ ℚ et y ∈ ℝ \ ℚ. A-t-on x + y ∈ ℝ \ ℚ ?

🧭 Quelle méthode ?

Vrai → raisonnement par l'absurde.

Signal : on veut montrer que x + y n'est pas rationnel. « Ne pas être rationnel » ne se manipule pas bien directement, alors qu'« être rationnel » donne une égalité utilisable. On suppose donc le contraire.

Outil : ℚ est stable par soustraction.

✍️ Rédaction

Supposons par l'absurde que x + y ∈ ℚ. Posons r = x + y, donc r ∈ ℚ.
Alors y = r − x. Comme r ∈ ℚ et x ∈ ℚ, et que ℚ est stable par soustraction, on a y ∈ ℚ.
C'est absurde puisque y ∈ ℝ \ ℚ. Donc x + y ∈ ℝ \ ℚ.

Version avec fractions : x = a/b et x + y = c/d avec a, b, c, d entiers, b ≠ 0, d ≠ 0. Alors y = c/d − a/b = (cb − ad)/(bd), qui est un quotient d'entiers avec bd ≠ 0. Donc y ∈ ℚ, contradiction.

⚠️ Piège Ne pas appeler le nombre rationnel « q » : on confond avec le q de l'écriture p/q (le dénominateur). Prends plutôt r.

Q1b · Rationnel × irrationnel

Feuille 1, ex. 1, question 1

Soient x ∈ ℚ et y ∈ ℝ \ ℚ. A-t-on xy ∈ ℝ \ ℚ ?

🧭 Quelle méthode ?

Faux → contre-exemple.

Signal : si on recopie l'absurde de Q1a, on écrit y = (xy)/x… et on bloque, car il faut diviser par x. L'endroit où la preuve bloque indique où chercher le contre-exemple : x = 0.

✍️ Rédaction

Faux. Contre-exemple : x = 0 ∈ ℚ et y = √2 ∈ ℝ \ ℚ. Alors xy = 0 ∈ ℚ.

Pour aller plus loin : si on ajoute x ≠ 0, l'énoncé devient vrai, avec le même absurde qu'en Q1a (y = (xy)/x serait rationnel).

⚠️ Piège Pour montrer qu'un « pour tout » est faux, on ne fait pas d'absurde : un seul contre-exemple suffit.

Q2 · Intervalle ou segment ?

Feuille 1, ex. 1, question 2

L'ensemble {x ∈ ℝ : 1 ≤ −2x + 1 < 3} est-il un intervalle ? Est-ce un segment ?

🧭 Quelle méthode ?

Calcul direct par équivalences, puis définitions.

On résout la double inégalité pour écrire l'ensemble sous la forme d'un intervalle. Ensuite on applique les définitions : un intervalle est un ensemble « sans trou » ; un segment est un intervalle [a, b] avec a, b réels : fermé (bornes incluses) et borné.

✍️ Rédaction

1 ≤ −2x + 1 < 3 ⟺ 0 ≤ −2x < 2 ⟺ 0 ≥ x > −1 (on divise par −2 < 0, donc on inverse les inégalités).

L'ensemble est donc ]−1, 0]. C'est un intervalle, mais pas un segment car il n'est pas fermé en −1.

Vérification : x = −0,5 donne −2x + 1 = 2 ∈ [1, 3[ ✓ ; x = 0,5 donne 0 ∉ [1, 3[ ✗.

⚠️ Piège Oublier d'inverser les inégalités en divisant par −2 : on trouve alors [0, 1[ au lieu de ]−1, 0]. Toujours vérifier avec une valeur.

Q3 · Valeur absolue et signe

Feuille 1, ex. 1, question 3

Soit x ∈ ℝ tel que |x + 2026| > 2026. A-t-on x > 0 ?

🧭 Quelle méthode ?

Faux → contre-exemple, trouvé en testant une valeur extrême.

Signal : une valeur absolue efface le signe, donc un nombre très négatif peut aussi la rendre grande. Outil : |A| > c ⟺ A > c ou A < −c.

✍️ Rédaction

Faux. Contre-exemple : x = −5000. Alors |−5000 + 2026| = |−2974| = 2974 > 2026, mais x < 0.

Pour comprendre : |x + 2026| > 2026 ⟺ x + 2026 > 2026 ou x + 2026 < −2026 ⟺ x > 0 ou x < −4052.

⚠️ Piège Partir sur un absurde « si x < 0 alors |x + 2026| < 2026 » : ce n'est vrai que pour x proche de 0. Avant de prouver, teste une valeur très négative.

Q4 · Égalité dans l'inégalité triangulaire

Feuille 1, ex. 1, question 4

Soient x, y ∈ ℝ tels que xy ≥ 0. A-t-on |x + y| = |x| + |y| ?

🧭 Quelle méthode ?

Vrai → disjonction de cas selon le signe.

Signal : l'hypothèse xy ≥ 0 parle d'un signe (règle des signes : x et y ont le même signe), et la conclusion contient des valeurs absolues. Outil : |a| = a si a ≥ 0, |a| = −a si a ≤ 0.

✍️ Rédaction

Vrai. Comme xy ≥ 0, x et y sont de même signe au sens large.

Cas 1 : x ≥ 0 et y ≥ 0. Alors x + y ≥ 0, donc |x + y| = x + y = |x| + |y|.
Cas 2 : x ≤ 0 et y ≤ 0. Alors x + y ≤ 0, donc |x + y| = −(x + y) = (−x) + (−y) = |x| + |y|.

Dans les deux cas, |x + y| = |x| + |y|.

⚠️ Piège Écrire seulement « même signe donc ça donne la même chose » : c'est l'idée, mais la copie doit contenir le calcul de chaque cas. Le cas x = 0 est inclus grâce aux inégalités larges.

Q5a · A minorée, B majorée, A ⊂ B : A est-elle bornée ?

Feuille 1, ex. 1, question 5

Soient A et B deux parties de ℝ telles que A est minorée, B est majorée et A ⊂ B. La partie A est-elle bornée ?

🧭 Quelle méthode ?

Vrai → preuve directe en dépliant les définitions.

Écrire les trois hypothèses avec des quantificateurs, puis prendre un x quelconque de A et enchaîner : x ∈ A ⇒ x ∈ B ⇒ x ≤ M.

✍️ Rédaction

Vrai. A est minorée : il existe m ∈ ℝ tel que ∀x ∈ A, m ≤ x.
B est majorée : il existe M ∈ ℝ tel que ∀x ∈ B, x ≤ M.

Soit x ∈ A. Comme A ⊂ B, x ∈ B, donc x ≤ M. Et comme x ∈ A, m ≤ x.
Donc ∀x ∈ A, m ≤ x ≤ M : A est bornée.

⚠️ Piège (important) Écrire « ∀x ∈ A, ∃m ∈ ℝ, m < x » : c'est toujours vrai (prendre m = x − 1), donc ça ne définit rien. Un minorant est le même pour tous les x : ∃m, ∀x. Et l'inclusion A ⊂ B s'écrit ∀x ∈ A, x ∈ B, sans accolades.

Q5b · … et B est-elle bornée ?

Feuille 1, ex. 1, question 5

Mêmes hypothèses. La partie B est-elle bornée ?

🧭 Quelle méthode ?

Faux → contre-exemple, puis absurde + propriété d'Archimède pour montrer « B n'est pas minorée ».

Signal : rien dans les hypothèses ne retient B vers le bas. On choisit un B qui « descend à l'infini ». Pour prouver qu'il n'est pas minoré (propriété négative), on raisonne par l'absurde.

✍️ Rédaction

Faux. Posons A = [0, 1] et B = ]−∞, 1].

Hypothèses : A est minorée par 0 ; B est majorée par 1 ; A ⊂ B car tout x ∈ [0, 1] vérifie x ≤ 1.

B n'est pas minorée : supposons par l'absurde que B est minorée par un réel m. Pour tout n ∈ ℕ, −n ≤ 1, donc −n ∈ B, donc m ≤ −n, c'est-à-dire n ≤ −m. Alors ℕ serait majoré par −m, ce qui contredit la propriété d'Archimède.

Donc B n'est pas bornée.

⚠️ Piège Dire seulement « B est simplement majorée » ne justifie rien. Un contre-exemple, c'est 3 étapes : poser A et B, vérifier les hypothèses, montrer que la conclusion échoue.

Q6 · Minoré ? Plus petit élément ?

Feuille 1, ex. 1, question 6

L'ensemble E = {|x − 1| : x ∈ ℝ₊} est-il minoré ? Admet-il un plus petit élément ?

🧭 Quelle méthode ?

Vrai et vrai → preuve directe : un minorant évident, puis la définition du min.

Signal : « plus petit élément ». Il faut deux choses : m minore E, et m ∈ E. Outil : une valeur absolue est toujours ≥ 0.

✍️ Rédaction

Minoré : vrai. Pour tout x ∈ ℝ₊, |x − 1| ≥ 0, donc 0 minore E.

Plus petit élément : vrai, c'est 0. 0 ∈ E car 1 ∈ ℝ₊ et |1 − 1| = 0. Et 0 minore E. Donc min E = 0 (et par conséquent inf E = 0).

⚠️ Piège Le min et le max appartiennent toujours à l'ensemble ; l'inf et le sup, pas forcément. Exemple : ]0, 1] a pour inf 0, mais pas de min. Pense aussi à vérifier que 1 ∈ ℝ₊.

Q7a · sup A > 0 : tous les éléments sont-ils > 0 ?

Feuille 1, ex. 1, question 7

Soit A une partie non vide et majorée de ℝ telle que sup(A) > 0. A-t-on a > 0 pour tout a ∈ A ?

🧭 Quelle méthode ?

Faux → contre-exemple.

Signal : le sup ne contrôle que le haut de A. Rien n'empêche A de contenir des nombres négatifs.

✍️ Rédaction

Faux. Contre-exemple : A = {−1, 1}. A est non vide, majorée par 1, et sup A = 1 > 0. Mais −1 ∈ A et −1 ≤ 0.

⚠️ Piège La bonne raison n'est pas « le sup n'est pas forcément dans A », mais « le sup ne dit rien sur les petits éléments ».

Q7b · … existe-t-il un élément > 0 ?

Feuille 1, ex. 1, question 7

Mêmes hypothèses. Existe-t-il a ∈ A tel que a > 0 ?

🧭 Quelle méthode ?

Vrai → absurde (ou contraposée) + « sup A est le plus petit majorant ».

Signal : une inégalité sur un sup. Si tous les éléments étaient ≤ 0, alors 0 serait un majorant, et le sup (plus petit majorant) serait ≤ 0.

✍️ Rédaction

Vrai. Supposons par l'absurde que pour tout a ∈ A, a ≤ 0. Alors 0 est un majorant de A. Comme sup A est le plus petit des majorants de A, on a sup A ≤ 0, ce qui contredit sup A > 0.

Donc il existe a ∈ A tel que a > 0.

💡 Réflexe à retenir Si M majore A, alors sup A ≤ M. Par contraposée : si sup A > M, alors il existe a ∈ A avec a > M. La question 7b, c'est ce réflexe avec M = 0. « Non vide » sert à garantir que sup A existe.

Q8 · Partie entière du double

Feuille 1, ex. 1, question 8

Soit x ∈ ℝ. A-t-on ⌊2x⌋ = 2⌊x⌋ ?

🧭 Quelle méthode ?

Faux → contre-exemple, en testant x = ½.

Signal : une égalité « trop belle » avec une partie entière. La partie entière « coupe » aux entiers, donc on teste un nombre non entier, typiquement ½.

✍️ Rédaction

Faux. Contre-exemple : x = ½. Alors ⌊2x⌋ = ⌊1⌋ = 1, mais 2⌊x⌋ = 2 × 0 = 0.

Pour aller plus loin : avec ⌊x⌋ ≤ x < ⌊x⌋ + 1, on obtient 2⌊x⌋ ≤ 2x < 2⌊x⌋ + 2, donc ⌊2x⌋ vaut 2⌊x⌋ ou 2⌊x⌋ + 1.
