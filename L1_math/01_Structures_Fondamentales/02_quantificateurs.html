🔢 Chapitre 2 — Les quantificateurs

📐 Propositions dépendant d'une variable

Une proposition P peut dépendre d'une variable x appartenant à un ensemble E, ce qu'on note P(x). On peut alors voir P comme une fonction :

P : E → {Vrai, Faux}
     x ↦ P(x)
📌 Exemple du cours Soit P(x) l'expression x² - 4x + 2 < 0, définie sur R.
P est la fonction de R dans {Vrai, Faux}, vraie pour les x tels que x² - 4x + 2 < 0, fausse sinon.
Par exemple : P(1) = Vrai et P(4) = Faux.

🎯 Le quantificateur existentiel : ∃

Pour exprimer que P(x) pourrait être vraie pour un certain x, sans savoir lequel, on utilise :

∃x ∈ E | P(x)

qui se lit : « il existe x dans E tel que P(x) est vraie ».

Comme toute proposition, cette expression peut elle-même être vraie ou fausse.

🌐 Le quantificateur universel : ∀

Pour exprimer que « P(x) est vraie pour tout x de E » on écrit :

∀x ∈ E, P(x)
SymboleSe lit
∀« quel que soit », ou « pour tout »
∃« il existe »
💡 Exercice du cours Le quantificateur ∃! se lit « il existe un et un seul ». Essaie de l'exprimer avec ∃ et ∀ vus précédemment (voir la correction dans la page d'exercices).

🔀 Distribuer les quantificateurs sur ∧ et ∨

Ces équivalences sont très utiles pour décomposer une preuve en raisonnements plus simples :

✅ Équivalences (marchent dans les deux sens) 
(∀x ∈ E, P(x) ∧ Q(x))  ⇔  ((∀x ∈ E, P(x)) ∧ (∀x ∈ E, Q(x)))
(∃x ∈ E, P(x) ∨ Q(x))  ⇔  ((∃x ∈ E, P(x)) ∨ (∃x ∈ E, Q(x)))
⚠️ Implications seulement (PAS des équivalences !) Pour les cas suivants, il n'y a qu'une implication dans un seul sens — il y a une « perte d'information » à les utiliser. Un contre-exemple existe pour chaque réciproque (à chercher en exercice) : 
(∃x ∈ E, P(x) ∧ Q(x))  ⇒  ((∃x ∈ E, P(x)) ∧ (∃x ∈ E, Q(x)))

((∀x ∈ E, P(x)) ∨ (∀x ∈ E, Q(x)))  ⇒  (∀x ∈ E, P(x) ∨ Q(x))
🚨 Pourquoi les parenthèses comptent Le cours insiste : on prend soin d'utiliser des parenthèses pour exprimer le plus clairement possible les propositions. L'absence de parenthèses peut créer des confusions dans les énoncés — ne les néglige jamais dans tes rédactions.

🔄 Négation des quantificateurs

Nier un quantificateur en inverse un autre — c'est une règle absolument fondamentale :

PropositionSa négation
∀x ∈ E, P(x)∃x ∈ E | ¬P(x)
∃x ∈ E, P(x)∀x ∈ E | ¬P(x)
💡 Moyen mnémotechnique Nier un ∀ le transforme en ∃ (et vice-versa), et on nie l'intérieur (P(x) devient ¬P(x)). C'est toujours comme ça, quel que soit le nombre de quantificateurs enchaînés — on les inverse un par un de gauche à droite.
📌 Cas particulier : l'ensemble vide Si E est vide, alors ∀x ∈ E, P(x) est toujours vraie ! (Il n'y a aucun élément pour contredire l'affirmation — on dit que c'est vrai « par vide ».)

✍️ Remarques typographiques

  • Après le x, on utilise indifféremment une virgule , ou la barre | qui se lit « tel que » (abrégé « tq »).
  • Le x précédé d'un quantificateur doit satisfaire tout ce qui est écrit après lui dans l'assertion.
  • On peut écrire ∀x ∈ R | 2 < 3 — une assertion un peu bizarre mais valide, où le prédicat ne dépend même pas de x (elle est vraie car 2 < 3 l'est, peu importe x).

Raccourcis d'écriture courants

RaccourciSignifie
∀x, y ∈ E∀x ∈ E, ∀y ∈ E
∃x, y ∈ E∃x ∈ E, ∃y ∈ E
🚨 Conseil fort du prof : ne pas utiliser les quantificateurs comme raccourcis dans une rédaction Les quantificateurs ne doivent jamais être mélangés à des phrases écrites en français dans une copie d'examen. Ils sont toujours écrits sur des lignes séparées pour exprimer soit une proposition vraie, soit ce qu'on souhaite prouver. Tu peux les utiliser comme raccourcis dans tes notes personnelles, mais pas en rédaction d'exercice ou d'examen.

🔤 Lettres « affectées » vs lettres « muettes »

Quand on analyse une assertion mathématique, on distingue deux sortes de lettres :

Type de lettreDescription
AffectéeDésigne un objet considéré comme connu, ou « fixé par la pensée »
Non affectéeDite aussi « muette » ou « variable » — n'est pas encore fixée
📌 Exemples de lettres muettes (x) 
∀x ∈ E, P(x)
∃x ∈ E, P(x)
f : R → R, x ↦ 2x + 1
Ici, x est forcément muette : on peut la remplacer par n'importe quelle autre lettre non affectée (ex: t) sans changer le sens de l'assertion : f : R → R, t ↦ 2t + 1 est rigoureusement équivalente.

Certaines expressions ont pour but d'affecter une lettre qui ne l'était pas :

  • « Choisissons un x ∈ ]a, +∞[ ; »
  • « Fixons un réel x > a ; »
  • « Posons x = 2 + 3 ; »
  • « Soient x et y dans X. »

C'est souvent plus facile de raisonner avec des objets fixés qu'avec des lettres muettes.

✍️ Trois rédactions types importantes

1️⃣ Pour prouver ∀x ∈ R, x < 1 + x² On écrit : « Choisissons x ∈ R » et si on parvient à prouver l'inégalité pour ce x (fixé, arbitraire), l'assertion sera prouvée pour tous les x.
2️⃣ Pour utiliser la proposition (A) : ∃x ∈ R | x⁵ - 5x + 1 = 0 On écrit : « Choisissons, d'après (A), un réel x vérifiant x⁵ - 5x + 1 = 0. »
3️⃣ Pour prouver ∃x ∈ R | x > x² On écrit : « Cette proposition est vraie car par exemple x = 1/2 convient. » (Il suffit d'exhiber un seul exemple qui marche !)
