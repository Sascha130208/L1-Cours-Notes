2️⃣ Décrire des ensembles

  • E = {n ∈ N | -π < n < π} = {0,1,2,3}
  • F = {x ∈ R | -π < x < π} = ]-π,π[
  • G = {n ∈ N | -2 < n < 3,5} = {0,1,2,3}
  • H = {x | x ≥ 0 et x ≤ 0} = {0}
  • I = {x | x ∈ R et x ∉ R} = ∅

Dans {x | condition}, le symbole | signifie « tel que ».

3️⃣ Ensemble des parties P(A)

P(A) contient tous les sous-ensembles de A.

P({a,b}) = {∅,{a},{b},{a,b}}

P({a,b,c}) =
{∅,{a},{b},{c},{a,b},{a,c},{b,c},{a,b,c}}

P(∅) = {∅}

P({∅}) = {∅,{∅}}

Cas avec des accolades imbriquées

On a :

P({a}) = {∅,{a}}

Donc :

P(P({a})) = P({∅,{a}})
             = {∅,{∅},{{a}},{∅,{a}}}

Le piège est {{a}} : ici {a} est un élément de l'ensemble de départ, donc le singleton qui le contient est {{a}}.

6️⃣ Comparaison par inclusion avec complémentaires

Pour les expressions travaillées :

X = A ∩ (B ∪ C)^c
Y = (A ∪ B) ∪ C^c
Z = (A ∩ B) ∪ C^c

Avec De Morgan :

(B ∪ C)^c = B^c ∩ C^c

Donc :

X = A ∩ B^c ∩ C^c

On obtient les inclusions :

X ⊂ Z ⊂ Y

Pourquoi X ⊂ Z ?

Si x ∈ X, alors :

x ∈ A
x ∈ B^c
x ∈ C^c

En particulier x ∈ C^c. Or C^c ⊂ (A ∩ B) ∪ C^c, donc x ∈ Z.

Pourquoi Z ⊂ Y ?

On sait que :

A ∩ B ⊂ A ∪ B

Donc, en ajoutant le même C^c :

(A ∩ B) ∪ C^c ⊂ (A ∪ B) ∪ C^c
⭐ Méthode pour prouver une inclusion
  1. Prendre un élément quelconque : « Soit x ∈ X ».
  2. Traduire les intersections par « ET » et les unions par « OU ».
  3. Utiliser les complémentaires : x ∈ A^c ⇔ x ∉ A.
  4. Montrer que les conditions obtenues donnent x ∈ Y.
  5. Conclure : X ⊂ Y.
