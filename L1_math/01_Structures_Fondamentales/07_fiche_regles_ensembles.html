🧠 Fiche — Petites règles à connaître : Ensembles

Cette fiche regroupe les réflexes et pièges essentiels à connaître pour le chapitre sur les ensembles, avec les notations utilisées dans le TD.

1️⃣ Symboles à connaître

NotationLectureSignification
x ∈ Ax appartient à Ax est un élément de A
x ∉ Ax n'appartient pas à Ax n'est pas un élément de A

🚨 Piège n°1 : ∈ et ⊂ ∈ relie un élément à un ensemble.
⊂ relie deux ensembles.

Exemple : a ∈ E mais {a} ⊂ E.

2️⃣ L'ensemble vide

Règle fondamentale :

∅ ⊂ A

est toujours vrai, quel que soit l'ensemble A.

En revanche :

∅ ∈ A

n'est pas forcément vrai.

  • a : un élément.
  • {a} : un ensemble qui contient a.

⚠️ À retenir ∅ ≠ {∅} et {∅} n'est pas l'ensemble vide.

4️⃣ Vérifier une inclusion

Pour montrer :

B ⊂ A

il faut vérifier que tous les éléments de B appartiennent à A.

Rédaction type :

Soit x ∈ B. Montrons que x ∈ A.
...
Donc x ∈ A.
Ainsi B ⊂ A.

5️⃣ Ensemble des parties P(A)

P(A) est l'ensemble de toutes les parties (sous-ensembles) de A.

Exemple :

P({a,b}) = {∅, {a}, {b}, {a,b}}

Pour un ensemble à n éléments :

|P(A)| = 2^n
💡 Pour ne pas oublier de parties Pour un ensemble {a,b,c}, classe les parties par taille : 0 élément, puis 1, puis 2, puis 3.

6️⃣ Cardinal

|A| = nombre d'éléments distincts de A.

|∅| = 0
|{∅}| = 1

L'ordre et les répétitions dans l'écriture ne changent pas un ensemble :

{1,2,3} = {3,1,2} = {1,3,1,2}

7️⃣ Ensembles usuels

N ⊂ Z ⊂ Q ⊂ R

Avec notamment :

  • N : entiers naturels
  • Z : entiers relatifs
  • Q : rationnels
  • R : réels

8️⃣ Décrire un ensemble

Dans :

A = {x ∈ R | condition}

le symbole | se lit « tel que ».

Exemple :

{x ∈ R | -1 < x < 3} = ]-1,3[

9️⃣ Intersection, union et différence

A ∩ B = éléments dans A ET dans B
A ∪ B = éléments dans A OU dans B
A  B = éléments dans A MAIS PAS dans B

À retenir :

∩  → ET
∪  → OU

🔟 Complémentaire

Si A ⊂ E :

A^c = E  A

C'est tout ce qui est dans l'univers E mais pas dans A.

1️⃣1️⃣ Lois de simplification

RègleRésultat
Union avec soi-mêmeA ∪ A = A
Intersection avec soi-mêmeA ∩ A = A
Union avec ∅A ∪ ∅ = A
Intersection avec ∅A ∩ ∅ = ∅
Union avec EA ∪ E = E
Intersection avec EA ∩ E = A

1️⃣2️⃣ Lois de De Morgan

(A ∪ B)^c = A^c ∩ B^c
(A ∩ B)^c = A^c ∪ B^c

1️⃣3️⃣ Produit cartésien

A × B = {(a,b) | a ∈ A et b ∈ B}

Ce sont des couples. Et :

|A × B| = |A| × |B|

⭐ Les réflexes à savoir par cœur

  1. ∈ = appartient, ⊂ = est une partie.
  2. ∅ ⊂ A est toujours vrai.
  3. ∅ et {∅} sont différents.
  4. P(A) = toutes les parties de A.
  5. Si |A| = n, alors |P(A)| = 2^n.
  6. ∩ = ET, ∪ = OU, \ = dans le premier mais pas dans le second.
  7. Pour montrer A = B, montrer A ⊂ B et B ⊂ A.
  8. Pour montrer A ⊂ B, prendre un élément quelconque de A et montrer qu'il est dans B.
