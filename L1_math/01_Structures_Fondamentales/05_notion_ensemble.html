📦 Chapitre 3 — Notion d'ensemble

On introduit ici quelques ensembles de base, ainsi que les relations appartenance et inclusion entre ensembles. Attention à ne pas confondre ces deux notations, qui n'ont pas le même sens.

🔢 Quelques ensembles usuels

  • N = {0, 1, 2, ...} : ensemble des entiers naturels.
    N* = N \ {0} = {1, 2, ...}.
    N_n = {k ∈ N | 0 ≤ k ≤ n} = {0, 1, ..., n} et N*_n = {k ∈ N | 1 ≤ k ≤ n} = {1, ..., n}.
    En particulier N*_0 = ∅.
  • Z = N ∪ (-N) où -N = {-n | n ∈ N} : ensemble des entiers relatifs.
  • Q = {p/q | p ∈ Z et q ∈ N*} : ensemble des rationnels.
  • R : ensemble des réels. R \ Q est l'ensemble des irrationnels.
  • C = {x + iy | x, y ∈ R} : ensemble des nombres complexes.
  • R+ = [0, +∞[, utile (entre autres) pour les longueurs.
  • R̄ = [-∞, +∞] = R ∪ {-∞, +∞} : la droite réelle achevée.
  • L'ensemble vide : ∅ = {}.
📌 Intervalles avec ±∞ Si a, b ∈ R̄ et a ≤ b alors -∞ ≤ a ≤ b ≤ +∞. De plus 
[a, b] = {t ∈ R̄ | a ≤ t ≤ b}
]a, b] = [a, b] \ {a}
[a, b[ = [a, b] \ {b}
]a, b[ = [a, b] \ {a, b}
💡 Un ensemble ne se répète pas et n'est pas ordonné {1, 2, 3} = {3, 1, 2} = {1, 3, 1, 2}, cet ensemble a pour cardinal 3 (il contient 3 éléments distincts, peu importe l'ordre ou les répétitions dans l'écriture).
⚠️ Exemples moins usuels mais corrects {∅} ≠ ∅, {{∅}}, {∅, {∅}}, N ∪ {N}.
{∅} n'est pas l'ensemble vide : c'est un ensemble qui contient un élément, à savoir ∅ lui-même. Ne confonds pas « ne rien contenir » et « contenir l'ensemble qui ne contient rien ».

On suppose aussi connus Z*, R*, C* = C \ {0}, R*_+, Q*, R_-, etc.

🧩 Appartenance, inclusion, égalité

L'appartenance x ∈ E

Se lit de plusieurs façons :

  • x appartient à E, ou
  • x est un élément de E, ou moins formellement,
  • E « contient » x.

L'inclusion A ⊂ B

C'est une relation entre deux ensembles A et B (on écrit aussi B ⊃ A). Elle signifie que chaque élément de A appartient également à B :

A ⊂ B  ⟺  ∀x ∈ A, x ∈ B

Cette relation peut se lire de plusieurs façons :

  • A est inclus dans B,
  • A est un sous-ensemble de B,
  • A est une partie de B,
  • B contient A.
🚨 Ne pas confondre ∈ et ⊂ ∈ relie un élément à un ensemble. ⊂ relie deux ensembles entre eux.

Exemple : on a 1 ∈ [0, 2] car 1 est un élément du segment [0, 2]. Mais on écrira {1} ⊂ [0, 2] : ici {1} n'est plus un élément mais un ensemble constitué de l'unique élément 1.

L'égalité A = B

Signifie que A et B sont les mêmes ensembles, c'est-à-dire qu'ils contiennent les mêmes éléments :

A = B  ⟺  ∀x, (x ∈ A ⇔ x ∈ B)

ou encore, façon très pratique pour prouver une égalité d'ensembles :

(A = B)  ⟺  (A ⊂ B et B ⊂ A)

L'inclusion, une relation d'ordre (mais pas totale)

L'inclusion vérifie les 3 propriétés qui définissent une relation d'ordre :

PropriétéÉnoncé
RéflexivitéA ⊂ A
Transitivité(A ⊂ B et B ⊂ C) ⇒ A ⊂ C
Antisymétrie(A ⊂ B et B ⊂ A) ⇒ A = B
⚠️ Mais ce n'est pas un ordre total Certains ensembles A et B ne sont pas comparables : on n'a ni A ⊂ B, ni B ⊂ A.

Exemple : {0, 1} et {1, 2} sont incomparables — aucun des deux n'est inclus dans l'autre.
