    Catégorie A : Relations d'équivalence des constructions

    A.1 La relation qui construit \(\mathbb{Z}\)

    Sur \(\mathbb{N}\times\mathbb{N}\), on pose \((n,m)\,R\,(n',m') \iff n + m' = n' + m\). Montrer que \(R\) est une relation d'équivalence. Quels couples sont en relation avec \((2,0)\) ?

    Correction
    • Réflexive. Soit \((n,m) \in \mathbb{N}^2\). \(n + m = n + m\), donc \((n,m)\,R\,(n,m)\).
    • Symétrique. Supposons \((n,m)\,R\,(n',m')\), i.e. \(n + m' = n' + m\). Alors \(n' + m = n + m'\), ce qui est exactement \((n',m')\,R\,(n,m)\).
    • Transitive. Supposons \((n,m)\,R\,(n',m')\) et \((n',m')\,R\,(n'',m'')\), i.e. \(n + m' = n' + m\) et \(n' + m'' = n'' + m'\). En additionnant : \[n + m' + n' + m'' = n' + m + n'' + m'.\] On simplifie par \(m' + n'\) (c'est permis dans \(\mathbb{N}\) : \(a + c = b + c \Rightarrow a = b\)) : \(n + m'' = m + n''\), soit \(n + m'' = n'' + m\). Donc \((n,m)\,R\,(n'',m'')\). \(\square\)

    Couples en relation avec \((2,0)\) : \((n',m')\) tel que \(2 + m' = n' + 0\), i.e. \(n' = m' + 2\) : \((2,0), (3,1), (4,2), \dots\) — tous les couples « de différence 2 », qui représentent bien l'entier \(2\).

    A.2 La relation qui construit \(\mathbb{Q}\)

    Sur \(\mathbb{Z}\times\mathbb{N}^*\), on pose \((a,b)\,R\,(c,d) \iff ad = cb\). Montrer la transitivité. Où utilise-t-on que les dénominateurs sont \(\ne 0\) ?

    Correction

    Supposons \((a,b)\,R\,(c,d)\) et \((c,d)\,R\,(e,f)\), i.e. \(ad = cb\) et \(cf = ed\). On veut \(af = eb\). Multiplions la première égalité par \(f\) : \(adf = cbf\). Or \(cf = ed\), donc \(cbf = b(cf) = b(ed) = bed\). Donc \(adf = bed\), soit \(d\,(af) = d\,(eb)\). Comme \(d \ne 0\) (\(d \in \mathbb{N}^*\)), on simplifie par \(d\) : \(af = eb\). Donc \((a,b)\,R\,(e,f)\). \(\square\)

    L'hypothèse \(d \ne 0\) est essentielle : si on autorisait \(d = 0\), tous les couples \((a,b)\) seraient en relation avec \((0,0)\), et la transitivité s'effondrerait : c'est pourquoi on ne divise pas par \(0\).

    A.3 Les entiers de von Neumann

    Avec \(0 = \emptyset\) et \(n+1 = n \cup \{n\}\), écrire \(0, 1, 2, 3\) comme ensembles, puis compter leurs éléments. Montrer par récurrence que \(\operatorname{card}(n) = n\).

    Correction
    • \(0 = \emptyset\), \(1 = \{\emptyset\}\), \(2 = \{\emptyset, \{\emptyset\}\}\), \(3 = \{\emptyset, \{\emptyset\}, \{\emptyset, \{\emptyset\}\}\}\). Cardinaux : \(0, 1, 2, 3\).
    • Récurrence. \(P(n) : \operatorname{card}(n) = n\). Initialisation : \(\operatorname{card}(\emptyset) = 0\). Hérédité : supposons \(P(n)\). Alors \(n+1 = n \cup \{n\}\), et \(n \notin n\) (c'est un fait de la construction : aucun entier n'est élément de lui-même), donc l'union est disjointe et \(\operatorname{card}(n+1) = \operatorname{card}(n) + \operatorname{card}\{n\} = n + 1\). \(\square\)

    Remarque : le cours écrit (par coquille) \(4 = \{0,1,3,4\}\) ; la bonne définition est \(4 = \{0,1,2,3\}\).

    Catégorie B : Irrationnels

    B.1 \(\sqrt 2\) n'est pas rationnel

    Correction

    Supposons par l'absurde \(\sqrt2 \in \mathbb{Q}\) : \(\sqrt 2 = \frac ab\) avec \(a \in \mathbb{N}\), \(b \in \mathbb{N}^*\) premiers entre eux. Alors \(a^2 = 2b^2\), donc \(a^2\) est pair. Par contraposée, si \(a\) était impair, \(a^2\) le serait ; donc \(a\) est pair : \(a = 2k\). Alors \(4k^2 = 2b^2\), soit \(b^2 = 2k^2\), donc \(b^2\) pair, donc \(b\) pair. Ainsi \(2\) divise à la fois \(a\) et \(b\), ce qui contredit « \(a, b\) premiers entre eux ». Donc \(\sqrt2 \notin \mathbb{Q}\). \(\square\)

    B.2 Opérations avec des irrationnels

    (a) Si \(r \in \mathbb{Q}^*\), montrer que \(r\sqrt2 \notin \mathbb{Q}\). (b) Si \(q \in \mathbb{Q}\), montrer que \(q + \sqrt 2 \notin \mathbb{Q}\). (c) Donner deux irrationnels dont la somme est rationnelle, et deux dont le produit est rationnel.

    Correction

    (a) Par l'absurde : si \(r\sqrt2 = s \in \mathbb{Q}\), alors \(\sqrt 2 = \frac sr \in \mathbb{Q}\) (quotient de rationnels, \(r \ne 0\)), ce qui contredit B.1. (b) Par l'absurde : si \(q + \sqrt2 = s \in \mathbb{Q}\), alors \(\sqrt2 = s - q \in \mathbb{Q}\), contradiction. (c) \(\sqrt2 + (-\sqrt2) = 0 \in \mathbb{Q}\) ; \(\sqrt 2 \cdot \sqrt2 = 2 \in \mathbb{Q}\). (On peut aussi prendre \(\sqrt2 \cdot \frac{1}{\sqrt2}\).) Conclusion : la somme ou le produit de deux irrationnels peut être rationnel ; la somme/produit rationnel-irrationnel (non nul) est irrationnel.

    B.3 Un irrationnel entre deux rationnels

    Trouver explicitement un irrationnel dans l'intervalle \(]0{,}1\;;\;0{,}2[\).

    Correction

    Cherchons de la forme \(y = q\sqrt2\) avec \(q \in \mathbb{Q}^*\). On veut \(0{,}1 < q\sqrt 2 < 0{,}2\), donc \(\frac{0{,}1}{\sqrt2} < q < \frac{0{,}2}{\sqrt2}\), c'est-à-dire environ \(0{,}0707 < q < 0{,}1414\). Prenons \(q = 0{,}1\). Alors \(y = 0{,}1\sqrt2 \approx 0{,}1414\), qui est irrationnel par B.2(a), et vérifie \(0{,}1 < 0{,}1\sqrt2 < 0{,}2\) car \(1 < \sqrt2 < 2\). \(\square\)

    (C'est exactement la méthode du cours pour la densité : on se ramène à un rationnel multiplié par \(\sqrt2\).)

    Catégorie C : Partie entière, Archimède, densité

    C.1 Calculs de parties entières

    Calculer \(E(\pi)\), \(E(-\pi)\), \(E(5)\), \(E(-0{,}1)\), \(E(\sqrt2)\), \(E(-\sqrt 2)\).

    Correction

    On cherche l'unique entier \(n\) avec \(n \le x < n+1\).

    • \(E(\pi) = 3\) (car \(3 \le \pi < 4\)).
    • \(E(-\pi) = -4\) (car \(-4 \le -\pi \approx -3{,}14 < -3\)).
    • \(E(5) = 5\) (car \(5 \le 5 < 6\)).
    • \(E(-0{,}1) = -1\) (car \(-1 \le -0{,}1 < 0\)).
    • \(E(\sqrt2) = 1\) (car \(1 \le 1{,}41\ldots < 2\)).
    • \(E(-\sqrt2) = -2\) (car \(-2 \le -1{,}41\ldots < -1\)).

    Piège : pour un négatif non entier, \(E\) n'est pas « on enlève les décimales » mais « l'entier immédiatement en dessous ».

    C.2 Propriété de la partie entière

    Montrer que pour tout \(x \in \mathbb{R}\) et tout \(k \in \mathbb{Z}\), \(E(x + k) = E(x) + k\).

    Correction

    Soit \(n = E(x)\), donc \(n \le x < n+1\). En ajoutant \(k\) : \(n + k \le x + k < n + k + 1\). Comme \(n + k \in \mathbb{Z}\), c'est exactement la caractérisation de \(E(x+k)\) (unique entier \(m\) avec \(m \le x + k < m+1\)). Donc \(E(x+k) = n + k = E(x) + k\). \(\square\)

    C.3 Approximation décimale

    Pour \(x = \sqrt2\), calculer \(r_n = \dfrac{E(nx)}{n}\) pour \(n = 1, 10, 100\) et vérifier \(0 \le x - r_n < \frac1n\).

    Correction

    \(\sqrt2 = 1{,}41421\ldots\)

    • \(n = 1\) : \(E(1{,}414\ldots) = 1\), \(r_1 = 1\) ; \(x - r_1 \approx 0{,}414 < 1\) ✓.
    • \(n = 10\) : \(E(14{,}142\ldots) = 14\), \(r_{10} = 1{,}4\) ; \(x - r_{10} \approx 0{,}0142 < 0{,}1\) ✓.
    • \(n = 100\) : \(E(141{,}42\ldots) = 141\), \(r_{100} = 1{,}41\) ; \(x - r_{100} \approx 0{,}0042 < 0{,}01\) ✓.

    Pour \(n = 10^q\), \(r_n\) est l'approximation décimale par défaut d'ordre \(q\).

    C.4 Densité : le théorème en action

    (a) Trouver un rationnel dans \(]\sqrt2, \sqrt 2 + 0{,}01[\). (b) Soient \(a < b\). Montrer qu'il existe \(n \in \mathbb{N}^*\) tel que \(\frac1n < b - a\). En déduire (sans la preuve du cours) qu'il existe un rationnel de la forme \(\frac{p}{n}\) dans \(]a, b[\).

    Correction

    (a) \(r_{1000} = \frac{E(1000\sqrt2)}{1000} = \frac{1414}{1000} = 1{,}414\) est dans \([\sqrt2 - 0{,}001, \sqrt2]\), donc en dessous de \(\sqrt 2\). Pour être au-dessus, prenons \(r_{1000} + \frac1{1000} = 1{,}415\) : comme \(x < r_n + \frac1n\) et \(r_n \le x\), on a \(\sqrt2 < 1{,}415 \le \sqrt2 + \frac1{1000} < \sqrt2 + 0{,}01\). ✓

    (b) Archimède (forme : \(\forall\varepsilon>0,\ \forall y,\ \exists n \in \mathbb{N},\ y \le n\varepsilon\)) avec \(\varepsilon = b - a > 0\) et \(y = 1\) : il existe \(n\) avec \(1 \le n(b-a)\) ; quitte à remplacer \(n\) par \(n+1\), on a \(n \ge 1\) et \(\frac1n < b - a\). Posons \(p = E(na) + 1\) ; alors \(E(na) \le na < p\), donc \(a < \frac pn\), et \(p \le na + 1\), donc \(\frac pn \le a + \frac1n < b\). Ainsi \(a < \frac pn < b\) avec \(\frac pn \in \mathbb{Q}\). \(\square\)

    On a utilisé : Archimède (pour fabriquer \(n\) assez grand) et la partie entière (pour fabriquer \(p\)). C'est exactement la mécanique de la preuve de densité.

    Catégorie D : Questions de compréhension (à répondre en une phrase)

    1. Pourquoi ne peut-on pas définir \(\mathbb{Z}\) simplement en « inventant \(-n\) » ?
    2. Pourquoi doit-on quotienter lors de la construction de \(\mathbb{Z}\) ?
    3. Pourquoi \(\mathbb{Q}\) est-il à la fois dense dans \(\mathbb{R}\) et dénombrable, alors que \(\mathbb{R}\) ne l'est pas ?
    4. Quelle propriété de \(\mathbb{R}\) manque à \(\mathbb{Q}\) ?
    Réponses
    1. Parce que « \(-\) » n'a pas de sens dans la théorie des ensembles de départ : on n'a que \(\emptyset\), les ensembles et les produits. On remplace donc « \(-n\) » par des couples \((n,m)\) censés représenter \(n-m\).
    2. Parce qu'un même entier relatif a plusieurs représentants \((n,m)\) (\(2\) est \((2,0)\), \((3,1)\), …) ; le passage au quotient les identifie pour qu'il n'y ait qu'un objet par entier.
    3. Dense : il y a des rationnels aussi près qu'on veut de tout réel (partie entière). Dénombrable : on peut numéroter tous les rationnels. Mais \(\mathbb{R}\) est trop gros pour être numéroté (diagonale de Cantor) : la densité parle de position, la dénombrabilité parle de taille. Ce sont deux notions indépendantes.
    4. La complétude : toute suite de Cauchy (ou toute suite croissante majorée) y converge. Dans \(\mathbb{Q}\), les approximations décimales de \(\sqrt2\) forment une suite de Cauchy sans limite dans \(\mathbb{Q}\).
