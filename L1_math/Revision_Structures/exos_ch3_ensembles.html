Catégorie A : Appartenance, inclusion, ensembles de parties

A.1 \(\in\) ou \(\subset\) ? [TD2 n°1]

Soit \(E = \{a, b, c\}\). Peut-on écrire : a) \(a \in E\) b) \(a \subset E\) c) \(\{a\} \subset E\) d) \(\emptyset \in E\) e) \(\emptyset \subset E\) f) \(\{\emptyset\} \subset E\) ?

Correction
  • a) Vrai : \(a\) est un élément de \(E\).
  • b) Faux (n'a pas de sens ici) : \(\subset\) relie deux ensembles ; \(a\) est un élément.
  • c) Vrai : tout élément de \(\{a\}\) (c'est \(a\)) est dans \(E\).
  • d) Faux : les éléments de \(E\) sont \(a, b, c\) ; \(\emptyset\) n'en fait pas partie.
  • e) Vrai : \(\forall x \in \emptyset,\ x \in E\) est vraie à vide.
  • f) Faux : \(\{\emptyset\} \subset E\) signifie \(\emptyset \in E\), ce qui est faux (cf. d).

A.2 Décrire autrement [TD2 n°2]

Décrire par énumération : \(E = \{n \in \mathbb{N} \mid -\pi < n < \pi\}\) ; \(G = \{n \in \mathbb{N} \mid -2 < n < 3{,}5\}\) ; \(H = \{x \mid x \ge 0 \text{ et } x \le 0\}\) ; \(I = \{x \mid x \in \mathbb{R} \text{ et } x \notin \mathbb{R}\}\).

Correction
  • \(E\) : entiers naturels \(n\) avec \(n < \pi \approx 3{,}14\) : \(E = \{0, 1, 2, 3\}\).
  • \(G\) : entiers naturels \(n < 3{,}5\) : \(G = \{0, 1, 2, 3\}\) (aussi \(= E\)).
  • \(H\) : \(x \ge 0\) et \(x \le 0\) \(\Leftrightarrow\) \(x = 0\) : \(H = \{0\}\).
  • \(I\) : aucun \(x\) n'est à la fois dans \(\mathbb{R}\) et hors de \(\mathbb{R}\) : \(I = \emptyset\).

(Dans le TD, \(F\) est écrit avec « \(-\pi < n < \pi\) » pour la variable \(x\) : sans doute une coquille ; si c'est \(\{x \in \mathbb{R} \mid -\pi < x < \pi\}\), c'est l'intervalle \(]-\pi, \pi[\).)

A.3 Ensembles de parties [TD2 n°3]

Décrire \(\mathcal{P}(\{a,b\})\), \(\mathcal{P}(\emptyset)\), \(\mathcal{P}(\{\emptyset\})\) et \(\mathcal{P}(\mathcal{P}(\{a\}))\). Combien d'éléments chacun a-t-il ?

Correction
  • \(\mathcal{P}(\{a,b\}) = \{\emptyset, \{a\}, \{b\}, \{a,b\}\}\) : 4 éléments (\(2^2\)).
  • \(\mathcal{P}(\emptyset) = \{\emptyset\}\) : 1 élément (\(2^0\)).
  • \(\mathcal{P}(\{\emptyset\}) = \{\emptyset, \{\emptyset\}\}\) : 2 éléments (\(2^1\)).
  • \(\mathcal{P}(\{a\}) = \{\emptyset, \{a\}\}\) (2 éléments), donc \(\mathcal{P}(\mathcal{P}(\{a\})) = \{\emptyset,\ \{\emptyset\},\ \{\{a\}\},\ \{\emptyset, \{a\}\}\}\) : 4 éléments (\(2^2\)).

Vérification : \(\operatorname{card}\mathcal{P}(E) = 2^{\operatorname{card}E}\).

Catégorie B : Calculs d'ensembles

B.1 Simplifier [TD2 n°4]

Simplifier : (1) \(A \cup B \cup C \cup B \cup A\) ; (2) \(A \cap (A \cup B)\) ; (3) \(A \cap (A \cap B)\) ; (4) \(A \setminus (A \cap B)\) ; (5) \(A \setminus (A \cup B)\) ; (6) \(A \setminus (B \setminus A)\) ; (7) \(A \cup (B \setminus A)\) ; (8) \((A \setminus B) \cap (B \setminus A)\).

Correction

On raisonne avec un élément \(x\) quelconque.

  1. \(A \cup B \cup C\) (idempotence : les doublons ne comptent pas).
  2. \(A\) (absorption) : \(\subset\) : \(A \cap (\cdot) \subset A\) ; \(\supset\) : si \(x\in A\) alors \(x \in A\cup B\) donc \(x \in A \cap (A\cup B)\).
  3. \(A \cap B\) (associativité et idempotence : \(A \cap A \cap B\)).
  4. \(A \setminus B\) : \(x \in A\) et \(x \notin A \cap B\) \(\Leftrightarrow\) \(x \in A\) et (\(x \notin A\) ou \(x \notin B\)) \(\Leftrightarrow\) \(x \in A\) et \(x \notin B\).
  5. \(\emptyset\) : \(x \in A\) et \(x \notin A \cup B\) est impossible (\(x \in A \subset A\cup B\)).
  6. \(A\) : \(x \in A \setminus (B \setminus A) \Leftrightarrow x \in A\) et \(\neg(x \in B \text{ et } x \notin A)\). Comme \(x \in A\), la parenthèse « \(x \in B\) et \(x \notin A\) » est fausse, donc sa négation est vraie : on garde \(x \in A\).
  7. \(A \cup B\) : si \(x \in A \cup B\), soit \(x \in A\), soit (\(x \in B\) et \(x \notin A\)), soit \(x \in B \setminus A\).
  8. \(\emptyset\) : un élément de \(A \setminus B\) est dans \(A\), un élément de \(B \setminus A\) n'est pas dans \(A\) : impossible d'être dans les deux.

B.2 Cardinaux de « disques » [TD2 n°5]

Déterminer le cardinal de : (1) \(Q = \{(a,b) \in \mathbb{N}^2 \mid a^2 + b^2 \le 9\}\) ; (2) \(D^+ = \{(a,b) \in \mathbb{N} \times \mathbb{Z} \mid a^2 + b^2 \le 9\}\) ; (3) \(D = \{(a,b) \in \mathbb{Z}^2 \mid a^2 + b^2 \le 9\}\).

Correction

On dénombre par valeur de \(a\) (somme d'ensembles disjoints, Prop. 17). Pour \(a\) fixé, \(b^2 \le 9 - a^2\).

\(a\) \(9 - a^2\) \(b \in \mathbb{N}\) possibles nb \(b \in \mathbb{Z}\) possibles nb
0 9 0, 1, 2, 3 4 \(-3, \dots, 3\) 7
1 8 0, 1, 2 3 \(-2, \dots, 2\) 5
2 5 0, 1, 2 3 \(-2, \dots, 2\) 5
3 0 0 1 0 1
  • (1) \(\operatorname{card} Q = 4 + 3 + 3 + 1 = \mathbf{11}\).
  • (2) \(a \in \mathbb{N}\) : \(\operatorname{card} D^+ = 7 + 5 + 5 + 1 = \mathbf{18}\).
  • (3) \(a \in \mathbb{Z}\) : \(a = 0\) donne 7 ; \(a = \pm1\) donne \(5 + 5\) ; \(a = \pm 2\) donne \(5 + 5\) ; \(a = \pm 3\) donne \(1 + 1\). Donc \(\operatorname{card} D = 7 + 10 + 10 + 2 = \mathbf{29}\).

Contrôle par symétrie : \(D\) s'obtient depuis \(D^+\) en ajoutant les \(a<0\), qui répètent les \(a>0\) : \(18 + (5 + 5 + 1) = 29\) ✓.

B.3 Régler une équation d'ensembles [TD2 n°10]

Soient \(A, B \in \mathcal{P}(E)\). Discuter et résoudre l'équation d'inconnue \(X \in \mathcal{P}(E)\) : (a) \(A \cup X = B\) ; (b) \(A \cap X = B\).

Correction

(a) \(A \cup X = B\). Condition nécessaire. Si une solution existe, \(A \subset A \cup X = B\). Donc il faut \(A \subset B\). Supposons \(A \subset B\) et cherchons les solutions. Si \(A \cup X = B\), alors \(X \subset B\) et tout élément de \(B \setminus A\) doit être dans \(X\) (il est dans \(A\cup X\) mais pas dans \(A\)). Donc \(B \setminus A \subset X \subset B\). Réciproque. Si \(B \setminus A \subset X \subset B\) (et \(A \subset B\)), alors \(A \cup X \subset B\), et pour \(x \in B\), soit \(x \in A\) soit \(x \in B \setminus A \subset X\), donc \(x \in A \cup X\). Bilan : pas de solution si \(A \not\subset B\) ; si \(A \subset B\), les solutions sont exactement les \(X\) tels que \(B \setminus A \subset X \subset B\).

(b) \(A \cap X = B\). Condition nécessaire. \(B = A \cap X \subset A\). Donc il faut \(B \subset A\). Supposons \(B \subset A\). Si \(A \cap X = B\), alors \(B \subset X\) et \(X \cap A = B\) signifie que la partie de \(X\) située dans \(A\) est exactement \(B\), donc \(X = B \cup Y\) avec \(Y = X \setminus A \subset E \setminus A\). Réciproque. Si \(X = B \cup Y\) avec \(Y \subset A^c\), alors \(A \cap X = (A \cap B) \cup (A \cap Y) = B \cup \emptyset = B\) (car \(B \subset A\) et \(Y \cap A = \emptyset\)). Bilan : pas de solution si \(B \not\subset A\) ; si \(B \subset A\), les solutions sont les \(X = B \cup Y\) avec \(Y \subset E \setminus A\) quelconque.

Catégorie C : Preuves d'égalités et d'implications

C.1 Un classique : \(\cap\) seule, \(\cup\) seule, les deux [TD2 n°7]

Soient \(A, B, C \subset E\). (a) \(A \cap B = A \cap C \Rightarrow B = C\) ? (b) \(A \cup B = A \cup C \Rightarrow B = C\) ? (c) \(A \cap B = A \cap C\) et \(A \cup B = A \cup C\) \(\Rightarrow B = C\) ?

Correction

(a) Non. Contre-exemple : \(A = \emptyset\), \(B = \{1\}\), \(C = \{2\}\). Alors \(A \cap B = \emptyset = A \cap C\) mais \(B \ne C\).

(b) Non. Contre-exemple : \(A = E = \{1,2\}\), \(B = \{1\}\), \(C = \{2\}\). Alors \(A \cup B = E = A \cup C\) mais \(B \ne C\).

(c) Oui. Montrons \(B \subset C\) ; l'autre inclusion est symétrique. Soit \(x \in B\).

  • Cas \(x \in A\) : alors \(x \in A \cap B = A \cap C\), donc \(x \in C\).
  • Cas \(x \notin A\) : comme \(x \in B \subset A \cup B = A \cup C\) et \(x \notin A\), on a \(x \in C\). Dans les deux cas \(x \in C\). Donc \(B \subset C\). En échangeant les rôles de \(B\) et \(C\), \(C \subset B\). Ainsi \(B = C\). \(\square\)

Moralité : \(\cap\) et \(\cup\) ne sont pas « simplifiables » seuls, mais ensemble ils le sont (disjonction de cas sur \(x \in A\)).

C.2 Différence et complémentaire [TD2 n°8]

Pour \(A, B, C \in \mathcal{P}(E)\), montrer : (1) \(A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C)\) ; (2) \(\complement_E A \setminus \complement_E B = B \setminus A\).

Correction

(1) Soit \(x\) quelconque. On traduit : \[x \in A \setminus (B \cap C) \iff x \in A \text{ et } \neg(x \in B \text{ et } x \in C) \iff x \in A \text{ et } (x \notin B \text{ ou } x \notin C).\] Par distributivité de « et » sur « ou » : \[\iff (x \in A \text{ et } x \notin B) \text{ ou } (x \in A \text{ et } x \notin C) \iff x \in (A \setminus B) \cup (A \setminus C). \qquad\square\]

(2) Soit \(x \in E\). \[x \in \complement_E A \setminus \complement_E B \iff x \notin A \text{ et } \neg(x \notin B) \iff x \notin A \text{ et } x \in B \iff x \in B \setminus A. \qquad\square\] (On a utilisé la double négation.)

C.3 Une implication entre égalités [TD2 n°9]

Soient \(A, B \in \mathcal{P}(E)\). Montrer : \((A \cap B = A \cup B) \Rightarrow (A = B)\).

Correction

Supposons \(A \cap B = A \cup B\). On a toujours \(A \cap B \subset A\) et \(A \subset A \cup B\).

  • Donc \(A \subset A \cup B = A \cap B \subset B\) : on obtient \(A \subset B\).
  • De même \(B \subset A \cup B = A \cap B \subset A\) : on obtient \(B \subset A\).

Par double inclusion, \(A = B\). \(\square\)

Remarque : la réciproque est vraie aussi (si \(A = B\) alors \(A \cap B = A = A \cup B\)), donc \(A \cap B = A \cup B \iff A = B\).

C.4 Associativité et distributivité (demandées par le cours)

Prouver : (a) \(A \cup (B \cup C) = (A \cup B) \cup C\) ; (b) \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\) ; (c) \(A \cup (B \cap C) = (A \cup B) \cap (A \cup C)\).

Correction

Soit \(x\) quelconque. On utilise que « ou » et « et » sont associatifs et que chacun se distribue sur l'autre (tables de vérité).

(a) \(x \in A \cup (B \cup C) \iff x \in A \text{ ou } (x \in B \text{ ou } x \in C) \iff (x \in A \text{ ou } x \in B) \text{ ou } x \in C \iff x \in (A\cup B) \cup C\). \(\square\)

(b) \(x \in A \cap (B \cup C) \iff x \in A \text{ et } (x \in B \text{ ou } x \in C) \iff (x \in A \text{ et } x \in B) \text{ ou } (x \in A \text{ et } x \in C) \iff x \in (A \cap B) \cup (A \cap C)\). \(\square\)

(c) \(x \in A \cup (B \cap C) \iff x \in A \text{ ou } (x \in B \text{ et } x \in C) \iff (x \in A \text{ ou } x\in B) \text{ et } (x \in A \text{ ou } x \in C) \iff x \in (A\cup B)\cap(A\cup C)\). \(\square\)

C.5 Images avec produit cartésien [TD2 n°13, extrait]

Soient \(E, F\) des ensembles, \(A \subset E\), \(B \subset F\). Comparer \(\complement_{E \times F}(A \times B)\) et \((\complement_E A \times F) \cup (E \times \complement_F B)\).

Correction

Soit \((x, y) \in E \times F\). \[(x,y) \notin A \times B \iff \neg(x \in A \text{ et } y \in B) \iff x \notin A \text{ ou } y \notin B \iff (x,y) \in (\complement_E A \times F) \cup (E \times \complement_F B).\] Donc les deux ensembles sont égaux. \(\square\)

Attention : \(\complement_E A \times \complement_F B\) est strictement plus petit en général (il n'exige « \(x \notin A\) ET \(y \notin B\) »). On a \(\complement_E A \times \complement_F B \subset \complement_{E\times F}(A \times B)\), avec inclusion stricte dès que \(A \ne E\) et \(B \ne \emptyset\) par exemple.

Catégorie D : Dénombrement élémentaire

D.1 Inclusion-exclusion à deux ensembles

Montrer, pour \(E, F\) finis : \(\operatorname{card}(E \cup F) + \operatorname{card}(E \cap F) = \operatorname{card}E + \operatorname{card}F\).

Correction

On partitionne : \(E \cup F = E \sqcup (F \setminus E)\) (union disjointe) et \(F = (F \setminus E) \sqcup (E \cap F)\) (union disjointe). Par la Prop. 17 : \[\operatorname{card}(E\cup F) = \operatorname{card}E + \operatorname{card}(F \setminus E), \qquad \operatorname{card}F = \operatorname{card}(F \setminus E) + \operatorname{card}(E \cap F).\] On en tire \(\operatorname{card}(F\setminus E) = \operatorname{card}F - \operatorname{card}(E \cap F)\), puis en remplaçant dans la première : \[\operatorname{card}(E \cup F) = \operatorname{card}E + \operatorname{card}F - \operatorname{card}(E \cap F). \qquad\square\]

D.2 Compter des paires de parties [TD2 n°34]

Soit \(E\) fini de cardinal \(n\). Dénombrer : \(\mathcal{A}_1 = \{(A,B) \in \mathcal{P}(E)^2 \mid A \subset B\}\) et \(\mathcal{A}_2 = \{(A,B) \in \mathcal{P}(E)^2 \mid A \cup B = E\}\).

Correction

Idée : se donner \((A, B)\) revient à décider, pour chaque élément \(x \in E\), de sa « situation » par rapport à \(A\) et \(B\). Ces \(n\) choix sont indépendants.

  • \(\mathcal{A}_1\) (\(A \subset B\)) : pour chaque \(x\), trois situations possibles : \(x \notin B\) (donc \(x \notin A\)) ; \(x \in B \setminus A\) ; \(x \in A\) (donc \(x \in B\)). La situation « \(x \in A\) et \(x \notin B\) » est interdite. Donc \(3\) choix par élément : \(\operatorname{card}\mathcal{A}_1 = 3^n\).
  • \(\mathcal{A}_2\) (\(A \cup B = E\)) : pour chaque \(x\), il doit être dans \(A\) ou dans \(B\) (ou les deux) : \(x \in A \setminus B\), ou \(x \in B \setminus A\), ou \(x \in A \cap B\). La situation « dans aucun des deux » est interdite. Donc \(3\) choix par élément : \(\operatorname{card}\mathcal{A}_2 = 3^n\).

Vérification pour \(n=1\), \(E=\{x\}\) : \(\mathcal{A}_1 = \{(\emptyset,\emptyset), (\emptyset,E), (E,E)\}\), 3 éléments ✓.

(Les deux ensembles ont même cardinal car \((A,B) \mapsto (A^c, B)\) est une bijection de \(\mathcal{A}_1\) sur \(\mathcal{A}_2\) : en effet \(A \subset B \iff A^c \cup B = E\). À prouver en exercice !)

Auto-évaluation finale

  • [ ] Je ne confonds plus \(\in\) et \(\subset\).
  • [ ] Je démarre toute preuve d'ensembles par « Soit \(x\)… » et je sais passer à la logique.
  • [ ] Je sais faire une double inclusion proprement.
  • [ ] Je sais trouver un contre-exemple à une égalité d'ensembles fausse.
  • [ ] Je sais compter en traitant les éléments un par un et en multipliant les choix.
