🔁 Comment réviser (méthode)

Dans cet ordre
  1. Fiche du chapitre : la lire en s'arrêtant à chaque blocage (conseil du cours : relire les définitions, faire un petit exemple).
  2. Flashcards du chapitre : répondre par écrit avant de retourner la carte, puis refaire les ratées.
  3. Exercices : chercher sans regarder la correction, rédiger comme en examen, puis comparer.
  4. Rituel final : refaire de mémoire les grandes preuves — double inclusion, g∘f injective/surjective, théorème de Cantor, √2 ∉ ℚ, densité de ℚ, récurrence.

Le calcul de la note (WIMS, examen, partiel) et l'obligation de passer les 3 contrôles WIMS sont détaillés au chapitre 1 du polycopié : s'y référer plutôt qu'à une recopie.

📥 Importer les flashcards dans Anki

Tu préfères Anki ? Les mêmes 155 cartes sont disponibles : flashcards-anki.tsv (clic droit → « Enregistrer le lien sous… »).

  1. Ouvrir Anki, Fichier → Importer, choisir flashcards-anki.tsv.
  2. Type de note : Basique ; séparateur : Tabulation.
  3. Correspondance des champs : colonne 1 → Recto, colonne 2 → Verso, colonne 3 → Étiquettes.
  4. Cocher « Autoriser le HTML dans les champs ». Les formules sont écrites en \( ... \), que Anki affiche avec MathJax.

⚠️ Coquilles repérées dans les documents sources

Pour ne pas se tromper en recopiant
  • Cours, §2 ch. 4 : le domaine de x ↦ √x est [0,+∞[ (le cours écrit ]0,+∞[).
  • Cours, ch. 5, §1 : 4 = {0,1,2,3} (le cours écrit {0,1,3,4}).
  • TD1 n°3(b) : l'énoncé écrit deux fois « A ⇒ B » ; probablement « (A ⇒ B) ou (A ⇒ C) ». Les deux lectures sont traitées dans la correction.
  • TD2 n°17 : la partie ℬ contient {a,c,f} avec f ∉ E ; probablement e à la place de f.
  • TD2 n°2 : l'ensemble F est écrit avec « −π < n < π » pour la variable x.
