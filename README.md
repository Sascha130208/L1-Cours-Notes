# DL1 — Notes de cours L1 (Maths & Info)

Notes de cours réécrites, complétées et mises en forme, à jour au fur et à mesure du semestre.

## 🌐 Site en ligne (le plus simple)

👉 **https://sascha130208.github.io/L1-Cours-Notes/**

Tout est lisible directement dans le navigateur, sur ordi comme sur téléphone — aucun téléchargement, aucun code affiché.

## 📂 Comment consulter

Ouvre **[index.html](index.html)** : trois onglets séparés, **Analyse**, **Structures fondamentales** et **Théorie des graphes**. Dans chaque onglet, tout est rangé dans le même ordre : Cours → Fiches → Exercices → Flashcards.

L'info (Unix/Linux + algorithmique) est dans **[L1_info/index.html](L1_info/index.html)**.

👉 Si tu as cloné ce dépôt, double-clique sur ces fichiers `.html` dans ton explorateur de fichiers pour les ouvrir dans ton navigateur.

## 🔄 Mises à jour

Ce dépôt est mis à jour à chaque nouveau chapitre vu en cours. Fais régulièrement :

```bash
git pull
```

pour récupérer les dernières notes.

## 📁 Structure

```
L1_info/
├── index.html                  ← sommaire
├── 01_Unix_Linux/
├── 02_Algorithmique/
├── Exercices/
└── Revisions/

L1_math/
├── index.html                  ← redirige vers l'accueil à onglets
├── Methodes_SF/                ← 🛠️ quel exercice de TD → quelle méthode
├── Revision_Structures/        ← fiches, exercices corrigés (ch. 2 à 5)
├── Flashcards/                 ← cartes à retourner
├── 01_Structures_Fondamentales/  ← cours détaillé
├── 02_Analyse/  03_Graphes/
└── Exercices/
```

Chaque chapitre existe en deux formats : `.html` (version colorée à lire dans le navigateur) et `.md` (texte brut, pratique pour copier/coller ou éditer).
